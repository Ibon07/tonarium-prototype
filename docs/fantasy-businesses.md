# 부동산 작업장과 고용 인력

도시의 대저택은 24,000G, 항구의 대저택은 18,000G이다. 기존 주택과 독립된 새 필지이며 생애당 공동 소유를 포함한 기존 3필지 한도를 유지한다. 기존 부동산 원장을 읽을 때 새 저택 필지만 메모리에서 채운다. 기존 소유권과 가격은 덮어쓰지 않으며 필지 추가만으로 생성자 저장을 강제하지 않는다.

작은 집의 기본 수납은 12kg/8종이다. 궤는 24kg/4종, 서랍 책상은 12kg/2종, 서랍장은 36kg/6종을 추가한다. 저택은 180kg/48종, 상업 창고는 240kg/48종으로 시작하며 개축 단계당 80kg을 더한다. 수납 중인 물품이 남은 공간을 초과하면 수납 가구를 철거할 수 없다. 가방 입출고는 기존 가방 제한을 지킨다.

일반 재료는 수량으로 보관하고, 음식·제작 장비·내부 지도는 기존 거래 물품의 parcel 형식을 사용한다. 음식의 제조 시각, 장비 품질, 지도 개별 사본과 저자는 보존하며 보관 중에도 음식은 상한다. 장착한 장비와 미확인 유물은 보관하지 못한다. 개별 물품 parcel은 묶음 전체를 회수한다.

길드 고용 인력 24명과 야간 암시장 매입 예속 인력 6명은 기존 정주 NPC와 다른 전용 ID를 가진다. 전 세계 부동산 원장의 단일 고용 기록을 사용하여 다른 장소·세션에서 같은 NPC를 중복 계약하지 못한다. 암시장 인력은 같은 세션의 실제 비정기 야간 개장과 해당 마을의 단서를 함께 요구한다. 길드는 기존 야간 운영 규칙대로 고용할 수 있다.

길드의 일반 고용 계약은 세계 시간 30일이며 가입비를 선납한다. 암시장 노예 거래의 예속 인력은 매입한 고용주의 현재 생애에 기한 없이 귀속되며 30일 뒤 자동 만료되지 않는다. 상업 작업의 임금과 부대 유지비는 계속 지불한다. 해방·해고 명령은 같은 저장 트랜잭션에서 해당 부대원과 원장을 함께 제거한다. 전투·활동 중에는 거절한다. 지도자 또는 실제 카리스마가 14 이상인 인물에게만 개인별 생산 기술 XP와 학습력(1~5)을 보낸다. 이 조건에 미달하면 종족·관찰 가능한 역할·계약비·임금만 공개한다. 고용주가 영구 사망하거나 세대가 바뀌면 고용 기록은 옛 생애에 남고 자동 상속하지 않는다.

상업 부동산에서 고용 인력에게 직업별 영업이나 실제 제작법을 배치할 수 있다. 기본 배치 정원은 2명이며 개축 단계당 1명씩 늘어난다. 작업은 세계 시간 4시간마다 1회, 정산 1번에 최대 12회다. 임금과 실제 보관 재료를 먼저 검사·소비하고 기술 XP를 학습력만큼 올린다. 제작 후 판매는 실제 제작법의 투입·산출을 따르고 고객 수만큼 제품을 판다. 재고 판매는 선택한 실제 보관 상품을 팔며 별도 제품을 만들어 내지 않는다. 제작 전용 운영은 창고에 제품을 보관한다. 음식 투입은 상하지 않은 실제 로트만 사용하고 생산 음식도 실제 작업 완료 시각부터 상한다. 제작 장비에는 개별 품질 기록을 붙인다.

금고 부족·재료 부족·창고 초과·세금 체납·임대 권한·매물·공사 등으로 쉬었던 시간은 나중에 생산하지 않는다. 입금·입고·재배치 전에 지난 시간을 소화하여 나중에 맡긴 재료나 돈으로 과거 작업을 만들지 않는다. 같은 시각의 새로고침을 반복해도 작업이나 수익은 중복되지 않는다. 상업용 구형 익명 자동 영업은 중지하고 남은 재료·임금은 회수할 수 있다.

전투 훈련이 있는 암시장 인력은 고용주 자신의 기존 부대에 편성한다. 편성 시 상업 배치를 해제하고, 부대의 기존 배치·부상·회복·유지비·임무 성장 흐름을 따른다. 부대에 편입한 뒤에는 부대 복무 계약으로 지속하며, 제적되면 고용소의 배치 대기로 돌아온다. 일반 직업도 자기 고용 전투원을 지휘할 수 있고 다른 여행자의 인력을 지휘하지 못한다.

고용·입출고·금고·배치 명령에는 현재 필지 revision과 고유 requestId가 필요하다. 부동산 원장과 캐릭터 진행을 기존 서버의 원자적 저장에 함께 넘기며 저장 실패 시 금화·재료·인력 예약을 반영하지 않는다.

2026-10-29 사용자 요청에 따라 아래 회귀는 작성만 하고 실행하지 않았다: `shared/fantasy-business.test.ts`, `server/fantasy-business-persistence.test.ts`. 타입 검사·빌드·완료 검사·브라우저 검증도 보류한다.


## 계절과 지역의 판매량

`shared/fantasy-business-demand.ts`의 상품 태그와 수요 함수를 사용한다. 공유 환경과 같이 게임 15일마다 계절이 바뀌며, 정산을 요청한 시각이 아니라 각 작업이 실제로 끝난 세계 시간으로 계절과 고객 수를 계산한다. 4시간 단위의 고객 수는 `floor((구간+1) × 기본수량 × 수요율 / 100) - floor(구간 × 기본수량 × 수요율 / 100)`이다. 같은 시간의 요청·재접속을 반복해도 새로운 판매가 생기지 않는다.

기본 수요율은 85%이다. 겨울의 보온품·연료·보존식은 +85%p, 여름의 음료·차·물·가벼운 직물은 +85%p이다. 여름 방한복은 -55%p, 겨울 얇은 직물은 -40%p이며, 봄의 공구·목제품은 +25%p, 가을의 보존식·연료는 +35%p이다.

지역 보정은 항구의 선박 자재·어망·보존식 +60%p, 설원 진입 지역의 보온품·연료 +65%p, 숲 지역의 목제품·수렵 용품 +45%p, 광산·공방 도시의 공구·금속 +60%p, 사막 지역의 물·차·음료 +70%p이다. 최종 수요율은 20~300%로 제한한다. 가격에 이 비율을 곱하지 않고, 해당 교대에 실제로 팔 수 있는 물품 수를 바꾼다.

판매 운영에서 제작법을 지정하면 재료와 임금을 소비하여 제품을 만들고, 수요가 낮아 팔지 못한 물품은 개별 장비·음식 기록과 함께 창고에 남긴다. 제작법 없이 재고 상품을 지정하면 창고에 실제로 남은 해당 상품만 판다. 재료가 부족해도 이미 만들어 둔 제품의 판매는 가능하다. 상한을 넘는 재료 소비·생산·매출은 적용하지 않는다. 제작 전용 운영은 계절 수요와 관계없이 정원·자본·재료·창고 한도를 지키면서 재고를 만든다.

상업 화면에서 운영 방식, 생산할 제품 또는 판매할 재고 상품을 고른다. 현재 계절·지역 수요 개수, 간단한 이유와 최근 정산의 생산·판매 개수·매출·임금을 한국어·영어·일본어로 표시한다. 해당 인력의 숨겨진 XP·학습력은 수요 화면에 공개하지 않는다. 능력을 읽지 못하는 인물에게 수치 해금 팁을 표시하지 않는다.

## 플레이어의 직접 제작

유효한 소유·공동 소유·임차 권한으로 이용하는 현지 상업건물에서는 현재 직업의 직접 제작을 수행할 수 있다. 작업장 액션의 `workshop` 필드가 실제 필지를 가리키며, 서버가 시작과 완료 권한을 확인한다. 공공 시설의 위치·영업시간 제한을 대체하지만 기존 직업·제작법·지식·가방 재료·실제 제작 시간은 유지한다. 제작 중에는 해당 필지를 판매·임대·공사로 잠글 수 없다.


상업 판매의 영업시간은 세계 시간 06:00 이상 18:00 미만이다. 현재 수요 표시는 이 시각을 직접 사용하며 야간은 판매량 0, 수요율 0으로 표시한다. 4시간 교대의 실제 판매는 교대 중간 시각으로 영업 여부를 판정하므로 14~18시 교대는 낮 영업, 18~22시 교대는 야간 휴점이다. 겨울·지역의 높은 수요도 야간에는 판매를 만들지 않는다. 사유 작업장의 제작은 계속할 수 있지만 야간 미판매품은 창고에 남으며 임금·재료·수납 상한을 계속 지킨다.

고용 원장과 부대의 교차 검사는 살아 있는 인물의 worker 부대원이 실제 동일 사용자·세대의 company 고용 기록에 속하는지도 검사한다. 부대에서 제적된 인력은 다시 배치 대기로 돌아가며 새 계약의 남은 유효기간은 최소 세계 시간 1일이다. 암시장의 예속 인력은 이때도 생애 귀속 상태를 유지한다.

추가 작성 후 미실행 회귀: 계절·항구·광산·사막별 실제 판매 개수, 낮 14~18시/밤 18~22시 교대, 야간 판매 0과 미판매 제작 재고, 30일 후 암시장 매입 인력 유지, 영구 사망·새 세대 제어 차단. 자동 테스트·타입 검사·빌드·브라우저 검증·추가 코드 리뷰는 사용자 요청 전까지 실행하지 않는다.

추가 작성 후 미실행 회귀: 부대에 편입한 예속 인력을 해방할 때 원장과 부대원이 함께 제거되고 원본 상태는 변경되지 않음.


## NPC의 독립적인 숙련 기록

선택형 `FantasyPropertyLedger.workerProgress`는 NPC ID별 생산 기술 XP만 보관하는 비소유 성장 원장이다. 기존 저장에는 없어도 된다. 고용 중 작업 성장, 해고·해방, 계약 만료 시 이 원장을 갱신하고, 다른 여행자가 다시 계약해도 이전 숙련을 이어간다. 고용 후보의 능력을 읽을 자격이 있을 때에도 보존한 숙련을 우선 표시한다. 자격이 없으면 후보와 고용 인력 모두 XP를 공개하지 않는다.

학습력은 인물 카탈로그의 고정 1~5를 유지한다. 성장 원장에는 고용주·세대·가격·배치·활동·부대 편입 상태를 보관하지 않으며, 다음 고용은 새 고용주와 새 계약으로 시작한다. 고용 진행과 성장 원장은 기존 부동산·캐릭터의 같은 원자적 저장에 포함한다.

추가 작성 후 미실행 회귀: 성장 후 해고→다른 플레이어 재고용의 숙련 유지, 성장 후 계약 만료→다른 플레이어 재고용의 숙련 유지, 새 계약에 이전 배치·고용주·활동을 넘기지 않음, 기존 저장의 선택형 호환과 잘못된 성장 원장 거절.
