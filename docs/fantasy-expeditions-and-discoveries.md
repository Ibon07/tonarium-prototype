# 원정·발견·랭킹 확장

2026-10-29 개발 기록. 사용자 요청에 따라 추가 테스트와 검사는 보류하고 [검사 대기 목록](fantasy-validation-backlog.md)에 모은다. 이 문서의 동작 설명은 구현 의도와 코드 변경 범위이며, 최종 변경 전체의 검증 완료 선언은 아니다. 배포·푸시는 진행하지 않았다.

## 룬과 지원 대상

같은 룬을 여러 슬롯에 넣고 저장할 수 있다. 각각 슬롯을 차지하고 기존 위력 점감·MP/위력 상한을 따른다. 일반 합성은 계산한 사거리 또는 반경이0 이하이면 제작을 막는다. 상한/하한 보정으로 불가능한 조합을 억지로 유효하게 바꾸지 않는다.

예외는 자기 축복과 자기 회복이다.0은 허용하되 음수는 허용하지 않는다.0을 사용하는 회복은 자신에게만 쓸 수 있다. 다른 사람에게 쓰는 축복·회복에는 양의 사거리와 시전자부터 대상까지의 실제 타일 거리를 적용하며, 광역 지원의 각 수혜자도 검사한다. 기존 직업의 단일 대상 기술과 원형 합성의 제작 규칙은 구분한다.

## 연금술은 결과를 발견하는 방식

미확인 조합은 재료와 비용만 표시하고 결과명·효과·출력물은 숨긴다. 기존 네 가지 정식 조합 메뉴와 새 약초·몬스터 부산물 합성 모두 같은 원칙을 따른다. 실패와 판정 기록도 미확인 조합 번호를 사용한다. 성공한 조합 또는 완독한 책이 가르치는 정확한 조합만 결과를 공개한다.

새 합성은 용기와 재료 목록을 정렬한 키로 기록한다. 등록 조합은 안정적으로 만들 수 있고, 호환되지만 알려지지 않은 실험 배합은 성공률65%를 사용하며, 호환되지 않는 배합은 실패한다. 실패는 재료와 시간을 소비하지만 약품·발견 지식·성공 의뢰 실적을 주지 않는다. 취소와 예약만으로도 발견하지 않는다.

기존 네 조합의 발견은 선택 필드 `alchemyKnowledge.formulas`로 보존한다. 새 합성의 `recipes`만 있는 저장은 계속 읽을 수 있다. `remedies-and-rites`의 완독은 본문에 적힌 치유약·해독약의 정확한 구식 배합과 두 가지 새 배합을 가르친다. 책을 받거나 읽기 시작한 시점에는 지식을 주지 않는다.

## 지속하는 전투 타일

합성 주문과 전투용 연금 약품은 화염·서리·독·폭풍 타일을 만들 수 있다.3라운드 동안 유지하고 같은 계열은 갱신하며 무제한 누적하지 않는다. 화염·독은 지속 피해, 서리는 이동 감소, 폭풍은 명중 방해를 준다. 타일 위의 아군·적·소환수·호송 수레도 영향을 받는다.

같은 계열은 같은 대상에게 한 라운드에 중복 적용하지 않고, 지속 타일로 기술 사용·숙련도를 반복 적립하지 않는다. 시야·장애물·현재 위치를 서버에서 검사한다. 화면에는 타일 종류와 남은 시간을 표시하고 저장한 전투도 효과를 보존한다.

일반 전장12개와 장애물이 많은 전장12개의 템플릿을 시드로 고른다. 일반 배치는 출발 공간과 호송 통로를 보존한다. 고룡 등 최상위 명시 도전은 기존 기준 전장을 유지한다. 최종 배치 적합성과 고룡 승률 회귀는 다음 검사에 포함한다.

## 유적·던전과 보상 기록

첫 진입 때 저장한 시드로 갈림길·막다른길·함정·특수방을 만든다. 재접속은 같은 배치를 사용한다. 기존 시드 없는 저장은 기존 고정 배치를 읽는다. 특수방은 접촉·봉헌·떠나기 등의 선택에 따라 강화·약화·회복이 달라진다.

파티 진행은 파티장의 배치를 공유하되 개인별 조사·해제·획득 기록을 유지한다. 현재 배치에 없는 방을 잠시 거쳤다가 원래 배치로 돌아와도 보상이나 같은 날 조사 판정을 반복 획득하지 않도록 별도의 누적 기록을 저장한다. 지형 변경으로 이전 조사 증거를 지우지 않는다.

## 안전한 방과 불침번

조사를 마치고 적과 함정을 처리한 방에서 야영할 수 있다. 야외와 던전 야영에는 시간에 따른 습격이 있고, 재접속/같은 시간 재처리로 다시 추첨하지 않는다. 중단되면 실제 경과분의 피로 회복만 남기고 완료 회복은 주지 않는다.

불침번은 각 플레이어가 신청한다. 같은 장소에서 유효하게 야영 중인 파티원과 건강한 배치 동료만 교대에 참여한다. 도로의 위치나 던전 시드·방이 다르면 함께 있는 것으로 세지 않는다. 이동·취소·부상 등으로 자격을 잃으면 이후 지원도 중단된다.

야영 위험은 세계 시간1시간마다 야외 `1.5% + 위험도×0.5%`, 던전 `3.5% + 위험도×1%`를 기본으로 하고 야영 장비의 보정을 적용한다. 유효 감시 인원이2명 이상이면 위험에0.35를 곱한다. 불침번에 참여한 시간은 일반 수면보다 피로 회복이 약25% 적다. 실제 파티/동료 경계와 오프라인 처리는 다음 통합 검사에 포함한다.

## 성자·성녀와 랭킹

동일한 성인 분기를 성별에 따라 성자·성녀로 표시한다. 직업 진행과 기술은 그대로 유지하고 캐릭터·신앙 메뉴·랭킹의 명칭을 함께 바꾼다.

랭킹은 서버가 점수를 계산한 상위10개의 인생을 저장한다. 생존자는 갱신하고 사망한 인생의 점수는 고정한다. 새 인생은 다른 세대로 기록한다. 공개 필드는 **닉네임·종족·직업·점수**뿐이며 계정 ID·내부 소유자·생존 여부는 보내지 않는다.

| 항목 | 계산 |
| --- | --- |
| 레벨 | 레벨×50 |
| 소지품 | 알려진 아이템별 등급 점수×수량 제곱근 보정, 수량 보정 최대3 |
| 직업·기술 숙련 | 각 XP의 제곱근×2 합산 |
| 완료 의뢰 | 중복 없는 의뢰×80 |
| 메인 조사 | 실제 완료/증거가 있는 단계×100 |
| 탐사 | 실제 방문한 고유 지역×40 |

총점과 항목별 점수 상한은 두지 않는다. 숙련 XP가 1,000,000을 넘더라도 랭킹 계산에 계속 반영한다. 같은 물건의 수량 보정은 기존처럼 9개에서 최대가 되어 중복 물품 대량 보유로 점수를 부풀리지 않게 한다. 비정상 수치 차단을 위한 안전 정수 검증은 유지한다. 골드·가짜 아이템·반복 방문은 점수를 더하지 않으며 현재 소지품만 평가하고 장비를 이중 집계하지 않는다. 랭킹 데이터가 없는 이전 저장은 메모리에서 도출하고 다음 실제 저장에 함께 기록한다. 단순 로드가 불필요한 디스크 저장을 강제하지 않도록 변경했다.

## 후속 검사

검사 명령·상세 시나리오는 [검사 대기 목록](fantasy-validation-backlog.md)에 기록한다. 최종 조합 변경, 배치 변경을 통한 보상 반복 방지, 파티 불침번, 랭킹 원자적 저장, 세 언어 화면과 전체 회귀를 사용자의 검사 요청 시 함께 수행한다. 운영 `data/fantasy.json`은 시험 데이터로 사용하지 않는다.
