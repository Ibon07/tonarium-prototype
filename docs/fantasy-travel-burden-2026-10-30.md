# 鞄と荷物による旅の所要時間

荷物が重いほど、また装備中の鞄が大きいほど、歩く旅の所要時間が長くなる。パーティーは各員の条件を反映した見積もりのうち、最も時間のかかる人に合わせて一緒に到着する。

## 荷物の数え方

`shared/fantasy-travel-burden.ts` の `fantasyTravelBurden(character)` が、既存の `fantasyBagState` から重量と鞄の構成を取得する。

- 重量はグラム。所持品欄にある品物と鞄そのものを、既存の品目別重量で一度だけ数える。
- 食品ロット・装備個体・地図個体の記録は、同じ品物の所持数に重ねて加算しない。
- 普通の鞄一つと魔法の補助鞄二つまでを扱う。魔法鞄の中身も実重量に含み、空間が広がっても重さは消えない。
- 鮮度を保つ魔法鞄の中の食品も、重量を差し引かない。容量は収納の制約であり、移動の軽減率には使わない。
- 受け取っていない地域の預かり品は所持品に含まれないため、受取前の移動重量には入らない。

## 計算

返す `multiplier` は「所要時間の倍率」で、速度の減少率そのものではない。たとえば1.20倍は所要時間が20%長くなる意味。

| 要因 | 徒歩の時間加算率 |
| --- | --- |
| 最初の背嚢・小さな旅の背嚢 | 0% |
| 丈夫な旅の背嚢 | 4% |
| 大きな遠征背嚢 | 8% |
| 装備中の魔法の補助鞄 | 一つにつき3%、二つまで |
| 所持重量 | 1kgにつき1%、重量分は66%まで |

`sizePenalty = 普通の鞄の率 + 魔法鞄の数 × 0.03`

`loadPenalty = min(0.66, 所持重量グラム / 100000)`

`penalty = min(0.80, sizePenalty + loadPenalty)`

`徒歩の所要時間倍率 = 1 + penalty`

大きな遠征背嚢と魔法鞄二つを装備して総重量20kgなら、鞄14%と重量20%を合わせて徒歩1.34倍。総重量35kgなら1.49倍。総重量66kg以上でも最大1.80倍に収まり、重い荷物によって時間が無制限に伸びない。大きな鞄に替えて収納上限が広がっても、同じ実重量の負担は軽くならない。

## 交通手段と乗り継ぎ

| 区間の交通手段 | 荷物の影響 |
| --- | --- |
| 徒歩 | 全量 |
| 乗合馬車・護衛付き添い | 徒歩の加算率の20% |
| 定期船・手伝い船・飛空艇・転移門 | 乗車・乗船区間の時間を変えない |

重さの徒歩加算率が34%の人なら、馬車は6.8%加算になる。運賃・報酬・所持金の判定を変えず、既存の交通手段の速度や有料移動の利点を保つ。

「徒歩＋定期船」「徒歩＋乗合馬車」では区間ごとに計算する。船の乗船時間は変わらなくても、港までの徒歩には全量の負担がかかる。道の途中からの引き返しや目的地変更では、残りの徒歩区間だけにその時点の荷物を反映し、計算済みの後続見積もりへもう一度倍率をかけない。

`fantasyTravelBurdenHours(character, baseHours, transport)` は単一区間、`fantasyTravelBurdenLegs(character, legs)` は乗り継ぎ区間、`fantasyTravelBurdenQuote(character, quote)` は区間付き見積もりを新しく返す。区間の経路・料金・開始位置の割合を保持する。いずれも荷物を一度だけ加える関数で、入力を変更しない。丸めは呼出側の既存の最終処理で行い、特技・疲労・天候の補正を二重にかけない。

## パーティー

各人の現在の鞄・荷物と既存の個人条件を反映して、それぞれの所要時間と料金を見積もる。共通所要時間は各人の所要時間の最大値。平均、リーダーの値、最も軽い人の値は使わない。各人の運賃は各人の見積もりのまま。

既存のパーティー画面の `travelHours` は、準備した全員の `plan.hours` の最大値を使っている。開始処理でも各人の予定到着時刻の最大値にそろえ、区間の時間を共通到着へ伸ばす。途中の目的地変更でも同じ扱い。承諾後に荷物や鞄が変わって見積もりが変わったときは、既存の見積もり再照合で準備を解き、現在の条件で確認し直す。

## 後日の確認対象

依頼により、テスト追加・テスト実行・型チェック・ビルド・シミュレーション・ブラウザー確認・レビューは今回行わない。後日の確認では以下を扱う。

- 同じ鞄で重量だけ増やすと徒歩が遅くなり、上限で止まること。
- 同じ重量で鞄の大きさだけ変えると、装備中の普通の鞄と魔法鞄の大きさの差が出ること。
- 魔法鞄や鮮度保存袋へ移しても、同じ所持重量の負担が消えないこと。
- 食品ロットや装備個体を二重計上せず、預かり品は受取前に含めないこと。
- 徒歩・馬車・船・飛空艇・門の違いと運賃が保たれ、乗り継ぎの徒歩だけに全量を加えること。
- 道の途中の再出発・引き返し・目的地変更で、すでに計算した区間へ重ねて加算しないこと。
- 軽いリーダーと重い同行者、重いリーダーと軽い同行者のどちらも最も遅い人に合わせること。
- 荷物変更後の承諾のやり直し、通常出発と目的地変更の双方で共通到着を保つこと。
