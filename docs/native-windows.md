# Windows ネイティブクライアント

Avalonia の 2D クライアントと Unity の 3D プレイヤーを組み合わせる。既存 Web 版と同じ Tonarium サーバー、kokosync、LiveKit に接続し、2D/3D を切り替えても同じユーザー・セッションを保つ。

## 作業の分担

| 作業 | 完了条件 | 状態 |
| --- | --- | --- |
| アプリ基盤 | 起動、接続設定、保存、配布、エラー表示 | 実装中 |
| 同期 | ネイティブ kokosync、ホーム接続、参加・退出、状態反映 | 実装中 |
| ホーム | セッション、フレンド、DM、グループ、イベント、プロフィール | 実装中 |
| 2D ルーム | 顔、距離別一覧、チャット、通知、ドック | 実装中 |
| アイテム | 付箋、キャンバス、チェス、サイコロ、2048、メディア | 実装中 |
| 音声・映像 | マイク、距離音声、画面共有、受信映像 | 実装中 |
| Unity | ホール、カフェ、ゲーム、アバター、移動、アイテム、切り替え | 実装中 |
| 確認 | Windows 起動、Web 版との相互接続、画面と通常操作の確認 | 未実施 |

確認結果と実行手順は実装後にこの文書へ追記する。未確認の機能を確認済みとは記載しない。
