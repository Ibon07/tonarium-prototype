# 音量スライダーの描画修正と確認（2026-10-26）

`VolumeMenus.tsx` の「人の声」「サウンドボード・効果音」「動画・画面共有」と、同じ部品を使う個別の声の音量が対象。`world.css` の `.volrow` 内だけにスタイルを適用する。44pxの入力領域内に16pxのつまみを描き、バーは左右8pxを除く範囲に描画する。入力値・刻み幅・変更イベント・保存処理は変更しない。

## 確認済み

実際の `base.css`・`world.css`・`chat-media.css`・`responsive.css` を読む独立した検証画面で確認した。Reactの実アプリを起動した確認ではない。

- 各入力の最小・最大・移動範囲の5%・50%・95%で画素を調べ、つまみの位置、欠けがないこと、バーが移動範囲の外に描画されないことを確認した。個別音量は最大200%として確認した。
- 各幅・各入力で両端と中央のクリック、端から端へのドラッグ、Home / End / 左右矢印、タッチ相当の両端タップを確認した。
- 動画シークとVR旋回速度のrangeには音量用スタイルが適用されず、ネイティブのappearanceが維持されることを確認した。中間値のスクリーンショットも目視確認した。
- 別の利用可能なNodeで `node scripts/check-changelog.mjs --base HEAD` が成功した。

再実行はPlaywright導入済み環境で `node scripts/test-volume-slider-browser.mjs`。第1引数はPlaywright、第2引数はsharpのモジュール名またはfile URL、第3引数以降はブラウザ実行ファイルのパスを指定できる。省略時はWindowsの標準配置のChromeとEdgeを使う。結果とスクリーンショットはGit対象外の `.local/` に出力する。外部サービスや実アプリのデータは使わない。
