# 悠久の旅路

`fantasy` ワールドで遊ぶ、平面の世界地図を使った生活と冒険の RPG。行き先を決め、依頼を引き受け、商売や制作をしながら自分の暮らしを進める。数値判定と保存は Tonarium サーバーが担当する。

現在の登録内容は **45地域、15系統51種族、38職業、261イベント、167依頼、165アイテム、86製法、34冊のゲーム内図書、137人のNPC、58種のモンスター、29種の地形行動**。地図21種はアイテム数と別枠で、販売するのは18種。共通の職業技370種に、専門149分野の専用298技を加える。司祭の信仰成長、不動産取引と契約、直接交換と有限共有市場、住民生活と法執行、荷車護衛と会話ストリーミングも以下の実装規則に含む。後続拡張全体の最終検証は進行中で、過去の検証結果とは区別する。

## 始め方

現在のローカル確認用入口は [RPG プロトタイプ](http://127.0.0.1:3011/?rpg=1)。Viteを別に動かす開発時は [5183の開発画面](http://127.0.0.1:5183/?rpg=1)を使う。通常の名前入力・ログイン後に「はじめる」を押すと、自分用の非公開（招待制）ファンタジーセッションを作成して、そのまま参加する。既定の3セッションや `sessions.json` は変更しない。新規セッションの初期ワールドとして開くため、次のワールド切り替え操作は不要。

既存のセッションから切り替える場合は次の手順を使う。

1. Web 版で名前を入力し、セッションへ参加する。
2. 左上の設定から「ワールド」→「悠久の旅路」→「切り替える」を選ぶ。
3. 通常の確認と 3 秒のカウントダウン後、セッション全員の画面が切り替わる。
4. 名前と性別を選び、無職のキャラクターを作る。抽選を使わず人間としてすぐ始められる。
5. 地図で目的地を選び、交通手段を比較する。まずは始まりの街「炉火の街ハース」で仕事や依頼を試せる。

プロフィールの表示設定が 2D でも 3D でも専用の平面 RPG 画面を表示する。既存セッションの初期ワールド、スポーン、家具、アイテムの切り替え確認は維持する。`sessions.json` の既定値は変更していない。

## キャラクターと種族抽選

基本の種族は人間。名前は 1〜24 文字、性別は男性／女性から選ぶ。人間の能力を手で振り分けたり、外見を細かく編集したりする工程はない。新しいキャラクターは無職で始め、ギルド、現地の NPC、GM の提案から職業を得る。既存の保存キャラクターは以前の職業を維持する。

新しい人物の旅支度は 35G と薬草 2・鉱石 2・木材 2・料理 1。35% で種族に関わる物を 1 個、独立した 20% で一般の贈り物を 1 個、最大 2 個追加する。同じ品が重なる場合もある。地図・専用依頼品・固有装備は含めず、既存キャラクターへ再配布しない。

望む場合だけ種族をランダムに抽選できる。機会は合計 5 回で、抽選するたびに 1 回を使う。同じ種族が再び出ることもある。候補を表示した後は、次のどれかを選ぶ。

- **この候補で作成**：残り回数があっても、表示中の種族で直ちに確定する。
- **キープ**：候補を 1 枠の保管先に置く。すでに保管した種族がある場合は新しい候補に置き換わる。
- **見送る**：今回の候補だけを消す。以前にキープした種族は残る。

候補を保留したまま次を抽選することはできない。キープ／見送りを選んでから次へ進む。5 回を使い切っても、人間、最後に表示中の候補、またはキープした種族から作成できる。抽選回数と保管状態はサーバーへ保存するため、再接続しても戻らない。生存中の人物を抽選し直す操作はない。救助が届かず人生を終えた場合だけ、足跡を残して次の人生を始め、新たな5回の抽選と旅支度を受ける。以前の所持金や装備を新人物へ移す機能はない。

種族は **15 系統・51 の下位種族**に分ける。人間、獣人、エルフ、ドワーフ、吸血族、竜血族、精霊、妖精、ゴーレム、小人、オーク系、海の民、異界の民、月影の民、神性の民が大きな系統。実際に生成するのは下位種族で、たとえば獣人には狐・狼・猫・兎・熊・鳥・蜥蜴・鹿・山羊・蝙蝠、エルフには森・ハイ・ダーク・雪原がある。半神・真竜・古竜・大天使・上位魔族・不死鳥・虚空の民はきわめて低確率の伝説種として含む。巨神は削除した。

以前の保存に巨神のキャラクターがいる場合は、一度だけ人間へ移す。進行・金貨・所持品・抽選回数・記録の版は保ち、HP は人間の上限まで下げる。MP を増やす移行はしない。現在の人間の抽選確率は 17.64% で、全種族の重みの合計は 100。

現在の数値、パッシブ・アクティブ、性別の固定、抽選確率は [世界観設定集](world-bible.md) と `shared/fantasy-data.ts` を参照する。世界設定集は開発用文書として提供し、ゲーム内の本棚や生成画面の種族図鑑には出さない。ゲーム内では所蔵のある図書館で「能力と術技の書」などを読める。各回は独立し、確率は `その種族の weight / 全種族の weight 合計` で求める。希少な種族にも不得意な能力があり、人間の単純な上位互換にはしていない。全系統と下位種族には韓国語・英語・日本語の正式名がある。

固定の性別はその種族の世界設定であり、性別そのものによる能力差はない。潮の民は陸地でも旅ができる。

## 能力と判定

人間の基準値は HP 100、MP 50、力・敏捷・知力・運・体力が各10。誕生時だけ HP ±5、MP ±3、基本能力5種それぞれ ±1 の整数の個体差を独立に抽選し、保存後は再抽選しない。性別で範囲は変わらない。体力の差1は最大HPにも4、知力の差1は最大MPにも3反映するため、他の補正のないレベル1の人間では最大HP91〜109、MP44〜56になり得る。手先とカリスマにはこの誕生時抽選を行わない。種族・装備・レベル等の補正は別に加わる。

| 能力 | 主な用途 |
| --- | --- |
| HP | 生命。危険な探索で失い、休息や回復品で戻す |
| MP | アクティブスキルの使用資源 |
| 力 | 山岳・火山の探索、力仕事、魔物との小競り合い |
| 敏捷 | 森や島の探索、危険回避、追跡 |
| 知力 | 遺跡・魔塔の探索、研究、調合、魔術 |
| 運 | 発見量を増やす追加判定、偶然を頼る選択 |
| 体力 | 洞窟・湿地・砂漠・雪原の探索、被害軽減、最大 HP |
| 手先 | 鍛冶・料理・錬金の職業で追加。制作やイベントの精密作業 |
| カリスマ | 商人・吟遊詩人・指導者で追加。仕事と対応するイベントの判定 |

判定は `ダイスの目 + 能力補正 + レベル等の補正 >= DC` で決まる。探索・狩猟等はd20、資源採集はd6、仕事・解体はd8、制作・釣り・錬金調合はd12を使い、地形行動にもd8・d12・d20がある。20面未満ではDCを面数に比例させ、補正を面数の半分の範囲に抑える。ログに面数、各出目、採用値、補正、合計、難易度、成否を表示する。対応する判定強化は追加ダイスによる有利、状態異常は対応能力の不利に作用し、差し引いた結果に応じて最高値か最低値を採る。

身体特性は小柄・極小・柔軟・軽い体・翼・水生・重い体・頑丈・大きな体・耐熱・耐寒・鋭い感覚・希薄な姿などに分かれる。隙間、罠、深い水、高い足場、高熱、寒さ、重い物、小さな痕跡の 8 状況で、探索の追加判定と対応するイベント選択に作用する。合計補正は -5〜+5。数値と短所は図書館の「能力と術技の書」に載せる。翼で長距離移動を省略したり、水生の体で海の交通を免除したりはしない。

種族にはパッシブとアクティブが各1つある。無職を除く37職は基本の2技に追加のパッシブ4・アクティブ4を持ち、共通の職業技は370種、司祭4分岐の専用8技は別枠。そのうち共通の追加296種は職業熟練、関連技の使用熟練、読了した本、現地の師、実際の探索・制作・採集・狩猟・釣り・指揮回数の条件で開く。職業等級は熟練0・30・100・250・600で変わる。現在の職業で解禁した技だけを使え、転職前の専門技を重ねて使うことはできない。同じ行動を6ゲーム時間内に繰り返すと獲得熟練が段階的に減り、失敗でも少量の経験を得る。

パッシブは該当する判定、報酬、被害軽減、移動に自動適用する。アクティブはMPを使い、即時回復、次の対応する判定、次の移動、次に受ける被害などへ作用する。次の行動に備えるスキル強化は1枠。対応する判定で消費し、期限付き強化は期限後に消える。装備や食品・宝石の持続効果は別に計算する。

20種の追加技には出目の変形もある。D6では安定の目 `2・2・3・4・5・6`、偶数の目 `2・2・4・4・6・6`、上半分の目 `4・4・5・5・6・6`。他の面数は6区間の比例対応で置き換え、再抽選しない。パッシブだけではダイス数を増やさず、対応するアクティブは次の判定1回に追加ダイスを与える。出目パターンは対応するアクティブ強化、期間デバフ、パッシブの順で1種類だけ選ぶ。複数のパッシブは上半分・偶数・安定の順で選び、目の変形を重ねない。

## 世界地図と交通

世界はアウレリア、ノクティス、シルヴァラ、カザランの **4 大陸と境界の群島、計 35 地域**。都市、森林、山岳、洞窟、遺跡、海岸、湿地、砂漠、火山、島、魔塔、雪原がある。大陸ごとの文化・服装・習慣やマナ修練の違いも公開設定に含む。画面の地図は訪問した場所か、所有する地図を使って記録した場所だけを表示し、未確認の地域は霧で隠す。

群島には、硝子珊瑚島、漂泊の浮島、巨茸の島、雷鐘の島、こだまの小島に加え、鏡波の島がある。既知の地点と現在地から続く未知の道を選び、少しずつ旅を進める。販売する地図は小さな一帯や航路を記した **15 種類**で、扱う市場・造船所と価格が異なる。持ち物で使うとその地図の地域を記録するが、訪問済みにはならず、図書館の読書だけでも霧は晴れない。旧保存との互換用に大陸・群島全体の古地図 3 種も残すが、新たな販売はしない。

| 交通手段 | 条件と特徴 |
| --- | --- |
| 徒歩 | 陸路でつながる地域間を無料で移動 |
| 乗合馬車 | 都市から出発し、陸路を速く移動。経路に応じた運賃が必要 |
| 定期船 | 港間の航路を使う。港まで・港からの陸路は徒歩と組み合わせ、船賃は海路分だけ必要 |
| 手伝い船 | 同じく陸路と組み合わせ、船仕事を手伝う代わりに無料で渡航。海路の所要時間は長い |
| 飛空艇 | 冒険者レベル 3 で解禁。陸と海を含む経路を速く移動し、高い運賃を払う |
| 転移門 | 両方の地域に門がある場合、門のネットワークで移動。基本 1 時間・60G |

画面の **G はゲーム内の金貨**。実際のお金や外部決済は使わない。移動画面は現在利用できる交通手段の費用と所要時間を表示する。経由地点や利用できない理由は GM に尋ねる。地図の陸路・航路は双方へ移動できる。門の線はネットワークの代表接続で、門のある地域同士は直接移動できる。

世界時計はサーバー全体で共有し、**実時間 1 分 = ゲーム内 30 分**の固定速度で流れる。プレイヤー設定や環境変数で速度を変える機能はない。ゲーム内 1 時間は実時間 2 分、ゲーム内の 1 日は実時間 48 分。移動系の特性・スキルは所要時間を減らし、最低 1 ゲーム時間となる。

| 活動 | ゲーム内時間 | 実時間 |
| --- | ---: | ---: |
| 職業・NPC の技を学ぶ・食事 | 1時間 | 2分 |
| 職業・種族イベント | 2時間 | 4分 |
| 探索・制作 | 3時間 | 6分 |
| 仕事 | 4時間 | 8分 |
| 野営・宿泊 | 8時間 | 16分 |
| 移動 | 交通手段と経路による | ゲーム時間 × 2分 |
| 読書・解体 | 1時間 | 2分 |
| 資源採集・桟橋釣り | 2時間 | 4分 |
| 海釣り | 4時間 | 8分 |
| 地形・種族・職業の現地行動 | 1〜2時間 | 2〜4分 |

時間のかかる活動は開始時に終了時刻を予約する。世界時計を飛ばさず、その時刻になってから到着、訪問記録、費用・材料の消費、報酬、回復、ダイス結果を確定する。進行中は別の行動を始めたり品物・スキルを使ったりできないが、同期と NPC・GM との会話はできる。終了時に食材が傷むなど条件が変わって完了できなければ、活動を解除して理由を日誌に残す。

オフラインでも世界時計と食品の時間は流れ、進行中の活動は同じ終了時刻まで続く。活動のないオフライン時間は空腹・疲労を増やさない。進行中の活動にはオフラインでも通常の空腹・疲労を適用する。再接続やサーバー再起動でも予定は保持する。

## 建物と図書館

ハースには市場、宿屋、食堂、ギルド、図書館、夜明けの神殿がある。白日王都にも夜明けの神殿がある。エンバーホールは市場、鍛冶屋、宿屋。月都は図書館、錬金工房、宿屋、契約の祠。白日王都・月都・赤織の街には考古学研究所があり、一般の遺物を売却できる。星詠みの塔は魔術師の塔と図書館。ほかの拠点も `shared/fantasy-town.ts` の明示的な配置を使い、どの都市にも全施設を自動で用意しない。港・転移門の交通タグは、室内の建物とは別に扱う。

到着した拠点で建物を選び、市場で売買、鍛冶屋で鍛造、錬金工房で調合、塔で魔術研究、宿屋で宿泊、食堂で食事、ギルドで転職や依頼を行う。制作には現在地に対応する設備が必要。

図書館はハース・白日王都・月都・星詠みの塔・緑帆港・波織りの里・赤織の街の7拠点にあり、所蔵は館ごとに異なる。ゲーム内で読める本は **34冊**。旅の手引き、生活書、短い物語、旅行記に加え、武術・素材・織物・交渉など10冊の分野書を揃える。読書行動を1ゲーム時間続けて完了すると読了記録が残り、指定技の解禁条件に使う。読むだけで全技を得たり地図を開いたりはしない。図書館のない場所や、その館にない本は開けない。開発用の世界設定集は本棚に表示しない。

公開プロフィールを持つ NPC は **94人**。建物や居住地で話しかけると大きな会話ウィンドウを開く。各地の実名NPCが依頼人や専門職の師を務める。最小化・閉じる・別メニューへの移動で履歴を消さず、同じ相手を開き直すと続けられる。狭い画面では全画面に近い表示になる。「新しい会話」で記録を消すボタンは置かない。現在地を離れた相手とは新しく会話を続けられない。

## 季節、服装、採集と狩猟

春・夏・秋・冬はそれぞれ15ゲーム日。4季で60日となり、ゲーム内の年表示も進む。場所、時間帯、季節に応じた気温と晴れ・曇り・雨・雪があり、屋外の寒暑・雨・暗さは判定に影響する。衣服は戦闘用防具とは別枠で、保温・涼しさ・防水を持つ。所持品から着替え、ランタンは持っていれば灯りになる。暗所に適した感覚のない人物は、暗い屋外や洞窟での行動に灯りが必要。

薬草・木材・鉱物・宝石の資源採集は土地の種類と資源に制限される。狩猟対象は48種で、生息地と最低危険度に応じて現地の候補に出る。追跡と実戦の判定があり、成功時に肉・登録された戦利品を得る。皮を持つ獲物は同じ場所で12ゲーム時間以内に一度だけ解体できる。漁師は港の桟橋で釣り、海釣りには帰港まで有効な購入済み・レンタルの漁船が必要。船は造船所で手配する。対象一覧は [48種の魔物](fantasy-monster-list.md) を参照。

地形行動は29種。山羊の獣人の岩足場、蝙蝠の獣人の反響調査、小柄な体の隙間調査、海の民の潜水、エルフ・精霊の森への感応、船大工の漂着材選別、書記の遺跡記録などを条件に応じて選ぶ。職業だけでなく場所・種族・身体特性・季節も確認し、MP消費、実際の判定、少量の品物や評判、熟練へ結び付く。翼で大陸間交通を飛ばす機能ではない。

## 空腹・疲労、宿泊と食品

空腹と疲労は 0〜100 で、高いほどつらい状態。活動 1 ゲーム時間あたり空腹が 2、疲労が 3 増える。野営・宿泊中は空腹だけが増え、完了時に疲労を軽減する。RPG に接続して何もせず待つ間は 1 ゲーム時間あたり空腹が 2、疲労が 1 増える。各値が 50／70／90 以上になると判定へ -1／-2／-3 の補正が付き、両方の補正を合計する。深刻な空腹・疲労が続くと HP にも負担が出る。

無料の野営はゲーム内 8 時間、実時間 16 分後に最大 HP の 20%、MP の 15%、疲労 15 を回復する部分的な休息。食事は別に必要。拠点では 8%、それ以外では `18% + 危険度 × 4%` の確率で小銭の盗難・襲撃・物音による回復不足が起きる。無料の全回復ではない。

| 宿屋の客室 | 費用 | ゲーム内時間（実時間） | 最大 HP / MP に対する回復 | 疲労軽減 |
| --- | ---: | ---: | --- | ---: |
| 相部屋 | 8G | 8時間（16分） | 55% / 40% | 45 |
| 個室 | 20G | 8時間（16分） | 80% / 75% | 75 |
| 特別室 | 50G | 8時間（16分） | 100% / 100% | 100 |

食事は宿屋または食堂で注文でき、ゲーム内 1 時間、実時間 2 分後に完了する。軽い食事は 5G・空腹 30 軽減、しっかりした食事は 12G・60 軽減、贅沢な食事は 25G・100 軽減。食事にも少量の HP・MP 回復がある。宿泊・食事中も時刻は進み、空腹が増えてから完了時に食事の軽減量を差し引く。

食品は入手時刻を持つまとまりごとに、共通の世界時計で変化する。オフラインでも食品の時間は止まらない。生肉や魚は傷みやすく、パンや料理も永続保存できない。干し肉は長旅向けの保存食。誰でも所持食品の見た目と匂いを確かめられるが、料理人かつ「食材の目利き」パッシブがあると経過時間・保存限度・栄養・品質を詳しく知る。傷んだ食品は効果が低下し、腹を壊す危険があり、制作にも使えない。

持ち物は名前と個数を並べ、名前を押すと詳細の窓を開く。食品の見た目・匂いと、能力がある場合の鑑定結果はその窓で読み、使用できる物はそこから使う。

## 仕事、依頼、制作と市場

仕事はどの地域でも行え、失敗したときも簡単な手伝いの賃金を得る。仕事・探索・資源採集・制作後のイベント抽選は **10%**で、条件を満たす候補がない場合は起こらない。各イベントは2つの選択肢を持ち、それぞれ異なる能力や難易度で判定する。成功なら金貨や品物、失敗なら少額の出費と経験を得る。イベントの選択前は、休息・食事・回復品・スキル以外の通常行動を進められない。

ギルドのある拠点では一般職を学べる。NPCは現地の対応する建物と教えられる職業の条件を満たす場合に取得を提案し、GMは登録済み職業への取得を案内する。町メニューの操作、または会話で1つの職業を選んで明示的に承認した後にサーバーが検証する。無料の学習はゲーム1時間・実時間2分後に完了する。犯罪職はギルド一般職一覧に出ない。以前の職業熟練は残るが、多職業の専門技を同時に使う機能はない。

犯罪職は架空の役割と選択型イベントとして実装する。手配・裁判・牢獄・税を統合した社会シミュレーションはない。会話中の自己申告やモデルの文章だけでは職業・報酬・所持品は変わらない。

依頼は**167件**。従来65件、個人メイン18章、地域サイド60件（共同討伐8件を含む）、行動依頼24件。メイン「暁の向こうへの航路」は四大陸の航海の手掛かりを集め、17章で島への航路を開き、18章の現地調査と航海日誌で完結する。実際に島へ到着していない旧完了者には結末を先に明かさず、到着後に追加報酬なしで日誌を残せる。終了後も暮らしと冒険は続けられる。

通常の依頼は指定地域を訪れ、必要数の品物を揃え、**依頼人の街へ戻って納品**する。指定地域を訪れず品物だけ買って達成することはできない。加工品は対応する職業で制作するか店で購入し、遺物は遺跡等で集める。完了した同じ依頼から繰り返し報酬を得られない。依頼人には現地に住む実名NPCを割り当て、依頼文をその人物の頼みとして読む。

メイン以外は現地ギルドの共有掲示へ流れる。通常契約は先着1人、共同討伐は複数人が同じ掲示へ参加できる。掲示は6ゲーム時間ごとに補充し、掲載12時間、完遂期限は掲載開始から36時間。受けたギルドと納品先の依頼人の街は別の場合がある。討伐は参加登録後に指定地の対象を実際に狩猟すると共同進捗へ加算し、必要数に達した参加者が依頼人へ報告する。期限切れは完了できず、放棄して次の掲示を確認する。季節指定5件と、秋末の薬草備蓄を優先する掲示、狩猟で変わる地域の魔物圧・討伐報酬補正がある。

限定依頼は発給地の神殿・祠と対象種族が条件。半神・天の民・大天使はハースと白日王都、魔の民・上位魔族は月都で関連する依頼を受ける。種族・系統・施設の明示条件はすべて満たす必要がある。ほかの種族の依頼を会話や保存データの操作で受注・達成することはできない。

アイテムは地図を別枠として **131種類、製法は70種類**。HP・MP・疲労・状態異常に対応する薬草、8種の金属の鉱石と延べ棒、丈夫な木材、多種類の魚、濃度や属性の異なる魔晶石、香辛料、絹、魔物の革、防具、宝石、武器、料理、季節向けの衣服と灯りを含む。現在の職業と現地の設備に対応する製法だけを制作画面へ出す。長い一覧は見出しを押して開き、材料を確認する。装備では同じ種類の素材へ置き換えたり、宝石を選んだりできる。画面とエンジンは共通の材料・予定産出量を使い、宝石は完成予定の装備数に合わせて必要になる。成功時に材料を一度だけ消費し、通常制作の失敗時は回収して再挑戦できる。

市場と専門店では在庫が異なり、珍しい素材や上級品は対応する工房、制作、危険な地域での低確率の発見から得る。一般の遺物は古代の粘土板、近代式の時計、王の物か不明な匙、片方だけの靴下などで、考古学研究所だけが買い取る。稀な特別遺物には回復・装着の用途があり、一般の市場では販売しない。

危険な探索・狩猟・海上活動などではHPを失う。HP0時に救助可能な拠点や近い陸路があれば保護され、所持金の10%を支払い、最大HPの半分で近くの拠点へ戻る。洞窟・島・危険度3以上・海上では救助されず、その人生を終える。編成した仲間の防護がある場合は一部の低危険度陸路で救助先を探せるが、危険地での生存を保証しない。死亡は原因・世代・訪問・達成・熟練等の足跡として残り、進行中の活動を中止する。次の人生を始めても旧人物は復活しない。

## 装備、状態異常と強化

装備部位は **武器・副手・防具・装身具の 4 枠**。剣、槍、弓、杖、弩、聖法書、鞭、投槍、盾、魔物の革の鎧、宝石の装身具などが実際の能力・判定・防護に作用する。装着と取り外しで品物を複製せず、装着中の品物は売却できない。最大 HP・MP を増やす品を外すと現在値も上限へ下がり、付け直しても回復しない。

制作した装備は同名でも個体別に記録し、品質1〜5、使用素材、宝石、制作時刻、実際の追加能力を持つ。品質には素材の等級、制作時の職業熟練等級、宝石と小さな乱数が反映する。所持品の基本一覧は名前×数量だけにし、クリックした詳細窓で個体を選んで装備・取り外しする。品質は短い名称と星、数値の効果は詳細内に出す。製作当時の熟練値そのものを個体へ記録する機能はなく、制作画面に現在の熟練を出す。衣服の着替えはこの4枠とは別。

状態異常は毒・火傷・凍傷・衰弱。毒は6ゲーム時間にわたり時間ごとにHP2を失い、判定-1。火傷は4時間、時間ごとにHP3を失う。凍傷は6時間、敏捷-2・力-1で、敏捷判定の目を下半分へ変える。衰弱は8時間、判定-2。凍傷の敏捷・衰弱の力・毒の体力判定には不利のダイスもあり、対応する判定強化の有利と相殺する。危険な探索で付くことがあり、薬草や解毒薬で治療できる。毒・火傷の被害は通常防護では防げない。オフラインの待機中はHPを減らさず、残り期間だけ共通時計に沿って経過する。予約中の活動はオフラインでも被害が進む。

料理 6 種は新鮮な場合に 6 ゲーム時間の食事強化を与える。食事強化は別の料理を食べると置き換わり、古くなった食品には付かない。宝石には 4 時間の集中・守り・幸運の効果がある。同じ効果 ID は重ねず更新し、異なる持続効果は状態異常を含め最大 8 個、1 効果の期間は最大 48 時間。期限後は能力・防護の補正も消える。食品の期限と、食後の強化の期限は別に管理する。

回復薬は HP・MP・疲労ごとに 4 等級あり、基礎回復量は 15・30・55・85。従来の回復薬 ID も維持する。解毒薬は毒・火傷・凍傷・衰弱を治療し、HP 10・MP 12 を回復する。希少な霊薬は力・知力・体力を恒久的に 1 ずつ高めるが、各能力への霊薬分は合計 +3 が上限。回復・治療・強化のいずれも必要ない品や、上限に達した霊薬は消費しない。

## 評判と価格交渉

評判は大陸・地域・町の 3 範囲に記録する。通常の仕事の成功、依頼の納品、犯罪職以外のイベントの成功で地域への貢献が蓄積し、町や大陸にも反映する。各記録は -100〜100。評判だけで商品の価格を自動で下げず、価格交渉の成功率と値引き幅に用いる。商人・吟遊詩人・指導者には交渉成功率の職業補正もある。

商品・客室・食事の 3 種を別々に交渉できる。対応する店や施設が必要で、成功時の値引きは最大 20%、有効期間は 8 ゲーム時間、同じ場所・種別の次の交渉までは 4 時間。宿泊・食事は開始時に有効だった値引きを完了時の支払いにも適用する。売値は基準価格の半分までで、値引き購入と売却を繰り返して利益を作れない。

町の施設画面に専用の価格交渉ボタンは置かない。現地NPCへ「値引きを交渉したい」などと明示して頼む。宿屋で客室か食事かが決まっていなければ、まず名前か番号でサービスを1つ選び、改めて確認へ返答する。「응」「yes」「はい」などの承認後に **D100を1回振り、出目が目標値以下なら成功**する。目標値は評判と職業補正から決まり、結果に出目と目標を出す。依頼やサービスを選んだだけで勝手にダイスを振らない。

## マナ修練と師からの学習

マナは職業を問わず、**実際にMPを使い、効果が働いた経験**で成長する。専用の修練ボタンや祈りの文を繰り返して進める仕組みではない。使用経験0・12・40・100・240で段階0〜4へ進み、制御熟練は段階ごとに最大5、全体で20。感応・呼吸循環・形の維持・放出と回収は世界内の学び方で、現行の進行は実効MP消費と反復効率の規則が判定する。次の判定等を強める技は、強化を準備しただけでなく実際にその効果を使う必要がある。

修練による最大 MP 増加は +20 まで。段階が進むと力・敏捷・体力にも補正があり、最大段階では力 +2・敏捷 +1・体力 +2。体力による最大 HP 増加も適用する。段階 2 から力・敏捷・体力の次の判定を補助する技、段階 3 で知力の集中、段階 4 で防護を使える。魔術師だけの仕組みにはしていない。

負荷は0〜100で、80以上は新たなマナ技を開始できない。使用でMPを消費し、疲労・負荷が増え、過負荷ではHPにも危険がある。負荷は経過したゲーム内の整数時間ごとに6ずつ下がる。

現地の対応する師からは、基礎の受け流し・落ち着いた手仕事・基礎の集中の 3 技を学べる。**1 技につき指導料 5G、1 ゲーム時間**。本人の所在地、建物、教えられる技、所持金と未習得であることをサーバーが検証し、完了してから支払いと習得を確定する。職業取得の無料・1 時間とは別の操作で、転職しても師から学んだ技は保持する。

追加職業技の「師から学ぶ」条件は、現在の職業を教えられる師と必要な職業熟練も確認する。学習記録は保持するが、別職業へ移ればその専門技は使えない。司祭独自の奉仕・誓約・教義・巡礼・神殿の信頼と4分岐は実装済みで、[司祭の成長規則](priest-growth-plan.md)を使う。職業熟練と信仰の証拠は別に保持する。

## 職業ごとの専門操作

指導者の部隊、裏社会の頭領の組織、召喚士の契約仲間は、雇用・契約、編成、現地任務、負傷時の治療、離脱後の再契約を扱う。健康で編成中の仲間が探索・狩猟の判定と防護を少量補助する。召喚にはMPの契約費と運用費があり、MP不足では補助できない。これは登録仲間の管理とダイス判定であり、個体を動かす戦場画面ではない。

魔術師は火・水・風・石・光と形の登録済み9組を、熟練に応じた1〜3枠へ準備して使う。MPを消費し、自分の判定強化・防護・回復へ作用する。錬金術師には4つの専門調合法があり、素材の等級と熟練等級、小さな品質変動で薬の等級を決める。専門調合の失敗時は最初の材料1個を失うため、通常制作の全回収とは異なる。

## ルールとローカル AI の GM

GM は韓国語・英語・日本語で話せる。現在地・仕事・依頼・移動・スキルなどの定義済みルール質問には登録データから答え、そのほかの自然な質問や相談は運営側のローカル AI へ送る。外部の有料生成 API や追加の API キーは使わない。サーバー側では返答の出典をルールとローカル AI に分ける。

GMが案内できる範囲は、既知の目的地や交通手段、現在の仕事、依頼と納品、所持品、職業スキル、失敗した理由、次に取れる行動。たとえば「お金を稼ぎたい」「受けている依頼」「왜 실패했어?」「Teach me to become a thief.」と入力できる。特定の職業を習いたい場合は短い説明と確認質問を返し、現職の仕事開始と混同しない。

**NPC・GMの会話内には行動選択・開始・確認のボタンを置かず、文章で選択して承認する。** 複数候補なら名前か番号を答えて1つに絞り、内容・費用・時間の確認を受けてから「응」「yes」「はい」などで承認する。1つの候補を選んだ段階ではまだ実行しない。職業・技能学習・売買・移動など、登録された行動だけをサーバーが再検証して実行する。自由な雑談やAIの文章を任意の操作へ変換する機能ではない。

ローカル AI に渡すのは、本人の能力・職業・技・身体特性、所持品、観察できる食品の状態、既知の地図、利用可能な施設、条件を満たす依頼、現在の活動・事件などの記録。未知の地名、他種族限定の依頼、未鑑定の食品の正確な状態、NPC の秘密は渡さない。分からない事実は分からないと答え、新しい公式設定や未実行の出来事を作らない。生成された雑談からゲーム操作を取り出して実行することもない。

GM の短い生成用履歴は仮ユーザー ID・言語ごとのサーバーメモリに保持する。NPC の会話履歴とは分け、永続保存はしない。入力は最大 500 文字、ローカル生成の待機上限は 45 秒。ルール質問はモデルの生成待ちより先に判定し、AI の返答準備中でも対応する簡単な質問を続けて送れる。NPC と GM のローカル生成は単一モデルの 2 スロットを共用し、最大 4 件を待機させる。雑談では無関係な設定を省き、通常は短い 2 文を指示する。返答全文の準備後に届ける方式で、トークン単位のストリーミングはまだない。モデルが利用できない場合もルール質問は使え、自由会話の接続失敗は明示する。準備・制限・実測値は [ローカル AI](local-npc.md) を参照。

画面のGM履歴もユーザー・言語ごとに分け、ほかのメニューへ移動して戻っても残す。要求ごとにユーザーと言語を追跡し、遅れた返答を取り違えない。ページ再読み込み後まで保存する機能ではない。会話の確認待ちは **実時間2分**で失効し、記録の版（revision）・現在地・人生が変わっても使えなくなる。その場合は新しい条件で頼み直す。地図・持ち物・町メニューの通常ボタンは引き続き使う。会話だけのボタン廃止と、通常メニューの操作は区別する。

## 保存と参加者の範囲

RPGの進行はサーバーの `data/fantasy.json` に、Tonariumの仮ユーザーIDごとに保存する。キャラクターと誕生時個体差、抽選、所持品、依頼、熟練・読了・解禁技、空腹・疲労、地図、食品の入手時刻別在庫、個別装備と衣服、持続効果、評判、マナ、仲間・合成魔法・漁船、司祭の信仰証拠と分岐、人生の足跡、予約中の活動、直近100件のログが対象。不動産原簿・戦場・パーティー倉庫も同じ保存トランザクションで扱う。世界時計は `data/fantasy-clock.json`、共有掲示・先着受注・共同討伐進捗は `data/fantasy-contracts.json` に別途保存する。同じIDなら再接続やサーバー再起動後も続けられ、別セッションでも同じ人物と世界時計を使う。旧保存には新項目を補い、保存に失敗した操作は確定しない。

仮 ID はブラウザが保持するプロトタイプ用の識別子で、認証付きの永続アカウントではない。別の ID を使う人が同じ人物かを判定する仕組みはない。同じ ID の複数画面から操作した場合は、記録の版を照合し、古い状態の操作を拒否して最新状態へ戻す。

セッションのワールド切り替えと通常のチャットは参加者で共有し、RPGの時計・ギルド掲示・共同討伐進捗は全ファンタジーセッションで共有する。人物の金貨・所在地・活動・イベントとメイン章進行は各自のもの。現地NPCへの共同準備は3回ごとに2人のNPCが協力した通知を残す。貢献の間隔は1人・1地域につき6ゲーム時間で、活動中は参加できず、金貨やアイテム報酬はない。記録は `data/fantasy-community.json`。共同討伐8件は実際の狩猟結果を共有する。最大6人のターン戦闘、10×8マスの移動・遮蔽、所有する仲間2体の指揮、同意した共同移動とパーティー倉庫に加え、双方の承認による直接交換と施設ごとの有限共有在庫を実装した。自由生成したAIの文章が共通シナリオやゲーム状態を確定することはない。

今回の対応は Web 版のみ。Avalonia／Unity に同等の地図 RPG は追加していない。

## 採択した職業と追加の制作

鹿・山羊・蝙蝠の獣人、風の精霊、霜の妖精を追加した。人間の17.64%と伝説種の確率は保ち、新種5種の合計3.9%は森エルフ・山ドワーフ・オーク・狐の獣人から配分した。

新しい生産12職には36製法を接続した。木工3・仕立3・織工3・革細工3・宝石細工3・薬草3・農夫1・漁師2・製パン4・陶工3・船大工3・書記5。穀物と亜麻、粉、布、粘土、器、外套、保存魚、補修板を加え、収穫→製粉→製パン、織物→衣服、器→調薬・保存食、船材→補修・納品の用途がある。稀なアーティファクトを普通の製法で作り出すことはできない。

## 職業依頼と続きの物語

職業限定依頼は現在の職業を条件とする。受注後に転職しても受注・達成の記録は残り、現在の条件を満たす職へ戻れば納品を続けられる。4地域の3段階の連作は先行する依頼の完了後に次が開く。未解禁の依頼IDを入力しても受注できない。依頼カードの物語は折りたたんで読み、転職や装備中の品物が納品を止めている場合は短く理由を出す。

装備中の1個は納品できず、余分に持つ分だけを納められる。最後の1個を渡す場合は手動で装備を外す。農地9・商業19・住居20の計48区画は売買・利用に加え、双方が承諾する賃貸と共有名義、既存区画内の設計改築、税と整備、有限の材料と賃金を使う雇用営業、公開競売と遺産競売を扱う。永続死亡後は遺産として世界に残し、新人物へ自動相続しない。任意座標へ建物を置く編集機能や材料なしの無限自動収益ではない。ブラウザー1.7B AIと同意した待機機器の共有支援は実装し、複数実機での長期計測を残す。

## 세부 의뢰의 이야기와 회상

메인18장의48개 세부 조사에 의뢰인 동기, 현장 장면, 세 가지 접근, 성공과 실패, 증거, 다음 조사의 이유를 한국어·영어·일본어로 연결했다. 구체적인 현장 설명은 도착 후에, 결과와 증거는 실제 판정 완료 후에 보여 준다. 받은 의뢰에서 ‘의뢰인의 사연’과 ‘확보한 단서와 이어지는 이야기’를 펼치고, 기록에서 ‘항해 이야기 다시 읽기’로 과거 장을 다시 읽는다. 미래 단계의 결과는 숨긴다.

회상은 성공한 조사 증명과 완료 기록을 사용하므로 최근 활동 기록100개 제한과 별개로 유지된다. 과거1~17장 완료에 세부 판정이 없으면 알려진 사실만 회상하고 실행 방법·시각을 꾸미지 않는다. GM·NPC에게 ‘확인한 단서를 알려 줘’ 또는 얻은 단서의 이름을 물으면 실제 확보한 사실을 설명한다. 아직 조사하지 않은 내용과 최종 발견은 단계별로 제한한다. [전체 시나리오 원고](fantasy-voyage-scenario.md)는 결말을 포함하며 게임 내 서가에 노출하지 않는다.
## 파티와 인물 몰입감 보강

[파티 메뉴](fantasy-party.md)는 최대6명이다. 초대를 직접 수락하고 공동 조사·같은 목적지와 수단의 이동·전투에 각자 준비한 뒤 파티장이 시작한다. 초대와 준비는 실제2분 뒤 만료되며 비용은 본인이 부담하고 개인 조사·지도·선택은 복사하지 않는다. 최근80개 파티 채팅과 직접 기부한 물품의 공동 창고가 있고 출금은 파티장이 승인한다. 전투 중도 합류도 본인이 동의해야 한다. 서버 재시작 시 명단은 다시 만들고 미분배 기부물은 살아 있는 원래 인생의 기부자에게 반환한다. 저장한 개인 진행은 유지한다.

이야기에는 개인 선택4종·8방법을 추가했다. 미라와의 약속, 부상 운반인 구조, 리라에게 온 매입 요구, 답장·귀환 준비의 우선순위를 각자 정한다. 선택은 선택한 인물의 금화·피로에만 영향을 주며 동료에게 비용을 전가하지 않는다. 진행을 막지 않는 부가 장면이고 추가 보상은 없다. 미라·사피·리라의28가지 재등장 반응은 확인한 단계와 본인의 선택을 기억한다. 실제 방문한 인물과 이야기하거나 받은 의뢰에서 현지 반응을 펼쳐 읽고, 자신의 선택은 기록에서 다시 읽는다.

[인원별 전투 균형](fantasy-party-combat-plan.md)은 실제 참전자1~6명을 기준으로 일반·정예·보스별 HP·피해를 보정한다. 소환수·부대·관전자는 플레이어 수에 넣지 않는다. 중도 합류는 본인 동의와 현지 조건을 검사하고, 적 능력은 상향만 하며 이미 입힌 피해를 보존한다. 퇴각으로 적을 약하게 만들지 않는다. 이전 저장의 두 줄 진형과 간이 사냥 예약은 호환 규칙으로 마무리한다.
## 턴 전투와 최상급 도전

[현재 전투 규칙](fantasy-combat.md)은1~6인 개별 입력·10×8칸의 이동·벽·엄폐·사거리·시야·아군 치유·방호·소모품·퇴각과 본인 동료 최대2명의 명령을 지원한다. 몬스터58종과 사람 상대5종에 고정 기본 능력치와 개체 편차가 있다. [전체 기준 능력치](fantasy-combat-monsters.md)는 실제 등록 데이터에서 작성했다. 범죄 직업 자체로 자동 적대하지 않으며 위법 발각·명시적 충돌 같은 행위로 사람 전투를 시작한다.

메인은1·3·6·7·10·14·16·17장에 전투를 넣었다. 고룡 등 최상급4종은 본편이나 일반 사냥에 나오지 않고, 현지 장치를 조사하고 위험을 확인한 본인의 도발로만 만난다. 기존 최고 품질 장비로 첫 도전이 가능하고 희귀 소재4종·제작품6종·명예 칭호를 보상으로 둔다. 아이템은 총165개, 제작법은86개다. 새 전투는10×8칸의 이동·벽·엄폐·사거리·시야, 본인 동료 최대2명의 직접 지휘와 본인이 동의한 파티원의 중도 합류를 지원한다.

## 거래·주민 생활·관청·호위의 후속 확장

[직접 교환과 공유 상점](fantasy-economy.md)은 같은 세션·현지의 실제 두 인물이 금화와 소지품 제안을 각각 승인한다. 제안 변경은 양쪽 승인을 해제하고 음식의 생성 시각·장비 개체의 품질을 보존한다. 시설별 유한 재고가 세계6시간마다 상한까지 입고되며, 공급과 현지 정책이 실제 가격에 영향을 준다. 남의 개인 인벤토리 전체를 보거나 착용품을 강제로 넘길 수 없다.

[주민 생활과 관청](fantasy-civics.md)은137명 주민의 거주지 안 일정·이웃 관계·공동 사업과 세력 변화를 기록한다. 실제 절도·폭행·갈취·동의한 금화 약탈만 사건 증거를 만들고 범죄 직업 자체는 유죄 사유가 아니다. 공개 세션의 양측 위험 동의가 없는 사람에게 플레이어 약탈을 하지 못한다. 관청에서는 자수·권한 있는 체포·심리/재심·피해 배상·벌금·형기와 석방을 처리하며, 새 인물에게 옛 형벌을 자동 상속하지 않는다. 구금 중 다른 행동은 제한한다.

[부동산 계약과 운영](fantasy-property-plan.md)은 임대·공동명의·개축·세금·정비·유한 고용 운영·일반/유산 경매를 처리한다. 건축은48개 기존 구획의 설계별 개축이며 자유 좌표 편집기는 아니다. 고용인은 실제 재료와 임금이 소진되면 멈춘다. 공공 매물 흥정은 중개 역할 NPC와 대화로 요청하고 승인한다.

[호위 전술](fantasy-escort-tactics.md)에서는 계약 주인이나 지정 지휘자가 수레에 이동·정지 방어를 명령한다. 본인 영웅과 동료, 다른 플레이어의 명령은 각각 구분한다. 수레 생존·습격자 격파·출구 도착을 모두 확인하고, 호위 보수는 기존 계약의 실제 동행 도착 뒤에만 지급한다.

NPC·GM 자유 대화는 운영 서버와 동의한 브라우저에서 생성되는 중간 문장을 순서대로 보여 준다. 취소·오류·자원 부족 복귀의 부분 답변은 최종 대화 기록과 구분하며 실제 행동은 말로 승인한 뒤 서버가 검증한다. 자세한 연결과 제약은 [로컬 대화](local-npc.md)와 [브라우저 지원](browser-ai-support.md)을 따른다. 후속 확장의1,143개 통합 검사와 저장 호환·빌드는 완료했으며, 이후 NPC 대화 버전5도1,189개 회귀 검사와 타입 검사·빌드를 통과했다. 이 기록은 실제 여러 PC의 AI 처리량·장기 RAM/VRAM 실측을 대신하지 않는다. 기존 실제 플레이 저장은 보존하고 게임·AI·갤러리 서버를 상시 실행하지 않는다.
