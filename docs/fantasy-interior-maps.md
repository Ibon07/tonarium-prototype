# 내부 탐사 지도

현재 직업이 기록사이고 전문 분야가 지도필사사(`scribe-maps`)인 캐릭터는 유적·던전 안의 조사하고 확보한 방에서 내부 지도 사본을 제작한다. 3게임시간과 필사용 종이 2장, 약초 먹물 1개, 리넨 1장을 쓴다. 제작 숙련과 판정에 따라 품질 1~5가 정해지고 제작 숙련이 오른다. 일반 기록사나 다른 전문 분야에서는 제작할 수 없다.

사본은 실제 `scribe-interior-map` 소지품 1개와 `interiorMaps`의 개별 기록 1개로 구성된다. 작성자·작성 시각·실제 저장된 `layoutSeed`·직접 걸은 방·그중 조사한 방·품질을 저장한다. 숨은 함정, 적, 보상, 특수 장치와 성공한 조사 내용은 저장하지 않는다. 판매 가격은 방 수, 조사 기록 수와 품질을 반영하며, 일부만 탐사한 지도도 제작·판매할 수 있다.

구입한 지도에서만 알게 된 방을 다시 필사하지 않도록 던전의 `visited`를 `revealed`와 구분한다. 구형 저장의 `visited`가 없는 경우 기존에 드러난 방은 실제 방문 기록으로 승계한다. 지도 사용 직전에 기존 방문 기록을 먼저 분리하고, 이후 사본에서 배운 방은 `revealed`에만 추가한다. 파티 배치 시드가 바뀌면 새 배치의 직접 방문 기록을 다시 쌓는다. 이미 얻은 개인 보상·발견·조사 날짜 기록은 기존 보존 규칙을 따른다.

지도는 특정 배치에 묶인다. 수령자가 아직 해당 내부 배치를 저장한 적이 없다면 사본의 배치를 그대로 사용한다. 이미 다른 시드의 배치가 저장되어 있으면 사용을 거절하고 지도는 소비하지 않는다. 같은 배치에서는 기존 정보를 합치며 조사 성공·퀘스트·적 격파·함정 해체·물품 수령을 완료한 것으로 만들지 않는다. 적을 물리치지 않고 돌아갈 수 있는 길도 직접 방문한 방을 기준으로 판정한다. 사본을 읽는 데 성공하면 실제 사본 1개를 소비한다.

시장 판매와 재구매, 플레이어 간 승인 교환, 파티 공동 소지품, 가방 초과 보관과 수령은 모두 개별 사본 메타데이터와 실제 수량을 함께 이동한다. 사본 ID를 지정하지 않는 일반 묶음 판매·교환은 거절한다. 기존 경제·서버 저장의 복제 후 원자적 저장 경로를 사용하며 저장 실패 때 원본 소지품이나 금화를 변경하지 않는다. 상업 창고는 경제 모듈의 공통 물품 소포 추출·수령 함수를 재사용한다.

구현 파일은 `shared/fantasy-interior-map-catalog.ts`의 순수 아이템·사본 정의와 `shared/fantasy-interior-maps.ts`의 행동·언어 함수다. 기존 생산 카탈로그의 종이·먹물, 직업 전문 분야, 던전·경제·가방 규칙을 연결한다. 던전 행동 화면에서 제작하고, 소지품의 개별 사본을 선택해 읽으며 시장이나 교환 화면에서 사본별로 거래한다. 한국어·영어·일본어 문구를 제공한다.

## 검사 대기

사용자 지시에 따라 아래 회귀는 작성만 했고 실행하지 않았다. 타입 검사·빌드·화면 확인·추가 리뷰도 실행하지 않았다.

- `shared/fantasy-interior-maps.test.ts`: 현재 전문 분야 제한, 재료·시간·숙련·품질, 숨은 정보 제외와 지도에서 배운 방의 재필사 금지.
- 저장 시드 일치·불일치·미생성 배치, 사용 후 방문·조사·보상·퀘스트 진행의 비변경과 기존 기록 보존.
- 가방 초과 보관·수령, 개별 사본 판매·시장 재구매·중복 요청, 물품 소포의 동일 ID·작성자·품질 보존과 중복 수령 거절.
- 후속 일괄 실행 시 실제 서버 저장 실패·오프라인 제작·재시작, 양측 교환 승인·품질 변경·사본 사용 중 거래 무효화, 파티 창고 반환, 상업 창고 출납, 작은 화면·키보드·세 언어를 추가 확인한다.
