# 계절·날씨 장비와 현재 효과 (2026-10-31)

계절·지역 기온·비·어둠에 대한 기존 판정을 확장했다. 의복은 소지한 것만으로 효과가 나지 않고 실제로 입어야 한다. 날씨 도구는 휴대하면 자동으로 쓰며, 같은 계열에서 가장 강한 도구 하나와 현재 의복의 효과를 합친다. 여러 개를 들고 효과를 무한히 중첩하지 않는다. 판매·소모·분실 후에는 계산에서 즉시 빠진다.

표의 가격은 기본 카탈로그 가격이며 실제 판매가·재고·영업시간은 기존 상점 규칙을 따른다. 냉각/보온/방수 수치는 기온 대응 계산용이며 공격력 보너스가 아니다. 새 물품은 종류에 맞는 무게를 가진다. 우산, 냉기 망토, 보온 외투와 세 종류의 마법 도구를 만드는 제작법 6개도 추가했다. 재료는 기존 비단·리넨·목재·모피·광석·마정석·설화초·향신료를 쓴다.

## 기존 물품 활용

- 침낭은 야영 보온 4, 모피 침낭은 보온 12를 제공한다.
- 주머니 속 난로돌은 기존 피로·MP 회복 효과에 야영 보온 12를 더한다.
- 야영 방수포는 야영 중 방수 14를 제공한다.
- 일회용 야영 결계부는 야영 중 방수 18로 비를 막는다. 비만 막아서는 소모되지 않으며 기존처럼 습격 한 번을 막을 때 소모된다. 소모 후에는 더 이상 비를 막지 못한다.
- 실제로 켠 모닥불은 야영 보온 8과 일반 랜턴 수준의 조명을 제공한다. 마법사 또는 불 피우는 도구·목재를 사용하는 기존 점화 규칙을 유지한다.

야영 전용 물건은 탐사·도보 이동 중에 펼친 것으로 계산하지 않는다. 반면 우산과 휴대 냉각·보온 마도구는 이동 중에도 작동한다. 보온 합계는 48, 냉각·방수 합계는 32에서 제한한다.

## 대응하지 못했을 때

추위와 더위는 야외 판정에 최대 -3, 비에 젖으면 -1을 준다. 두꺼운 겨울옷은 더운 지역에서 열 부담이 생기므로 여름옷으로 갈아입거나 냉각 도구로 보완해야 한다. 어둠을 포함한 환경 불이익의 합계는 최대 -6이다. 이 수치는 기존 탐사·일·채집 등 공통 판정에 적용하며 전투 피해량을 새로 일괄 조정하지 않는다.

야영의 기본 피로 회복에서 기후 불이익 단계당 3, 비에 젖으면 4를 덜 회복한다. 8시간 전체 기준 최대 손실은 13이다. 날씨가 변하면 실제 노출 시간에 따라 나누어 반영한다. 불침번 회복 감소는 별도로 적용한다. 중간 저장·재접속·잘게 나눈 시간 갱신이 손실이나 회복을 중복시키지 않는다. 기존 야영 기록에는 새 누적 손실 필드가 없어도 불러올 수 있다.

시설 안, 동굴과 던전 내부는 바깥의 비·기온에서 보호받는다. 도시에서 여관을 쓰지 않고 노숙하면 야외 기후를 적용한다. 이동 중에는 출발 도시의 실내 보호를 계속 받지 않으며 경로상 가까운 지역과 현재 세계 시간으로 날씨를 계산한다.

## 야간 광원

일반 시야의 어둠 판정 불이익:

| 광원 | 불이익 |
| --- | ---: |
| 없음 | -4 |
| 길드 대여 랜턴 | -3 |
| 일반 랜턴 / 야영 모닥불 | -2 |
| 별빛 유리등 등 상급 마법등 | -1 |

가장 강한 광원 하나를 사용한다. 좋은 휴대등도 밤의 사각지대를 모두 밝히지는 못한다. 종족 고유 야간 시야의 기존 면제는 유지하며, 범죄 직업의 조건부 야간 업무는 더 작은 어둠 기본값을 사용한다. 광원도 적응 시야도 없는 경우 기존 야외 행동 제한 역시 유지한다. 대여품·일반품·상급품의 설명을 세 언어로 실제 수치에 맞췄다.

## 이동 중 교체

소지품·장비 창에서 의복을 갈아입거나 무기·보조 손·방어구·장신구를 장착·해제할 수 있다. 실제 소유 및 장비 개체 조건을 검사한다. 진행 중인 경로·도착 시각·이동비·활동 난수 시드는 그대로 유지하며 교체 자체로 시간을 진행하지 않는다. 파티 이동도 각자의 장비를 교체할 수 있지만 이동 결정 권한을 바꾸지 않는다. 가방 교체와 다른 활동의 병행은 이번 허용 대상에 포함하지 않는다. 전투·부상·구금 등 기존 제한도 유지한다.

## 스탯 영역

피로·허기는 기존 두 게이지로 계속 표시한다. 50 미만에는 관련 디버프를 만들지 않고, 실제 판정 불이익이 생기는 50·70·90에서 각각 -1·-2·-3을 디버프 쪽에 표시한다.

스탯 아래 `현재 효과`를 강화/디버프로 나눴다. 현재 기후와 대응 장비, 어둠, 피로·허기, 일시적 음식·기술 효과와 상태이상, 본인의 현재 전투 방호·조준·축복·상태를 설명한다. 마우스 올리기·키보드 포커스·터치로 설명을 열고, 포커스를 옮기거나 Escape로 닫을 수 있다. 시간제 효과는 남은 게임 시간을, 전투 효과는 남은 라운드와 강도를 보여 준다. 기후 표시는 별도 영구 디버프로 저장하지 않아 날씨·장비가 바뀌면 곧바로 갱신된다. 툴팁은 UI와 화면 경계 안에 배치한다.
