# NPC별 초상화

현재 게임의 공개 NPC160명 모두 각각 따로 생성한 상반신 애니메이션풍 WebP 일러스트를 사용한다. 기존137명의 이미지는 유지하고, 신규 장인21명과 원정대 보급 담당·떠돌이 지도 상인2명도 같은 그림체로 개별 제작했다. 참고 이미지는 비율·선화·채색의 기준으로만 쓰며 인물의 종족·나이·성별·직업·표정·소품과 거주지 복식·기후를 개별 반영한다. 게임의 초상화 경로는 WebP만 선택한다. 이미지가 없거나 불러오지 못하면 SVG나 다른 NPC 얼굴 대신 이름의 첫 글자만 표시한다.

## 현재 일러스트

2026-10-31 추가23명은 초안을 모두 제작한 뒤 기존 미라·갈렌·보린과 비교해 전원 그림체를 다시 보완했다. 초안에서 길어진 얼굴·목·상체와 좁은 머리를 줄이고, 큰 둥근 머리·짧은 상체·큰 눈·단순한 머리카락 명암으로 맞췄다. 여성은 가는 어깨·팔·허리를 유지하고 남성은 직업에 맞는 체격을 유지하면서 같은 머리 비율을 쓴다. 자세·표정·의상 구조·소품은 인물마다 유지한다.

세리트와 브란은 두꺼운 털깃·손목 털장식의 방한복, 카자란 인물들은 얇은 아마포와 열린 조끼·짧은 소매를 쓴다. 넬라는 머리 위 잘림을 막기 위해 전체 머리와 묶은 머리가 들어오도록 여백을 다시 보완했다. 전원 얼굴·머리·손·복장을 육안으로 확인하고, 같은 크기로 놓은 기존/신규 비교 화면3장으로 전체 그림체를 재검토했다. 비교 자료는 `work/qa/npc-additional-illustrations/review-final-01.png`부터 `03.png`까지 보존한다.


이번 정착지 확장으로 추가한43명도 같은 참고 그림체로 개별 제작했다. 신규 도시와 마을의 시설 담당33명·생활 주민9명·햇살목초지 여관 주인1명이다. 솔바람마을은 풍성한 털 방한복, 실바라는 매듭 저고리와 비막이 어깨천, 카자란은 얇은 아마포와 통풍되는 옷으로 구분한다. 얼굴·팔·손·의복·귀와 머리의 잘림을 검수하고, 잘린 귀나 머리 끝은 재생성해 보완했다. 신규43장의 투명 WebP와 원본 PNG, 실제 생성 프롬프트·검수 기록을 모두 보존하며 기존94명의 파일은 유지했다.

전신을 그리지 않고 머리 전체부터 허리까지를 담는다. 마지막으로 제공된 미라 참고 이미지에 맞춰 머리와 머리카락이 화면 높이의 약 절반을 차지하는 큰 머리·짧은 몸통 비율을 사용한다. 여성은 좁은 어깨·가느다란 팔·잘록한 허리와 부풀지 않는 옷으로 마른 체형을 표현한다. 남성은 종족과 직업에 맞춰 마른 체격·보통 체격·넓고 탄탄한 체격을 구분한다. 머리카락은 개별 모발 질감 대신 큰 덩어리와 단순한 명암으로 표현한다. 그림체는 통일하되 자세·얼굴·머리 모양·실제 옷 구조·장신구를 인물마다 구분한다. 눈·손·팔·옷·종족별 귀와 뿔·후광을 육안으로 검수한다.

머리색은 은색·연보라·청록·분홍·청흑·코랄·금발·자연 갈색 등14종으로 나누고, 피부도 밝은 톤·올리브·갈색·짙은 갈색을 사용한다. 오크의 녹색, 조수족의 청록·파랑, 월영족의 라일락·슬레이트, 마족의 장미·자주 계열 안에서도 여러 피부색을 구분한다. 색상은 직업이나 범죄 여부·성별에 연동하지 않는다.

모든 인물은 기본 제공 `image_gen`으로 한 명씩 개별 생성한다. 생성 원본의 투명 배경을 유지한 채 최대 높이1200의 WebP로 최적화하고, 대화창에는 상반신과 머리가 잘리지 않도록 맞춘다. 생성 이미지는 런타임 AI 대화 모델과 별개인 정적 파일이다.

복장은 미리 정한 각 NPC의 `homeLocation`과 지역별 `wardrobe`를 기준으로 제작한다. 이번 기후·성직자 복장 보완 대상은 추운 지방8명, 더운 지방18명, 사제3명으로, 두 조건이 겹치는 네라를 포함해 총28명이다. 추운 지방은 큰 털깃·풍성한 털 안감·손목 털장식과 닫힌 긴소매를 분명히 드러내며, 그 안의 여성 체형은 가늘게 유지한다. 더운 지방은 얇고 밝은 린넨, 짧은 소매나 민소매, 가벼운 열린 조끼, 얇은 햇빛 가리개 가운데 두 가지 이상이 눈에 띄도록 구분한다. 직업에 필요한 앞치마·보호 장갑과 지역별 여밈 방식도 유지한다.

사제 이오나·아우렐·네라는 성직자 칼라, 성의와 캐속, 길게 내려오는 두 갈래 스톨, 성스러운 문양과 메달로 직업을 나타낸다. 루네리아의 네라는 동양식 여밈과 풍성한 털 방한복을 함께 갖춘다. 기존 얼굴·머리·피부·자세·소품은 보존하며, 수정 전 원본은 `work/qa/npc-climate-before/`에 남긴다. 검수용 갤러리는 거주지·기후·복식 문화를 표시하고 추운 지방·더운 지방·사제별로 모아 볼 수 있다.

- 게임용 파일: `client/public/fantasy/npc-illustrations/<npc-id>.webp`
- 인물별 연결: `shared/npc-portrait-illustrations.ts`
- 최종 제작 프롬프트·색상·파일 지문: [npc-illustration-prompts.json](npc-illustration-prompts.json)
- 원본과 검수 기록: `work/qa/npc-illustration-sources/`, `work/qa/npc-illustration-prompts/`
- 파일 연결·투명 채널·크기·중복 검사: `client/src/world/npc-illustrations.test.ts`

초기 상반신94명은 `work/qa/npc-illustrations-review-01.png`부터 `16.png`까지 전체 화면으로 마지막 미라 참고 이미지와 다시 비교했다. 여성의 어깨·팔·허리 폭, 머리 대비 몸통 길이, 손과 소매 연결, 귀·뿔·후광의 잘림을 점검했다. 발견한 여분의 손·팔, 넓은 여성 상체, 작은 머리와 잘린 뿔은 개별 재생성으로 수정한 뒤 다시 확인했다. 다른 제작 담당자의 교차 검수도 완료했다. 94개 파일은 모두 서로 다른 지문이며 실제 투명 배경을 갖춘다. 당시94장 WebP 합계는 약22.1MB였으며, 대화할 때 해당 NPC의 파일만 불러온다.

상반신 연결을 활성화한 뒤 타입 검사·화면 자동 검사44개·웹 빌드가 통과했다. 실제 게임의 분리된 테스트 세션에서 여관의 린을 만나 초상화 표시와 시설 안내 대화를 확인했다. 화면은 `work/qa/npc-illustrations-game-chat.png`에 보존한다.

## 제작·검수 방법

새 NPC는 기존 미라·갈렌·보린과 같은 상반신 그림체로 개별 생성하고, `shared/npc-portrait-illustrations.ts`의 명단에 등록한다. 거주지 문화·기후는 `shared/npc-wardrobe.ts`를 기준으로 프롬프트에 반영한다. 제작 프롬프트와 원본 PNG는 보존하고, 실제 게임에서는 투명 WebP만 제공한다.

사용하지 않는 이전 SVG160장, 디자인 표와 SVG 생성·렌더링 도구는 제거했다. 과거 버전은 Git 이력에서 확인할 수 있다. 초상화는 하나의 래스터 연결표만 사용하며, 누락·로드 실패 시 다른 얼굴이나 SVG 대신 이름 첫 글자를 표시한다.

`client/src/world/npc-illustrations.test.ts`는 전체 명단·파일 연결·해상도·투명 채널·중복 지문을 검사한다. `client/src/world/npc-portraits.test.ts`는 실제 표시 컴포넌트의 인물별 연결·미등록 ID의 안전한 표시와 제작 기록의 신원·복식 정보를 검사한다. 이미지의 얼굴·손·머리·의상·잘림과 기존 그림체 일치는 자동 검사와 별도로 육안 확인한다.

현재160장 합계는36,037,058바이트(약36.0MB)이며, 기존 상반신 이미지는 이번 코드 정리에서 변경하지 않았다. 제거한 이전 SVG는822,543바이트(약0.82MB)다.
