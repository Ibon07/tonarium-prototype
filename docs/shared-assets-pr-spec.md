# 공유 시스템 최신 명세

현재 구현 명세는 [중앙 공유 시스템과 코드 맵](shared-systems.md), 등록 절차는 [중앙 등록 안내](shared-systems-registration.md)입니다. 이 문서들을 기준으로 개발합니다. 과거 첨부 파일이나 미완료 worktree를 다시 요구할 필요가 없습니다.

확정 사항: 맵은 코드로 작성하고, 중앙에는 오브젝트와 독립된 동작 시스템을 PR로 등록합니다. 기존 오브젝트·텍스트·사용자를 연결하고 시스템끼리 이벤트를 전달합니다. 맵 제작자는 시스템 버전을 지정하지 않습니다. 호환되는 새 버전은 실행 상태와 오브젝트를 유지해 반영하며, 비호환 버전은 기존 동작을 보존합니다. 앱 관리자 승인·새 로그인·본인확인·맵 편집 ACL·시각적 맵 편집기는 범위에 포함하지 않습니다.

기존 [공유 에셋 구현](shared-assets.md)과 [과거 검증 기록](shared-assets-verification.md)은 이전 구현의 참고 자료로 남겨 둡니다.
