# 전투 평가·수치 조정과 로컬 검증 — v3, 2026-10-30

로컬 기능 검증과 공통 수치 1차 조정을 마쳤다. 모든 개별 직업·종족 균형이 확정되었다는 뜻은 아니다. 아래의 조정용 결과와 최종 독립 결과를 구분한다. 실서버 장시간 플레이와 실제 KokoaAI 자유 대화 품질은 사용자 요청대로 추후 운영 로그에서 확인한다.

## 이번 변경

- 전투력 평가에 실제 사용 가능한 기술의 공격·회복·방호·사거리·이동·일부 제어 효과를 반영한다. 여러 기술을 단순 합산하지 않고 공통 MP와 12행동 예산에서 선택한다. 현재 HP/MP 소모로 개인 등급을 낮추지 않는다.
- 실제 편성한 부하·소환물 최대 2기를 평가에 포함한다. 각 기여의 상한은 본체의 35%이며, 중복 ID와 행동할 수 없는 동료는 제외한다. 비교 표본도 동료를 먼저 고용·배치한 뒤 등급을 계산한다.
- 높은 등급의 평가 간격을 좁혔다. 실제 능력 평가량 440까지는 같고, 초과분은 2.5배의 지수로 표시한다. 표시 경계 360/520과 의뢰 5건 요건은 유지한다. **마스터 진입의 실제 평가량은 520에서 472로 낮아진다.** 기존 획득 등급을 자동 취소하지 않으며, 과거 심사 점수와 새 점수는 직접 비교하지 않는다.
- 일반 몬스터의 고정 체력·공격력을 조정했다. 7등급의 낮은 명중·500공격·과도한 마법저항을 함께 쓰던 구조를 없앴다. 8등급은 긴 전투를 견디는 체력·방어 쪽에 비중을 둔다. 등급이 올라갈 때 모든 능력치가 동시에 증가해야 한다는 임의의 제약 대신, 공격 감소를 체력과 방어로 보상한다.
- 11종의 상위 몬스터는 방어로 한 턴을 쓰는 행동, 매턴 주문, 재생 등의 차이를 반영한 고정 종별 수치를 갖는다. 플레이어 직업·등급·장비나 목표 승률을 보고 적 수치를 바꾸지 않는다. 실제 전투는 기존 주사위 판정을 사용한다.
- 비교 전술은 느린 회복자가 회복 전에 한 번 더 맞는 위험, 유효 회복량, 침묵으로 바뀐 적의 실제 공격, 안전한 마무리를 구분한다. 미래 난수는 읽지 않는다.
- 측정 도구는 캐릭터 전체 전투 데이터와 기준 기록의 일치, 최대 HP/MP로 쉰 상태, 고유 ID, 빠짐없는 비교 집합을 확인한다. 변조된 체력·마나와 누락·중복으로 평균을 바꾸는 입력을 차단한다.

기존 직업별 HP 차등과 역할은 유지했다. 예: 마법사 0.72배, 전사 1.28배, 기사 1.38배, 방패수 1.55배. 이번에 직업의 공격력을 일괄 같게 만들거나 지원 직업을 개인 승률만으로 약화하지 않았다.

## 목표와 비교 조건

일반 1–6등급: 동급 60–80%, 한 단계 낮은 적 80–100%, 한 단계 높은 적 10–40%. 상위전: 6→7 최대 5%, 7→7 약 40%(35–45), 8→7 약 60%(55–65), 7→8 최대 20%, 8→8 약 50%(45–55).

주요 비교는 일반 인간·기본 전사/기사/궁수/마법사/사제이며, 희귀 종족과 특수 전직을 섞지 않는다. 고정 등급 대표 점수에 가까운 합법적인 레벨·숙련·장비를 선택한다. 상위전은 검증된 제작 입력으로 만든 최고 품질의 일반 제작 장비 전 부위를 쓰며, 고룡 보상 장비는 제외한다. 대표 점수보다 훨씬 강한 무제한 마스터 전체에게 같은 확률을 보장하는 의미가 아니다.

준비 전술은 해당 등급 HP 포션 1개와 MP 포션 1개를 허용한다. 개별 전투의 난수와 몬스터 변동폭을 직업 간 짝지어 비교한다. 합산 평균의 합격이 모든 직업·종족·몬스터 조합의 합격을 뜻하지 않는다. 원본에는 직업별·종별 행, 오류, 소스 해시와 비교 누락을 별도로 남긴다.

## 기능 회귀 검사에서 고친 테스트 조건

- 빈사 전투 저장 테스트가 등급이 다른 두 사람의 단독 조우를 파티 문맥 없이 시작하고 있었다. 실제 파티 시작과 같은 파티장 문맥으로 고쳤으며, 원래 원자적 저장·회복·재시도·MP 쿨다운 검증은 그대로 유지했다.
- 실제 전투 저장 후 카탈로그 수치가 바뀌는 배포 상황을 추가 검사한다. 저장한 적의 전투 스냅샷을 유지해 재접속·다음 행동·재저장이 가능한지 확인한다. 이 수정으로 저장 검증을 완화하지 않았다.

## 해석의 한계와 이후 확인

- 모든 개별 직업·종족의 승률이 목표 안이라는 결론은 내리지 않는다. 공격/방어/지원/지휘와 적 패턴의 상성, 표본의 장비와 유효 전술에 따라 차이가 있다. 특히 상위전 원거리·회복 직업은 현재 자동 전술에서 물리 전사보다 불리한 행이 있다.
- 일반 12종·주요 5직업의 3/6등급 폭 검사에서는 일부 낮은 HP 사제의 회복 전 사망 위험을 확인했다. 하이엘프 사제 3등급 누락은 장비 조건 때문이며, 합법적인 무장 없는 3등급이 전혀 없다는 뜻이 아니다.
- 전투력의 사거리 가중치는 일반적인 접근 상황의 추정값이다. 빠른 적과 원거리 적에게 항상 두 번의 안전 공격을 보장하지 않는다. 과회복만으로 낮은 HP 사제의 부진을 설명하지 않는다.
- 열린 전장 비교로 좁은 틈·비행·수영·함정·야간 등 모든 신체 특성과 환경의 가치를 평가할 수는 없다.
