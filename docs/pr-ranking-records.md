# 同名ランキング記録の集約（PR 本文案）

## 変更

取得済みのランキングを表示側で名前の完全一致によりまとめ、反物質が最大の記録を代表に表示する。同値なら先の記録を採用し、代表の元インデックス順で集約後の順位を付ける。残りの記録は入力順のまま展開できる。元データ、サーバー、保存、API、依存パッケージ、変更履歴は変更しない。

開閉状態は名前で保持する。本人判定には各記録の `self` だけを使い、子に本人記録があれば折りたたみ中も包含を表示する。件数は同一人物や人数ではなく「記録数」とする。

## 利用者向けの変更

- 同じ名前のランキング記録をまとめ、代表順位と記録数を確認できる。残りの記録はボタンで展開・折りたたみできる。
- 自分の記録をアイコンと文字で識別でき、折りたたみ中も自分の記録が含まれることが分かる。
- 狭いパネルではランキング内を横にスクロールできる。数値は途中で改行されず、開閉ボタンは Tab・Enter・Space で操作できる。
- ランキングの文言とプレイ時間の単位が日本語・英語・韓国語に対応する。
