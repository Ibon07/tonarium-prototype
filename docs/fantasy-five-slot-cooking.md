# 다섯 칸 요리와 반복 제작 — 2026-10-30

**상태: 사용자 요청으로 검증 실행 및 발견 문제 수정.** 판타지1,584건·NPC159건·필수 완료 검사가 통과했다. 세 언어 Chrome12조합과 실제 공유 창고 WebSocket 갱신도 확인했다. [최종 검증 기록](fantasy-cooking-validation-2026-10-30.md)의 범위와 잔여 작업을 따른다. 커밋·푸시·PR·배포 및 실사용 저장 데이터 수정은 하지 않았다.

## 최신 사용자 요구

- 요리 한 번의 재료는 총 다섯 개 이하다. 한 칸은 재료 한 개이며 같은 재료를 여러 칸에 넣으면 그 칸 수만큼 소비한다. 종류별 수량을 5개씩 넣는 방식이 아니다.
- 자유 요리는 주재료 세 칸과 추가 재료 두 칸이다. 주재료는 모두 채우며 추가 칸은 비워 둘 수 있다. 추가 재료는 서로 다른 주재료 위치에 하나씩 연결한다.
- 고정 요리는 정확한 조합으로 특정 음식이 나온다. 신규 48종은 서로 다른 재료 다섯 개를 각 한 개씩 사용한다. 기존 요리의 원래 배합과 지식·도구·직업 조건은 유지하며, 다량 생산은 재료 배수 대신 반복 횟수로 요청한다.
- 반복 횟수의 최대치는 현재 선택한 소지품 또는 현지 상업 건물 창고의 실제 재고와 야외 장작 소모를 기준으로 계산한다. 두 출처를 자동으로 섞어 쓰지 않는다. 개인 창고는 이용 권한이 있는 현지 작업장에서만 사용한다.
- 고정 요리는 실제 음식명과 판타지 향토 이름을 섞고, 자유 요리는 야매·즉흥 조리다운 별명을 사용한다. 새 결과 114종과 이전 저장 호환 음식·탄 음식에 한국어·영어·일본어 이름을 부여했다.

## 결과와 생산 진행

신규 고정 48종, 정상 자유 요리 20계열 × 세 후보 = 60종, 위험 계열 두 개 × 세 후보 = 6종이다. 신규 완성 음식은 114종, 새 식재료는 19종이다. 전체 이름·다섯 재료 조합·영양·보존 정보는 [요리 확장 목록](fantasy-cuisine-expanded-list.md)에 있다.

자유 요리는 주재료의 분류 조합으로 계열을 정하고 정확히 일치하는 계열이 없으면 분류가 가장 많이 겹치는 계열을 고른다. 첨가 재료와 연결한 주재료에 따라 세 후보의 가중치가 바뀐다. 구체적인 같은 분류의 재료 차이는 작은 결정적 취향 가중치로 반영한다. 정상 재료라도 숙련·상태·난이도 판정에 실패하면 별도의 실패 음식인 **숯이 된 저녁**이 나온다. 먹을 수 없는 재료·독성 재료·부패한 재료는 성공 판정으로 정화되지 않고 해로운 후보로 이어진다.

각 반복은 한 번의 조리 시간이 끝날 때 따로 판정·소모·음식 생성·숙련·정상 성공 의뢰 진행을 정산한다. 따라서 중간에 취소해도 이미 끝난 음식과 숙련은 남고 아직 시작/완료되지 않은 회차의 재료는 소비하지 않는다. 실제 소모는 완료 회차에 정산한다. 이후 재고가 다른 이용자나 직원 생산으로 바뀌거나 작업장 권한이 사라지면 남은 반복은 중단될 수 있다. 시작 시 최대치는 전체 재료의 독점 예약을 뜻하지 않는다.

결과 생성 시점을 음식의 제조 시간으로 기록하고 재접속/시간 분할이 후보 난수를 다시 뽑게 하지 않도록 회차별 난수와 완료 수를 저장한다. 서버의 공유 시간 순서 정산은 한 번에 최대128개 완료 시각 단계까지만 처리하며, 공용 캐릭터 추격도 한 번에 최대128회차다. 남은 작업은 같은 체크포인트를 저장하고 다음 틱에 이어서 진행한다.

창고는 재료를 가방으로 이동시킨 뒤 사용하는 방식이 아니다. 식품 묶음별 제조·보존 이력을 유지하여 창고에서 직접 소비하며 결과는 개인 소지품/기존 초과 보상 처리로 전달한다. 변경 저장이 실패하면 원본 창고와 플레이어 상태에 반영하지 않는다. 허가된 이용자에게만 갱신된 시설 창고 정보를 전달한다.

원시 행동 해석의 예전 수량 범위는 과거 저장 자료를 읽는 용도로 남겼다. 신규 시작에서는 다섯 재료 단위와 단일 배합을 별도로 검사한다. 예전 배수 배합을 그대로 완료할 수 없는 경우 재료를 소비하지 않고 중단하도록 하고, 프로필 전체 로딩 실패로 확대하지 않는지를 다음 검사에서 확인한다.

- `shared/fantasy-cuisine-catalog.ts`: 식재료 19종, 고정 요리 48종과 배합, 정상/해로운 자유 계열 및 세 후보의 번역 이름.
