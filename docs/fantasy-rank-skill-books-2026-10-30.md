# 昇格報酬の技能教本 — 2026-10-30

## 仕様

- 登録済み冒険者等級6で、ギルドから教本を1冊選べる。
- 聖職等級4（信仰225）で、司祭として神殿から教本を1冊選べる。
- 二つの報酬は別枠で、それぞれ一生に1回。昇格後すぐに選ぶ必要はない。転職や再接続で選択を初期化しない。
- 選択肢は現在の職業の未習得の通常技能。職業の基本技能・拡張技能・対応する通常の書籍解放技能が対象。退役技能、職業分岐、種族技能、奥義、聖者の奇跡、最後の黎明は対象外。
- 選んだ技能の `rank-manual-<skill-id>` を持ち物へ1冊追加する。重量・枠数が不足する場合は選択を確定しない。
- 対応する職業で持ち物から読むと1冊を消費して、その技能を習得する。報酬教本に限り、通常の熟練度・書籍・師匠等の解放条件を免除する。
- 別の職業ではその職業の技能を表示・使用しない。元の職業へ戻ると習得が復元される。
- 二つの報酬で同じ技能は選べない。選択後、読む前に通常の方法で習得した場合は教本を消費しないが、選択のやり直しはできない。

## 保存・検証

`character.rankBookRewards.adventurer` と `.priest` に `{ skill, book, hour, readAt? }` を保存する。各保存記録の技能・教本ID、重複、現在の人生以降の時刻、受取可能な等級を検証する。教本の読書には未読の受取記録と実際の所持数が必要。

受け取りは通常の `FantasyAction` / ストア更新を通す。サーバーの現在の状態で受取済み・技能候補・場所・職業・鞄を再確認するため、古い画面からの再送では追加報酬を得られない。

## 保留中の確認

依頼者の指示に従い、この作業ではテスト、型チェック、ビルド、シミュレーション、ブラウザー確認、レビューを実行していない。以下は後日の確認項目。

- 冒険者登録等級5/6、聖職等級3/4の境界、および戦力だけでは冒険者報酬を受け取れないこと。
- 信仰225での神殿受取、他職業・神殿外・閉館中・移動中・戦闘中・行動中の拒否。
- 両方の報酬の独立性、同じ技能の重複拒否、転職・再接続・人生更新後の扱い。
- 持ち物に教本が追加され、読むまで技能を得ず、読書で1冊だけ消費すること。
- 通常の解放条件を満たさなくても報酬教本だけで習得し、他の書籍や通常習得条件が変わらないこと。
- 古い選択肢、連打・同時受取、偽造した技能・教本・受取記録の拒否。
- 鞄の重量・枠数が不足した場合に報酬枠を失わず、空きを作って再受取できること。
- アクティブ技能、パッシブ技能、装備補正、戦闘、転職後の非表示と復職後の復元。
- 韓国語・英語・日本語の選択画面、持ち物の読書、エラーと履歴表示。
