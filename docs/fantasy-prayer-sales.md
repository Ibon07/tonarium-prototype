# 기도와 상태별 판매

기도는 신전에서 누구나 할 수 있으며 게임 0.5시간, 즉 고정 세계 시간 속도에서 실제 1분이 걸린다. 완료한 세계 날짜에 하루 한 번만 기록한다. 사제는 직업 숙련도 3을 얻고, 이전 범죄로 악명이 있으면 최대 2만큼 줄어든다. 악명은 0 미만으로 내려가지 않는다. 범죄 직업이라는 이유만으로 별도의 돈이나 평판을 지급하지 않는다. 일반 기도도 같은 일일 제한을 사용한다.

날짜는 모든 플레이어가 공유하는 세계 시각의 `Math.floor(hour / 24)`로 정한다. 자정을 넘겨 완료하면 다음 날의 기도로 기록한다. 같은 날의 기록이 있으면 예약 단계부터 거절하고, 완료할 때도 다시 확인한다. 기록은 저장·재접속 후에도 유지한다. 현재 일이 진행 중인 동안에는 다른 행동을 시작할 수 없는 공통 규칙도 적용한다.

판매창은 소지품의 개수와 한 개의 매입가를 보여준다. 상태가 변하는 식품과 식재료만 판매창에서 신선·변화·부패 묶음으로 나누며, 일반 인벤토리 목록은 원래 수량 합계를 유지한다. 신선한 식품은 기존 기본 매입가인 정가의 절반 내림값, 상태가 변한 식품은 그 매입가의 절반 내림값을 쓴다. 판매 가능한 값은 최소 1G이며, 부패품은 0G로 표시하고 팔 수 없다.

서버는 버튼에서 전달받은 상태에 해당하는 묶음만 한 개 소비하고 같은 상태 안에서는 오래된 것부터 고른다. 상태가 다른 식품을 대신 팔지 않는다. 여러 상태가 섞였는데 상태를 고르지 않았거나, 그 사이 노화하여 선택한 상태가 없어졌다면 매각을 거절한다. 장비는 개별 식별자 선택과 착용 중 보호를 유지한다. 현재 지역에 매입할 가게가 없으면 가격은 확인할 수 있어도 매각할 수 없다.

여관·식당의 모든 식사는 게임 0.5시간, 실제 1분으로 맞췄다. 회복량·영양·가격은 기존 값이며, 세계 시각을 건너뛰거나 클릭 즉시 보상을 지급하지 않는다.

주요 코드: `shared/fantasy-prayer.ts`, `shared/fantasy-sales.ts`, `shared/fantasy-life.ts`. 검증은 `shared/fantasy-prayer.test.ts`, `shared/fantasy-sales.test.ts`, `shared/fantasy-life.test.ts`에서 일일 제한·자정·저장 재개·혼합 식품의 선택 매각·노화·착용 장비 보호·반시간 식사를 확인한다.

실제로 읽을 수 있는 도서 34권의 한국어·영어·일본어 본문은 세계 안에서 쓴 안내서와 이야기로 정리했다. 기도·작업 장부·식사 시간 안내를 새 규칙에 맞췄으며, NPC·GM·서버·버튼·현실 시간 같은 외부 설명은 넣지 않는다. 숨겨진 개발용 설정집은 서가에 노출하지 않으며, 지역별 소장 목록·완독 기록·직업 숙련과 연결된 기술 습득은 유지한다. `shared/fantasy-library-immersion.test.ts`에서 전체 본문과 실제 독서 및 기술 해금 과정을 함께 확인한다.
