# ホーム（セッション外の画面）

名前を入れて「はじめる」の後、セッションに入っていないときに出る画面。部品は `client/src/home/`。

## 画面
- **左のナビ** ホーム／フレンド／セッション／イベント／グループ／ワールド／アイテム。フレンドには未読の DM があればその数（赤）、なければオンラインのフレンドの人数、イベントには 1 週間以内のイベントの数が出る。下に所属グループの頭文字（押すとグループの画面。未読があれば赤い点）と、自分のカード（押すとステータス、歯車でプロフィール設定）
- **上** 検索（開いているページのセッション・フレンド・グループ・ワールド・アイテムを名前で絞る）、通知のベル（フレンド申請と招待。未読があると赤い点）、「セッションを作る」
- **ホーム** 先頭に「おかえり」と未読のメッセージ（[messages.md](messages.md)）。「フレンドの今」に参加できるセッションを、「参加 OK」のフレンドがいるものを先に、中にいるフレンドが多い順に並べる。カードの下には、残っているアイテムのひとこと（盤面が途中など）と次のイベントが出る。カードには人数・画面共有中・ワールド・公開範囲・中にいる人（フレンドが先。名前の横に 2D/3D/画面共有のアイコン）が出て、「参加する」で入る。「オンラインのフレンド」には参加できるセッションにいないフレンドが並び、「誘う」でセッションかグループに誘える。右の「イベント」には今週のカレンダーと 1 週間以内のイベント
- **フレンド** 左にフレンド全員（オンラインが先。ステータスと未読の数）、右に選んだ相手との DM。相手のステータスに合わせて「参加する」か「行ってもいい？」が出る
- **セッション** 参加できるセッション全部。自分が作ったものは、だれもいなければ「消す」
- **イベント** 日付ごとの一覧と「イベントを作る」。「来る／たぶん／むり」で返事（押し直すと取り消し）、会場があれば「会場へ」で入る。作った人は消せる
- **グループ** 所属しているグループとほかのグループ。「入る」「抜ける」「フレンドを誘う」。作った人は消せる。名前を押すとグループの画面（チャンネル・セッション・イベント・メンバー。[messages.md](messages.md)）
- **ワールド** ワールドの種類の一覧。「このワールドでセッションを作る」
- **アイテム** アイテムの種類と説明（見るだけ。出すのはセッションの中）

## セッションの公開範囲
「セッションを作る」で名前・トピック・ワールド・公開範囲を決める。見える人は `shared/home.ts` の `canSeeSession` で決め、サーバーは見えないセッションには入れない。
- **パブリック** だれでも
- **フレンド+** 作った人のフレンドと、中にいる人のフレンド（人の出入りで見える人が変わる）
- **グループ+** そのグループのメンバーと、メンバーのフレンド（中ではゲストとして表示）
- **グループ** そのグループのメンバー
- **インバイト** 作った人と、誘われた人だけ
作った人がだれかを誘うと、その人は `invited` に入って以後ずっと見える。`sessions.json` のセッションはパブリック扱い。

## グループ・イベント・招待
- グループはだれでも作れて、一覧からだれでも入れる。メンバーはオンラインのフレンドを誘える
- イベントはタイトル・日時・グループ（任意）・会場のセッション（任意）を持ち、作った人は最初から参加者。だれでも参加表明できる
- 招待（セッション・グループ）はオンラインの相手にだけ届く通知で、ホームのベルと、セッション内の通知欄の両方に出る。「参加」「入る」でそのまま入る。フレンド申請と招待はセッションに入っても消えない

## 保存
作ったセッション・グループ（チャンネルも）・イベントは `data/home.json` に保存され、再起動しても残る（`friends.json` と同じ）。セッション内のチャットは消えるが、アイテムは `data/items.json` から戻る。サーバーは `sessions.json` のセッションの後ろに `home.json` のセッションを並べ、人ごとに見えるものだけを `snapshot` と `sessions` メッセージで送る。
