# ホーム（セッション外の画面）

名前を入れて「はじめる」の後、セッションに入っていないときに出る画面。部品は `client/src/home/`。

## 画面
- **左のナビ** ホーム／フレンド／セッション／イベント／グループ／ワールド／アイテム（最後に開いたページをブラウザに覚える）。フレンドには未読の DM があればその数（赤）、なければオンラインのフレンドの人数、イベントには 1 週間以内のイベントの数が出る。下に所属グループの頭文字（押すとグループの画面。未読があれば赤い点）、クライアントモード（[screens.md](screens.md)）、自分のカード（押すとステータス、歯車でプロフィール設定）。いちばん下（自分のカードの上）に「フィードバック」（Notion のフォームを新しいタブで開く。URL は `client/src/feedback.ts`。最初の画面の「このサイトについて」にも同じリンクがある）。セッション中のメニューから開いたときは「セッションから離脱」も出る
- **上** 検索（開いているページのセッション・フレンド・グループ・ワールド・アイテムを名前で絞る）、通知のベル（フレンド申請と招待。未読があると赤い点）、「セッションを作る」
- **ホーム** 各セクションは 1 段だけで、はみ出す分は横にスクロールし、タイトルの横の「もっと見る」でそれぞれのページへ行く。上から「フレンドの今」（→ フレンドの「フレンドの今」タブ）・「オンラインのフレンド」（→ フレンド）・「直近のイベント」（→ イベント）・「パブリックセッション」（→ セッション）・「新着ワールド」（→ ワールド）。24 時間以内に「来る」と答えたイベント（開催中も含む）があるときだけ「直近のイベント」を一番上に出す。「フレンドの今」と「直近のイベント」は出すものが無ければセクションごと出さず、ほかは「〜はありません」と出す。「フレンドの今」はフレンドがいるセッションだけを、「参加 OK」のフレンドがいるものを先に、中にいるフレンドが多い順に並べる。「直近のイベント」は開催中（始まってから 3 時間。イベントは終わりの時刻を持たないため）を先に、次に 1 週間以内のものを近い順に。イベントのカードはセッションと同じ形で、主催・来る人・「来る／たぶん／むり」・会場があれば「会場へ」。「パブリックセッション」はフレンドがいないけれど入れるセッション（見えているセッションはどれも入れる）。「新着ワールド」のカードから、そのワールドでセッションを作れる。検索するとどのセクションも絞り込まれる。カードの下には、残っているアイテムのひとこと（盤面が途中など）と次のイベントが出る。カードには人数・画面共有中・ワールド・公開範囲・中にいる人（フレンドが先。名前の横に 2D/3D/画面共有のアイコン）が出て、「参加する」で入る。「オンラインのフレンド」には参加できるセッションにいないフレンドが並び、「誘う」でセッションかグループに誘える。右の欄はタイトルのドロップダウンで切り替える（ブラウザに保存）：フレンドの今（フレンドがいるセッション。押すと参加）・イベント（今週のカレンダーと 1 週間以内のイベント）・参加できるセッション・ワールド・アイテム（セッション中は押すと目の前に出す）。グループの画面以外のどのページでも出る
- **フレンド** 「フレンドの今」はフレンドがいるセッションをホームと同じ順でカードに並べる。「すべて」は左にフレンド全員（オンラインが先。ステータスと未読の数）、右に選んだ相手との DM。相手のステータスに合わせて「参加する」か「行ってもいい？」が出る。「リクエスト」に届いたフレンド申請（承認・拒否）、「ブロック中」にブロックした人（解除）
- **セッション** 参加できるセッション全部。自分が作ったものは、だれもいなければ「消す」。セッション中は上に「参加中」のセッションと、ワールドの切り替え・離脱
- **イベント** 日付ごとの一覧（「月」でカレンダー。日を押すとその日だけ）と「イベントを作る」。どのイベントにも主催者（作った人。自分なら「あなた」）が顔つきで出る（ホームの右の欄・グループの画面も同じ）。「来る／たぶん／むり」で返事（押し直すと取り消し）、会場があれば「会場へ」で入る。作った人は消せる
- **グループ** 所属しているグループとほかのグループ。「入る」「抜ける」「フレンドを誘う」。作った人は消せる。名前を押すとグループの画面（チャンネル・セッション・イベント・メンバー。[messages.md](messages.md)）
- **ワールド** ワールドの種類の一覧。「このワールドでセッションを作る」。セッション中は「このワールドに切り替える」
- **アイテム** アイテムの種類と説明。セッション中は「目の前に出す」

## セッションの公開範囲
「セッションを作る」で名前・トピック・ワールド・公開範囲を決める。見える人は `shared/home.ts` の `canSeeSession` で決め、サーバーは見えないセッションには入れない。
- **パブリック** だれでも
- **フレンド+** 作った人のフレンドと、中にいる人のフレンド（人の出入りで見える人が変わる）
- **グループ+** そのグループのメンバーと、メンバーのフレンド（中ではゲストとして表示）
- **グループ** そのグループのメンバー
- **インバイト** 作った人と、誘われた人だけ
作った人がだれかを誘うと、その人は `invited` に入って以後ずっと見える。`sessions.json` のセッションはパブリック扱い。

## グループ・イベント・招待
- グループはだれでも作れて、一覧からだれでも入れる。メンバーはオンラインのフレンドを誘える
- イベントはタイトル・日時・グループ（任意）・会場のセッション（任意）を持ち、作った人は最初から参加者。だれでも参加表明できる
- 招待（セッション・グループ）はオンラインの相手にだけ届く通知で、ホームのベルと、セッション内の通知欄の両方に出る。「参加」「入る」でそのまま入る。フレンド申請と招待はセッションに入っても消えない

## セッションのサムネイル

セッションカードの上部には最新のサムネイルを表示する。固定セッション（`sessions.json`）とユーザー作成セッションは同じ仕組みを使う。

サーバーは 3D の参加者から、参加者一覧で先頭の接続 ID を撮影役に選ぶ。撮影役が 2D に切り替えるか退出したら、残った 3D の参加者から同じ順序で選び直す。選出直後と、その後約 3 分ごとに `thumbnailRequest` を送り、撮影役の現在の 3D 視点を幅 320px・縦横比維持で撮影する。UI と自分の一人称パーツは写さず、シャッター音・フラッシュ・通知も出さない。3D でない場合や描画の準備ができていない場合は送信せず、次の依頼を待つ。

撮影には別のオフスクリーンレンダラーを使い、撮影後に破棄する。JPEG の品質は 0.65。サーバーは撮影役からの `thumbnailUpload` だけを受け付け、MIME が `image/jpeg`、デコード後のサイズが 64 KiB 以下であることを検証する。不正な送信は破棄し、画像の内容を含めずログに記録する。受理した画像はメモリ上の最新 1 枚を置き換え、`sessionInfo.thumbnail` として全員へ配信する。

画像がまだない場合と、3D の参加者がいない場合は、`WORLD_TINT` によるワールドごとの仮画像を表示する。画像領域は常に 16:9 で、更新によってカードの高さは変わらない。参加者が 0 人になったら撮影役と画像を破棄し、仮画像に戻す。画像は再起動後には残さない。

## 保存
作ったセッション・グループ（チャンネルも）・イベントは `data/home.json` に保存され（`sessions.json` のセッションを画面から改名したときの名前も `renamed` に入る。`sessions.json` は書き換えない）、再起動しても残る（`friends.json` と同じ）。開始から 30 日以上過ぎたイベントは、起動時とイベント作成時に取り除かれる。書き込みは変更が続いても 800 ミリ秒に 1 回へまとめられる（サーバー終了時は、保留中の分も書き出してから落とす）。セッション内のチャットは消えるが、アイテムは `data/items.json` から戻る。サーバーは `sessions.json` のセッションの後ろに `home.json` のセッションを並べ、人ごとに見えるものだけを `snapshot` と `sessions` メッセージで送る。
