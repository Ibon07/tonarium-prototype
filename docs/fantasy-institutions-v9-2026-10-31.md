# 의뢰 소속·혼합 파티 보수·공헌 기록 v9 (2026-10-31)

이번 범위는 승인된 개선안 2~5번이다. 1번인 길드 복귀 제한은 추가하지 않았다. 등록 가능한 직업으로 돌아오면 과거 길드 등급과 혜택이 즉시 다시 활성화되는 기존 동작을 유지한다. 전투 주직업 1개와 생산·생활 서브직업 1개의 동시 사용도 유지한다.

## 의뢰를 받는 곳

| 소속 | 정식 수주 대상 | 수주 장소 | 실적 |
| --- | --- | --- | --- |
| 모험가 길드 | 실제 길드 등록을 마친 등록 허용 직업 | 해당 지역 길드 | 길드 의뢰 실적 |
| 신전 | 사제와 사제 세부분기 | 해당 지역 신전 | 기존 신앙·봉사 성장 |
| 뒷골목 | 범죄 분류 직업 | 지역에 실제로 존재하는 범죄 연락책 | 별도 조직 신뢰·공적 |
| 주민 부탁 | 개별 의뢰의 종족·선행 조건 등을 충족한 사람 | 실제 의뢰인이 있는 지역 | 개인 의뢰 진행 |

의뢰의 소속을 공통 판정 함수로 결정하고 서버 수주·공적·시설 화면·NPC 거래에서 함께 사용한다. 길드 등급의 기본 표시값만 있다고 등록자로 취급하지 않는다. 사제와 범죄 직업이 길드 건물에 방문하거나 가공을 맡기는 것은 막지 않는다. 이미 수주한 의뢰를 일괄 삭제하지도 않는다.

신전 의뢰 8개와 뒷골목 의뢰 16개를 추가했다. 주민·신전·뒷골목 의뢰는 실제 의뢰인과 시설을 기준으로 게시하고, 길드의 지역 의뢰 집계는 유지한다. 통상 게시물은 소속별 최대 3개를 선택하며 기존 단체 토벌의 별도 게시 규칙은 유지한다. 세계 시간 2시간 갱신, 공개 의뢰 선점, 단체 의뢰 시작 시각도 유지한다. 누가 먼저 게시판을 열었는지에 따라 전체 물량이 바뀌지 않는다. 지명의뢰는 길드 소속 의뢰만 선정한다.

## 사제와 범죄 직업의 성장

범죄 직업은 서로 다른 정식 뒷골목 의뢰를 완료하면 조직 신뢰 20과 사용 가능한 공적 20을 얻는다. 신뢰 문턱은 0·20·60·140·280의 5단계다. 보급품, 기술 서적 단서, 유물 연구 단서를 단계와 공적에 따라 일생에 한 번씩 교환한다. 단서 보상으로 특수 전직이나 기술을 즉시 주지는 않는다. 수주 기록·생애·완료 전환을 확인하므로 같은 완료 요청을 반복하거나 이전 생애의 이력으로 새 공적을 만들 수 없다. 뒷골목 의뢰 완료로 일반 마을 평판을 올리지 않는다.

사제는 기존 신전 등급과 봉사·기도·교리·순례 조건을 사용한다. 여기에 실제 플레이어 2명 이상이 참여한 승리에서 다른 플레이어를 회복·보호·구조한 실효 공헌을 추가 신앙으로 기록한다. 보통 1점, 다른 사람의 HP 회복과 피해 방지가 합계 50 이상이거나 구조가 있으면 2점이다. 세계 하루 4점, 누적 40점, 기록 최대 30건이며 작은 지원만 반복하면 30점에서 기록 한도에 닿는다. 자기 자신과 자기 소환수만 지원한 경우, 단독전, 패배, 이탈, 이전 생애, 사제 전직 이전·이후의 잘못된 증명은 제외한다. 같은 승리는 저장·재접속 후에도 한 번만 인정한다. 이 기록이 기존 전문 분기의 봉사나 교리 조건을 대신하지는 않는다.

상세 수치와 보상은 [뒷골목 의뢰](fantasy-underworld-v9-2026-10-31.md), [공헌 및 사제 봉사](fantasy-contribution-v9-2026-10-31.md)를 참조한다.

## 혼합 파티의 의뢰 정산

사용자 지시대로 직업과 무관하게 보수를 공평하게 나눈다. 정식 대표가 받은 한 의뢰의 실제 금화 총액에 완료 보너스까지 포함해 나누며, 인원별 보상을 따로 생성해 총액을 복제하지 않는다. 금화는 정수라 나머지가 생기면 차이가 최대 1G가 되도록 지급한다. 정상 의뢰 경험치는 각 참여자에게 한 번씩 온전히 부여한다. 길드 공적이나 신전·뒷골목 성장 자격은 금화 분배와 별도로 판단한다.

- 정식 대표가 수주하면 같은 파티의 현장 동료에게 동일 수주 기록을 연결한다. 종족·선행 의뢰·시설 등 참여 조건은 유지하되, 동행을 위해 직업 조건만 완화한다.
- 조사 성공 장면이나 실제 토벌 승리에 같은 장소·같은 던전 방에 있던 생애를 기록한다. 서명된 파티원은 전투 불참을 선택했어도 현장에 있었다면 의뢰 진행과 보수에 참여한다. 전투 전리품의 기존 공헌 조건은 별개다.
- 전투가 끝난 뒤 도착한 사람은 과거 승리에 끼어들 수 없다. 이전 생애·다른 파티·탈퇴한 사람·현장 증명이 없는 사람도 제외한다. 반면 참여를 마친 뒤 같은 파티로 다른 곳에 간 사람이나 부상자는 이미 번 보수를 잃지 않는다.
- 대표가 물품 제출과 최종 보고를 맡는다. 동행자의 의뢰 화면에는 공동 보수와 대표 보고를 표시하고, 독립적인 중복 보고는 막는다. 동행자는 자기 참여를 포기할 수 있다.
- 포기·탈퇴·사망·새 생애·해산 시 미정산 연결을 정리한다. 지급받지 못한 오래된 연결이 나중의 새 의뢰 수주를 막지 않는다. 대표의 유효한 개인 수주 기록은 보존한다.
- 보수·경험치·공적·완료 기록을 한 저장 작업으로 확정한다. 저장 실패 시 전원 상태를 되돌리며 재시도로 중복 지급하지 않는다. 변경된 동료 프로필도 접속 화면에 전달한다.

공동 수주 연결은 변경 후 새로 수주한 의뢰부터 만든다. 이전에 받아 둔 개인 수주를 현장 참여 증명 없이 소급해서 파티 보수로 재계산하지 않는다.

메인 이야기는 기존처럼 개인 진행을 유지한다. 이 변경으로 다른 사람의 메인 장을 자동으로 수주하거나 완료하지 않는다.

## 공헌과 경제 검사

전투 결과에 기본적으로 접힌 상세 공헌을 추가했다. 피해, 회복, MP 지원, 피해 방지, 제어, 도움, 구조를 실제 발생량으로 기록한다. 초과 피해·초과 회복·소유 소환수의 중복 합산·발동하지 않은 버프는 부풀리지 않는다. 기존 보상용 공헌 판정은 유지하며 새 수치가 보수를 차등 배분하지 않는다.

1~6인 구성으로 실제 전투 엔진 144전을 실행해 오류와 시간 초과가 없었고, 역할별 회복·보호·제어·소환수 기여가 기록됨을 확인했다. 이는 모든 직업의 목표 승률을 새로 인증한 결과는 아니다. 기존에 공개한 직업별 남은 승률 편차는 여전히 별도 조정 범위다.

경제는 각 계절 시작점에서 4인 × 14일의 실제 회계 API 시뮬레이션을 실행했다. 계절별 공유 시장 구매, 고용 NPC 생산, 판매, 임금, 세금, 부동산, 가공 수수료를 계산하고 중복 처리 137회와 초과 출금 14회를 막았다. 40,000G에서 봄·가을 38,443G, 여름·겨울 38,446G가 되었으며 수입·지출 잔차는 모두 0G다. 생산·재고·물품 소모 없이 돈이 복제되는 문제를 재현하지 않아 가격·임금 계수를 임의로 낮추지 않았다. [조건과 80행 수요표](fantasy-economy-v9-2026-10-31.md)에 범위를 남겼다.
