## 완료 — 미사용 RPG 자산·코드 정리

사용자의 최적화 요청으로 실제 참조가 끊긴 SVG160장과 생성기·렌더러3개, 이전 초상화 디자인/중간 연결 파일, 사용하지 않는 이전 상점 UI를 제거했다. 삭제 파일은 총165개이며 SVG만822,543바이트다. 현재160장 WebP와 제작 원본·프롬프트는 유지했다. RPG 모듈23개의49개 import 선언에서 미사용 바인딩을 정리하고, 이전 `MagicSlot` UI와 불필요한 계산·NPC 대화의 미사용 상태 구독을 제거했다. 현재 원형 룬 UI·한정 수량 상점·판매·제작 기능은 유지한다.

- 초상화는 래스터 연결표를 직접 사용하고, 항상 참이던 공개 플래그와 파일 확장자 판별을 없앴다. SVG 전용 테스트는 현재160명 컴포넌트 표시·신원·복식 기록 검사로 교체했다.

- 검사: 관련19/19, 클라이언트99/99, RPG UI47/47, 공유 게임 로직·픽스처1407/1407, GM·초기화·브라우저 캐시 정리38/38, `check:completion` 통과. 별도 읽기 전용 검토에서 수정할 결함이 없었다. 폐기한 SVG용 검사 대신 실제 래스터 표시·기록을 검사하므로 예전 클라이언트102건과 현재99건은 구성 차이가 있다.

## 완료 — RPG 로딩·반복 계산·서버 병목 개선

추가 최적화 요청으로 CPU 프로파일과 동일 조건의 이전/이후 코드를 측정했다. 시설별 상품을 상품마다 재구성하던 경제 저장 검증이 병목이었으며, 요청한 시설만 계산·호출 내 인덱스·시설별 허용 목록 재사용으로 개선했다. 거래 화면은 한 요청에서 재고 스냅샷·가격·판매 그룹을 재사용한다. 전역 플레이어/권한/시세 캐시는 두지 않으며 변경된 재고·날짜·할인·이동은 다음 요청에서 다시 계산한다.

- 동일 Node24·강제 GC·6회 표본 중앙값: 재고 동기화13.13→2.70ms, 거래 화면42.31→7.63ms, 경제 검증504.82→7.20ms. 상점96개와 경제 상황6개 결과가 이전/이후 완전히 같다. 강제 GC 후 유지 힙은 약28.6→27.9MB로 비슷하며 피크 RSS 변동을 큰 메모리 개선으로 주장하지 않는다.
- 보조 패널17개를 필요할 때 로드하고 전투 오류 문구·거래 전송 함수를 큰 UI에서 분리했다. 초기 RPG 추가 JS1,251,562→864,451바이트(약31% 감소), 호스트 초기 JS는 늘지 않았다. 지도와 메뉴 탐색은 유지하고 세 언어의 로딩·실패 재시도를 지원한다.
- 공유 로직1411/1411, 클라이언트99/99, RPG UI50/50, 서버 거래·권한·백업41/41, 측정 도구1/1, 도구 포함 타입 검사와 `check:completion` 통과. 별도 읽기 전용 검토에서도 결함이 없었다.
- 브라우저에서 메뉴16종·전투 조작·지연 중 인물 변경·로딩 세 언어·실제 모듈 요청 중단 후 재시도를 확인했다. 임시 확인 서버/탭은 종료했고 임시 HTML도 제거했다. 실제 기능 실행은 저장 실패·재고 선점·거래 권한 등의 서버 회귀 검사로 별도 확인했다.
- 재측정 명령: `npm run benchmark:fantasy -- --iterations=8 --output=work/qa/fantasy-performance/report.json`. 실제 계정·진행도나 외부 AI를 사용하지 않는다. 상세 설명은 [성능 기록](fantasy-performance.md), 원자료는 `work/qa/fantasy-performance/`.
- 이 수치는 로컬 Node 함수 처리 시간이며 운영 서버 네트워크/DB·AI 추론 시간을 의미하지 않는다. 운영 다중 접속·장시간 플레이는 배포 후 로그 대상이다. 기존 큰 청크 경고는 유지되며 PR391은 Draft로 유지한다.
