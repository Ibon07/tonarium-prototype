# 野営の火と野外料理

ギルドの補給品に、火口箱、煮炊き鍋、旅のフライパン、折り畳み焼き網、湯沸かし、まな板を追加する。道具は繰り返し使える。魔術師本人、またはサーバーが同じ場所の同行者として確認した魔術師がいれば、無料で火をおこせる。それ以外では火口箱と木材1個が必要になる。

野営の火は活動開始時に確定し、その場で木材を一度だけ消費する。途中で魔術師が離れても、保存した火元を後から変更しない。火をおこせなくても焚き火なしで休める。野外料理では火が必須となる。

野外料理は職業を問わず使える。肉串、焼き魚、薬草煮込み、干し肉、薬草茶の五つを用意する。既存の肉、魚、薬草、香辛料を使い、新しい水資源は追加しない。傷んだ食材は使えない。完成した食品は既存の食品ロットに記録し、保存期間と傷みを適用する。追加の肉串と焼き魚は12時間で傷む簡素な食事で、戦闘能力の強化は持たない。

料理人は料理熟練100以上で折り畳みまな板を持つ場合、煮込みと干し肉を1個多く作れる。その他の職業でも同じ料理を作れる。火と調理道具を使い、材料だけを消費する。

一覧と品目は `fantasy-outdoor-cooking-catalog.ts` に分離し、データ登録との循環参照を避ける。サーバーは `fantasyOutdoorCookingError` で条件を確認し、活動時間を進めた後に `applyFantasyOutdoorCooking` で完成品を記録する。同行魔術師の有無をクライアントから受け付けない。進行中の別活動を止める既存の制限を適用し、料理の開始で他の活動を取り消さない。

今回の作業では、依頼に従いテスト、ビルド、型検査、シミュレーション、ブラウザー確認を実行しない。
