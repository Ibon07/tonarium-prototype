# 기나긴 여정 — 현재 개발된 내용

배포 PR 준비 단계에서 최신 `develop`을 통합하고 테스트용 인생 초기화 버튼과 확인창을 제거했다. 실시간 월드 변경 시 계정 진입·복귀, 같은 계정의 여러 접속에 대한 일반 홈 표시, 다른 세션에서 사용 중인 계정 보호를 실제 WebSocket 회귀로 확인했다. 최종 판타지908·NPC159·브라우저AI92·화면95·계정33·진단34의1,321개와 기존 Tonarium 검사229개, 총1,550개가 통과했고 `check:completion`도 통과했다. 빌드는 약43.4MiB이며 서버용 AI 모델 약1.7GiB는 별도다. 실제 배포·여러 기기·장기 플레이와 AI 품질의 남은 범위는 아래 기록을 따른다.

최신 추가 작업으로 [플레이·GM/NPC 대화 기록과 운영자 조회](fantasy-diagnostics.md)를 연결했다. 기본 최대14일·64MiB의 비공개 기록에서 날짜·NPC·언어별 대화를 다시 읽고 HTML로 내보낼 수 있다. 판타지908·NPC159·브라우저AI92·클라이언트55·계정30·진단34, 총1,278개 검사와 타입 검사·별도 빌드가 통과했다. 프록시·로그 보호·저장 장애의 실제 접속 검사와 제한된 모델 재검수는 [최신 검증 기록](fantasy-predeploy-diagnostics-validation.md)에 분리했다. 아래 단계별 수치는 각각 당시 기록이다.

실제 로컬AI는12개 표본 뒤 지침을 다시 보완해 세 언어6개를 재생성했다. 질문과 무관한 정보·한국어1인칭·GM 말투는 일부 개선됐지만 추상적인 조언과 어색한 일본어가 남아 전체 품질 합격으로 처리하지 않았다. 실제 운영 동시 처리·서로 다른 기기와 장기 플레이도 후속 검증 범위다. 이번 작업의 임시 서버와 모델은 종료했고 실제 인물 저장·계정은 변경하지 않았다.

2026-10-27 기준의 구현 현황이다. 핵심 확장과 NPC 대화 개편에 이어 RPG 전용 계정·복구와 월드 저장 묶음 백업·오프라인 복원을 연결했다. NPC 대화 버전5는 일반 원문756개·불확실성 문안54개와 성향별 문장168개,137명 각각의 공개 취향·역할을 사용한다. 체감 날씨·서로 다른 시설/관계 안내와 질문 전체를 확인하는 실시간 AI 연결을 포함하며, 이 대화 단계의1,189개 회귀 검사와 타입 검사·빌드를 마쳤다. 아래의 이전 단계별 검사 수와 문안 수는 당시 완료 기록이며 이번 계정·백업 단계의 결과와 구분한다. 로컬 입구는 [게임 열기](http://127.0.0.1:3011/?rpg=1)다. 표시 이름으로 Tonarium에 접속한 뒤 판타지 월드 안에서 언어를 고르고 월드 계정에 로그인한다. 서버가 계정 소유자를 확정한 뒤에만 개인 캐릭터 화면과 AI 동의를 연다. ## 월드 계정과 저장 운영

[월드 전용 계정](fantasy-accounts.md)은 Tonarium의 표시 이름과 별도이며, 브라우저 저장소의 공통 ID를 덮어쓰지 않는다. 아이디·비밀번호로 로그인한 뒤 서버가 예약된 `fantasy:UUID` 소유자를 확정해야 개인 진행·물품·대화·부동산에 접근한다. 다른 기기에서도 같은 계정으로 이어 할 수 있고 새 로그인은 이전 로그인 세션을 무효화한다. 계정 생성·복구 때만 보여 주는 복구 코드를 보관하고, 계정 화면에서 비밀번호·복구 코드 변경과 로그아웃을 할 수 있다. 계정 변경이나 인증 상실 때 이전 소유자의 개인 화면과 대화·처리 중 요청을 비운다.

기존 브라우저 ID는 소유권 증명이 아니므로 예전 캐릭터를 자동으로 가져오지 않는다. 당사자를 확인한 운영자가 서버를 멈추고 이전 도구의 기본 읽기 전용 계획을 확인한 뒤 명시적으로 적용한다. 이 과정에서 원장을 백업하고 기존 RPG 소유 참조를 예약 소유자 ID로 함께 옮긴 다음24시간 유효한1회 연결 코드를 발급한다. 사용자는 아직 캐릭터가 없는 새 계정의 ‘이전 캐릭터 연결’에서 코드를 사용한다. 다른 인물과 병합하거나 이미 소유된 캐릭터를 가져오지 않는다.

[월드 저장 백업과 복구](fantasy-backups.md)는 최근24개와 날짜별 최신14일의 스냅샷을 보관한다. 시작·정상 종료와 실행 중5분 간격의 변경된 묶음 백업, 저장 변경 전 보존, 파일 지문·JSON 형식 확인, 오프라인 복구 계획과 적용, 중단된 복구의 되돌리기를 제공한다. 복원할 때는 스냅샷의 계정·소유자·비밀번호 및 복구 코드 해시를 유지하고 로그인 세션과 이전 캐릭터 등록 코드 목록만 비운다. 복구 후 사용자는 다시 로그인하며 필요한 등록 코드는 운영자가 새로 발급한다. 같은 호스트·프로세스 네임스페이스의 중복 서버는 운영 잠금으로 막고, 컨테이너의 비정상 종료와 볼륨 관리 절차는 운영 문서에 따로 정리했다.

실제 여러 PC의 장시간 멀티플레이·공유 AI 처리량과 RAM/VRAM·실제 모델의 세 언어 자유 답변·장기 플레이 밸런스는 남은 검증 범위다. 계정·백업 기능이 이 실측과 최종 플레이 검수를 대신하지는 않는다.

이번 계정·백업 단계에서는 판타지905개·NPC145개·브라우저AI92개·클라이언트55개·계정/백업/이전30개, 총1,227개 자동 검사와 타입 검사·빌드가 통과했다. 실제 HTTP·WebSocket과 임시 저장으로 기기 변경·인증 폐기·동일 계정의 서로 다른 Tonarium 이름 간 친구/DM 분리·복구/이전을 확인했다. 외부 Kokosync 서비스 검사는 설정을 켜지 않아 건너뛰었고 실제 여러 PC나 모델의 속도를 측정하지 않았다. 원본 플레이 저장은 그대로이며 실제 계정 생성이나 소유자 이전도 실행하지 않았다. 이전 해시 자산을 보존하고 최종 빌드를 로컬 실행 폴더에 반영했으며 관련9개 로컬 포트는 모두 닫혀 있다. 결과는 [계정·저장 운영 보고서](../work/qa/world-accounts-complete.json)에 있다.

계정·백업 단계 이후 실제 브라우저26항목, 인증한6인 파티와1,200명령 부하, 운영 복구10단계, 실제 외부 Kokosync 연결, 기존 고룡 방식200전을 추가로 확인했다. GM 상태 질문의 한국어 표현과 세 언어 접근성 이름도 수정해 빌드에서 다시 확인했다. 대화 회귀38개·클라이언트55개·NPC147개와 타입 검사·빌드가 통과했으며, 각 검사 집합은 겹치므로 이전 전체 검사 수에 합산하지 않는다. 상세 증거와 실제 모델·물리적 다중 PC·장기 플레이의 구분은 [추가 검증 기록](fantasy-feasible-validation.md)을 따른다.

다른 검수를 종료한 뒤 메모리 여유를 다시 확인해 기존1.7B 모델도 제한적으로 실행했다. CPU2스레드·2048토큰·1슬롯에서 세 언어 NPC/GM9응답이 완료됐고 전체 응답은 약7.1~13.6초였다. 질문 누락이나 설정과 다른 날씨가 실제 표시 답변에도 있어 자유 생성의 정확성·자연스러움은 미통과로 남겼다. 준비된 정보 응답과 전송 기능의 통과와 구분한다. 운영 규모·브라우저 GPU·긴 문맥·동시 처리의 성능을 보장하는 수치는 아니다.

## 세부 전직과 발견

[세부 전직149갈래](fantasy-job-advancement-candidates.md)는 목록만 있는 제안에서 실제 선택·시간 예약·저장·기술 사용으로 연결했다. 사제 외145갈래의 전용290기술과 사제4갈래의 전용8기술을 합쳐298개다. 패시브와 액티브의 효과는 갈래에 맞는 판정·제작·방호·회복·조준 지원·공격 등에 나뉘며, 기존 공통 기술370개와 별개로 센다. 종족·멘토·마나·합성마법 기술을 이668개 합계에 다시 넣지 않는다.

전직 단서는 새 전직 교본을 만드는 대신 기존34권의 이야기·생활·무예·기록 본문에 숨겼다. 독서 예약만 해서는 갈래를 발견하지 않으며, 실제1게임시간의 독서를 마친 뒤에 해당 갈래를 알게 된다. 발견한 갈래만 전문 분야 선택창에 나타나고, 발견만으로 그 기술을 자동 지급하지 않는다. 기존에 선택해 저장한 분야는 새 단서 책을 읽지 않았더라도 표시와 사용을 유지한다.

이미 직업이 있으면 현지 길드·신전 화면은 현재 직업과 발견한 전문 분야를 먼저 보여 준다. 다른 기본 직업은 맨 아래 ‘직업 변경’을 직접 열어야 나타난다. 정확한 전직 수치·필수 기술·해금 방법은 화면·툴팁·GM·NPC에서 설명하거나 추측하지 않는다. 사제는 신앙과 숙련, 다른 직업은 숙련과 실제 기술 보유를 확인하지만 조건 미충족 사유는 일반적인 문장으로만 안내한다. 본인의 현재 신앙·숙련·실적과 실제 실행 비용·시간은 확인할 수 있다. 신앙 기록의 팁과 전직 조건 안내는 제거했다.

기본 직업을 바꾸어도 이전 직업의 분야 기록과 사용 숙련은 보존한다. 현재 직업에서 선택한 분야만 활성화하고, 이전 분야의 기술을 동시에 쓰거나 새 인물에게 넘기지 않는다.

기간 활동은 세계 시각의 종료 때 결과가 확정된다. 게임 1시간은 실제 2분, 8시간 숙박은 실제 16분이다. 오프라인에도 진행 중인 활동과 음식 노화는 계속되지만, 아무 활동 없이 접속하지 않은 시간에는 허기·피로를 추가하지 않는다. 대화창의 최소화·닫기·메뉴 이동은 현재 브라우저의 대화 기록을 지우지 않는다.

새로 시작하는 직업 작업은 실제30초마다 총16번 판정해 중간 사건·수입을 즉시 기록하고, 종료 때 합계와 직업 숙련을 남긴다. 작업 전체 시간은 실제8분이며 총 보상 예산도 유지한다. 같은 시점의 재접속·동기화로 보상을 중복 지급하지 않는다. 이미 진행 중인8회 방식 작업과 중간 기록이 없던 예전 작업은 각자의 방식으로 안전하게 마무리한다. 식사는 실제1분이며, 식사와 객실 버튼에 회복 효과를 표시한다. 진행 중인 활동이 있으면 다른 행동과 NPC 대화는 막고 기록·소지품·상태 열람과 GM의 상태 안내는 유지한다.

신전의 기도는 세계력 하루1회다. 완료한 날짜를 기준으로 사제는 숙련+3, 기존 악명은 최대2 감소한다. 누구든 신전에서 기도할 수 있으며 악명이0이면 더 내려가지 않는다. [기도와 판매 규칙](fantasy-prayer-sales.md), [작업 중간 기록](fantasy-work-progress.md)을 참고한다.

허기와 피로는 각각50·70·90 이상에서 판정-1·-2·-3이며 합계 최대-6이다. 18시부터 다음날6시까지는 밤이며 야외에서 조명이 없으면 어둠 보정-3과 일부 활동 제한을 받는다. 범죄 직업이 밤에 자기 직업 작업을 할 때만 어둠 보정을-1로 줄이고 판정+1을 더한다. 야간 채집·사냥의 조명 조건을 없애지는 않는다.

인벤토리 기본 목록은 이름과 수량만 보인다. 클릭하면 개별 장비의 품질·소재·보석·효과, 장착·해제, 복식·소모품·음식 관찰을 확인한다. 기본 메뉴의 긴 도움말은 줄이고 도서관 책에서 규칙을 읽도록 구성했다. 세계 설정집은 게임 내 책장에 넣지 않는다.

판매 화면에서는 상태가 다른 음식을 신선·묵음·부패별 수량과 매입가로 나눠 선택해 판다. 일반 소지품 목록은 그대로 합쳐 보이며 부패한 식품과 착용 중인 마지막 물건은 팔 수 없다. 배운 기술만 기술창에 나타나고, 기술 이름을 누르면 효과와 숙련 설명을 확인한다. 사용할 수 없는 버튼은 마우스를 올리거나 키보드로 초점을 맞추면 이유를 표시한다. 읽을 수 있는34권의 세 언어 본문에서는 GM·NPC·서버·버튼 등 세계 밖 표현을 제거했다.

플레이 화면에서 [테스트용 인생 초기화](fantasy-test-tools.md) 버튼과 확인창을 제거했다. 자동 회귀 테스트용 서버 요청은 명시적으로 활성화한 로컬 테스트 서버에서만 유지한다.

NPC는 자기 시설의 실제 객실·식사·상품·책·수업을 안내하고, 없는 객실을 물으면 인물의 말투로 바로잡는다. 자유 생성에도 같은 시설 정보를 우선 제공하며 게임·서버·설정집 등을 언급하는 대사는 인물의 말로 대체한다. 흥정 주사위와 판정값은 별도 연출과 기록에 남기고 NPC가 시스템 수치를 낭독하지 않는다. 대화창은 제목줄을 끌어 옮기고 화면 안에 유지할 수 있다. 같은 플레이어·월드에서는 닫았다 열거나 다른 NPC를 만나도 위치가 유지된다. 모바일 전체화면 배치는 유지한다. [NPC별 초상화](npc-portraits.md)는 같은 얼굴의 재색칠이 아니라 외모·복장·종족 특징을 구분한 개별 파일이다.

## 메인 의뢰의 진행과 난도

메인18장에는 수락 후 순서대로 성공해야 하는 조사48단계를 연결했다. 1~6장은 현장 채록·의뢰인과 대조의2단계, 7~18장은 현장 채록·현장 재검증·의뢰인과 대조의3단계다. 과거 방문과 일반 물품만으로는 완료할 수 없다. 물품은 조사·복원용 재료이며, 단서의 증명은 별도의 실제 판정으로 확보한다. 권장 레벨은2에서15까지, D20 목표는13에서31까지 높아진다. 수락 레벨이나 희귀 종족·특정 직업을 강제로 요구하지 않는다.

각 조사에는 흔적 관찰·분석·복원 접근이 있으며 현장에서는 민첩/체력·지능·힘/손재주, 기록 대조에서는 운/카리스마·지능·손재주(없으면 민첩)를 사용한다. 기존 기술·장비·몸 특성·피로·허기·날씨와 일시 주사위 효과도 해당 판정에 반영한다. 한 시도는 게임0.5시간, 실제 약1분이며 결과는 끝날 때만 확정한다. 실패하면 피로가4 더 쌓이고 위험한 야외에서는 부상을 입을 수 있지만 성공한 단계는 남는다. 메인 의뢰를 포기해도 확보한 조사 기록은 남아 재수락 시 이어 가며, 같은 단계의 경험치를 반복 수령할 수 없다.

기존 완료 기록과 기존 보상은 유지한다. 새 메인 완료 보상은 총2305XP, 조사48단계의 최초 성공 보상은 합계522XP다. 이미 수락한 옛 메인은 미완료 조사부터 수행하고, 옛12장 완료 인물은13장으로 이어 간다. 받은 의뢰의 접힌 ‘장 안의 세부 의뢰’와 GM 안내에서 다음 단계만 확인한다. 성공한 세부 조사의 단서는 보고 전에도 대화 지식에 들어가며, 장 전체의 결론은 보고 뒤에만 전달한다.

48단계 모두 세 언어로 현장 장면·서로 다른 세 접근·성공·실패와 재시도·확보한 증거·다음 조사 이유를 작성했다. 첫 단계 이후에는 바로 앞 단계의 증거가 있어야 이어진다. 의뢰인의 동기와 위험은 수락 후 읽고, 현장의 설명과 구체 접근은 그 장소에 도착해서 확인한다. 아직 얻지 않은 증거와 성공 장면은 미리 보여 주지 않는다. [전체 시나리오](fantasy-voyage-scenario.md)는 결말을 포함하는 별도 원고다.

결과는 실제 조사가 끝난 뒤 기록에 추가한다. ‘항해 이야기 다시 읽기’는 저장된 조사 증명과 완료 장에서 복원하므로 최근 기록100개의 제한으로 지워지지 않는다. 옛1~17장 완료 기록에 세부 판정이 없으면 확인된 사실만 회상하며, 없었던 접근법이나 시각을 만들지 않는다. 옛18장 완료만으로는 새 결말을 공개하지 않는다. GM·NPC는 직접 확인한 항해 단서를 이름으로 설명하거나 최근 단서를 정리하고, 미확인 결과를 추측해 확정하지 않는다.

서사는 미배달 편지에서 시작하는 완결형 항해로 바꿨다. 네 대륙에서 서로 다른 항법과 사람들의 사연을 잇고,17장에서 섬으로 향하는 항로를 열어18장에서 실제 도착·정체 확인·항해일지로 마무리한다. 주요 의문을 다음 장편으로 미루지 않는다.

## 대화로 행동을 요청하는 방법

NPC·GM 대화 안의 행동 버튼은 없앴다. 직업·기술·거래·이동 등을 요청하면 가능한 내용을 안내한다. 후보가 여러 개면 **이름이나 번호로 하나를 선택**하고, 다시 나온 내용·비용·시간 확인에 **“응”, “yes”, “はい”**처럼 승인해야 실행한다. 후보 선택과 최종 승인은 별개이며, 잡담에서 임의 행동을 만들거나 모르는 물건을 지급하지 않는다.

흥정도 마을 시설의 버튼 대신 **현지 NPC에게 명시적으로 요청**한다. 여관에서 “흥정하고 싶어”라고만 했다면 객실·식사 중 대상을 먼저 고르고 다시 승인한다. 승인 뒤 **D100을 한 번 굴려 주사위 값이 목표값 이하면 성공**한다. 목표는 평판과 직업 보정으로 정하며 결과에 주사위와 목표를 표시한다.

확인 대기는 **실제 2분** 동안만 유효하고, 현재 기록의 버전·위치·삶이 바뀌면 무효가 된다. 조건이 달라졌다면 다시 요청한다. **지도·인벤토리·마을 메뉴의 일반 조작 버튼은 유지**한다. 이번 변경은 대화 안의 행동 선택·확인 방식에 해당한다.

## 이전 사전 대사 버전2의 자연스러운 표현 — 2026-10-27 완료

버전2 당시NPC137명 모두 준비된 대사를 사용했다. 당시 원문은8성향 공유문안과 GM문안의648개였으며, 인물마다 별개의 대사집 전체를 새로 작성한 구조는 아니었다. 한국어·영어·일본어 원문 전체를 교열해 안부에는 안부를 직접 답하고, 감사·작별·응원에서 반복되던 번역투·추상적인 비유·불필요한 훈계를 줄였다.

첫 인사는 짧은 인사와 이름 소개를 두 문장 이내로 만들고 말투와 한국어 받침에 맞춰 조사를 고른다. 대화 중 재인사할 때는 이름 소개를 반복하지 않으며, 이를 위해 친밀도나 지식 권한을 올리지는 않는다. 모든 문장에 강제로 붙이던 관계 호칭을 제거했고, 기존의 짧은 안부 문형도 새 교열 문안으로 통합했다. 기본 신원·나이·성별·종족·직업 안내와 수업·시설·독서 안내의 조사와 정중체, 영어 관사도 함께 다듬었다.

NPC101개와 GM20개의 관련 검사, 마지막 편집 부분56개의 재확인 검사와 타입 검사·빌드가 통과했다. 이56개는 앞선 검사에 포함되는 부분을 다시 실행한 것이며 합산하지 않는다. NPC137명×세 언어의 첫 인사411개 조합과 재소개 방지·권한 유지, 준비 대사의 개인 정보 보호를 확인했다. 합성 인물의 실제 서비스288개 응답도 다시 검토했고 모델 호출·행동 제안·프로필 변경은 모두0이었다. 이번 교열의 직접 브라우저 클릭 검수는 하지 않았다.

원본 플레이 저장과 기존 해시 자산을 보존하며 로컬 코드와 빌드를 반영했다. 이미 표시된 과거 대화는 보존하고 새로 받는 답변부터 적용한다. 테스트 외 게임·AI 서버는 계속 종료 상태다. ## 이전 일반 질문의 AI 사전 대사 — 2026-10-27 완료

인사·작별·감사·안부·일반 피로·걱정·외로움·응원·가치관·여행 준비·도둑질에 대한 입장·마나 정의의12유형을 준비했다. Codex AI가 작성하고 검수한 NPC용576개와 GM용72개, 합계648개 원문이다. NPC137명은8가지 말투와 등록된 인물 정보·언어·관계에 따라 문안을 선택한다. 모든 NPC에게 각각 별개의 대사집을 생성했다는 뜻은 아니다. GM은 감정이나 플레이어의 성향을 추정하지 않는 객관적 안내체를 쓴다.

등록된 짧은 질문 전체가 일치할 때만 준비된 문안을 사용한다. ‘남의 물건을 훔쳐도 괜찮을까?’를 상품 문의로 처리하던 사례는 준비된 입장 설명으로 답한다. 가격·재고·현재 능력·진행 중인 행동·개인 기록·복합 질문·전직 조건·행동 요청은 현재 조회와 승인 경로를 유지한다. 사전 답변에는 모델·공유 기기 생성 호출이 없고 기존 대화 기록도 유지한다.

버전3은 모르는 정보 대응 → 사과·칭찬 → NPC별 취향을 추가한다. 공통 문안756개와 불확실성 문안54개,137명 각각의 고정된 음식·취미·싫어하는 것 설정을 세 언어로 제공한다. 기존 규칙 안내 전체가 AI 사전 생성인 것은 아니며, 시설·현재 상태 등에는 코드로 작성한 문장도 있다. 짧은 이름 설명은 실제 등록 설정과 본인의 발견·소유·독서 기록을 확인하고, 모르는 정보는 임의로 만들지 않는다. 일반 조언과 복합 대화는 기존 자유 생성으로 이어진다.

버전4는 NPC의 정보 안내를 자연스러운 대화체로 바꾼다. 가격·수량과 진행도 등의 표기를 실제 문장으로 풀고, 시설·수련·제작·도서·현재 소식·용어 설명·성격·전문 분야·행동 확인을 세 언어로 함께 수정한다. 실제 서버 수치와 지식 제한·승인 절차는 유지하며 GM의 안내체는 바꾸지 않는다.

버전5는 NPC의 기온 안내를 체감 표현으로 바꾸고 시설·관계·일반 대화·가격·소식·진행 안내에 직업과 성향별 관점을 강화한다. 성향 문장168개를 추가했으며 동일한 고정 문장을 모든 인물에 붙이지 않고 공개 취미·역할을 함께 활용한다. 전체 질문을 다루지 못하는 상세·복합 질문과 개인적인 추천·이유는 실제 NPC 설정으로 실시간 AI에 연결한다. 존재하지 않는 설정·미확인 시세를 임의로 만들거나 비공개 조건을 풀어 주지는 않는다. 최신 [세 언어 예시](../work/qa/dialogue-templates-preview.html)는522개 서비스 응답과 별도 검수 자료를 제공한다. 실제 플레이 인물이 아닌 합성 검수 자료이며, 실제 생성 모델은 이번 검사에서 실행하지 않았다.

가격·재고·오늘의 지역 소식·날씨·현재 행동·받은 의뢰 진행은 문장 틀만 준비하고 매 요청의 서버 상태를 결합한다. 실제 거래 묶음 가격과 수량을 시설 안내와 AI 입력에도 반영하며, 거래 정보가 없으면 가격을 추정하지 않는다. 소식은 현재 세계 날짜·지역의 공공 기록만 사용하고 NPC의 의뢰 안내는 자신이 맡긴 건으로 제한한다. NPC는 세계 안의 시간만 말하고 GM은 현실 시간도 함께 안내한다. 과거 대화와 기존 행동 승인 절차는 유지한다. 최신 비교 자료는 [응답 예시](../work/qa/dialogue-templates-preview.txt)와 [검증 보고서](../work/qa/dialogue-templates-complete.json)에 기록한다.

최종 판타지905개·NPC99개·클라이언트47개·직업/사제 화면11개·브라우저AI92개, 총1,154개 자동 검사와 타입 검사·빌드가 통과했다. NPC의14,796개 주제·언어·관계 키와 생성 없이 이어지는 대화·개인정보·동적 질문 제외를 검사했다. 별도 합성 인물로 실제 NPC/GM 서비스288개 응답을 확인해 모델 호출·브라우저 생성·행동 제안·프로필 변경이 모두0임을 확인했다. 이전 비교의 해당64행도 전후 대조했다. 화면 직접 클릭 검수는 이번 변경에서 하지 않았다.

원본 플레이 저장의 지문과 이전 해시 자산을 보존하며 로컬 실행 폴더에 반영했다. 이번에는 게임·AI 서버를 시작하지 않았으며 외부 배포나 GitHub 변경은 하지 않았다. 자료는 [읽기용 대화집](../work/qa/prewritten-dialogue-preview.txt), [세 언어 비교](../work/qa/prewritten-dialogue-preview.html), [전체648문안](../work/qa/prewritten-dialogue-catalog.json), [검증 보고서](../work/qa/prewritten-complete.json)에 있다. 등록되지 않은 표현과 상세 자유 질문은 기존 생성 경로를 사용하며, 앞서 발견한 자유 생성의 설정 날조·시설 설명 오류가 모두 해결된 것은 아니다.

전투 직업(모험가·전사·기사·창술사·궁수·정찰병·격투가·마검사·방패수·마법사·사냥꾼·사제·소환사)은 현지 길드에서 육로 호위를 배정받는다. 알려진 경로와 인접 미답 지역 범위에서 최대 기본12시간의 육로를 고르며 해상·전이문은 호위 경로에 쓰지 않는다. 배정 수락 때에는 보수가 없고, 의뢰받은 호위 동행으로 출발해 실제 도착하면 한 번 지급한다. 현재 경로 기준 이동비0G·보수3~17G이며 같은 왕복 구간은 완료 후12게임시간을 기다려 다시 배정받는다. 다른 이동수단으로 도착하면 호위 완료로 인정하지 않는다. 받은 의뢰의 호위 항목과 이동수단 선택에서 도착 후 보수와 시간을 확인한다.

시장에는 침낭·모피 침낭·방수포·경계 말뚝·기존 랜턴, 마탑에는 경보종·일회용 야영 결계부·별빛 유리등·난로돌을 판다. 침낭의 기본 피로 회복은25, 모피 침낭은33이고 난로돌은+5를 더하지만 중첩 침낭은 더하지 않는다. 경보종은 불상사 확률45%감소, 방수포·말뚝·광원은 각각10%감소로 곱해 적용하며 장비를 모두 가져도 위험은 남는다. 결계부는 야영 습격 한 번을 막고1장만 소모하며 습격이 없으면 남고 도난·소음은 막지 않는다. 여관 회복에는 야영 장비가 영향을 주지 않는다.

여행·마도·음식·재미용품24개와 제작법10개를 더해 일반 아이템165개·제작법86개다. 음식12종은 기존 유통기한·감각 관찰·상태별 매각·신선할 때의 버프 규칙을 사용한다. 고급 스튜·꼬치·푸딩의 힘/체력/운 강화는 시간제이며 상한을 넘겨 무한 중첩하지 않는다. 시장·마탑·식당 재고는 실제 해당 시설에서만 구매하고, 상점 목록은 종류별로 접고 펼치거나 이름으로 찾는다. 신규 적대 조우 포함 사건261개, 은밀정찰 포함 지형 행동29개다.


이전 메인·여행·야영 확장 당시의 검증: 판타지554개·NPC61개·화면47개, 총662개 자동 검사와 타입 검사·웹 빌드가 통과했다. 세 언어 화면은 서버를 띄우지 않은 정적 렌더로 검사했고 실제 브라우저 클릭 검수는 하지 않았다. 실제 플레이 저장 복사본의 정상 로드와 원본 파일 지문 불변을 확인했으며, 빌드를 실행 폴더에 반영했다. 개발용 게임·AI·갤러리·화면 포트3011/18081/8190/5183은 꺼진 상태다.

## 새벽너머의 항로 — 18장 완결

메인은 미배달 편지에서 시작해 네 대륙의 별길·바람 노래·나침반·조류 단서를 모으고, 경쟁 선단의 위조와 보호 안개를 넘어 미지의 섬을 찾는 항해 이야기로 전면 교체했다. 각 장은 실제 현지 인물의 의뢰와 다음 기록 보관자를 이어 준다. 17장에서 항로를 완성하면 새벽너머섬의 이름·지도·배편이 열리며, 18장에서 섬에 도착해 현장 조사3단계와 항해일지를 마무리하면 본편이 끝난다.

총18장·세부 조사48단계, 권장Lv2~15·D20목표13~31·조사당 실제1분의 난도는 유지한다. 물품은 조사 재료이며 현장 증거를 대신하지 않는다. 성공한 단서와 최초 경험치는 포기 후에도 남아 중복 수령을 막는다. 최종장은 섬에서 마무리하므로 수락항으로 되돌아갈 필요가 없다. ‘받은 의뢰’와 ‘기록’에 종료 장면을 읽는 항목이 남으며, 끝난 뒤에도 여행·생활·의뢰를 계속한다.

공개 지도에는 처음부터 최종 섬을 넣지 않는다. 17장 전에는 모든 보통 지도·인접 미답지·이동수단에서 숨기며, 이후 확인한 배편으로만 들어간다. 호박빛항의 정기선과 무료 일손 배편으로 오갈 수 있다. 무인섬이므로 여관·시장·새 상주NPC는 없다. 실제 재고와 생존 준비를 챙겨야 한다.

기존 완료 장·능력·재산·조사 단서는 보존한다. 예전18장 완료자는 섬을 직접 방문해 보상 없이 항해일지를 완성한다. 이전 장소에서 예약된 정상 최종장 조사만 안전하게 취소하며 현재 섬 예약이나 다른 활동은 유지한다. 최종 발견과 종료 장면은 실제 도착·종료 기록이 있어야 GM·NPC가 말한다. 새 삶에는 종료 성취를 넘기지 않고 이전 삶의 완료 발자취는 남긴다.

이전 항해 이야기 개편 당시의 검증: 판타지573개·NPC61개·화면47개, 총681개 검사와 타입 검사·웹 빌드를 통과했다. 18장 전체 순차 진행,17장 전 섬 숨김·17장 항로 해금, 실제 섬 도착·현지 종료, 구 완료자의 무보상 일지, 종료 전 정보 보호·종료 후 자유 플레이·저장 호환을 확인했다. 세 언어의 마지막 장·종료 기록 화면은 정적 렌더로 검사했고 실제 브라우저 클릭 검수는 하지 않았다. 기존 플레이 저장의 복사본은 정상 로드됐고 원본 파일 지문은 바뀌지 않았다. 실행 폴더에 새 빌드를 반영했으며 실제 게임·AI·갤러리 서버는 켜지 않았다.

## 파티와 인물 몰입감 보강

[파티 메뉴](fantasy-party.md)는 최대6명이다. 초대를 직접 수락하고 공동 조사·같은 목적지와 수단의 이동·전투에 각자 준비한 뒤 파티장이 시작한다. 초대와 준비는 실제2분 뒤 만료되며 비용은 본인이 부담하고 개인 조사·지도·선택은 복사하지 않는다. 최근80개 파티 채팅과 직접 기부한 물품의 공동 창고가 있고 출금은 파티장이 승인한다. 전투 중도 합류도 본인이 동의해야 한다. 서버 재시작 시 명단은 다시 만들고 미분배 기부물은 살아 있는 원래 인생의 기부자에게 반환한다. 저장한 개인 진행은 유지한다.

이야기에는 개인 선택4종·8방법을 추가했다. 미라와의 약속, 부상 운반인 구조, 리라에게 온 매입 요구, 답장·귀환 준비의 우선순위를 각자 정한다. 선택은 선택한 인물의 금화·피로에만 영향을 주며 동료에게 비용을 전가하지 않는다. 진행을 막지 않는 부가 장면이고 추가 보상은 없다. 미라·사피·리라의28가지 재등장 반응은 확인한 단계와 본인의 선택을 기억한다. 실제 방문한 인물과 이야기하거나 받은 의뢰에서 현지 반응을 펼쳐 읽고, 자신의 선택은 기록에서 다시 읽는다.

[인원별 전투 균형](fantasy-party-combat-plan.md)은 실제 참전자1~6명을 기준으로 일반·정예·보스별 HP·피해를 보정한다. 소환수·부대·관전자는 플레이어 수에 넣지 않는다. 중도 합류는 본인 동의와 현지 조건을 검사하고, 적 능력은 상향만 하며 이미 입힌 피해를 보존한다. 퇴각으로 적을 약하게 만들지 않는다. 이전 저장의 두 줄 진형과 간이 사냥 예약은 호환 규칙으로 마무리한다.

## 턴 전투와 최상급 도전

[현재 전투 규칙](fantasy-combat.md)은1~6인 개별 입력·10×8칸의 이동·벽·엄폐·사거리·시야·아군 치유·방호·소모품·퇴각과 본인 동료 최대2명의 명령을 지원한다. 몬스터58종과 사람 상대5종에 고정 기본 능력치와 개체 편차가 있다. [전체 기준 능력치](fantasy-combat-monsters.md)는 실제 등록 데이터에서 작성했다. 범죄 직업 자체로 자동 적대하지 않으며 위법 발각·명시적 충돌 같은 행위로 사람 전투를 시작한다.

메인은1·3·6·7·10·14·16·17장에 전투를 넣었다. 고룡 등 최상급4종은 본편이나 일반 사냥에 나오지 않고, 현지 장치를 조사하고 위험을 확인한 본인의 도발로만 만난다. 기존 최고 품질 장비로 첫 도전이 가능하고 희귀 소재4종·제작품6종·명예 칭호를 보상으로 둔다. 아이템은 총165개, 제작법은86개다. 새 전투는10×8칸의 이동·벽·엄폐·사거리·시야, 본인 동료 최대2명의 직접 지휘와 본인이 동의한 파티원의 중도 합류를 지원한다.
