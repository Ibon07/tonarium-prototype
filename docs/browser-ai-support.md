# 廃止したブラウザ AI 支援

NPC・GM の AI 自由会話は外部 KokoaAI に統一した。AI 支援の選択画面・設定、プレイヤー端末でのモデル取得・実行、ユ휴端末による回答生成と共有は廃止した。ゲーム言語の選択と会話履歴は維持する。

以前の WebLLM ワーカー・モデル設定・資源監視・共有ブローカー・ライブラリ依存も削除した。移行処理は既知の旧 AI 設定キー二つと既知の Qwen モデル用キャッシュ要求だけを整理し、ゲーム・アカウント・言語の保存やキャッシュ全体を消さない。ゲーム世界へ入ったときに実行する。ブラウザの保存領域へのアクセスが拒否された場合でもゲームは続行できる。

現在の構成と運営設定は [KokoaAI 会話](local-npc.md) と [配備手順](deploy.md#rpg-のサーバー-ai) を参照。環境変数は `KOKOAAI_BASEURL`、`KOKOAAI_MODEL`、`KOKOAAI_APIKEY`。キーは運営サーバーだけに保存する。接続失敗時もプレイヤー端末へ回答生成を委ねない。
