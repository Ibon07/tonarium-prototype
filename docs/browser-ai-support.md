# 브라우저 AI 대화 지원

개발 중인 **판타지 게임 월드 안에서만** 플레이어가 동의하면 NPC·GM 자유 대화를 브라우저에서 생성한다. 자신의 대화를 우선 처리하고, 별도로 공유에 동의한 유휴 기기는 같은 판타지 세션의 다른 플레이어 답변도 도울 수 있다. 작업과 결과는 중앙 서버를 거쳐 전달한다. Tonarium 공통 로그인·홈·다른 월드에는 언어 선택·AI 동의·지원 설정을 표시하지 않는다. 중앙 서버의 Qwen3 4B는 기여자 부재·기기 자원 부족·실패 시 답변을 이어받는다.

## 플레이어 조작

- 처음 판타지 월드에 들어가면 게임 언어를 고르고 아래 **네 가지 선택** 중 하나를 고른다. 공유 여부와 AI 켜기·끄기를 각각 명확히 정하며, 공유 없는 선택도 이전 설정에 맡기지 않고 켜기와 끄기를 구분한다. 기존 동의(v1)는 새 선택 전까지 본인 기기 설정만 유지하고 새 공유 권한은 꺼져 있다.
- 첫 AI 지원 동의창 안에서도 **한국어 / English / 日本語** 버튼으로 언어를 바꿀 수 있다. 동의창과 게임 전용 화면·대화에 함께 적용하며 Tonarium 전체 언어는 바꾸지 않는다.
- 선택은 이 브라우저에 저장한다. 언어 선택 옆의 **AI 지원**으로 켜거나 끈다. 한국어·영어·일본어를 따른다.
- AI 지원 체크는 본인 기기를 사용할지 정하는 설정이다. 설정 안에서 **대화하지 않을 때 다른 모험가 돕기**와 **내 질문을 다른 플레이어 기기에서 처리하도록 허용**을 각각 바꾼다. 지원을 끄면 기여는 멈추지만 도움받기 선택은 유지된다. 상태에는 실제 동작과 **다른 모험가 답변 돕는 중**, **서버 AI 사용**을 표시한다.
- 준비 중에도 기존 서버 AI로 대화할 수 있다. 별도 프로그램이나 브라우저 확장 설치는 없다.
- 끄면 진행 중인 지원을 취소하고 워커와 모델 실행 메모리를 해제한다. 실행 중인 질문은 중앙 서버로 넘긴다.
- 월드에서 나가거나 다른 종류의 월드로 바꾸면 진행 중인 지원을 취소하고 모델과 자원 감시를 해제한다. 켜기·끄기 선택은 유지하되 공통 화면에서는 다시 로드하지 않는다. 다음 판타지 입장 때 저장된 선택을 읽는다.
- 언어 설정은 판타지 전용으로 저장하며 게임 영역과 대화창에만 적용한다. 기존 게임 언어 선택은 이어받지만 Tonarium 문서 전체의 언어를 변경하지 않는다.

| 선택 | 내 기기 AI | 유휴 기기로 타인 돕기 | 다른 플레이어 기기에서 내 질문 처리 |
| --- | --- | --- | --- |
| AI 지원 켜고 서로 돕기 | 켬 | 허용 | 허용 |
| 지원 끄고 도움받기 | 끔·모델 다운로드 없음 | 하지 않음 | 허용 |
| 공유 없이 AI 켜기 | 켬·본인 대화만 처리 | 하지 않음 | 허용하지 않음 |
| 공유 없이 AI 끄기 | 끔·모델 다운로드 없음 | 하지 않음 | 허용하지 않음·서버만 사용 |

**공유 없이 AI 켜기**는 본인 기기와 서버만 사용하며, 기기 자원이 부족하면 서버가 답변한다. **공유 없이 AI 끄기**는 본인 기기와 타인 기기 모두 사용하지 않고 서버만 사용한다. 두 선택 모두 타인에게 질문을 전달하지 않는다.

## 모델과 다운로드

1.7B에서 실제 한국어 답변의 의미·문장 오류가 반복되어, 더 큰 모델 비교 후보로 **Qwen3-4B-q4f16_1-MLC**를 적용한다. 브라우저용 4비트 MLC 형식이며 서버의 GGUF 파일을 재사용하지 않는다. 서버도 공식 Qwen3 4B Q4_K_M을 사용한다. 기존 0.6B·1.7B 동의는 새 모델의 다운로드·공유를 허용하지 않으며, 새로운 용량 안내에서 다시 선택해야 한다.

- 실행 엔진: `@mlc-ai/web-llm` **0.2.86**에 고정.
- 공식 모델 저장소: <https://huggingface.co/mlc-ai/Qwen3-4B-q4f16_1-MLC>
- 모델 revision: `a5c9fab855e3ccbdfed2e7e69683d75f30332161`.
- 고정 저장소 파일 합계: **2,279,167,154바이트**, 약 **2.28GB**. 실행 WASM은 별도 약 **7MB**이며 전송 부가 비용은 달라진다. 모델과 실행 파일을 받을 때 용량을 안내한다.
- 공식 WebLLM 카탈로그 GPU 메모리 추정: **3431.59MB**. 안내에는 약 3.5GB로 표시한다. Tonarium의 실측값이나 전체 브라우저 메모리 상한이 아니다.
- 문맥 4096토큰, 브라우저 출력 최대 160토큰, 생각 모드 비활성화. 실제 토큰화·기기 성능에 따라 처리 시간이 달라진다.
- 브라우저가 공식 Hugging Face 저장소에서 가중치를 직접 받으며 MLC 공식 배포에서 모델 실행 WASM을 받는다. 질문을 이 다운로드 제공자에게 AI 생성 요청으로 보내지는 않는다.

## 처리와 서버 권한

1. 플레이어의 질문은 기존처럼 중앙 서버에 도착한다.
2. 서버는 간단한 규칙 질문·직업 확인·흥정 승인 등을 먼저 처리한다. 규칙 답변은 모델에 보내지 않는다.
3. 준비된 본인 기기를 우선 선택한다. 본인용 문맥에는 해당 플레이어에게 허용된 설정·현재 상태·짧은 대화 기록이 들어가며 다른 기기용 문맥과 분리한다.
4. 본인 기기를 사용하지 않는 요청자가 도움받기에 동의했고 공개 문맥만으로 답할 수 있는 질문이라면, 같은 판타지 세션의 동의한 유휴 기기 한 곳에 별도 공개 요청을 보낸다. 기기 답변은 일회용 식별자로 서버에 돌아온다.
5. 서버는 연결·요청·기한·본문을 확인해 대화를 한 번만 기록한다. 브라우저 대사는 게임 판정이나 보상이 아니다.

타인에게 보내는 요청은 공개 NPC 프로필·공개 사실 또는 일반 GM 안내와 현재 질문 한 건으로 새로 만든다. 개인용 메시지·이전 대화·캐릭터 이름·능력·소지품·개인 의뢰·조건부 NPC 지식은 복사하지 않는다. 짧은 공개 잡담·위로·가상 이야기·농담과 기초 개념을 우선 지원하고, 식별정보·개인 상태·이전 기록·게임 행동 요청에는 공유 후보를 만들지 않는다. 필요한 개인 문맥이 있는 대화는 본인 기기나 서버에서 처리한다.

질문 원문과 공개 문맥은 처리하는 플레이어 기기에서 열람할 수 있으므로, 도움받기 허용 전에 이 점을 안내한다. 상대방 식별자·원래 요청 식별자는 기여 기기에 보내지 않는다. 받은 브라우저 문장은 신뢰되지 않은 대사이며 골드·아이템·직업·퀘스트·주사위 결과는 기존 서버 규칙만 변경한다. JSON 행동·도구 호출은 실행하지 않고 `browser` 출처를 붙인다.

연결마다 한 개의 생성만 빌려주며, 브라우저 답변 기한은 20초다. 중단·오류·만료 시 중앙 서버 생성으로 돌아간다. 일회용 lease와 실행 epoch를 확인하므로 재배정 후 도착한 늦은 응답, 중복 응답, 다른 연결에서 보낸 응답은 채택하지 않는다. 캐릭터·위치·진행 revision·참가 상태가 바뀐 오래된 질문은 대화 기록에 합치지 않는다.

한 요청은 본인 기기 또는 기여 기기 중 한 곳만 시도하고 실패하면 서버로 돌아간다. 기여자 선택은 순환하며, 모델 준비·자원 상태·빈 생성 슬롯·새 공유 동의·동일 세션·본인 대화 비활성을 모두 확인한다. NPC 대화창이 펼쳐져 있거나 GM 메뉴가 열려 있으면 기여하지 않는다. 최소화·닫기·다른 메뉴 이동 후 본인 처리도 끝났을 때 다시 가능해진다.

본인 질문이 들어오면 기여 작업을 취소하고 짧은 예약과 처리 중 표식으로 본인 요청을 우선한다. 취소 완료와 새 준비 알림 전에는 기기를 재배정하지 않는다. 질문자의 동의 철회·퇴장·새 인생, 제공자의 중단·기기 부족·퇴장·연결 종료도 작업을 취소하며, 늦은 결과는 채택하지 않는다. 공유 작업 종료 후 워커의 대화 상태도 정리한다.

## 자원 보호

브라우저에서 정확한 CPU/GPU 사용률과 여유 RAM·VRAM을 항상 읽을 수는 없다. 다음의 이용 가능한 신호만 사용한다.

- 화면 프레임 간격과 이벤트 루프 지연.
- 지원되는 브라우저의 긴 작업 관측.
- 선택적으로 제공되는 `navigator.deviceMemory`와 JS 힙 사용 비율. 둘 다 전체 기기의 실시간 여유 메모리를 뜻하지 않는다.
- 페이지 표시 상태, 온라인·게임 서버 연결, 실제 WebGPU 준비·GPU 오류.

AI 지원을 켠 선택과 실제 기기 사용 가능 여부를 분리한다. 준비 완료 시점과 매 생성 요청 직전에 신호를 새로 확인한다. 알려진 기기 메모리가4GB 이하라면 모델을 내려받지 않고 서버를 사용한다. JS 힙 사용 비율이85% 이상이면 모델을 해제하고,75% 이하로 내려온 뒤에만 안정 상태를 확인하기 시작한다. 이는 전체 기기의 실시간 여유 RAM을 직접 측정한 값은 아니다.

표시 중인 화면이8FPS 미만이거나 이벤트 루프 지연·긴 작업이1초 이상이면 즉시 중단·해제한다.28FPS 미만 등의 부하가3회 연속 관측될 때도 모델을 해제해 자원을 돌려준다. 성능·메모리 압박 뒤에는 최소45초의 재개 대기와25초의 안정 상태를 확인한다. 잠깐 다른 탭을 보거나 최초 접속했다는 이유만으로 이 긴 성능 대기를 적용하지 않는다. 숨겨진 페이지는 즉시 연산을 쉬며60초 이상 숨겨지면 모델을 해제한다.

성능의 3회 연속 판정은 서로 다른 1초 관측만 센다. 대화창 열기·준비 완료·작업 수신이 같은 관측을 다시 확인해도 횟수를 늘리지 않는다. 페이지를 다시 표시하거나 복원할 때는 프레임·이벤트 루프 측정과 타이머를 새로 시작하여, 숨겨진 시간이나 복원 직후의 짧은 구간을 화면 정지로 잘못 세지 않는다. 실제로 표시 중인 화면의 심한 정지와 지속적인 부하, 메모리 보호는 유지한다.

단순한 비활성 탭·연결 대기 등 짧은 휴식 뒤에는 남아 있는 모델을 재개할 수 있다. 해제 후 자동 재다운로드는 최초 준비를 포함해 세션당 두 번으로 제한한다. 이후에는 명시적인 재시도만 허용하여 무한 다운로드·로딩을 막는다. 사용자가 끈 지원은 자동으로 켜지지 않는다. TypeError로 보고된 메모리 할당 실패도 입력 오류와 구분해 GPU·메모리 실패로 처리하고 모델을 해제한다. GPU 오류는 반복 재시도하지 않고 서버 경로를 사용한다.

자원 부족을 감지하면 현재 요청의 브라우저 준비 상태를 즉시 철회한다. 서버는 대기 중인 기기 작업을 취소하고 같은 질문을 서버 모델로 이어서 처리한다. 이후에 도착한 기기 답변은 폐기하며 한 번만 대화를 기록한다. 동의 선택은 켜진 채 유지하고 화면에는 한국어·영어·일본어로 “서버 AI 사용” 상태를 표시한다. 인터넷·게임 서버 자체가 연결되지 않은 경우에는 연결 대기 상태를 표시한다.

WebGPU·shader-f16·안전한 실행 환경과 탭 간 Web Locks를 사용할 수 있어야 브라우저 지원을 준비한다. 4B의 큰 텐서를 처리할 수 있도록 어댑터의 `maxBufferSize`와 `maxStorageBufferBindingSize`가 각각 1GiB 이상인지 WebLLM 초기화·다운로드 전에 확인한다. 이 수치는 여유 VRAM 측정값이 아니다. 다른 탭이 지원을 맡고 있으면 새 모델을 동시에 로드하지 않는다. 비호환 환경은 서버 AI로 동작한다.

서버 경로도 실제 추론 서비스가 실행되어 있어야 한다. 표준 Compose의 모델 준비·CPU 추론 서비스와 운영 점검은 [서버 AI 배포 절차](deploy.md#rpg-のサーバー-ai)를 따른다. `서버 AI 사용`은 전환 경로 표시이며 서버 모델이 정상임을 확인한 결과가 아니다.

## 캐시와 메모리 수명

모델 준비가 끝나 실행 메모리에 올라오면 선택 모델의 가중치·토크나이저·설정·WASM을 담은 CacheStorage 항목을 삭제한다. 현재 4B와 이전 Tonarium 0.6B·1.7B 지원 모델의 정확한 공식 URL만 관리하며 게임 데이터나 다른 모델의 캐시는 지우지 않는다. 시작 정리는 다운로드나 WebLLM 초기화 없이 실행한다.

정상 종료는 모델 unload 응답과 캐시 정리를 기다린 뒤 워커를 종료한다. 멈춘 다운로드나 워커는 1.5초의 정리 유예 뒤 강제 종료하고 정리 표시를 남긴다. 강제 종료 뒤 비동기 삭제가 반드시 끝났다고 보장하지 않는다. 다음 접속·다음 준비 때 탭 소유권을 얻은 상태에서 다시 정리한다. 브라우저나 운영체제의 HTTP·드라이버 캐시까지 완전히 지운다는 뜻은 아니다.

준비 후 저장 캐시를 지우므로 다시 켜거나 새로 준비하면 모델을 재다운로드할 수 있다. 이 정책은 동의 화면에도 표시한다.

## 검증

4B 변경은 공식 메타데이터·토크나이저·실행 WASM의 호환성, 이전 모델 동의로 다운로드하지 않는 점, GPU 선행 조건과 이전 모델의 준비 알림 거부를 자동 검사한다. 이 변경 과정에서 사용자 PC에 4B를 내려받거나 로드하지 않았다. 아래 2026-10-25의 실제 브라우저 속도는 이전 1.7B 측정이며, 4B의 실제 GPU 생성 속도·품질 검증은 별도로 필요하다.

캐시 URL 범위·미동의 무추론·실행 수명·중단·재개·자원 힌트·재다운로드 제한·오래된 lease·서버 복귀를 자동 테스트한다. 임시 게임 서버와 여러 WebSocket 연결에서 본인 우선·공개 문맥 분리·동일 세션의 유휴 기여·동의 철회·위조/중복/늦은 결과 차단·중단 후 서버의 단일 답변을 검증한다. 모델 생성은 검사용 응답으로 대체하며 실제 다중 기기의 생성 속도와 배포 환경 부하는 별도 확인 대상이다.

공유 기능의 최종 검수에서 브라우저AI90개·화면45개, 총135개 검사와 타입 검사·웹 빌드를 통과했다. 실제 클라이언트 제어기와 서버 배정기를 직접 연결해 공유 시작·반복 상태 확인 중 작업이 유지되고 본인 대화 시작 때만 취소되는지 확인했다. 분리된 테스트 화면에서 새 공유 동의와 도움받기 전용 선택, 세 언어의 설정을 확인했으며 모델은 내려받지 않았다. 동의 화면은 `work/qa/shared-ai-consent.png`, 도움받기 설정은 `work/qa/shared-ai-receive-settings.png`에 보존한다. 실제 여러 PC의 생성 성능은 업로드 후 검증한다.

검증 명령은 `npm run typecheck`, `npm run build -- --outDir ../work/fantasy-vnext-dist`, `npm run test:browser-ai`, `npm run test:fantasy`, `npm run test:npc`, `npm run test:client`다. 브라우저 지원 38개·판타지 444개·NPC 41개·클라이언트 24개로 총 **547개 테스트**가 통과했다. 이탈한 세계의 오래된 생성 결과는 버리고, 다시 참가한 뒤의 문맥에도 섞이지 않는 것을 실제 WebSocket으로 확인했다. 판타지 밖에서의 지원 준비 광고도 거부하고 홈 NPC는 중앙 서버로만 응답한다. 자원 압박·GPU 실패·강제 종료는 주입한 신호와 가짜 워커로 재현하며, 실제 하드웨어를 과부하 상태로 만들지는 않았다.

배포 빌드의 신규 브라우저에서 Tonarium 로그인 → 홈 → 카페에는 언어·AI UI가 없고, 판타지로 전환한 다음 언어 선택 → AI 동의 순서로 표시되는 것을 확인했다. 게임은 영어를 골라도 문서 전체 `lang`은 원래 `ja`로 유지되고 게임 영역만 `en`을 사용한다. 카페로 돌아가면 게임 패널과 AI UI가 사라진다. 월드 밖의 초기화·기억된 동의로 인한 자동 다운로드 방지, 퇴장 시 작업·모델·감시 해제, 재입장 시 선택 유지도 테스트한다.

2026-10-25 별도 테스트 세이브를 사용하는 실제 브라우저에서 공식 1.7B 모델의 다운로드·준비와 한국어·영어·일본어 자유 대화를 확인했다. NPC 답변에 `browser` 출처와 정확한 MLC 모델명이 표시되었고 짧은 답변의 요청부터 수신까지 각각 약 **1.0초·0.6초·0.9초**였다. 지원을 끈 뒤에는 기존 서버 모델의 `local` 출처와 답변을 확인했다. 모델을 이미 준비한 뒤 각 언어 한 번씩 측정한 값으로 다운로드 시간은 포함하지 않는다. 긴 질문·최초 실행·다른 기기의 속도를 대표하는 수치는 아니다. 한국어·일본어에는 어색한 문장이 남아 있어 자연스러운 설정 대화의 품질까지 보장하지 않는다. 전체 RAM·VRAM 사용량은 실측하지 않았다.

별도의 배포 빌드 화면에서도 새 워커의 모델 준비 후 첫 한국어 질문은 **11.7초**, 이어진 한국어 질문은 **1.0초**로 브라우저 생성 출처를 확인했다. 첫 생성과 후속 생성의 차이는 있으나, 이 두 번만으로 GPU 준비 비용과 문맥 처리 비용을 분리해 측정한 것은 아니다. 배포 빌드의 AI 오류 로그는 없었다. 기존 Three.js의 Clock 사용 중단 예정 경고와 큰 번들 크기 빌드 경고는 남아 있다.

로컬 게임 `http://127.0.0.1:3011/?rpg=1`에 반영했다. 범위 수정 직전의 최신 저장 데이터는 `work/qa/before-world-scope-20261025-162837/`에 백업했다. 추론 측정은 `work/qa/browser-ai-data/`, 이번 로그인·월드 전환 검증은 `work/qa/browser-ai-scope-data/`의 별도 저장 데이터를 사용했다. 실제 3011 입구에서도 공통 로그인에 언어·AI UI가 없는 것을 확인했다. 테스트용 개발·미리보기 서버는 검증 후 종료하며 실제 게임 3011과 기존 중앙 AI 18081은 유지한다.
