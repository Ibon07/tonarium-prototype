# 소지품에서 가방 착용과 행동 이름

2026-10-29 구현 기록. 사용자의 명시적인 요청에 따라 테스트, 검사, 타입 확인, 빌드, 브라우저 확인을 실행하지 않았다. 아래 항목은 구현 상태이며 검증 완료를 뜻하지 않는다.

## 구현

- 가방 교체 전용 펼침 목록을 제거했다. 소지품의 가방을 클릭하면 세부 창의 **착용 / Equip / 装備** 버튼으로 착용한다.
- 착용한 가방은 세부 창에서 **해제 / Unequip / 外す**를 표시한다. 해제는 기본 배낭(20 kg / 24종)으로 돌아가며, 이 용량에 들어가지 않으면 해제할 수 없다.
- 가방 상태에는 착용 중인 가방 이름, 무게, 품목 수를 표시한다. 지역 보관품 수령 기능은 유지한다.
- 가방 착용과 해제는 결과 가방의 무게와 품목 수 한도를 모두 만족해야 한다. 기존에 초과 상태여도 새 가방의 한도를 초과하면 거절한다. 무게와 품목 초과 이유는 KO/EN/JA로 제공하고, 버튼 설명과 서버 판정에서 같은 함수를 사용한다.
- 일반 소지품 증감의 기존 초과 상태 복구 규칙은 유지한다. 가방이 같으면 초과량을 늘리지 않는 정리 동작은 계속 가능하다.
- 무기·방어구·장신구에서 이미 착용한 개체의 버튼은 **해제 / Unequip / 外す**로 표시한다. 다른 개체를 고른 경우에는 착용과 현재 장비 해제를 제공한다.
- 음식 행동은 **먹기 / Eat / 食べる**, 물약은 **마시기 / Drink / 飲む**, 그 외 사용 행동은 **사용 / Use / 使う**로 통일했다. 복식 변경과 전투 전용 아이템의 기존 동작은 유지한다.

## 수정 파일

- `shared/fantasy-bags.ts`: 공용 착용 가능 판정, 결과 용량의 절대 한도 적용.
- `shared/fantasy-bag-catalog.ts`: 소지품에서 착용하는 설명.
- `client/src/world/FantasyInventory.tsx`: 가방 세부 창 버튼, 장비 동작 이름, 음식·물약 동작 이름.
- `client/src/world/FantasyBagPanel.tsx`: 별도 교체 목록 제거, 착용 가방 이름과 안내 유지.
- `client/src/world/fantasy-inventory-actions.ts`: 사용 동작의 다국어 이름.
- `shared/fantasy-bags.test.ts`, `client/src/world/fantasy-inventory-actions.test.ts`: 미실행 회귀 사례 추가.

## 실행 대기

사용자가 검증 실행을 요청한 뒤에만 수행한다.

- 가방 테스트: 미보유 가방 거절, 무게 초과, 품목 수 초과, 기존 초과 상태에서 가방 변경 거절, 정확한 무게 한도 허용, 실패 시 원본 불변.
- 행동 이름 테스트: KO/EN/JA 음식·물약·기타 사용 이름.
- 타입 확인, 빌드, 저장소 완료 검사(`npm run check:completion`).
- 브라우저: 소지품 클릭 → 가방 착용 → 같은 가방 해제, 작은 가방으로 변경 시 사유, 음식 먹기·물약 마시기·장비 착용/해제, 세 언어 및 작은 화면 확인.

## 한계

- 테스트·검사·빌드·브라우저를 실행하지 않아 컴파일과 실제 화면 동작은 미확인이다.
- 기본 배낭은 기존 모델대로 암묵적 기본 용량이며 별도 판매 가능한 소지품으로 만들지 않았다. 착용한 가방을 해제하면 돌아간다.
- 전투 패널, 사제·다운 상태 파일 및 공유 인수인계·검증 목록은 이 작업에서 수정하지 않았다.
