# 직업별 세부 전직 후보

현재 38직업 중 무직을 제외한 37직업의 세부 전직 149갈래 목록이다. 일반 직업의 145갈래와 사제의 네 길을 실제 선택과 저장에 연결했다. 정확한 해금 조건과 방법은 플레이어에게 공개하지 않는다. 마법사의 별·화염·얼음·땅·바람 계열을 포함한다.

일반 분야는 [전문 분야 규칙](fantasy-job-paths.md), 사제의 돌봄·수호·서약·순례 네 길은 별도의 신앙 성장을 따른다. 기본 직업과 숙련은 유지하며, 종족이나 성별로 갈래를 강제하지 않는다.

## 범죄 계열 6직업

| 기본 직업 | 세부 전직 갈래 |
| --- | --- |
| 도둑 (`thief`) | 소매치기 · 침입도둑 · 함정해체꾼 · 괴도 |
| 밀수업자 (`smuggler`) | 항만밀수꾼 · 국경밀수꾼 · 위장운송상 · 암시장중개인 |
| 암살자 (`assassin`) | 단검암살자 · 독술암살자 · 그림자추적자 · 위장침투자 |
| 산적 (`bandit`) | 길목약탈자 · 산악습격자 · 해적 · 약탈대장 |
| 첩자 (`spy`) | 잠입첩자 · 정보분석가 · 암호해독자 · 이중첩자 |
| 범죄조직 두목 (`crimeboss`) | 암시장두목 · 도적길드장 · 밀수조직장 · 그림자정보망주 |

총 37개 기본 직업에 **149개 전문 갈래**를 구현했다. 무직은 현지 길드·스승·일상 사건으로 기본 직업을 얻는 흐름을 유지한다. 현재 갈래의 전문 능력만 활성화하며, 다른 기본 직업으로 바꾸면 해당 분야의 능력은 비활성화한다. 기본 생활 직업은 공동시설에서도 계속 수행한다.
