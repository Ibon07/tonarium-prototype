# 職業別の奥義紋章と演出

`FantasyUltimateEffects.tsx`は、戦闘オーバーレイの`viewBox="0 0 1000 800"`を持つSVG内で使う。共通の円に文字を入れる表示から、21職業それぞれの図形紋章と攻撃・支援の動きへ分けた。タイトルや台詞は親コンポーネントが表示する。

```tsx
<FantasyUltimateEffects
  id={skillId}
  ultimate={ultimate}
  source={{ x: sourceX, y: sourceY }}
  target={{ x: targetX, y: targetY }}
  tier={4}
  durationMs={beatDuration}
  seed={beat.id}
/>
```

`source`と`target`はタイル番号ではなくSVGの座標。キャスターに職業紋章を描き、対象へ技ごとの軌道・着弾・防護を描く。`seed`は粒の位置を同じ戦闘イベントで固定する。`tier`は1～4へ制限し、粒の数を上限12個へ収める。複数の長いトレイルを使う技でも、図形を小さなパスへまとめ、1イベント100ノード以内を想定した固定上限の構成にしている。新しいタイマーやイベントリスナーは追加しない。

`FantasyUltimateAnimation`には現在の`job`と、職業・奥義スラッグからなる安定した`sigil`を追加した。旧来の`motif`・色・記号は互換のため残すが、新しい図形の振り分けは`job`を使う。通常の技名・習得条件・威力は変更しない。基準の演出時間は通常1900ms、吟遊詩人・指導者・頭領2200ms、魔術師・召喚士2400ms。親が渡した`durationMs`を優先し、CSSの動きと遅延をその時間の割合で揃える。

| 職業 | 固有紋章 | 専用の動き |
| --- | --- | --- |
| 冒険者 | 門・山並み・短剣と道標 | 曲がる探索路から大きな門を展開 |
| 戦士 | 大剣・割れた弧・破片 | 大きな剣閃を振り抜き、裂け目と破片が広がる |
| 騎士 | 紋章盾・冠・左右の槍 | 盾と槍を下から立ち上げる |
| 槍使い | 三叉槍・巻き付く竜の線 | 直線の突きへ竜の軌道が巻き付く |
| 格闘家 | 拳・山・衝撃線 | 拳を叩き込み、山形の地割れを描く |
| 盾持ち | 六角城壁・石積み・胸壁 | 三枚の城壁が時間差で立ち上がる |
| 弓使い | 翼のある弓・矢・双星 | 五本の高い放物線と羽根の残光 |
| 狩人 | 鷹の目・照準・罠の歯 | 照準を絞り、精密射撃と罠の線を重ねる |
| レンジャー | 鹿角・葉・森の弓 | 葉の軌道が扇状に飛び、枝が伸びる |
| 斥候 | 方位針・風道 | 三本の風道を走り、方位針が回る |
| 魔剣士 | 剣・交差軌道・星 | 星の軌道と剣を回し、二重の斬撃を描く |
| 魔術師 | 六点の星座・交差術式・流星 | 巨大な星座陣と三本の流星が落ちる |
| 召喚士 | 一対の門・契約の菱形と刻印 | 左右別の展開で門を開き、契約線が繋がる |
| 吟遊詩人 | 竪琴・弦・音波 | 三本の旋律が対象へ届き、五線と音波が広がる |
| 指導者 | 王冠・中央旗・部隊旗 | 三本の旗を掲げ、命令の弧が走る |
| 盗賊 | 双短剣・鍵穴・迂回の線 | 交差斬りと消える軌道から鍵穴が浮かぶ |
| 暗殺者 | 三日月・細い刃・暗殺の印 | 月が覆う間に二重の斬線と印が現れる |
| 山賊 | 戦斧・裂けた稜線 | 斧を振り下ろし、稜線と地割れが走る |
| 密輸人 | 錨・隠れ航路・波 | 曲がる航路の先へ錨が落ち、波が流れる |
| 密偵 | 菱形の目・分断した符号 | 目が開き、左右の符号と照合線が現れる |
| 頭領 | 冠・鎖・情報網 | 網を広げ、冠と左右の鎖が降りる |

粒も職業ごとに分散距離・上下の偏り・形・数を変えている。樹木系は葉、打撃系は欠片、星や契約は菱形、射撃や旋律は光片を使う。強い点滅や画面全体の明滅は行わず、単発の描画・移動・フェードで表す。`prefers-reduced-motion: reduce`では軌道と粒を非表示にし、キャスターの固有紋章だけを静止表示する。

## 統合時の注意

- 親の旧来の`ultimate.motif`による共通紋章を、このコンポーネントへ置き換える。旧来と重ねない。
- 専用演出の寿命と渡す`durationMs`を同じ戦闘ビートの時間へ揃える。
- 成立した奥義だけを対象にし、外れ・MP不足・選択だけで再生しない。
- 三言語のタイトルと大技用の画面レイヤーは親側の責任とする。

## 未実施の確認

依頼によりテスト、型チェック、ビルド、ブラウザ確認、QAは実行していない。許可後の確認候補は、21職業の紋章・動きの区別、表示端でのクリッピング、実イベントの座標と演出寿命、連続イベントでの消去、動きを減らす設定。
