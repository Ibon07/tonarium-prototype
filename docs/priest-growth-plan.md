# 사제의 신앙 성장과 전문 분기 — 내부 개발 명세

이 문서는 개발·검증용이며 플레이어가 읽는 도서가 아니다. 전직의 정확한 수치·행동 조건·반복 제한 공식은 게임 화면·도서·GM·NPC 설명에 노출하지 않는다. 플레이어 본인의 신앙과 완료한 실적은 확인할 수 있지만, 그 기록에 전직 팁이나 공략을 덧붙이지 않는다.

사제는 기존 직업 숙련·기술 사용 숙련과 별도로 봉사, 교리 독서, 성소 순례와 서약을 기록한다. 이 기록은 실제 완료 의뢰·완독·방문과 서버가 확인한 행동으로만 쌓인다. NPC나 GM의 대사로 신앙, 새로운 신격이나 계시를 만들어 주지 않는다. 기존 치유사 저장의 사제 이전, 사제의 기본 10기술과 하루 한 번 기도 규칙은 유지한다.

## 성장 근거

| 기록 | 인정 조건 | 중복 처리 |
| --- | --- | --- |
| 봉사 | 사제·신전 의뢰 또는 약초·회복품·식량을 전달하는 등록 의뢰의 실제 보고 완료 | 같은 의뢰 ID는 한 번 |
| 교리 | 여행자 입문서, 약과 의식의 절차, 남겨 두는 말과 약속의 실제 완독 | 같은 책은 한 번 |
| 순례 | 신전이 실제 있는 서로 다른 지역 방문 | 같은 신전 지역은 한 번 |
| 서약 | 신전에서 이미 수락한 봉사 의뢰를 서약하고 실제 보고 완료 | 같은 의뢰로 서약을 반복할 수 없음 |
| 기도 | 기존 하루 한 번 기도의 실제 완료 | 세계 날짜별 한 번, 성장 근거는 최초 30일만 저장 |

기존 서버 기록에 남아 있는 완료 의뢰·완독·방문은 처음 사제 활동을 할 때 확인한다. 기도와 서약은 새 성장 규칙으로 직접 수행한 기록만 사용한다. 사제가 아닌 동안의 행동으로 새 기도·서약 실적을 만들 수 없다. 진행 중 의뢰를 포기하거나 신전에서 정직하게 서약을 철회하면 결과를 남기되 이행 점수는 주지 않는다.

신앙은 `봉사×4 + 교리×3 + 성소×2 + 이행한 서약×5 + min(기도 일수,10)`이다. 성장 단계는 신앙 0·20·45·80·130에서 높아진다. 기도만으로 분기를 열 수 없고, 같은 책·봉사·성소·서약을 반복해 점수를 얻을 수 없다.

신전 신뢰는 각 신전 지역에서 따로 계산한다. `교리×2 + 그곳에서 보고한 봉사×5 + 그곳에서 이행한 서약×8 + min(그곳 기도 일수,5)`이며 최대 100이다. 다른 신전에 가면 그 신전의 실제 현지 실적을 사용한다. 표시용 전체 신뢰 합계와 현지 신전의 분기 허가를 혼동하지 않는다.

## 첫 분기와 변경

현지 신전에서 다음을 모두 갖추면 첫 전문 분기를 무료로 선택한다. 선택 의식은 세계 1시간, 실제 2분의 활동이다. 예약 순간에는 분기나 금화를 확정하지 않고 활동 완료 때 다시 검증한다.

선택 목록에는 관련된 기존 도서의 일화를 실제로 완독해 알게 된 갈래만 나타난다. 개발용 배정은 돌봄→약과 의식의 절차, 수호→조용한 검의 첫 장, 서약→남겨 두는 말과 약속, 순례→여행자 입문서다. 전직 전용 교본이나 새 도서 목록을 만들지 않으며, 본문은 인물의 경험·서약·여행 이야기로 암시하고 수치·필수 기술 공식은 적지 않는다. 미발견 갈래를 요청해도 필요한 책의 제목이나 방법을 오류로 알려 주지 않는다. 이 책 배정은 신규 선택에만 적용하고, 기존에 선택해 저장된 분기는 새 단서 책을 읽지 않았더라도 표시·기술·사용·저장 호환성을 유지한다.

- 사제 직업 숙련 30 이상.
- 봉사 1건, 교리 도서 1권, 서로 다른 성소 2곳.
- 실제 이행한 서약 1건 또는 서로 다른 봉사 3건, 신앙 20 이상. 과거에 모든 봉사 의뢰를 끝낸 인물도 실제 완료 기록으로 진입할 수 있다.
- 현재 방문한 신전의 신뢰 10 이상.

한 번에 한 분기만 활성화된다. 변경은 첫 선택 조건에 더해 신앙45와 사제 숙련100 이상이어야 한다. 신전에서 120G를 내고 이전 선택 후 세계24시간을 기다려 변경한다. 정확한 성장 조건과 대기시간 공식은 공개하지 않고, 거래 비용과 의식 소요시간은 실행 버튼에 표시한다. 미충족 사유는 ‘아직 이 길의 인정을 받지 못했습니다’ 같은 일반 문장으로 안내한다. 기존 직업 숙련과 모든 기술 사용 숙련은 보존한다. 이전 분기의 기술은 목록에서 숨기고 새 분기의 두 기술만 사용한다. 선택 전의 임시 강화는 변경 때 끝나며, 변경으로 MP나 HP를 채워 주지 않는다. 사제에서 다른 직업으로 바꾸면 기록은 남지만 분기 기술은 사용하지 못한다. 새 변경 조건에 못 미치는 기존 분기 인물도 저장을 읽고 현재 분기와 기술을 유지한다.

| 분기 | 패시브 | 액티브 |
| --- | --- | --- |
| 돌봄의 길 | 온기 어린 손길: 위험 피해 1 감소 | 자비의 은총: MP12, HP40 회복. 전투에서는 동료 치유 가능 |
| 수호의 길 | 성소의 파수: 위험 피해 3 감소 | 서광의 방벽: MP10, 다음 위험에 방호8. 전투에서는 동료 방호 가능 |
| 서약의 길 | 약속의 증인: 지능 판정+2 | 맹세의 명료함: MP8, 다음 지능 판정+5 |
| 순례의 길 | 순례자의 걸음: 일반 이동 시간 0.25시간 단축 | 길을 지키는 기도: MP6, 다음 위험에 방호5 |

위 수치는 첫 분기 기준이다. 신앙 45 이상부터 성장 단계마다 회복 기술은+4, 방호·판정 기술은+1, 이동 패시브는+0.05시간씩 증가한다. 기존 기술 사용 숙련의 소폭 개선도 적용된다. 일반 이동의 기존 최소 시간과 전이문 고정 시간은 유지하며, 순례 기도가 랜턴·교통비·계절 대비를 대신하지 않는다. 영구 사망과 구조 규칙을 무시하는 부활은 추가하지 않는다.

전투의 자비의 은총은 생활 회복량의2배를 기준으로 최대100, 두 방호술도 생활 방호량의2배를 사용한다. 맹세의 명료함은 생활에서는 다음 지능 판정 보정이고, 전투에서는 아군의 다음 공격 명중에10%p(성장 후 최대15%p)를 지원한다. 지원은 한 번 소비하고 최대2라운드 후 만료하며 같은 효과를 중첩하지 않는다. 목표·사거리·회복 필요 여부와 실제 MP를 검사하며, 효과 없는 회복이나 이미 준비한 생활 방호를 반복해 숙련을 얻지 못한다. 순례 이동의 첫 수치를0.25시간으로 정해 유료 일반 교통의 시간 반올림에서도 실제 단축이 남게 했다. 도보의 정수 올림과 기존 최소 시간은 유지한다.

## 화면·저장·검증

사제 전용 ‘성소의 길’에서 신앙과 성장 단계를 보고, 접힌 기록·서약·분기를 열어 확인한다. 신앙 기록의 팁·해금 공식·정확한 조건 안내는 제거한다. 배운 분기 기술만 기존 기술창과 전투창에 나온다. 세 언어 안내와 일반적인 비활성 사유를 제공한다.

새 저장은 캐릭터의 선택적 `priestGrowth`에 넣고 옛 인물의 소지품·금화·직업·조사 기록은 유지한다. 신앙 점수는 별도로 임의 저장하지 않고 고유 증거에서 계산한다. 저장 검사에서 존재하지 않는 의뢰, 미완독 책, 미방문 성소, 미래의 기도, 중복 서약과 근거 없는 분기를 거절한다.

구현은 `shared/fantasy-priest-growth.ts`, 행동 완료와 예약은 `shared/fantasy-engine.ts`, 하루 기도 연결은 `shared/fantasy-prayer.ts`를 따른다. 집중 검사는 증거 중복 방지, 실제 의뢰 완료/철회, 기도만의 성장 제한, 현지 신뢰, 분기 비용·대기시간·숙련 보존, 실제 치유 사용, 예약 완료 전 미지급과 잘못된 저장 거절을 포함한다.

사제 외36직업의145갈래도 실제 선택·예약·저장과 고유290기술을 사용한다. 사제4갈래를 합쳐 전체149갈래이며, 발견과 비공개 조건·현재 직업 전용 화면은 [전문 분야 규칙](fantasy-job-paths.md), 이름 전체는 [전직 목록](fantasy-job-advancement-candidates.md)을 따른다.
