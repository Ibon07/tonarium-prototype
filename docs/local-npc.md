# NPC・GM の KokoaAI 自由会話

ゲームの生成先は外部の OpenAI 互換 API に統一した。ブラウザのモデル実行・端末間支援、自前のモデル取得・llama.cpp 推論、旧 `NPC_LLM_*` 設定は廃止した。

## 運営設定

```env
KOKOAAI_BASEURL=https://chat.kokoa.dev/v1
KOKOAAI_MODEL=lfm3-1.7b
KOKOAAI_APIKEY=<運営サーバーに保存する秘密値>
```

Coolify に保存済みなら、同名の値をアプリコンテナに渡して再ビルド・再デプロイする。標準 Compose は三変数を渡す。API キーを Git、ブラウザ、VITE_ 変数、会話本文へ含めない。キーがないと自由生成は利用できない。旧ローカルモデルやプレイヤー端末へは引き継がない。具体的な配備と旧コンテナ整理は [配備手順](deploy.md#rpg-のサーバー-ai) を参照。

## 接続

```text
プレイヤー画面 → Tonarium ゲームサーバー → HTTPS KokoaAI /v1/chat/completions
```

NPC と GM は同じ接続設定を読む。モデル ID は要求に含め、サーバーが返した有効なモデル名を画面へ届ける。URL 内の認証・クエリ・フラグメントは拒否し、リダイレクトしない。Bearer 認証はサーバーの送信ヘッダーだけに付ける。model/messages/stream/max_tokens/temperature に加え、LFM3 の思考を要求する `chat_template_kwargs: { enable_thinking: true }` を NPC・GM の両方で明示する。`cache_prompt` は送らない。KokoaAI がこの拡張を実際のモデルへ渡すかは配備後のゲーム内試験で確認する。思考を要求することと、思考本文を画面で隠すことは別である。

JSON と SSE を受信する。SSE では途中の発言を順次表示し、思考ブロックや実行命令は表示しない。入力・出力・受信量を制限し、期限は要求全体で45秒、出力上限は1536トークン。NPC と GM の要求は共有の送信枠で制限する。実際の速度・品質は外部サーバーの実行設定と負荷によって変わる。

## 世界と会話の権限

韓国語・英語・日本語の選択はゲーム画面右上に置く。AI 支援の同意・設定は表示しない。会話ウィンドウと履歴はプレイヤー・NPC・言語ごとに分け、別メニューや別 NPC に移っても混ぜない。

NPC には所属施設の品物・本・客室・料理と許可された現在情報、公開人物設定を渡す。関係・依頼条件を満たさない知識、秘密、未発見地域や詳細転職条件は含めない。インターフェースには名前・職業・地域・年齢・性別・種族を表示し、内部の性格説明・話し方・得意分野・関係一覧は隠す。GM は客観的で硬めの文体を使う。

施設への韓国語の質問では、一音節の食材名「배」「쌀」を助詞や価格・在庫の質問と区別して照合する。「배가격」「배는 몇개」も扱い、学習を尋ねる「배울 수 있어」の一部を食材名として拾わない。

確定済みの価格・在庫・現在状態などはゲームサーバーが答える。自由な質問は AI へ送る。既存の案内を生成 AI の応答と偽らない。AI の文章は報酬・職業・技・移動・判定を直接変更しない。会話で実行を提案する場合も、明示的な承認とサーバー検証が必要である。

互換性のため診断の `source: local` は「サーバー経由の生成」を表す識別子として残る。ローカルモデルを起動する意味ではない。廃止された端末支援メッセージから作業・回答を受け付けない。

## 検証

`npm run test:kokoa-ai` で三言語の JSON/SSE、Bearer 認証、設定不備、HTTP エラー、期限とキーの非公開を確認する。テスト用 WebSocket → ゲーム → HTTPS API では、NPC・GM の認証と旧端末支援メッセージの無効化も確認する。自己署名のテスト CA だけを子プロセスに追加し、TLS 検証は無効化しない。

`npm run check:kokoa-ai` は運営サーバーの環境変数から接続を検査する。`-- --generate` を付けたときだけ、実プレイヤーの記録を使わず、三言語の NPC・GM 合成質問を実際に生成する。キー・生の上流エラーは出力しない。認証エラーと文章品質の検査を区別する。

今回の作業環境から未認証の `/v1/models` は401を返した。実際の API キーは運営サーバーにだけあるため、本番の認証済み生成成功は別途確認が必要である。型・ビルド・合成応答の成功はその代わりではない。

## 過去の比較記録

[2026-10-28 の LFM3 CPU 比較](https://github.com/katteni-kaihatu/tonarium-prototype/actions/runs/40691802892/job/122828219104) は公式 Q4_K_M と llama.cpp b11938 を使った隔離実験である。思考なしは三言語・三指示条件・四ターンの36応答を生成した。思考ありは韓国語4応答・英語2応答の後、英語の回想要求が90秒で時間切れとなり、日本語へ進まなかった。全文脈でも話者・文法・記憶の問題があった。

特定の量子化・CPU 実行構成の結果であり、KokoaAI の実行構成・速度・品質と同じとは断定しない。旧 Qwen/ローカル LFM3 の実行・取得・CI スクリプトは撤去した。モデルの生成成功と、NPC として自然で設定を守る品質とは分けて評価する。
