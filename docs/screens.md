# 画面と基本操作

## 入る・出る
- 名前を入れて「はじめる」→ ホーム（[home.md](home.md)）でセッションの「参加する」を押すと入って通話につながる。ドックの切断ボタン、またはメニューの「セッションから離脱」でホームに戻る
- セッション中は左上のメニューボタンにホバーするとホームの左メニューが出て、押すと最後に開いたページを、背面のセッションを暗くぼかした上にシートで開く（Esc か背面のクリックで閉じる）。シートの中ではセッションカードが「移動する」になり、ワールドのページで選ぶといまのセッションのワールドを切り替えられる（確認とカウントダウンあり）。アイテムのページからは「目の前に出す」
- クライアントモード（左メニュー）：セッション中は 2D⇔3D の切り替え。セッションの外では次に入るときのモードを選ぶ（ブラウザに保存）。VR は準備中
- マイクのミュートは未接続中でも切り替えられ、次に入ったセッションで反映される
- 参加画面ではマスコットの tona（紫）と rimu（オレンジ）がカードの裏からのぞき、クリックや名前の入力でぴょんと跳ねる。2D/3D の切り替え中も 2 人が交互に跳ねる（画像は `client/public/brand/tona.webp`・`rimu.webp`、部品は `client/src/world/Mascot.tsx`）

## 画面
- **左：プレイヤー／アイテム** 自分から近い順に「すぐそば（〜3m）」「声が届く（〜15m）」「とおく」に分けて並ぶ。ついていっている人は相手の下にぶら下がる。近づいている人はうっすらオレンジ、離れていく人はうっすら水色に光る。行をクリックでプロフィール、… で操作（そばにいく・ついていく・つんつん、アイテムは手に持つ・ウィンドウを開く・しまう など）
- アイテムの「出す」で所持アイテム（全種類）から選んで「目の前に出す」。カメラは 3D でのみ出せる
- **上：顔** 2D でウィンドウを何も開いていないときは、自分・すぐそば・声が届く人を画面中央にグリッドで大きく並べる。ウィンドウがあるときや 3D では上に、自分と、すぐそばの人を大きく（最大 4 人、発話中は緑の枠、直近 30 秒の発言を吹き出しで表示）、声が届く人を小さく（最大 3 人＋人数）。3D アバターの胸から上を描く（全員分を 1 枚のキャンバスで描いている。`client/src/world/Portraits.tsx`）。たたむと人数だけになる。左右のパネルを開閉しても位置は変わらない。顔を押すと、その人をウィンドウとして中央に大きく出す（プロフィールは顔の右上の「…」から）。つんつんされた人のタイルには指でつつく演出が出て、本人には音が鳴る
- **右：通知・ログ／メッセージ** 上のタブで切り替える。通知・ログ：通知（つんつん・ハンマーで叩かれた・フレンド申請・セッションやグループへの招待・「行ってもいい？」・来たら知らせる。最新のアナウンスは上に固定）、ログ（チャットと入退室などのできごと。開いたときは一番下から表示し、一番下を見ている間は新しいログや画像の読み込みに合わせて追従する。上にスクロールして読んでいる間は動かない）。送信範囲は「声の範囲」（送った時点で 15m 以内にいる人だけに届く）・「全体」・「アナウンス」（誰でも送れる）。メッセージ：DM とグループのチャンネルにセッションを離れずに返信できる（[messages.md](messages.md)）
- **セッション名** 左上の歯車（セッションの設定）でだれでも変えられる。全員に反映され、ログに出る（40 文字まで）
- **下：ドック** マイク、画面共有、サウンドボード（近くの人に聞こえる。距離で小さくなる）、ウィンドウの「カンタン／フリー」、切断（2D/3D の切り替えは左上のメニューのクライアントモード）
- 2D/3D の切り替えには 1〜2 秒の疑似ローディングが入る。長さはプロフィール設定の倍率（なし〜×3。端末に保存）で変えられる
- ログに貼った URL はリンクになり、OGP（タイトル・説明・画像）のカードが出る。開くときは確認が出て、新しいタブで開く。OGP はサーバーが取りに行く（`/ogp`。ローカル・プライベートなアドレスには行かない）
- 左と右のパネル、上の顔はたためる（ブラウザに保存）

## ウィンドウ
- 画面共有・カメラのライブ・ついていく人の視点・チェス・2048・キャンバス・付箋はウィンドウで開く。タイトルバーに「閲覧中」の人のアイコンが出る
- ドックで「カンタン」（既定。いちばん新しく開いた・押したものを大きく表示し、ほかは下に小さく並ぶ。小さい方を押すと入れ替わる）と「フリー」（重ねて表示・タイトルバーをドラッグで移動）を選べる（ブラウザに保存）
- アイテムのウィンドウの ✦（注目を集める）を押すと、ほかの人のアイテム欄のその行と 3D 空間のそのアイテムが 10 秒ほど光り、通知とログにも出る
- リストの「表示中」を押すと確認してから閉じる。画面共有は自動では開かない。リストや顔の「ライブ」を押すと開く（自分の共有も同じ）。最大化したウィンドウは前面のパネルより上に出る

## マップ（試験中）

2D の画面にマップを入れるべきか試すためのもの。プロフィール設定の「2D のマップ」で なし（既定）／2D マップ／3D マップ を選ぶ（この端末に保存）。2D で参加しているときだけ、背景に出る（`client/src/world/MapLayer.tsx`）。マップを出している間は、ウィンドウが無いときの大きい顔の並びは出さず、上の顔の帯だけにする。ウィンドウはこれまで通りマップの上に開く。

- どちらも、パネルやウィンドウの無いところを左クリックするとその場所へ歩いていく（3D の歩く速さと同じ秒速 4m。3D 空間の中に立つ。「スポーンに戻る」で戻れる）。歩いている間は目的地の印と道筋（点線）が出る。まっすぐ向かい、家具に当たったら向きをずらしてよけ、1 秒近づけなければその場で止まる。別の場所を押すと行き先が変わり、そばにいく・ついていく・スポーンに戻る・3D の人に運ばれる と歩くのをやめる。歩いている間の位置は 0.2 秒ごとに送る（`client/src/walk.ts`）。ホイールで拡大縮小、ホイールを押しながらドラッグで動かす、スペースで元の位置と倍率に戻す（ボタンなどにフォーカスがあるときのスペースはそちらの操作になる）
- 2D マップ：真上から見た図。床・家具・スポーンエリア・置いてあるアイテム・人の顔と名前、自分のまわりの「すぐそば」（3m）と「声が届く」（15m）の円
- 3D マップ：実際の 3D ワールドとアバター・アイテムを斜め上から見る。右ドラッグで角度を変えられる。天井や梁で見えなくならないよう高さ 3m より上は描かない。アバターは上からだと小さいので、頭の上に顔の目印を出す
- スマホ（タッチ端末）では「画面」タブの背景に出て、タップで移動だけできる（拡大縮小・平行移動・回転はなし）

## スマホ

最低限使える程度の対応。幅 720px 以下でスマホのレイアウトになる（`client/src/phone.ts` の `usePhone`）。

- マウスの無いタッチ端末（`touchOnly`）は 2D だけ。クライアントモードの 3D は押せず、外で 3D を選んでいても 2D で入る。スマホのブラウザは画面共有できないので、ドックの画面共有ボタンも出さない
- PWA としてインストールできる（Android の Chrome は「アプリをインストール」、iPhone の Safari は共有メニューの「ホーム画面に追加」、PC の Chrome / Edge はアドレスバーのインストールボタン）。アドレスバーの無い全画面で開く。`client/public/manifest.webmanifest` と `client/public/sw.js`。sw.js はキャッシュせず、つながらないときにだけ「接続できません」を出す。インストールには HTTPS（localhost は例外）が要る
- ホーム：左のナビは下のバー（ホーム／フレンド／セッション／イベント／グループ）。「その他」で、ワールド・アイテム・所属グループ・クライアントモード・自分のカードを含むナビ全体を下から出す。右の欄は出さない
- セッション：下のタブ「画面」（顔とウィンドウ）「プレイヤー」（プレイヤーとアイテムのリスト）「通知・ログ」で 1 つずつ全面に出す。リストからウィンドウを開くと「画面」に移る。左右のパネルはたためず、ウィンドウはカンタン表示だけ（設定は保存しない）。ドックの上のお知らせは「画面」のときだけ出す

## プロフィール・フレンド
- ステータス（参加 OK・オンライン・声かけて・取り込み中とひとこと）はホームの左下の自分のカードから変える（[messages.md](messages.md)）
- 参加画面の丸いアイコン、ホームの左下の自分のカードの歯車、セッション内の設定「プロフィールを編集」から、アイコン・3D アバター・自己紹介を設定できる。どれも名前ごとにサーバーの `data/` に保存される（再起動しても残る）。認証はないので、同じ名前を入れた人は誰でも変えられる
- 他の人のプロフィールから フレンド申請（相手の通知で承認すると成立。名前の組で `data/friends.json` に保存）、ブロック（その人の声・チャット・通知・効果音が自分に届かなくなる。ブラウザに保存）、通報（`data/reports.log` に追記されるだけ）
