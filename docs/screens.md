# 画面と基本操作

## 入る・出る
- ログイン画面の「デスクトップ版をダウンロード」から、名前の入力やログインなしで [Electron 版の配布ページ](https://github.com/katteni-kaihatu/tonarium-prototype/releases) を別タブで開ける。
- 名前を入れて「はじめる」→ ホーム（[home.md](home.md)）でセッションの「参加する」を押すと入って通話につながる。ドックの切断ボタン、またはメニューの「セッションから離脱」でホームに戻る
- セッション中は左上のメニューボタンにホバーするとホームの左メニューが出て、押すと最後に開いたページを、背面のセッションを暗くぼかした上にシートで開く（Esc か背面のクリックで閉じる）。シートの中ではセッションカードが「移動する」になり、ワールドのページで選ぶといまのセッションのワールドを切り替えられる（確認とカウントダウンあり）。アイテムのページからは「目の前に出す」
- クライアントモード（左メニュー）：セッション中は 2D⇔3D の切り替え。セッションの外では次に入るときのモードを選ぶ（ブラウザに保存）。対応する単体ブラウザではセッション内で「VR準備」→「VR開始」を選べる。操作と制限は [WebXR対応表](webxr.md) を参照
- マイクのミュートは未接続中でも切り替えられ、次に入ったセッションで反映される
- 参加画面ではマスコットの tona（紫）と rimu（オレンジ）がカードの裏からのぞき、クリックや名前の入力でぴょんと跳ねる。2D/3D の切り替え中も 2 人が交互に跳ねる（画像は `client/public/brand/tona.webp`・`rimu.webp`、部品は `client/src/world/Mascot.tsx`）

## 画面
- セッションの設定の「ワールド変更」で既存のワールド選択モーダルを開く。変更先を選び、確認画面で「切り替える」を押すと、カウントダウン後に全員のワールドが変わる。選択モーダルを閉じたり、確認画面でキャンセルしたりすると変更されない。変更待ち中は新たな変更を選べない。
- **左：プレイヤー／アイテム** 自分から近い順に「すぐそば（〜3m）」「声が届く（〜15m）」「とおく」に分けて並ぶ。ついていっている人は相手の下にぶら下がる。近づいている人はうっすらオレンジ、離れていく人はうっすら水色に光る。行をクリックでプロフィール、… で操作（そばにいく・ついていく・つんつん、アイテムは手に持つ・ウィンドウを開く・しまう など）
- アイテムの「出す」で所持アイテム（全種類）から選んで「目の前に出す」。カメラは 3D でのみ出せる
- **上：顔** 2D でウィンドウを何も開いていないときは、自分・すぐそば・声が届く人を画面中央にグリッドで大きく並べる。ウィンドウがあるときや 3D では上に、自分と、すぐそばの人を大きく（最大 4 人、発話中は緑の枠、直近 30 秒の発言を吹き出しで表示）、声が届く人を小さく（最大 3 人＋人数）。3D アバターの胸から上を描く（全員分を 1 枚のキャンバスで描いている。`client/src/world/Portraits.tsx`）。顔の描画は、グリッド・顔ウィンドウ・エモート中は通常の頻度と解像度、上に帯だけで出ているときは約 20fps・解像度 1 倍に落とし、たたんでいる間は止める。たたむと人数だけになる。左右のパネルを開閉しても位置は変わらない。顔を押すと、その人をウィンドウとして中央に大きく出す（プロフィールは顔の右上の「…」から）。つんつんされた人のタイルには指でつつく演出が出て、本人には音が鳴る
- **右：通知・ログ／メッセージ** 上のタブで切り替える。通知・ログ：通知（つんつん・ハンマーで叩かれた・フォローされた・セッションやグループへの招待・「行ってもいい？」・来たら知らせる。最新のアナウンスは上に固定）、ログ（チャットと入退室などのできごと。開いたときは一番下から表示し、一番下を見ている間は新しいログや画像の読み込みに合わせて追従する。上にスクロールして読んでいる間は動かない）。送信範囲は「声の範囲」（送った時点で 15m 以内にいる人だけに届く）・「全体」・「アナウンス」（誰でも送れる）。メッセージ：DM とグループのチャンネルにセッションを離れずに返信できる（[messages.md](messages.md)）
- **セッション名** 左上の歯車（セッションの設定）でだれでも変えられる。全員に反映され、ログに出る（40 文字まで）
- **下：ドック** マイク、画面共有、サウンドボード（近くの人に聞こえる。距離で小さくなる）、エモート、音量（[audio.md](audio.md)）、ウィンドウの「カンタン／フリー」、切断（2D/3D の切り替えは左上のメニューのクライアントモード）
- 2D/3D の切り替えには 1〜2 秒の疑似ローディングが入る。長さはプロフィール設定の倍率（なし〜×3。端末に保存）で変えられる
- ログに貼った URL はリンクになり、OGP（タイトル・説明・画像）のカードが出る。開くときは確認が出て、新しいタブで開く。OGP はサーバーが取りに行く（`/ogp`。ローカル・プライベートなアドレスには行かない）
- 左と右のパネル、上の顔はたためる（ブラウザに保存）。3D では Tab で左右のパネルをまとめてたたむ（文字の入力中は効かない）

## エモート（Web版）

- 2D・3D共通の選択画面は周囲のメニューと同じテーマで表示する。マーク・名称・説明で選べ、実行中の項目は二重の枠で示す。名称・説明は折り返し、出典ボタンの領域を確保する。狭い画面は1列に切り替わり、高さが足りなければメニュー内をスクロールできる。

- ドックの笑顔ボタンから「手を振る」「ぴょんぴょん」「しょんぼり」「ばたん」を選ぶ。同じセッションの参加者に同期し、2〜3秒で元の姿勢に戻る。再生中は次のエモートを待つ。
- 3Dではアバター自身が動き、頭上に漫画風の文字や星が出る。移動位置や当たり判定には影響しない。2Dでは通話タイル・拡大通話窓を一時的に全身が見える構図にして、動きと吹き出しを表示する。
- プレイヤーリストにはアバターとは別に、エモート名と小さなマークが出る。遠くの人はマークだけ表示する。
- エモートごとの効果音は「効果音」音量と距離に連動する。ブロードキャスト中は全員に聞こえる。個別ミュートした人の音は鳴らず、ブロックした人のエモートは表示しない。ブラウザの音声制限がある場合は画面を一度操作すると音が有効になる。
- 接続中だけ送信でき、再接続後に古いエモートを再送しない。OSのアニメーション抑制設定ではアバターの動きとズームを止め、文字とマークで伝える。

## ウィンドウ
- 画面共有・カメラのライブ・ついていく人の視点・チェス・2048・キャンバス・付箋はウィンドウで開く。タイトルバーに「閲覧中」の人のアイコンが出る
- ドックで「カンタン」（既定。いちばん新しく開いた・押したものを大きく表示し、ほかは下に小さく並ぶ。小さい方を押すと入れ替わる）と「フリー」（重ねて表示・タイトルバーをドラッグで移動）を選べる（ブラウザに保存）
- アイテムのウィンドウの ✦（注目を集める）を押すと、ほかの人のアイテム欄のその行と 3D 空間のそのアイテムが 10 秒ほど光り、通知とログにも出る
- ハンマー通知は1回目から打撃回数を表示する。同じ送信者の直前の打撃から10秒以内（10秒ちょうどを含む）にまた叩かれると、元の通知の位置と初回時刻を保って回数を更新し、未読に戻す。他の通知が間に入ってもまとめる。10秒を超えた場合や、削除・保持上限で元の通知が消えた場合は、新しい通知になる。2D・3D共通。
- リストの「表示中」を押すと確認してから閉じる。画面共有は自動では開かない。リストや顔の「ライブ」を押すと開く（自分の共有も同じ）。最大化したウィンドウは前面のパネルより上に出る
- 画面共有ウィンドウの「ラクガキを開始」で、参加者ごとに描画モードを切り替える。キャンバスと同じ6色の丸いボタンでペン色を選び、ドラッグ（タッチ操作も可）で映像に線を描く。「消しゴム」は押すたびに切り替わり、色を選ぶとペンに戻る。「全部消す」で全消去する。線の色・部分消去・全消去を同じ共有を見る参加者と同期する。カーソルには参加者名と識別色を表示する。ウィンドウのサイズや映像の縦横比が違っても、余白を除いた映像内の同じ位置に重なる。「ラクガキを終了」・ウィンドウを閉じる・退出で本人のカーソルが消え、描画は共有終了まで残る。途中参加でも消去結果を含む既存の描画を受け取る。永続保存はせず、共有終了後の別共有には描画を引き継がない。ペン色と消しゴムの選択も共有が変わると初期状態に戻る。
- 3D 内の共有ディスプレイにも描画と名前付きカーソルを表示する。描く操作は共有ウィンドウから行う。

## マップ（試験中）

操作のブラウザ回帰テストは、依存関係を用意した環境で `node scripts/verify-map-browser.mjs` を起動し、別の端末で `node scripts/test-map-browser.mjs [既存Playwrightのmodule URL] [ブラウザ実行ファイル]` を実行する。実物のMap2Dにマウス・タッチ入力を送り、OrbitControlsのpointer capture、右・中ドラッグ、キャンセル、capture喪失、左クリック・タップ、回転後の移動先を検証する。pointercancelはCDPのtouchCancelと押下後の合成イベント、capture喪失はブラウザのreleasePointerCaptureを使う。これはローカル状態の操作テストであり、複数クライアント間の同期やスマホ実機の確認は別途行う。

2D の画面にマップを入れるべきか試すためのもの。プロフィール設定の「2D のマップ」で なし／2D マップ（未保存時の既定）／3D マップ を選ぶ（この端末に保存）。2D で参加しているときだけ、背景に出る（`client/src/world/MapLayer.tsx`。両マップを `Map2D.tsx`・`Map3D.tsx` に分けて遅延読み込みする。読み込み中は背景のみ表示する。座標・移動は `mapShared.ts`、カメラは `mapCamera.tsx`、人物は `view3d/Participants3D.tsx` を共有する）。マップを出している間は、ウィンドウが無いときの大きい顔の並びは出さず、上の顔の帯だけにする。ウィンドウはこれまで通りマップの上に開く。

- どちらも、パネルやウィンドウの無いところを左クリックするとその場所へ歩いていく（3D の歩く速さと同じ秒速 4m。3D 空間の中に立つ。「スポーンに戻る」で戻れる）。歩いている間は目的地の印と道筋（点線）が出る。まっすぐ向かい、家具に当たったら向きをずらしてよけ、1 秒近づけなければその場で止まる。別の場所を押すと行き先が変わり、そばにいく・ついていく・スポーンに戻る・3D の人に運ばれる と歩くのをやめる。歩いている間の位置は 0.2 秒ごとに送る（`client/src/walk.ts`）。ホイールで拡大縮小、中ドラッグで平行移動、右ドラッグで回転と俯角変更、Space で元の視点に戻す（ボタンなどにフォーカスがあるときのスペースはそちらの操作になる）
- 2D マップ：床・地上の家具・スポーンエリア・アイテムの目印・街の線路と電車を平面で表示し、全参加者を既存設定の全身アバターと名前で表示する。自分の歩行、位置指定・追従・スポーン、3D 参加者の位置と向き、着席の配置を既存の状態から反映する。名前は人物と同じ補間位置に付ける。右ドラッグで水平回転と俯角（床を選択できる範囲）、中ドラッグで平行移動、ホイールでズーム、Space で視点を戻す。床・経路・目的地・近接／音声範囲・湯気・目印は人物と同じカメラで投影し、クリックした床との交点へ移動する。右／中ドラッグ、左ドラッグ、複数ボタン操作、キャンセル、capture 喪失では移動しない。複数ボタンを押した操作は、最後のボタンを離しても移動せず、次の左クリックから移動できる。建物や家具の立体モデルは追加しない
- 3D マップ：実際の 3D ワールドとアバター・アイテムを斜め上から見る。右ドラッグで角度を変えられる。天井や梁で見えなくならないよう高さ 3m より上は描かない。アバターは上からだと小さいので、頭の上に顔の目印を出す
- 声の湯気（試験中）：プロフィール設定の「声の湯気」（既定は有効）で、発話した人のいた場所（3m ごとのセル）に熱が溜まり、マップ上に温かい光として出る。熱は会話が終わっても残り、半減期 150 秒でゆっくり冷めて消える。溜まるのは発話の長さと場所だけで、会話の内容や誰が話したかは残らない。熱は手元のクライアントだけが持ち、セッションやワールドが変わると消える。サウンドボードや動画の音では温まらない（`client/src/voiceHeat.ts`、熱の保持とサンプリングは `mapShared.ts`、描画は `MapLayer.tsx` と `Map3D.tsx`）
- パネル開閉・画面サイズ変更では視点を保ち、Space の戻り先は新しい表示範囲に合わせる。ワールド種別を切り替えると視点をリセットする。保存済みの「なし／2D／3D」は上書きしない
- スマホ（タッチ端末）では「画面」タブの背景に出て、タップで移動だけできる（拡大縮小・平行移動・回転はなし）

### マップの回帰確認

`node scripts/verify-map-browser.mjs` で実物のマップを使うローカルfixtureを起動し、別の端末で `node scripts/test-map-browser.mjs [既存Playwrightのmodule URL] [ブラウザ実行ファイル]` を実行する。デコーダーは既存のThree.js同梱ファイルから供給し、外部サービスへは接続しない。右・中ドラッグ、左押下→右押下→右解放→左解放と次のクリック復元、キャンセル・capture喪失、ズーム・Space、タッチ入力、受信した参加者状態の表示、ワールド切替、3Dマップ描画を検証し、画像を `.local/verification/` に保存する。参加者状態はfixtureが投入するため、実サーバーを通した複数クライアントの同期確認は別途必要。

## スマホ

幅 720px 以下、またはマウスの無いタッチ端末で幅 1024px 以下・高さ 540px 以下のときにスマホのレイアウトになる（`client/src/phone.ts` の `usePhone`）。回転して幅が 720px を超えても、横画面ではタブ式の操作を維持する。

- 高さ 540px 以下の横画面では、タブを右端、ドックを下端に置き、顔の帯とウィンドウを左右に分ける。顔の帯・顔一覧・状態のお知らせは収まらない場合にスクロールできる。ノッチ・ホームインジケーターの余白も確保する。
- 歯車、プレイヤー・アイテムの操作、サウンド、エモート、音量のメニューは表示領域に収め、長い場合は内部をスクロールする。回転・キーボード表示などで表示領域が変わった場合も位置と高さを再計算する。外側のタップ、元のボタン、Esc で閉じる。別のメニューボタンを押した場合は先のメニューを閉じる。
- プロフィールカードと確認ダイアログは画面の高さに合わせてスクロールできる。タッチ端末では左上メニューの疑似ホバーを出さず、ボタンでホームシートを開く。
- 今回の確認範囲と未確認の操作は [横画面の検証記録](testing/phone-landscape.md) を参照。

- マウスの無いタッチ端末（`touchOnly`）は 2D だけ。クライアントモードの 3D は押せず、外で 3D を選んでいても 2D で入る。スマホのブラウザは画面共有できないので、ドックの画面共有ボタンも出さない
- PWA としてインストールできる（Android の Chrome は「アプリをインストール」、iPhone の Safari は共有メニューの「ホーム画面に追加」、PC の Chrome / Edge はアドレスバーのインストールボタン）。アドレスバーの無い全画面で開く。`client/public/manifest.webmanifest` と `client/public/sw.js`。sw.js はキャッシュせず、つながらないときにだけ「接続できません」を出す。開くときに前段のプロキシが 502・503・504 を返したら（デプロイ中など）、代わりに「メンテナンス中です」を出して 5 秒ごとに開き直す（一度でもサイトを開いて sw.js が入ったブラウザだけ）。インストールには HTTPS（localhost は例外）が要る
- ホーム：左のナビは下のバー（ホーム／タイムライン／フレンド／セッション／イベント）。「その他」で、グループ・ワールド・アイテム・所属グループ・クライアントモード・自分のカードを含むナビ全体を下から出す。右の欄は出さない
- セッション：下のタブ「画面」（顔とウィンドウ）「プレイヤー」（プレイヤーとアイテムのリスト）「通知・ログ」で 1 つずつ全面に出す。リストからウィンドウを開くと「画面」に移る。左右のパネルはたためず、ウィンドウはカンタン表示だけ（設定は保存しない）。ドックの上のお知らせは「画面」のときだけ出す

## プロフィール・フレンド
- ステータス（参加 OK・オンライン・声かけて・取り込み中とひとこと）はホームの左下の自分のカードから変える（[messages.md](messages.md)）
- 参加画面の丸いアイコン、ホームの左下の自分のカードの歯車、セッション内の設定「プロフィールを編集」から、アイコン・3D アバター・自己紹介を設定できる。どれもログインしたアカウントごとに残り、変えられるのは本人だけ（画像はストレージ、自己紹介は DB。[storage.md](storage.md)）。ゲストはアイコンと 3D アバターだけ設定できる（[login.md](login.md)）
- 他の人のプロフィールから フォロー（お互いにフォローするとフレンド。アカウント ID の組で DB に保存。[timeline.md](timeline.md#フォロー)）、ブロック（その人の声・チャット・通知・効果音が自分に届かなくなる。ブラウザに保存）、通報（DB の `reports` に残るだけ）
