# 직업별 전문 분야

현재 기본 직업 36개의 전문 분야 145갈래를 실제 전직으로 선택할 수 있다. 사제의 네 길은 별도의 신앙 성장 규칙을 사용하므로 전체 전문 갈래는 149개다. 무직에는 전문 분야를 붙이지 않는다.

## 선택과 기록

직업 화면은 현재 기본 직업과 이미 알게 된 전문 분야의 이름·분야만 보여 준다. 아직 알지 못한 갈래는 이름·분야·남은 개수·잠긴 버튼을 표시하지 않는다. 알려진 갈래가 하나도 없으면 일반적인 빈 안내만 표시한다. 다른 기본 직업은 별도의 직업 변경 항목을 펼쳐 확인한다. 전문 분야를 택해도 기본 직업과 기존 숙련은 보존한다.

전문 분야의 흔적은 기존 동화·일기·여행기·생활서·직업서의 본문에 흩어져 있다. 새 전직 안내서를 만들거나 책의 제목에 전직을 내세우지 않는다. 기존 읽을거리34권과 지역별 소장 목록, 첫 본문은 유지한다. 책마다 정해진 서로 다른 중간·후반·끝 위치에 글을 두며, 언어를 바꾸거나 다시 접속해도 같은 장면을 찾는다. 이름이 많은 장면은 두 문학 단락으로 나누어 한 문단에 이름이 몰리지 않게 한다. 숫자·필수 기술·수련 순서·전직 조건을 적은 목록은 넣지 않는다.

책을 실제로 완독하면 그 글에서 만난 갈래를 알게 되지만, 그것만으로 전직하거나 기술을 받지는 않는다. 실제 선택은 별도로 확인한다. 발견은 각 인물의 독서 기록을 따르므로 새 인생에 자동 상속하지 않는다. 업데이트 전에 이미 선택한 갈래는 발견한 것으로 인정하며, 해당 도서가 독서 기록에 없어도 선택과 기술을 보존한다.

한 기본 직업에는 전문 분야 하나를 기록한다. 다른 기본 직업으로 바꾸면 이전 전문 분야의 능력은 비활성화하고, 그 직업으로 돌아오면 저장한 전문 분야를 다시 사용한다. 여러 직업의 전문 능력을 동시에 쌓지 않는다. 종족·성별로 전문 분야를 제한하지 않는다.

준비가 되지 않은 분야는 일반적인 안내와 비활성 버튼만 표시한다. 정확한 조건·수치·기술 이름·해금 방법은 직업 화면, GM·NPC 대화와 도서에서 공개하지 않는다. 목록 자체에 조건을 붙여 미리 알려 주지 않는다.

처음 선택하는 데는 금화가 들지 않는다. 이미 정한 전문 분야를 바꾸는 비용은 100G이며, 변경 직후 곧바로 다시 바꿀 수는 없다. 전직은 공통 시계의 시간 행동으로 진행하고, 완료 전에는 새 분야의 능력이 적용되지 않는다. 사제의 비용과 성장 기록은 [사제 성장](priest-growth-plan.md)을 따로 따른다.

## 능력과 검증

현재 활성 분야는 그 분야에 맞는 고유 패시브 하나와 액티브 하나를 준다. 일반 145갈래에 총290개 기술이 있고 사제의 네 길은 별도 기술을 사용한다. 이름은 갈래의 도구·관찰·몸놀림·문화에 맞추어 한국어·영어·일본어로 각각 작성했다. 선택하지 않은 분야의 기술 이름·효과는 기술 목록과 공개 갈래 목록에 표시하지 않는다.

패시브는 능력 판정·방호에, 전투 분야에서는 공격·명중·방어·마력 방호에 작은 보정을 준다. 현재 갈래의 보정만 한 번 적용하며 기존 일반 패시브 합산에 다시 넣어 중복하지 않는다. 직업이 보유하지 않은 별도 능력치를 새로 끼워 넣지 않는다.

액티브는 분야에 따라 다음 판정의 준비, 다음 일·제작의 성과 보정, 이동 준비, 자기 회복, 방호를 사용한다. 전투 분야의 실제 공격·아군 회복·보호와 사거리·마력 구분도 연결한다. 화상·냉기·독을 쓰는 일부 기술은 유효 명중 후 제한된 확률로 짧은 상태 효과를 준다. 생활 기술의 이름을 바꾸어 전투 공격으로 만들지 않는다.

기술을 준비하기만 해서는 숙련을 받지 않는다. 준비한 강화가 실제 판정·피해 방호·일·제작·이동에 쓰이거나 부족한 HP를 실제 회복해야 한다. 현재 강화가 남아 있으면 같은 기술이나 다른 준비 기술을 다시 쓸 수 없으며 이유를 표시한다. 이미 최대 HP인 대상의 회복과 새로고침·재전송으로 경험을 반복 수령하지 않는다.

이름만으로 새로운 무기·배·농장·소환수를 지급하지 않으며, 그런 기능은 기존 장비·부동산·동료·이동 규칙을 따른다. 실제 효과는 배운 기술을 눌러 설명에서 확인한다.

서버는 현재 인물과 직업, 등록된 전문 분야, 저장된 성장 기록, 비용·변경 대기 조건을 확인한다. 다른 직업의 분야를 제출하거나, 과거 시각·미래 시각·임의 효과를 저장해서 혜택을 얻을 수 없다. 이전 분야의 기술 경험은 기록하되 현재 분야의 패시브·액티브 각 하나만 활성화한다.

자동 검사는 145갈래 전체의 유효 선택, 고유290기술의 세 언어 이름·효과, 준비되지 않은 선택 거절, 변경 비용, 직업 변경과 복귀, 위조 기록, 중복 능력, 비공개 안내, 공통 시계의 예약과 완료, 강화 준비와 실제 소비의 숙련 차이를 확인한다. 사제 네 길을 포함한149갈래의 모든 단서가 실제 소장 도서에 있고 각 언어의 본문에 나타나는지, 완독 전에 발견되지 않는지, 기존 선택은 보존되는지도 확인한다. 전투 효과와 다인 난도는 실제 전투 어댑터·엔진 검사와 별도로 비교한다.
