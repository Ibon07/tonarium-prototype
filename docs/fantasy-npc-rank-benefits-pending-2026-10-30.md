# NPC 등급 혜택 대화 — 미실행 확인 항목

사용자 지시에 따라 테스트, 타입 검사, 빌드, 브라우저 QA, 별도 리뷰를 실행하지 않았다.

- 길드/신전 NPC가 현재 등록 모험가/성직 등급과 해금된 혜택, 수령 가능 여부, 일일/생애 수령 기록, 대여/반납 상태를 KO/EN/JA로 안내하는지 확인한다.
- 잘못된 시설과 GM에서는 담당 시설을 안내하고 수령 제안을 만들지 않는지 확인한다. 관련 없는 자유 대화와 다른 직업의 숙련 질문은 기존 대화로 전달되어야 한다.
- 구체적인 혜택 수령/반납은 공유 서버 규칙으로 자격·시설·시간·비용·소지품 등을 확인한 뒤 기존 확인 창구를 통해서만 실행되는지 확인한다.
- 모험가 6/성직 4등급 교본 목록에는 현재 직업의 아직 배우지 않은 일반 기술만 나오며, 정확한 기술 이름/번호 선택 후 확인을 거쳐 실물 교본을 받는지 확인한다. 소지품에서 읽기 전에는 기술을 습득하지 않아야 한다.
- 대화 목록은 사용자·NPC별로 격리되고 등급/프로필 수정, 생애 변경, 이동, 언어 변경, 2분 경과 시 무효가 되는지 확인한다.
- 교본을 이미 받은 경우 선택한 기술과 읽기 여부를 안내하고, 비공개 전직·기적 조건이나 보상은 노출하지 않는지 확인한다.
