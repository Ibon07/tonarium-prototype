# 非同期のやりとり（ステータス・メッセージ・グループ）

いまいない人とも、あとから追いつけるようにする仕組み。Discord の「サーバー・チャンネル・DM」を下敷きにして、ボイスチャンネルの代わりにセッション（空間）を並べる。部品は `client/src/home/`（`messages.tsx`・`status.tsx`・`GroupPage.tsx`）と、セッション内の `client/src/world/SessionMessages.tsx`。

## ステータス
VRChat にならった 4 段階と、32 文字までのひとこと。ホームの左下の自分のカードを押して変える。最近使ったひとことは 5 つまで選び直せる。
- **参加 OK**（青）フレンドのホームの「フレンドの今」で、その人がいるセッションが上に出る
- **オンライン**（緑）いつもの状態
- **声かけて**（オレンジ）フレンドからは「参加する」の代わりに「行ってもいい？」が出る。押すと本人に通知が届き、「どうぞ」でセッションへの招待が返る（返事を待たずに入ることは止めていない）
- **取り込み中**（赤）セッションやグループへの誘いと「行ってもいい？」が届かない。つんつんの音も鳴らない。メッセージは届く

オフラインの人はひとことと「◯時間前まで」だけが見える。ステータスとひとことは名前ごとに `data/people.json` に残る。

## メッセージ
- **DM** フレンドとの 1 対 1。フレンドページの一覧で相手を選ぶと右に出る。相手がいなくても送っておける
- **チャンネル** グループの中の会話。最初は「雑談」の 1 本で、グループを作った人だけが増やせる（8 本まで）。先頭のチャンネルにセッションのまとめが残る
- 送れるもの：文字、画像・動画、声のメッセージ（マイクのボタンで録り始め、もう一度押すと送る。60 秒まで）。チャンネルでは日程の相談も付けられる
- DM とグループのチャンネルの添付画像は、元の縦横比を保ち、本文の幅と高さ 180px の範囲に全体を表示する。画面幅や端末の向きを変えると、その時点の本文幅に合わせて縮小する。画像を押すと拡大表示できる。
- Windows ネイティブ版も画像・動画と音声メッセージを送れる。音声は NAudio で録音し、Windows の Media Foundation で AAC/MP4 に変換する（追加のエンコーダーは不要）。Web 版の WebM/Opus と同じ会話に保存され、Web 版からも再生できる。ネイティブ版の録音も最長 60 秒
- 開いている会話は読んだことにする。開いたときに未読があれば「ここから未読」の線が出る。読んだ位置は名前ごとに保存し、別のタブにも反映する
- 「来たら知らせる」：オフラインのフレンドの DM で押すと、その人がオンラインになったときに 1 回だけ通知が届く

### 添付画像のレイアウトと確認方法

DM とチャンネルは `client/src/home/messages.tsx` の `Thread`・`MessageView`、画像は `client/src/world/common.tsx` の `ChatImage` を共用する。本文の `.msgbody` は縦方向の Flex 配置で、`min-width: 0` により会話の幅まで縮められる。画像の `.chatimg` は `align-self: flex-start` で横方向の stretch を防ぎ、幅・高さを自動計算する。本文幅の上限と高さの上限を同時に適用し、`object-fit: contain` で画像全体を収める。寸法を読み込み時の JavaScript で固定しないため、画面幅の変更後も同じ制約が適用される。

表示を確認するときは、DM とチャンネルのそれぞれに縦長（例：400×1200）、横長（1600×400）、正方形（800×800）の画像を添付する。PC 幅、スマホの縦向き・横向きの幅で、全周が見えること、円などの形が歪まないこと、本文から横にはみ出さないことを確認する。表示したまま幅を狭く・広く変更し、スマホでは端末の向きも変えて再確認する。高さ上限より小さい画像も確認し、不要に引き伸ばされないことを確かめる。

## 日程の相談
チャンネルのカレンダーのボタンで、日時と会場（任意）を付けて送る。メンバーは「来る／たぶん／むり」で答え、押し直すと取り消せる。「来る」が 3 人（`PLAN_QUORUM`）そろうとイベントになり、以後の返事はイベントの参加者にも反映される。イベントの返事も同じ 3 択。

## グループの画面
owner（作成者）と編集者にだけ歯車が表示され、名前と端末の画像を設定できる。owner のみメンバーから編集者を選んで追加し、一覧の × で削除できる。編集者管理は選択時に反映し、名前は「名前を保存」で反映する。グループ削除も owner のみ。色の変更・画像の削除は今回の対象外。

`groupUpdate { groupId, name?, editors? }` はサーバーで権限を検証する。名前は owner/編集者のみ変更でき、前後の空白を取り40文字まで、空文字は無視する。編集者の変更は owner のみ受け付け、現在のメンバーの名前から owner と重複を除いて保存する。脱退時は編集者からも外れる。不正な要求は無視し、変更後は `groups` を全員に再配信する。owner/editors は名前で保持し、名前そのものの認証は別 Issue で扱う。

画像はプロフィールアイコンと共通の選択・正方形切り抜き・128px JPEG 変換を経て、`POST /group-image/:groupId?name=<送信者名>` に送る。サーバーは owner/編集者を検証し、アイコンと同じ JPEG 判定と300,000バイト上限を使う（元ファイルの拡張子では判定しない）。`data/group-images/<groupId>.jpg` に保存し、異なる拡張子の旧ファイルは削除する。保存後に `imageVersion` を増やして全員へ配信し、`GET /group-image/:groupId?v=<imageVersion>` で取得する。画像は選択後すぐに保存され、グループ削除時には画像も削除される。

グループ名・`editors`（名前の配列）・`imageVersion` は `data/home.json` に残り、画像とともに再起動後も戻る。旧データで editors がなければ空配列として読む。見出し・ナビ・一覧・公開範囲のチップ・セッション内の会話一覧は共通の `GroupAvatar` で画像を表示し、画像がなければ従来の頭文字を表示する。

グループの一覧で名前を押すか、左の所属グループの頭文字を押すと開く。未読のチャンネルがあるグループの頭文字には赤い点が付く。
- 上：ホームの見出しの行に、グループ名・ベル・フレンドを誘う・抜ける（作った人は消す）・このグループのセッションを作る が並ぶ。検索はこの画面では出さない
- セッション：このグループのセッションをホームと同じカードで並べる。入れる範囲は「グループ」（メンバーだけ）か「グループ+」（メンバーのフレンドも）を選ぶ
- チャンネル：タブで切り替える
- イベント：このグループのこれからのイベントと返事
- メンバー：セッションにいる人、ゲスト（グループ+ のセッションに来ているメンバー以外の人。「メンバーに誘う」が出る）、オンライン、オフラインに分けて、ステータスと一緒に並べる

## セッションのまとめ
グループ・グループ+ のセッションで、2 人以上が 10 分以上いたとき、全員が出た時点で先頭のチャンネルにまとめが残る。いた人、時間、セッションに残っているアイテムのひとこと（盤面が途中・付箋の中身・写真など）、その間の全体チャットが入る。「続きをする」で、そのセッションに入ってアイテムのウィンドウを開く。

10 分は `.env` の `RECAP_MIN_MINUTES` で変えられる（動作確認では 0 にすると、入ってすぐ出てもまとめが残る）。

アイテムのひとことは `shared/items.ts` の `itemSummary`。セッションカードにも出る（盤面が途中、付箋など）。

## セッションの中
右のパネルの上に「通知・ログ」と「メッセージ」のタブがある。メッセージでは会話を選んで返信でき、セッションを離れずに DM やチャンネルに答えられる。
- 「ここに呼ぶ」：いまいるセッションへの誘いを送る。受け取った人のカードの「参加する」で入れる
- 箱のボタン：いまいるセッションのアイテムを共有する。受け取った人は「続きをする」でそのセッションに入って開ける

## 保存
| ファイル | 中身 |
|---|---|
| `data/messages.json` | 会話ごとのメッセージ（300 件まで）と、名前ごとの読んだ位置 |
| `data/people.json` | 名前ごとのステータス・ひとこと・最近のひとこと・最後にいなくなった時刻・来たら知らせる の待ち |
| `data/items.json` | セッションごとのアイテム。5 秒ごとに変わっていれば書き出す。再起動すると、持っている人・編集中の人・ライブ中のカメラは外れる |

DM はフレンドどうしでしか送れず、チャンネルはそのグループのメンバーにしか届かない。認証はないので、同じ名前を入れれば誰でもその人のメッセージを読める。
