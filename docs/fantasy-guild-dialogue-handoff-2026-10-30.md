# 길드·NPC 거래·스킬 안내·승률 목표 — 2026-10-30

현재 상태는 **코드 반영 / 검증 미실행 / 미커밋·미배포**다. 사용자의 요청에 따라 테스트·시뮬레이션·타입 검사·빌드·브라우저 검사는 다음 일괄 검사 요청까지 실행하지 않는다. 이전 작업의 통과 결과를 이번 작업의 근거로 쓰지 않는다.

## 반영

- 등급 명칭은 `코퍼 (1)`부터 `마스터 (8)`까지 숫자를 괄호로 함께 표시한다. KO/EN/JA 공통.
- 일반 의뢰와 메인 이야기, 채집·납품·제작·낚시·조사·던전 및 호위에 등급을 표시한다. 목적지와 보고 지역의 위험도, 적의 총합, 작업 난이도·희소 재료를 반영한다. 안전한 보통 약초 의뢰는 낮고, 위험 지역의 비전투 의뢰는 높다.
- 등록 등급은 코퍼에서 시작한다. 현재 등급의 서로 다른 의뢰를 5건 완료·보고한 뒤, 다음 등급 전투력 기준을 통과하면 한 단계 승급한다. 포기·취소·기한 만료·다른 등급 의뢰는 현재 승급 실적으로 계산하지 않는다. 완료와 호위 도착 영수증을 서버 저장 직전에 기록한다. 승급 뒤 카운터는 0, 이미 인정한 의뢰는 다시 인정하지 않는다.
- 과거 전투력만으로 받은 심사 기록은 이력으로 남지만 새 등록 실적을 자동 지급하지 않는다. 기존 완료 의뢰도 소급 가산하지 않는다. 장비를 바꾸거나 직업을 바꿔도 등록 등급을 자동 강등하지 않는다.
- 실버 (3) 이상은 글로벌 게임 하루마다 주간 06–18시에 길드를 방문하면 해당 등급의 개인 지명의뢰를 받을 수 있다. 길드 직원이 먼저 대화를 열고, 플레이어가 대화로 승낙한다. 당일 재접속·환생·재방문으로 재추첨하지 않는다. 조건에 맞는 미완료 의뢰가 없는 날에는 새 의뢰를 꾸며내지 않는다.
- 시장 등 시설 NPC에게 물품·약초·가격·수량을 묻고, 물품/번호와 수량을 말해 견적을 받은 뒤 확인하여 구매한다. 1–99개, 한 재고 묶음, 실제 시설 가격과 전역 재고를 사용한다. 돈·무게·슬롯·재고 검사는 기존 거래 처리로 확정한다.
- 여관은 공동 객실 8, 개인 객실 4, 특실 2의 동시 숙박 자리를 갖는다. 글로벌 저장의 진행 중 숙박 예약을 세어 잔여 수를 안내하고 확정 순간에도 정원을 재확인한다. 숙박 완료·취소 후 자리는 해제된다. 방 종류와 비용·회복량은 기존 규칙 유지.
- 길드 NPC에게 등급에 맞는 게시 의뢰를 추천받고 이름/번호를 지정해 실제 게시물 ID로 수주한다. 다른 플레이어의 선점·개인 지명 대상·기한·수락 조건을 기존 서버 예약 처리로 확인한다.
- 모든 게임 거래는 준비된 대화 경로가 실제 상태를 조회하고 제안한다. 자유 대화 AI가 임의 물품·보상을 지급하지 않는다. 확인한 거래의 가격이나 상태가 바뀌면 재확인을 요구한다.
- 스킬 목록과 전투 선택에는 짧은 용도 설명을 표시하고, 선택한 스킬의 기존 상세 수치 안내를 유지한다. 특수 바닥의 아군 영향도 표시한다.
- 마지막 새벽 명령 확정 시 별도 확인창: 즉시 빈사(실신), **전투 승리 시 영구 사망** 및 대가를 되돌릴 수 없음을 고지한다. 기본 초점은 취소. 취소/ESC는 전송하지 않으며 전투 상태·라운드·접속·인물 변경으로 낡은 확인은 폐기한다. 승인 시에도 현재 서버 규칙의 유효성을 다시 확인한다. 활성 조건과 승리 사망 규칙은 유지한다.

## 승률 목표와 실제 반영의 구분

몬스터의 고정 등급별 HP·공격·방어·명중·저항을 1차 조정했고, 종별 차이와 기존 패턴·개체 편차를 유지했다. 인간 적대자 능력치는 이번 몬스터 조정에서 보존했다. 등록 등급이나 현재 장비에 맞춰 적의 능력치를 실시간으로 늘리거나 승패 확률을 강제하지 않는다.

| 기준 전투력에 맞는 모험가 | 상대 | 목표 승률 |
| --- | --- | --- |
| 1–6등급 | 같은 등급 | 60–80% |
| 1–6등급 | 한 단계 아래(1–6) | 80–100% |
| 1–6등급 | 한 단계 위(1–6) | 10–40% |
| 6등급 | 7등급 몬스터 | 5% 이하 |
| 7등급 | 7등급 몬스터 | 약 40% |
| 8등급 | 7등급 몬스터 | 약 60% |
| 7등급 | 8등급 몬스터 | 20% 이하 |
| 8등급 | 8등급 몬스터 | 약 50% |

이 숫자는 **실측 결과가 아니다**. 동일한 등록 등급이라도 장비를 벗거나 압도적인 장비를 갖추면 전투력은 달라진다. 단독 1대1·해당 등급의 기준 장비/능력·합리적 전술로 향후 측정한다. 파티·무리 토벌의 총합 등급과 전술 차이는 별도다. 실제 시뮬레이션 후 목표 밖인 능력치는 추가 조정해야 한다.

## 통합/재개

- 신규 프로토콜 15: `fantasyGuildVisit` → `fantasyGuildGreeting`. 이 메시지는 월드 계정 권한과 현재 위치/인생을 확인하고, 대화창을 연다. 길드 방문 알림은 별도 일일 저장 후 전송한다.
- 신규 선택 상태 `character.guildProgress`; 서버 구조 검증 및 모든 권한 있는 저장의 완료 실적 동기화.
- 신규 저장 `fantasy-named-commissions.json`: 사용자별 마지막 알림 날짜/게시물 ID. 기존 의뢰 원장이 개인 게시와 수락을 소유한다. 서버 저장 실패 시 중복 지급 대신 새 알림을 보류한다.
- 신규 객실 조회 `FantasyStore.innAvailability`, 경제 상태 `rooms`; UI와 NPC가 동일 값을 사용한다.
- 운영 데이터 `data/fantasy.json`은 편집하지 않았다.
