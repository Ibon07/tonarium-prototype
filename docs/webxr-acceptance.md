# WebXR 改修の対象と検証記録

2026-10-26、改修前の棚卸し。対象は通話中に中央へ表示できる画面と、その上に重なる操作画面。

| 入口 | 対象 |
| --- | --- |
| `WindowLayer.useResolved` | 画面共有、視点配信、カメラ配信、参加者の顔、画像、動画、YouTube、付箋、サイコロ、お絵描き伝言、バイク詳細、共有システムのアイテム操作 |
| `items/panels.ts` / `View3D.NoteEditor` | チェス、AIチェス、2048、お絵描きCanvas、空間から選択した付箋の編集 |
| `WindowLayer` の固定キー | サバイバー、サバイバー図鑑、AD研究所、AD空間設定 |
| 通話中のダイアログ | プロフィール編集・参加者プロフィール、ワールド変更、セッション作成・編集、ステータス、アイテム追加、確認、外部リンク確認、画像拡大 |
| 通話中の補助表示 | 設定・音量・音・エモート等のポップオーバー、サバイバーの選択、ADのオフライン報酬 |
| 通話の操作面 | ホームメニュー、近くの一覧、チャット・通知、ドック |
| VR追加表示 | 端末開閉、終了、ブラウザ操作への切替、2D復帰、操作キー、文字入力、selectの選択肢、スティック操作説明 |

改修前は `TerminalSurface` が `document.body` 全体を1枚のHTMLMeshに描画し、中央ウィンドウとVR追加表示が同じ面に収まっていた。端末は開いた位置で固定されるが、パネル個別のグラブ・同時配置はない。頭は床原点へ直接加算、手の姿勢は同期されず、保持物は頭の向きから配置される。レーザーは深度テスト無効だが、レティクルはない。ADのボードはカメラのクォータニオンをそのままコピーする。

## 実装と自動検証

- 1: 右上の起動操作を撤去し、既存クライアントモードの「VR」→「VR開始」へ集約。
- 2・3: 初期のlocal-floor追跡点を目の位置へ合わせ、頭と左右gripSpaceの位置・向きをアバターへ適用。既存avatar送信・ピア直接配信・サーバー保存に任意のXR姿勢を追加し、値を検証。自分の手はフレームごとの追跡を使う。
- 4: 保持を始めたコントローラを記憶し、そのレイから既存の床上配置を計算。頭の方向と、反対の手でのパネル操作から独立。
- 5・8: パネルごとのDOM描画・レイ入力・グラブ配置・破棄を追加。左腕一覧、VR操作、操作キー、選択肢、文字入力、説明を独立した表示面に分離。
- 6・7: レーザーと丸印をパネルより後に描画し、深度テスト・深度書込を無効化。スプライトとAD研究所等のビルボードで世界座標のロールを除去。
- 9: 表示面を幅390px・高さ最大680px、DOMボタンを最小44pxに設定。Canvasの縦横比と操作座標は維持。

追加テスト: `test:xr` に初期位置・実移動・ロール・保持レイ・姿勢検証を追加。`test:sync` に左右の手・切断・VR終了を2ピアとサーバーへ送るテストを追加。ブラウザ模擬入力にはパネル個別の座標・重なった元DOMへの入力・同時表示・グラブ・解除・個別開閉・破棄の確認を追加。いずれも今回の環境では未実行。
