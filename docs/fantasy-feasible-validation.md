# 로컬에서 가능한 추가 검증 — 2026-10-27

이 문서는 먼저 진행한 브라우저·다중 접속·복구·모델 검사 기록이다. 이후 추가한 플레이·대화 로그, AI 지침 보완과 실제 생성 재검수, 프록시·파일 보호 검사는 [후속 검증](fantasy-predeploy-diagnostics-validation.md)을 따른다. 아래 당시의9개 실제 응답과 검사 수를 후속 검사와 혼합하지 않는다.

월드 계정 입장부터 개인 저장·대화 표시·재접속까지 브라우저로 확인하고, 별도의 임시 저장소로 다중 접속과 운영 복구를 검사했다. 모든 플레이 인물과 계정은 검수용이며 원본 `data/fantasy.json`의 SHA256는 유지했다. 두 브라우저 문맥과 여러 WebSocket 접속은 실제 여러 PC의 성능 검증과 구분한다.

## 수치와 범위

- 인증한 다중 접속 검사 10그룹: 1,286개 WebSocket 송신·9,815개 수신·계정 HTTP 요청20건. 이 중 6접속의1,200명령 부하는 약30초다. 장기 누수나 운영 최대 동접 수의 증거로 사용하지 않는다.
- 운영 복구 검사 10단계: 서버 실행6회·관리 CLI18회. 살아 있는 서버의 작업 거절3회와 실제 복원 명령의 강제 종료1회를 포함한다. 기대한 거절과 중단 뒤 복구까지 통과했다.
- 외부 Kokosync 선택 실행 검사: 1건 통과·실패0·건너뜀0, 약24.3초. 실제 스냅샷257,167바이트와 큰 첨부240,000문자를 확인했다. 연결은 종료했지만 외부 중계 서버의 빈 방 메타데이터 보관 정책은 별도다.
- 세 언어의 정식 정보 응답12건: 날씨·실제 가격/재고·소장 도서·미등록 용어 거절을 확인했다. 이 검사는 실제 모델 생성 품질이나 생성 속도를 측정하지 않는다.
- 기존 고룡 검증 방식 그대로200전: 최고 장비48/100승, 일반 장비2/100승, 미완료0. Lv20 인간6인과 정해진 동료·소모품·자동 전략의 결과이며 모든 플레이 방식에 같은 승률을 보장하지 않는다.
- 수정 관련 대화 회귀38개·클라이언트55개, NPC 검사147개와 타입 검사·웹 빌드가 통과했다. 서로 겹치는 검사 집합이므로 단순 합산하지 않는다. 이전 전체1,227개 검사는 별도의 완료 기록이다.

## 실제 모델의 제한된 확인

처음에는 여유 RAM이 부족해 모델을 실행하지 않았다. 다른 검수를 모두 종료한 뒤 여유가 늘어 새로 확인한4,498MiB에서 기존 Qwen3-1.7B-Q8_0을 실행했다. 새 모델이나 실행 파일을 내려받지 않았다. 이번 설정은 CPU2스레드·1슬롯·문맥2048토큰·Q8 KV·최대 출력80토큰·mmap이다. 운영 기본 설정이나 브라우저 WebGPU의 성능으로 일반화하지 않는다.

NPC·GM의 한국어·영어·일본어 생성9개가 완료됐다. 서비스 전체 응답은 약7.1~13.6초, 중앙값10.6초였다. 모델 프로세스의 최대 작업 집합은2,150MiB, 관측된 최소 여유 RAM은1,885MiB였다. 준비 후120초의 사전 제한으로 모델을 종료하면서 마지막1요청은 의도한 중단 오류로 남겼고, 동시 생성·대기열 표본은 실행하지 않았다. 이는 실패한 답변을 정상 대사로 저장했다는 의미가 아니다.

연결 성공과 내용 품질은 분리한다. 린의 나이가 여관 운영에 미치는 영향을 묻자 날씨 이야기로 질문을 빗나간 한국어 답변과, 주어진 온화한 날씨와 다른 더운 날씨 묘사가 실제 서비스 출력에서도 관찰됐다. 같은 질문의 영어 답변은 나이34세와 실제 설정인 과거 행상 경험에 맞았다. 일본어와 GM의 일부 문장은 말투·표현이 고르지 않았다. 이 내용 정확성과 자연스러움은 통과로 처리하지 않았다. 완료9건은 모두 출력이 정상 종료됐고 입력도 문맥 상한에 맞았으므로, 관찰된 문제를 단순한 잘림으로 해석하지 않는다. 정식 정보 응답12건의 통과가 이 자유 생성 문제를 해결했다는 뜻은 아니다.

## 발견해 수정한 부분

1. “지금 내가 뭘 하고있어?”를 단순 상태 질문으로 인식하지 못해 AI로 보내던 문제를 고쳤다. `뭘/무엇을`, 주어 뒤의 `지금`, `있나요`를 지원하며 미진행/작업 중 상태에서 모델 호출 없이 답한다. NPC에게 묻는 말·조언·복합 행동 요청은 가로채지 않는다. 수정 전 실패를 재현한 뒤 자동 검사와 실제 브라우저에서 다시 확인했다.
2. 월드 영역·모험 메뉴의 화면 읽기용 이름이 일본어로 고정되어 있던 두 속성을 현지화했다. 최종 빌드에서 한국어·영어·일본어를 바꿔 각 접근성 이름을 확인했다.

실행용 파일은 별도 폴더에 빌드한 뒤 이전 해시 자산을 보존하며 반영했다. GitHub 변경이나 외부 배포는 하지 않았다.

## 추가 확인이 필요한 범위

실시간 AI의 질문 충족·사실 일치·말투 품질 개선과 재검수가 필요하다. 실제 여러 PC의 서로 다른 GPU·네트워크, 운영 서버의 동시 AI 처리량, LiveKit 통화/WebRTC, 장기 수동 플레이와 전체 경제·계절 캠페인, 배포 환경과 Docker 장애 복구도 남아 있다. 실제 모델의 원문과 자원 조건은 아래 보고서에 기록한다.
