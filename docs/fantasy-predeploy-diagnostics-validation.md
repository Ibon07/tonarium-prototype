# 플레이 기록·AI 답변·배포 전 추가 검증

배포 PR 통합 후 재검증에서는 아래 이전1,278개 집합이 화면95·계정33을 포함한1,321개로 늘었다. 최신 Tonarium의 동기화·월드·타임라인·공유 시스템·카메라·번역 자료·문서·변경 이력 검사229개도 통과해 총1,550개다. `check:completion`의 변경 이력 정책·번역 자료·타입·별도 웹 빌드가 모두 통과했다. 월드 전환·다중 탭·홈 접속 상태·다른 세션의 계정 보호3개를 새로 재현·검증했고 초기화 UI는 제거했다. 한 병렬 검사에서는 NPC 시험 서버의10초 시작 대기가 초과되어, 빌드와 분리한 최종 전체 재검사를 수행해0실패를 확인했다. 아래 실제 모델 표본과 과거 브라우저 검수의 한계는 유지한다.

2026-10-27 작업 기록이다. 실제 플레이로 확인할 항목을 나중에 추적하도록 [운영자용 플레이·대화 로그](fantasy-diagnostics.md)를 연결했다. 사용자가 선택한 범위대로 월드 안의 모든 GM·NPC 질문과 답변을 저장하며, 날짜·NPC·언어·익명 플레이어별 조회와 HTML·텍스트·JSON 내보내기를 제공한다. 서버에 공개 관리 화면을 추가하지 않았다.

## 구현과 확인

로그는 게임 저장과 별도이며 기본 최대14일·총64MiB·메모리 대기1,024건으로 제한한다. 개인 식별자는 HMAC으로 바꾸고 계정 API 내용·인증 쿠키·복구 코드는 로깅 입력에서 제외한다. 자유 대화에 들어간 알려진 인증정보 형식은 추가로 가리지만 모든 개인정보를 알아내는 기능은 아니다. 쓰기 장애·과부하 때 게임 행동을 막지 않는다. 정상 종료 때 쓰기를 기다리고, 강제 종료의 미완성 행은 읽을 때 건너뛴다.

실제 임시 서버와 인증 계정3개로 세 언어 정식 응답·규칙 응답·모의 생성 응답·활동 중 거절·오류·자원 변화·연결 중단·종료 저장을 확인했다. 이 모의 생성은 전송·기록 검증이며 실제 모델 품질 표본으로 세지 않는다. 최종65개 사건에 포함된 요청18건·응답18건을 확인했고, 조회기는 정상 대화를 한 항목으로 묶으며 미완료·중단된 대화도 남겼다. 필터·읽기 전용 동작·HTML 이스케이프·기존 파일 덮어쓰기 거절을 검사했다.

검수 중 요청 번호를 다시 쓰거나 계정을 바꾸면 이전 비동기 답변이 새 로그에 붙을 수 있는 문제를 재현했다. 호출마다 내부 표식을 만들어 해당 호출의 완료만 인정하도록 고쳤다. 단위 검사와 실제 NPC·GM 접속 모두에서 이전 답변이 새 대화에 기록되지 않는 것을 확인했다. 독립 코드 검수에서도 같은 수정과 개인정보 경계·메모리 제한·조회 동작을 확인했다.

## 배포 경계

임시 TLS 프록시·WSS·인증 쿠키·Host/Origin·신뢰 프록시 설정, 잘못된 요청 크기/형식/시간 제한, 계정 저장의 손상·쓰기 실패를15개 항목으로 확인했다. 시스템 인증서 저장소는 수정하지 않았고 시험 인증서는 삭제했다.

정적 파일 제공 경로의 문자열 접두사 검사에서 인코딩한 구분자로 공개 폴더와 이름이 비슷한 형제 폴더를 읽을 수 있던 문제를 가짜 파일로 재현했다. 실제 경로 포함 여부와 링크 대상을 확인하도록 고친 뒤 인코딩 우회·잘못된 UTF-8·NUL·폴더·외부 접합점·캐시 동작8항목을 검사했다. 공개 영역 밖의 파일 내용은 응답에 포함되지 않았다.

실제 운영 모드 HTTP에서 로그와 키 경로6개가 공개되지 않았고, Vite 개발 서버에서도 `work/`의 HTML 내보내기·진단 JSONL·비밀 키3개 경로가403으로 거절됐다. 이 결과는 실제 호스팅 환경의 프록시·볼륨 설정 확인을 대신하지 않는다.

## 실제 모델 품질

질문과 무관한 날씨·시설 전체 목록이 나이·조언 질문을 흐리던 문맥을 줄였다. 복합 날씨·옷차림 질문에는 필요한 현재 정보를 유지하고, 답변 마지막 지침에 해당 언어의 말투·질문 우선·구체적 조언·1인칭 답변을 넣었다. 숨긴 전직 조건과 행동 승인·서버 검증은 유지했다. 품질 징후 표시는 진단용이며 자동 합격 판정이나 두 번째 모델 호출을 추가하지 않는다.

첫 재검수에서는 기존1.7B 모델로 한국어·영어·일본어12개 답변을 실제 생성했다. 서비스 원문과 전달 문장이 모두 같았다. 한국어 나이 질문의 날씨 일탈은 사라졌고 영어·일본어 GM 조언은 일부 개선됐지만, 한국어 GM 조언의 임의 설정·말투와80토큰 시험 상한의 잘림, NPC의1인칭·자연스러움과 옷차림 조언은 여전히 부족했다. 이12개는 품질 합격으로 처리하지 않았다.

최종 지침에서는 린의 나이·경험 질문과 GM의 출발 전 긴장 조절 질문을 세 언어로 다시 생성했다.6개 모두 실제 로컬 생성이며 원문과 전달 문장이 같고 정상 종료됐다. 한국어 린은1인칭 대화체로 바뀌었고, 한국어 GM의 임의 거리·동행 약속과 잘림은 이번 표본에서 없어졌다. 영어는 두 문장 안에서 답했고 일본어 GM도 정중한 호흡 방법을 제안했다. 다만 한국어 조언의 구체성과 일본어 나이 답변의 자연스러움은 여전히 부족하다. 자동 품질 징후가0개여도 이 의미상의 문제를 놓쳤으므로 전체 품질은 부분 개선으로 남겼다. 앞선 대장장이·옷차림 문제는 최종6개에 포함하지 않았다.

최종6개는 CPU2스레드·문맥2048·1슬롯·Q8 KV·최대 출력80토큰의 순차 표본이다. 서비스 응답은 약9.4~12.5초, 중앙값10.8초였고 관측된 모델 최대 작업 집합은2,058MiB, 최소 여유 RAM은1,889MiB였다. 운영 출력 상한과 브라우저 GPU 환경은 이 시험과 다르다. 표본은 제한된 확률적 생성이며, 모든 NPC·긴 대화·운영 동시 접속·브라우저 WebGPU의 품질이나 성능을 인증하지 않는다.

## 남은 범위와 근거
