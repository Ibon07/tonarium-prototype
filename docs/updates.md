# 自動更新と更新後の復元

プロフィール設定の「更新設定」で Web 画面の自動更新を保存する。既定は Web がオン、Electron 内の Web 画面がオフ。待機時間は1～300秒の整数で、既定は5秒。不正な入力や保存失敗は表示し、保存済みの値を維持する。Web と Electron の設定は別のキーで保存する。

既存の更新通知に残り秒数、「今すぐ更新」「自動更新をキャンセル」を表示する。キャンセルした版では設定変更や同じ版の再通知でも再開しない。新しい版を検知した場合は再度カウントダウンする。開始済みの期限は待機時間・オン／オフの変更では変えない。追加更新を検知した場合も残り時間を維持し、最新の画面を読み込む。

Electron 本体はアプリメニューの「アプリの更新」で設定する。取得後の自動再起動は既定でオフ、待機時間は5秒。「起動時に更新を確認する」が有効な対応配布形式で選択できる。「終了時に適用する」は独立した既存設定として維持し、カウントダウンをキャンセルしても変更しない。即時更新・期限満了・終了時更新は共通の状態保存と適用ロックを通す。終了時更新では適用後に起動せず、即時更新・自動再起動では起動する。新しい版のダウンロード中に期限が過ぎた場合は、古い版を適用せず取得完了後に最新版を適用する。

Linux AppImage と Windows NSIS が自動適用に対応する。ZIP・tar.gz は既存どおり Releases からの手動更新を案内する。通話・録音中であることを理由に更新を延期しない。保存領域の障害などで復元データを保存できない場合は、理由を表示して適用を中止する。

## 保存・復元する状態

- 参加名とID、参加セッション、2D／3Dモード、3D座標・高さ・視線、一人称／三人称とカメラ距離。
- ホームのページ、グループとチャンネル、DMの相手、左右パネル・スマホタブ、ウィンドウの位置・最大化、アイテムの手元設定と音量。
- チャットとメッセージの入力、メッセージの予定入力、伝言ゲームの回答途中の文章・絵、プロフィール文と一部のダイアログ、検索・カレンダーの表示。
- マイクの希望状態と歩行先。通話・位置同期の接続結果を確認し、接続・同期・マイク利用・音声再生に失敗した場合はダイアログで案内する。「再試行」を押す操作で音声の再生と録音・音声送信の再試行を行う。

Web の復元データはタブごとの sessionStorage を使い、別タブには引き継がない。Electron 本体の再起動には接続先の localStorage に一回分を保存する。24時間を超えたデータや不正な形式は適用せず理由を表示する。通信の資格情報や画面共有ストリームは保存しない。元のセッションの削除・権限喪失・接続失敗は案内する。ワールドが変わった場合はモードを復元し、元の座標は適用しない。

## 録音と画面共有

画面共有は更新時に終了し、自分の共有ウィンドウを閉じる。再開には共有元の再選択が必要なことをダイアログで案内する。

録音メッセージは MediaRecorder の区間を更新前に確定し、音声 Blob と宛先を IndexedDB に保存する。アップロードの完了を待たず更新する。マイク権限が付与済みなら、同じ宛先への録音を更新後に自動再開する。許可が必要、権限の状態を確認できない、機器に接続できない場合はダイアログを表示し、「再試行」を押す操作で再試行する。通信の復帰に失敗しても録音の復元を試み、未送信の音声区間は送信できるまで保持する。

MediaRecorder の別インスタンスで同じファイルに追記できないため、録音停止時に各区間を別々の音声メッセージとして送信する。更新中の無音区間は含めない。各区間の録音上限は既存と同じ60秒。送信した区間は保持対象から外し、送信完了後に保存済み Blob を削除する。更新が中止された場合は元の画面で録音を再開する。

## 復元を見送る状態

- 画面共有元、ファイル選択、ポインターロック、全画面表示：ブラウザ・OSの再選択やユーザー操作が必要。画面共有以外は既存の操作から再開する。
- ローカルカメラ映像の配信：トラックを保存できず、機器の利用許可や公開先の再確認が必要なため、既存の配信操作から再開する。
- 動画・YouTube等の再生位置、細かなスクロール位置、ドラッグ途中・ゲーム操作の途中、全ダイアログの編集内容：個々のコンポーネントや外部iframeへの依存が大きく、一律の復元に伴う保守負担が高い。明示した下書き・画面状態のみを保存する。
- 共有アイテム・ゲーム・メッセージ履歴：クライアントの古いコピーを上書きせず、サーバーから最新状態を再同期する。送信済み要求の再送は二重実行を避けるため行わない。既存の通信に受領確認のない送信途中の要求は、更新をまたぐ到達を保証しない。
