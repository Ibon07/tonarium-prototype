# 声・音とついていく

- セッションの設定（左上の歯車）の「ブロードキャストモード」をオンにすると、そのセッションの全員に、距離に関係なく全員の声・サウンドボード・動画の音が聞こえ、「声の範囲」のチャットも全員に届く。誰でも切り替えられ、ログに出る
- 声は話している人との距離で大きさが変わる（2m までは等倍、15m で無音）。3D の人と、ついていっている 2D の人は左右にも振り分けられる。画面共有の音は空間化しない
- 音量（どれも自分にだけ効き、ブラウザに保存）
  - 全体：ドックのスピーカーボタンで「人の声」「サウンドボード・効果音」「動画・画面共有」をそれぞれ 0〜100% に変えられる。項目ごとに未保存の場合だけ、人の声は従来どおり100%、サウンドボード・効果音と動画・画面共有は5%で初期化する。0%を含む保存済みの値は維持し、読み込み時の上書きや移行は行わない。設定画面と再生処理には同じ音量設定を使う。動画・YouTube のウィンドウにあるアイテムごとの音量には、これがさらに掛かる
  - 人ごと：左のプレイヤー一覧の行（とおくのチップも）を右クリックすると、その人の声の音量（0〜200%）とミュートを変えられる。アカウント ID ごとにこのブラウザに覚える。ミュート中の人の行には赤いスピーカーの印が出る。サウンドボードには人ごとの音量は掛からない（`client/src/volume.ts`、`client/src/world/VolumeMenus.tsx`）
- 2D の人は 3D の人に「ついていく」と、その人の少し後ろに小さくなって付いていき、そこからの音が聞こえる。ドックの上の「ライブをリクエスト」で相手に視点のライブを頼め、相手が通知の「ライブを始める」（またはドックの上の「視点をライブ」）で始めると、ついていっている人だけに視点が配信されてウィンドウで見える。画面共有やカメラのライブとは別なので同時に使える。ついてくる人がいなくなるか 2D に戻ると止まる
- 「そばにいく」は相手（アイテムなら置いてある場所か持っている人）の手前に移る。3D では瞬間移動する
