# 파티 전투의 잠정 균형 기준

이 문서는 현재1~6인 턴 전투에 연결한 인원별 잠정 계산 기준이다. 별도의 전투 엔진과 저장소가 이 계산을 사용하여 실제 피해와 보상을 처리한다. 기본 수치는 다양한 인간 플레이어·직업 조합을 모두 검증한 확정 밸런스가 아니며, 현재 동작은 전투 규칙 문서를 함께 참고한다.

## 실제 참가자와 전투 시작 기록

서버가 자기 전장의 참가 명단과 현재 HP를 읽어 `createFantasyPartyCombatSnapshot({combatId,wave,roster})`에 전달한다. `kind=player`, `participation=engaged`, `hp>0`인 인물만 센다. 파티 정원, 같은 방에 있는 사람, 참가 대기자, 관전자, 소환수, NPC는 인원에 포함하지 않는다. 같은 플레이어의 여러 접속은 한 명으로 세며, 살아 있는 참전 상태와 죽음·관전 상태가 서로 충돌하면 기록을 확정하지 않는다.

`playerId`는 서버가 계정과 현재 인생을 조합해 만든 참가자 식별자다. 브라우저가 보낸 인원수·HP·역할·참가 여부를 그대로 사용하지 않는다. 이 순수 함수 자체가 접속 권한을 확인하는 것은 아니므로, 전장 서버가 소유권·같은 전장·실제 참가 승인을 먼저 검증해야 한다.0명은 전투를 시작할 조건이 아니며,7명 이상도 조용히6명으로 자르지 않고 거절한다.

결과의 `participantIds`와 기록 객체는 변경할 수 없으며 `balancePolicy`도 함께 고정된다. 적은 시작 기록을 사용하고, 동의한 지원자가 합류하면 새 참가 기록으로 상향만 한다. 사망·후퇴·접속 종료로 HP 상한·공격을 낮추지 않고, 합류로 HP가 늘어도 이미 가한 피해량을 보존한다. 생성한 적 능력치를 매 차례 다시 추첨하지 않는다.

## 잠정 계수

모두 같은 적의 1인 기준 능력치에 곱하는 값이다. 공격 계수는 **적중률이나 판정 난이도가 아닌 명중 한 번의 피해량**이다.

| 실제 참전 | 일반 HP / 피해 | 정예 HP / 피해 | 보스 HP / 피해 |
| --- | --- | --- | --- |
|1명|1.00 /1.00|1.00 /1.00|1.00 /1.00|
|2명|1.55 /1.04|1.70 /1.06|1.85 /1.08|
|3명|2.05 /1.08|2.35 /1.12|2.65 /1.16|
|4명|2.50 /1.12|2.95 /1.18|3.40 /1.24|
|5명|2.90 /1.16|3.50 /1.24|4.10 /1.32|
|6명|3.25 /1.20|4.00 /1.30|4.75 /1.40|

일반 적은 여러 명이 협력하면 더 빠르게 정리할 여지를 둔다. 정예와 보스는 집중 공격을 더 견디되 HP를 인원수 그대로 곱하지 않는다. 피해 증가 상한을20%·30%·40%로 나누어 인원이 늘었다는 이유로 약한 직업이 갑자기 일격사하는 위험을 제한한다. 최종 수치에는 피해 감소·치유·행동 제한과 실제 장비 차이를 함께 검증해야 한다.

`scaleFantasyPartyEnemy(base,snapshot,rank)`는 최대 HP를 올림하고 피해는 반올림한다. 낮은 기본 피해에서는 정수 반올림의 영향이 커지므로 소형 몬스터도 별도로 확인한다.1인 기준은 모든 등급에서 그대로다. 예를 들어 최대HP200·피해25·라운드당2행동 보스는6인에서 HP950·피해35·2행동이 된다.

## 행동과 추가 참가

인원에 따른 적 행동 배율은 항상1이다. 참가자마다 반격을 추가하지 않으며 예고된 브레스와 방어 성향은 실제 전투 엔진에서 처리한다.10×8칸의 벽·엄폐·이동·사거리를 적용하고, 본인이 소유한 건강한 편성 동료 최대2명에 각각 한 행동을 명령한다. 동료는 적의 플레이어 수 배율이나 독립 보상 인원이 아니다.

현재의 중도 합류는 `addFantasyCombatParticipant`를 사용한다. 같은 파티·세션·장소의 살아 있는 인물이 직접 요청하고 활동·다른 전투·사건·이야기 진행·위험 동의 조건을 확인한다. 기존 참가자를 포함해 최대6명이며, 합류 때 이전 선택을 지우고 새 전장 버전과 실제1분의 입력 기한을 열어 모두 다시 고른다.

`nextFantasyPartyCombatWave(previous,{completedWave,roster})`는 이후 다중 전장의 경계용 계산 도구이며 현재의 중도 합류 규칙과 다르다. 실제 종료와 호출 권한은 서버가 확인한다. 한 명을 내보내 현재 보스를 약화시키거나 끝난 전투에 보상만 받으러 들어갈 수 없다.

## 개인 참여 보상 방침

`fantasyPartyRewardEligibility`는 보상을 주지 않고 **대상 식별자만 계산**한다. 시작 기록에 포함된 인물 중 승리 때 유효 행동이 있고 전체 라운드의 절반 이상에 실제 참여한 인물을 기본 대상으로 삼는다. 유효 행동을 한 뒤 전투 중 쓰러진 사람은 그 상태를 서버가 확인한 경우 참여 시간 때문에 배제하지 않는다. 처음부터 죽은 인물, 관전자, 대기자, 무행동 참가자, 적은 기여만 남기고 일찍 이탈한 인물은 제외한다.

유효 행동은 실제 피해·필요한 회복·피해를 줄인 방어·방호를 포함하고 피해량 순위만 쓰지 않는다. 빈 회복·자동 방어·같은 요청 재전송은 기여를 만들지 않는다. `activeRounds`는 접속 시간이 아니라 직접 정상 행동을 확정한 라운드이며, 동료의 유효 명령은 지휘 숙련과 주인의 기여에 연결한다. 동료 이름으로 전리품을 복제하지 않는다.

개인 XP는 적격자별 기본 보상이고, 금화·재료·희귀품은 적의 등록된 전투 전체 예산에서 배분한다. 인원수만큼 같은 드롭을 복제하지 않는다. 서버가 전투와 인생별 지급 결과를 저장하고 중복 확정을 막는다. 빠른 메인 승리 라운드에 직접 정상 행동을 확정한 생존자의 통로 확보 인정과 실제 기여자 보상은 구분한다.

## 구현 경계와 다음 검증

순수 계산 모듈은 수치만 다루고 현재 전투 엔진과 서버가 권한·피해·저장·합류·보상을 확정한다. 공동 이동도 각자가 목적지와 수단에 동의하며, 파티 채팅은 최근80개, 공동 창고는 파티장 승인 출금이다. 개인 메인 선택을 파티장이 대신 정하지 않는다. [파티 규칙](fantasy-party.md)을 함께 따른다.

자동 전술의 초반51종족·중급168조합과 세부 갈래를 사용하는1,174전에서 정체나 무한 회복은 없었다. 현재 고룡 기준은Lv20 인간6인·소환 동료2명·동일한 기술 숙련과 회복 재고다. 첫 최상급 도전 전에 정상 제작 가능한 최고 장비는100전 중48승, 같은 제작법의 일반 재료·보석 없는 장비는100전 중2승이었다. 실제 브라우저의 이동·방어·승리·전용 기술 사용과 두 탭의 파티·창고·동의 이동도 확인했다. 자동 전략 표본과 두 탭 검수는 모든 조합이나 여러 PC의 장기 플레이를 대체하지 않는다. 현재 인원 계산 정책은 `provisional-1`이며 모르는 정책은 거절한다. 장비와 난도 기준은 [전투 검증](fantasy-combat.md)을 따른다.
