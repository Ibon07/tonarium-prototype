# 작업 중간 판정과 기록

새로 시작한 일하기는 게임 4시간, 실제 8분을 예약하고 **게임 15분마다, 실제 30초마다** 총 16번 판정한다. 판정 때마다 직업에 맞는 짧은 사건과 받은 금화·경험치를 기록한다. 도둑은 소매치기, 요리사는 주문 요리 준비, 대장장이는 금속 가공, 사제는 신전 돌봄처럼 38직업에 각각 맞는 작업명을 사용한다.

중간 금화와 경험치는 그때 실제로 지급한다. 작업 종료 기록은 그동안의 합계이며 다시 지급하지 않는다. 전부 성공했을 때의 기본 금화14·경험치10, 전부 실패했을 때의 기본 금화5·경험치4로 기존 4시간 일의 예산을 유지한다. 정수 보상을 16회에 분산하므로 어떤 회차에는 금화나 경험치가 0일 수도 있다. 보상 패시브나 준비한 보상 기술은 전체 작업에서 한 번만 반영한다. 직업 숙련과 평판·농사/어업 생산물은 종료에 정산한다. 범죄 작업은 두 판정에 한 번씩 성공에 악명1, 실패에 악명2가 추가되며 100을 넘지 않는다. 빈도가 늘어도 작업 전체의 악명 범위는 기존과 같다.

저장된 `activity.work`에는 완료 횟수·성공 횟수·이미 받은 금화·경험치와 `totalSteps:16`을 기록한다. 각 회차의 판정은 예약 때의 seed와 회차로 정해지며 클라이언트가 결과를 제출하지 않는다. 접속 중 자주 갱신하거나 오프라인 뒤 한꺼번에 갱신해도 순서와 보상이 같다. 오프라인 작업도 중간 시각이 되면 서버가 처리한다. 저장에 실패하면 진행·보상 전체를 확정하지 않고 같은 결과로 재시도한다. `totalSteps`가 없는 이전 중간 기록은 기존 8회·실제 1분 간격과 회차별 보상을 그대로 이어간다. 중간 기록 자체가 없는 더 오래된 작업은 종료 시점의 한 번 정산을 유지한다. 어느 경우에도 이미 받은 보상을 다시 지급하거나 진행 횟수를 초기화하지 않는다.

피로와 허기는 각각 50·70·90 이상일 때 판정에 1·2·3씩, 합계 최대6을 감점한다. D6·D8 같은 작은 주사위의 보정 상한에 도달한 숙련자도 이 불이익을 받는다. 진행 중 정각을 지날 때 욕구와 상태이상을 갱신하므로, 중간 판정은 그때의 상태를 사용한다. 정각을 지나지 않은 반시간 식사·기도는 반올림된 피로 수치를 새로 만들지 않는다.

세계의 야간은 18시부터 다음 날 6시 전까지다. 도시·탑 바깥에서는 조명이 없을 때 어둠 감점3과 날씨·복식·기온 감점이 적용된다. 범죄 직업은 야간 일하기에만 보정1을 받고 그 작업의 어둠 감점은1로 줄어든다. 야간 채집·사냥 등을 조명 없이 할 수 있는 면제는 주지 않는다.

작업·숙박·여행 등 기간 행동 중에는 동기화 외의 새 행동을 시작할 수 없다. 기도·매매·기술·장착도 서버에서 거절한다. NPC 대화 제한과 비활성 버튼 안내는 게임 화면에서 이 상태를 함께 사용한다.

구현은 `shared/fantasy-work.ts`, `shared/fantasy-engine.ts`, `server/fantasy-store.ts`이며 중간 기록의 세 언어 표시는 `fantasyWorkLogText`를 사용한다. 테스트는 `shared/fantasy-work.test.ts`에서 주기·재접속·저장 실패·직업별 예산·피로와 야간 보정·기존 저장을 확인한다.
