# 고용 전투원과 부대

고용원장에서 전투원으로 편입한 NPC는 `worker-${npc.id}` 부대원으로 저장한다. NPC 후보 중 `combatJob`이 등록된 여섯 명만 전투원이 된다. 일반 직업도 이미 편입한 고용 전투원을 편성·치료·재계약·제적할 수 있다. 이전 지도자 직업의 부대 기록이 남아 있어도 새 고용 전투원 기록과 함께 보존한다. 지도자·범죄조직두목·소환술사의 기존 부대·조직·소환 모집과 지휘 제한은 유지한다.

원장을 거치지 않는 `command.hire worker-*`는 거절한다. 기본 모집 목록에도 이 NPC를 넣지 않는다. 실제 편입은 기존 고용 소유권·생애·활동 상태를 확인한 원장 행동이 `enlistFantasyWorkerCompanion`을 호출하는 경로로만 처리한다. 편입한 계약의 소유권과 생애 검증은 고용원장에서 담당하며, 사망 후 새 생애에 자동 상속하지 않는다.

`FantasyCompanion`의 기존 다섯 필드는 유지하고, 고용 당시 성장 수준을 `workerLevel` 1~6으로 선택 저장한다. 전투 능력은 이 값과 기존 `missions` 기록으로 성장한다. 유효 수준은 `workerLevel + floor(missions / 8)`, 최대10이다. 실제 HP·MP·공격·방어·기민함·지능·명중·마법 저항과 직업별 공격·방호·조준·속박·화염·치유 기술에 적용한다. 고용주의 현재 직업이 생산직이어도 전투원 자신의 수준과 직업을 따른다.

편성은 부대·조직·소환을 모두 합쳐 두 명까지다. 편성하지 않았거나 부상·이탈·HP 0인 동료는 전투나 탐사 지원을 제공하지 않는다. 전투 HP는 저장된 부상 비율을 반영하고, 쓰러진 전투원은 기존 부상·치료 경로로 돌아간다. 치료와 재계약은 수준과 임무 기록을 보존한다. 전투 조작은 기존 소유자 ID와 생애 검사를 사용하므로 다른 플레이어는 명령할 수 없다.

일반 직업에는 고용 전투원 메뉴를 표시한다. 범죄조직두목이나 소환술사가 고용 전투원도 보유하면 기존 소속과 고용 전투원 관리 화면을 전환할 수 있다. 각 화면에 합계 전투 편성 상한, 고용 전투원의 수준·임무·HP·상태와 치료·재계약 비용을 한국어·영어·일본어로 표시한다.

## 검사 대기

사용자 요청에 따라 `shared/fantasy-worker-companions.test.ts`를 작성만 했으며 실행하지 않았다. 타입 검사·빌드·브라우저·추가 리뷰도 실행하지 않았다.

- 일반 직업의 소유 전투원 편입, 원장 우회 고용·중복 편입·비전투 후보·수준 위조 거절.
- 이전 지도자 부대와 새 고용 전투원 공존, 기존 직업별 모집 제한, 소속을 합친 실제 전투 편성2명.
- 다섯 필드 이전 저장과 `workerLevel` strict 검증, 고용 수준·임무 성장·직업별 실제 전투 기술.
- 탐사 지원·부상·치료·이탈·재계약·제적, 실제 전투 HP의 지속과 타인 명령 거절.
- 후속 일괄 검사에서 원장 소유자·생애 교차 검증, 저장 실패·재시작·이중 편입 요청, 사망·환생, 세 언어·직업 전환·작은 화면을 확인한다.
