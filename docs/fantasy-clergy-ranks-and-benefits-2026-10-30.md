# 신앙 등급과 등급 혜택 제안

## 2026-10-31 사제의 등급 소속 변경

사제와 모든 사제 세부전직은 **신전의 성직 등급만 사용**한다. 모험가 길드 등록·승급, 길드 승급 실적 적립, 모험가 등급 보상·할인·지명 의뢰 대상에서 제외한다. 주직업이 사제인 동안에는 서브직업과 무관하게 같은 규칙을 적용한다.

이전 직업에서 얻은 길드 기록은 삭제하지 않고 비활성 상태로 보관한다. 사제가 아닌 주직업으로 변경하면 기존 기록을 다시 사용한다. 이전 길드 대여 장비의 반납과 보증금 환급은 가능하다. 길드 시설 방문·주민 가공 서비스 자체를 금지하는 변경은 아니다.

후속 요청으로 범죄 직업도 길드 등록 대상에서 제외했다. 현재 명단과 적용 범위는 [길드 등록 대상](fantasy-guild-eligibility-2026-10-31.md)을 따른다. 생산·생활 서브직업에 별도의 모험가 등급을 부여하지 않는다. 아래 표의 모험가 등급 대응은 성장 난이도 비교이며 사제에게 모험가 등급을 지급한다는 의미가 아니다.

검사는 등록·승급 거절, 과거 기록의 비활성화·재사용, 할인·보상·실적 차단, 저장·재시작, 세 언어의 NPC/GM 답변과 대여 장비 반납을 포함한다. 관련 서버·공유 회귀 **42/42개**, UI **14/14개**를 통과했다. 기존 주·서브직업 단계의 전체 1,761개 검사와 구분하며, 이번 변경 후 전체 검사를 다시 실행한 것은 아니다. 원자료는 `work/qa/balance-v8-2026-10-31/priest-guild-{green,regressions,ui,completion}.log`에 보관한다.

## 구현한 성직 등급

사용자 후속 지시로 성직 1–5등급의 목표 도달 난이도를 모험가 1·2·4·6·8등급에 대응시켰다. `shared/fantasy-priest-ranks.ts`가 경계와 KO/EN/JA 명칭을 소유하고, 신앙 메뉴와 GM의 본인 정보에 사용한다. 별도 저장 필드 없이 현재 신앙에서 계산한다.

| 성직 등급 | 대응 모험가 등급 | 최소 신앙 |
| --- | --- | --- |
| 수련 사제 (1) | 코퍼 (1) | 0 |
| 서원 사제 (2) | 브론즈 (2) | 45 |
| 정식 사제 (3) | 골드 (4) | 135 |
| 고위 사제 (4) | 미스릴 (6) | 225 |
| 대사제 (5) | 마스터 (8) | 315 |

모험가 한 단계의 의뢰5건 × 봉사4+서약5 신앙 = 신앙45를 성장량의 기준으로 사용한다. 순례·교리·기도도 기존처럼 신앙에 더해진다. 전투력 심사와 과업의 차이가 있으므로 실제 소요 시간의 동등성을 측정한 것은 아니다. 성직 등급 취득에 모험가 등록 등급이나 전투력 심사를 요구하지 않는다.

신앙은 기존의 기도·봉사·교리 독서·성소 순례·이행한 서약으로 쌓는다. 기술 성장용 기존 신앙 경계0/20/45/80/130과 내부 단계0–4는 성직 칭호와 분리하여 스킬의 신앙 보정과 전직 조건을 추가로 높이지 않았다. 성직 등급은 사제 전문 분기와 독립적이며, 대사제가 되어도 성자/성녀·성기사·이단심문관으로 자동 전직하지 않는다. 신전의 지도자 권한도 자동 지급하지 않는다. 직업 변경 시 기존 신앙 기록은 유지하고 사제 전용 메뉴는 기존처럼 숨긴다.

## 혜택 제안 — 아직 구현하지 않음

등급은 신분과 기관의 신뢰를 나타내도록 보급·숙박·정보·의뢰에 보상을 둔다. 전투 스탯은 기존 숙련·기술·장비 성장으로 조정한다. 아래는 사용자가 선택할 수 있는 구체적인 제안이며 현재 지급되는 혜택으로 표시하지 않는다.

### 모험가

| 등록 등급 | 누적 혜택 제안 |
| --- | --- |
| 코퍼 (1) | 길드 시설과 일반 의뢰 이용 |
| 브론즈 (2) | 원정용 랜턴·침낭을 보증금으로 대여 |
| 실버 (3) | 하루 한 번 지명의뢰. 이 항목은 앞선 작업에서 이미 코드에 연결됨 |
| 골드 (4) | 하루 한 번 한정 수량의 길드 보급품 5% 할인 |
| 플래티넘 (5) | 협약 여관 숙박료 5% 할인 |
| 미스릴 (6) | 하루 한 번 길드 중개 호위 의뢰의 보수 5% 추가 |
| 아다만트 (7) | 고위험 의뢰의 사전 정찰 보고서와 대규모 원정 준비 지원 |
| 마스터 (8) | 명예 칭호·명예의 전당·전용 의뢰와 기관의 특별 대우 |

### 사제

| 성직 등급 | 누적 혜택 제안 |
| --- | --- |
| 수련 사제 (1) | 신전의 기존 기도·봉사 이용 |
| 서원 사제 (2) | 순례자 숙소 이용권. 실제 쉼 시간과 유한 정원 적용 |
| 정식 사제 (3) | 신전 치료비 10% 할인 |
| 고위 사제 (4) | 신전 서고의 희귀 교리서 열람과 한정 성물 재료 구매권 |
| 대사제 (5) | 신전의 명예 칭호·상위 봉사/의식 의뢰·특별 순례 초청 |

향후 적용 시 할인은 평판·흥정과의 합산 상한을 두고, 대여는 반환/보증금, 보급은 일일 전역 수량, 서고는 해당 신전 소장 목록을 존중해야 한다. 무료 무제한 회복이나 성직 등급만으로 기적 지급은 제안하지 않는다. 특별 대우와 명예 칭호 역시 유저의 파티장 권한이나 다른 플레이어의 행동을 강제하지 않는다.

## 검증 상태

사용자 지시에 따라 테스트·타입 검사·빌드·브라우저 검사는 실행하지 않았다. 다음 일괄 검사 때 신앙 0/44/45/134/135/224/225/314/315 경계, 세 언어 명칭 및 숫자 괄호, 사제 외 직업의 메뉴 숨김/기록 유지, 기존 신앙 스킬 보정 유지, 대사제와 성자/성녀 분기의 독립을 확인한다. 혜택 제안은 기능을 켜거나 저장 상태를 바꾸지 않는다.
