# 파티와 개인 이야기 진행

판타지 월드의 파티 메뉴에서 최대6명이 함께 조사·이동·전투하고 파티 채팅과 공동 창고를 이용한다. 같은 판타지 세션의 살아 있는 인물이 초대를 직접 수락해야 참가한다. 파티장은 동료를 초대하고, 전원 준비가 끝난 조사·이동·전투를 시작한다. 다른 사람의 준비·선택·직업·구매를 대신 결정하지 않는다.

## 함께 조사하는 순서

1. 파티를 만들고 같은 세션의 동료를 초대한다. 초대는 실제2분 동안 유효하다.
2. 각자가 메인 의뢰를 수락하고 같은 장소의 같은 세부 조사 단계로 이동한다.
3. 각자 자신의 조사 방법을 고르고 준비한다. 관찰·분석·복원을 서로 다르게 골라도 된다.
4. 2~6명 전원이 준비하면 파티장이 함께 조사를 시작한다. 준비도 실제2분 뒤 만료된다.
5. 같은 세계 시각에 예약하지만 판정은 각자의 능력·장비·기술·피로·허기·환경으로 따로 진행한다. 시작만으로 증거나 보상을 주지 않는다.

성공한 사람만 자신의 해당 단계와 최초 성공 경험치를 얻는다. 실패한 사람은 개인 조사로 재시도할 수 있다. 이미 성공한 사람에게 같은 단계의 증거·경험치를 다시 지급하지 않는다. 서로 진행도가 다르면 개인 진행으로 맞춘 뒤 다시 함께 조사한다. 파티 전용 추가 능력치나 인원수 보너스는 없다.

파티에 들어가는 것만으로 의뢰가 수락되거나 단서·지도·완료 기록이 복사되지 않는다. 상위 진행자의 위치명과 단서도 초보자에게 보여 주지 않는다. 명단에는 이름·파티장 여부·같은 장소인지·조사 호환 여부·준비 여부만 전달한다. 개인 소지품·NPC 대화·이야기 선택·비용을 자동 공유하지 않고, 공동 창고에는 직접 기부한 물품만 공개한다.

## 준비와 저장

각자의 준비는 현재 인생·장소·조사 단계에 연결된다. 개인 행동을 시작하거나 이동·사망·전생·접속 종료·세션 이탈이 발생하면 준비가 해제된다. 참가자가 늘거나 줄면 전원 다시 준비한다. 파티장이 떠나면 남은 순서의 다음 인물이 맡는다. 이미 시작한 개인 활동은 파티 탈퇴로 취소되거나 다른 사람에게 넘어가지 않는다.

조사 시작은 모든 참가자의 예약을 한 번에 저장한다. 한 명이라도 조건이 맞지 않거나 저장에 실패하면 아무도 시작하지 않는다. 완료 후의 각자 판정과 기록은 기존 개인 저장 방식으로 유지한다.

파티 명단·초대·준비는 현재 서버 연결 동안만 유지한다. 서버가 재시작되면 파티를 다시 만들지만, 저장한 개인 조사 예약·성공 증거·의뢰·이야기 선택은 남는다. 같은 사람이 여러 창을 열어도 정원을 여러 번 차지하거나 보상을 여러 번 받지 않는다.

## 개인 선택과 재등장 인물

기존18장·48개의 조사 흐름 사이에 개인 선택4종을 더했다. 1장의 미라에게 하는 약속,7장의 부상 운반인 구조,10장의 지도 매입 요구 대응,12장의 답장과 귀환 준비 우선순위다. 각각 두 방법이 있으며 표시된 금화나 피로만 본인에게 적용한다. 선택은 인생별 한 번이고 포기·재수락으로 비용과 결과를 되풀이하지 않는다. 추가 경험치·단서·금화 보상은 없다.

이 선택은 부가 장면이므로 기존 예약과 진행을 막지 않는다. 선택하지 않고 조사하는 것도 가능하다. 핵심 정답과18장 완결은 유지하고, 어떻게 도왔는지와 누구에게 무엇을 약속했는지가 기록과 인물 반응에 남는다. 파티원끼리 다른 방법을 골라도 함께 조사할 수 있다.

미라·사피·리라는 진행 지점에 따라28개의 서로 다른 반응을 보인다. 미라는 답장을 기다리는 두려움, 사피는 항로를 나누고 싶은 마음, 리라는 검증되지 않은 항로 공개의 위험을 중심으로 의견을 주고받는다. 직접 방문해 여정·걱정·지도·약속을 물으면 확인한 단계와 본인의 선택에 맞춰 답한다. 미확인 답장이나 섬의 정식 이름을 앞당겨 말하지 않는다. 받은 의뢰에서도 현재 장소의 인물 반응을 펼쳐 읽고, 기록에서는 실제 선택한 결과를 다시 읽는다.

## 파티 전투

전투 메뉴에서 각자 같은 상대에 준비한 뒤 파티장이 ‘함께 전투 시작’을 누른다. 최상급 도전과 사람 선제공격의 위험도 본인이 확인해야 한다. [전투 규칙](fantasy-combat.md)에 따라 각자의 행동을 입력하며 전술 지형·앞뒤 진형·아군 회복·방호·소모품과 소유한 부대·소환 동료의 명령을 사용할 수 있다. 실제 참전자 수로 적의 시작 능력을 정하며 중도 퇴각으로 적을 약하게 만들지 않는다. 경험치는 실제 기여자별, 금화·소재는 전투 전체 수량 안에서 분배한다.

같은 파티·세션·장소에 있는 동료의 진행 중 전투에 본인이 합류를 요청할 수 있다. 살아 있는 인물이어야 하고 현재 활동·다른 전투·미해결 사건이 없어야 한다. 조사 전투는 자신의 해당 진행 단계가 맞아야 한다. 최상급 도전은 합류자도 현지 경고를 직접 확인하고 명시적으로 동의해야 한다. 최상급과 사람 선제공격의 위험 확인을 파티장이 대신하지 않는다.

중도 합류 후에도 플레이어는 최대6명이다. 전장의 기존 참가자가 퇴각·사망해도 정원을 다시 뚫거나 적을 약하게 계산하지 않는다. 새 참가자는 적의 능력을 상향하는 쪽으로만 반영하고, 이미 가한 피해를 비율로 지우거나 체력이0인 적을 되살리지 않는다. 합류 때 전장 버전을 높이고 기존 라운드의 모든 플레이어·부대 명령을 지운 뒤 실제1분의 새 입력 기한을 연다. 아직 확정되지 않은 소모품은 소비하지 않으며 모든 생존자는 행동을 다시 선택한다. 저장에 실패하면 참가자 연결과 적 능력도 모두 이전 상태를 유지한다.

[인원별 전투 계산](fantasy-party-combat-plan.md)의 기본 계수는 실제 턴 전투에 연결했으며 다양한 종족·직업의 실제 플레이로 계속 조정해야 한다. 파티장이 다른 사람의 이야기 선택을 강제로 정하는 기능은 두지 않는다.

## 동의한 공동 이동

같은 장소의2~6명이 각자 같은 목적지와 이동수단을 고르고 준비한 뒤 파티장이 출발한다. 목적지를 아는지, 이동 가능한 경로인지, 본인의 운임을 감당하는지 각각 확인한다. 준비는 실제2분 후 만료하고 개인의 인생·장소·경로 시간·운임이 달라지면 다시 선택해야 한다.

출발 예약은 전원을 한 번에 저장한다. 한 명이라도 조건이 맞지 않거나 저장이 실패하면 아무도 출발하지 않는다. 출발 시각은 같고 도착은 동의한 사람 중 가장 느린 이동 시간에 맞춘다. 개인 이동 보정이나 평판으로 다른 사람의 금화를 대신 내지 않고, 각자의 정상 운임을 완료 때 따로 처리한다. 이동 중에는 원래 장소에 진행 중인 이동 경로를 표시하며 받은 의뢰·개인 단서·개인 선택을 복사하지 않는다. 이동을 시작한 뒤 파티에서 나가도 이미 저장한 개인 이동은 계속된다.

## 파티 채팅

같은 파티의 참가자에게만 최근80개 메시지를 전달한다. 메시지당500자이며 빈 글·제어문자·위조 작성자 필드는 거절한다. 다른 파티나 판타지 세션에는 표시하지 않고, 탈퇴·세션 이동 후에는 옛 파티의 채팅을 새로 받지 않는다. 채팅·명단·초대·준비는 서버 재시작 후 유지하지 않는다. 기존 개인 NPC 대화와 메인 선택 기록은 별개다.

## 공동 물품 창고

살아 있고 현재 활동·전투·사건이 없는 파티원은 자신의 실제 물품을 창고에 기부할 수 있다. 개인 인벤토리 전체를 보여 주지 않으며 금화 송금 기능은 추가하지 않는다. 착용 중인 무기·갑옷·의복은 먼저 벗어야 하고, 개별 제작 장비는 실제 개체를 지정한다.

음식은 수량과 최초 제작·획득 시각을 그대로 보관해 신선도가 초기화되지 않는다. 제작 장비도 품질·재료·보석·추가 능력치·제작 시각을 보존한다. 충돌 없는 소지품 개체ID는 새로 부여할 수 있지만 성능을 다시 추첨하지 않는다.

물품은 먼저 출금을 요청하고 파티장이 승인한다. 파티장이 자기 요청을 처리할 때도 요청 후 승인 순서를 따른다. 승인 시 요청자와 파티장은 같은 장소에 있어야 하며 요청자의 인생·활동·수량을 다시 확인한다. 타인의 승인 권한 위조, 오래된 창고 버전, 중복 요청과 이미 처리한 요청의 재사용은 거절한다. 거절은 요청만 없애고 물품을 소비하지 않는다. 승인한 물품은 실제 수령자의 개인 소지품이 된다.

창고·기부자 차감·수령자 지급은 개인 기록과 같은 저장 파일에서 원자적으로 확정한다. 저장에 실패하면 기부·승인·환수 어느 쪽도 일부만 적용하지 않는다. 요청 처리 전에 파티원의 세계 시각을 맞추므로 음식의 원래 시각을 보존해도 늦게 갱신된 수령자의 저장을 깨뜨리지 않는다.

탈퇴할 때 아직 분배하지 않은 본인의 기부 잔량은 원래 기부자에게 돌려준다. 환수 저장에 실패하면 탈퇴를 확정하지 않는다. 서버 재시작 때 파티는 해산하며 아직 분배하지 않은 기부물은 살아 있는 같은 인생의 기부자에게 한 번만 반환한다. 이미 승인받아 다른 사람에게 전달된 물품은 회수하지 않는다. 사망했거나 새 인생으로 바뀐 기부자의 물품은 새 인물에게 상속하지 않고 기존 기부 기록에 남긴다.
