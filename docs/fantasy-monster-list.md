# 현재 몬스터와 사람 전투 상대

현재는 몬스터58종과 사람 적대자5종, 총63개 전투 대상이 있다.

[전체 목록과 기본 능력치](fantasy-combat-monsters.md) · [전투와 최상급 도전 규칙](fantasy-combat.md)

슬라임·고블린·오크·해골·트롤·오우거·그리핀·와이번·히드라·드래곤에 미믹·코볼트 습격자·하피·바실리스크·만티코어·가고일·듀라한·리치·피닉스·트리엔트를 더했다. 노상강도·밀렵자·철가면 사병·경비대·기사도 사건에 따라 상대할 수 있다.

기존48종 가운데 최상급4종은 일반 사냥에서 제외했다. 고룡·고대 서리용·고대 폭풍용·공허빛 키메라는 위험한 장치를 조사하고 직접 도발해야만 전투를 시작하며 메인에 강제로 등장하지 않는다. 본편에는 초반부터 후반까지8개의 간헐적 통로 전투가 있다.
