# 기나긴 여정 — 배포 전 간단 검증 · 2026-10-31

이번 PR은 누적된 RPG 변경을 최신develop에 통합하고, Tonarium 로그인으로 월드에 진입하게 한다. 별도 RPG 가입·비밀번호·복구·이전 기능은 폐기한다. GM의 성장 힌트도 현재 본업·생활직·활동에 맞게 추가했다.

## 데이터 전환

**이 버전의 첫 서버 시작에서는 기존 RPG 계정과 모든 캐릭터·소지품·재산·진행도 및 RPG 전용 백업·진단 기록을 영구 삭제한다.** 사용자가 기존 RPG 캐릭터와 진행도도 초기화하도록 명시했다. Tonarium 계정DB·홈·친구·DM·다른 월드는 보존한다. 한 번 완료한 뒤에는 새 RPG 진행도를 재시작 후에도 보존한다. 삭제 범위·실패 시 동작·완료 마커는 [로그인 전환 안내](fantasy-accounts.md)와 [백업 안내](fantasy-backups.md)에 적었다.

검증은 별도의 임시 디렉터리와 localhost전용 PostgreSQL17의 일회용DB로 수행했다. 운영 서버나 기존 실제 DATA_DIR에 초기화를 실행하지 않았다.

## PR 자동검사 후 추가 확인

GitHub 자동검사에서 외부 HTTPS AI 통합 테스트의 준비 데이터가 새 초기화 절차로 삭제되어, AI 응답 대신 캐릭터 생성 안내를 받는 실패를 재현했다. 테스트용 현재 데이터 마커를 넣고, 월드 입장 전 비공개 정보가 없으며 입장 뒤 의도한 캐릭터가 불러와졌는지 확인하도록 고쳤다. 실제 서버의 초기화·인증 조건은 완화하지 않았다. 사용하지 않는 이전 테스트 우회 환경변수도 제거했다.

수정 후 `test:kokoa-ai`16/16, `test:npc`163/163, `server/fantasy-gm-chat.test.ts`21/21을 순차 실행해 통과했다. HTTPS 검사는 로컬 모의 제공자로 전송·인증·스트리밍을 확인하며, 운영 KokoaAI의 실대화 품질을 검증한 결과는 아니다. 마지막 테스트 수정 뒤 타입 검사도 통과했다.

## 검증 중 수정

로그아웃한 인증 세션의 기존 WebSocket이 RPG명령을 계속 실행할 수 있던 문제를 재현해 수정했다. 로그아웃 응답 전 해당 세션의 연결만 닫으며, 같은 계정의 다른 세션은 유지한다. 명령과 RPG 비공개 데이터 송신 전DB에서 세션·만료를 다시 확인하므로 외부에서 삭제하거나 만료시킨 세션도 차단한다. 늦게 도착한 비공개 응답도 새 계정 화면으로 넘기지 않는다.

초기 PR에는 가공 담당 NPC21명의 개별 SVG를 보완했다. 이후 사용자의 추가 요청에 따라 이21명과 보급 담당·지도 상인2명을 기존 그림체의 상반신 WebP로 다시 제작했다. 현재 게임에서는160명 전원 개별 WebP를 쓰고 SVG 대체 표시는 제거했다. 기존137장의 래스터 파일과 제작 기록은 유지했다.

## 범위와 남은 확인

이번 요청에 맞춰 간단한 회귀 검사를 수행했으며, 긴 전투 승률 시뮬레이션을 다시 실행하지 않았다. 이전 단계의 전체 RPG1985건 등의 기록을 이번 코드 전체 검사 결과로 주장하지 않는다. 운영 서버의 장시간 플레이·다중 사용자 부하·외부KokoaAI의 실대화 품질은 배포 후 로그로 확인할 영역이다.

빌드는 성공했지만 Vite의 큰 청크 경고는 남아 있다. 실제 기기별 초기 로딩 속도와 추가 코드 분할은 별도의 성능 확인 대상이다. PR생성은 배포나 병합을 의미하지 않는다.
