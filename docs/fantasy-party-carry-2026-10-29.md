# 파티 목록에서 동료 부축 — 2026-10-29

부축과 내려놓기는 전투 중 행동 선택에서 제거하고 파티 탭의 동료 목록으로 옮겼다. 빈사인 동료 행에는 `부축하기`, 현재 부축 중인 동료 행에는 `내려놓기`를 표시한다. 자신에게는 부축 버튼을 표시하지 않는다.

`FantasyPartyPanel.tsx`는 기존 `{t:'fantasyAid', target, method:'carry'|'putDown'}` 요청을 사용한다. 요청 중에는 기존 `fantasyPending`으로 중복 클릭을 막고 프로필 응답을 받으면 기존 수신 처리가 대기를 해제한다. 새 전송 프로토콜이나 별도 클라이언트API는 추가하지 않았다.

화면은 연결·요청 대기, 자신의 생존/의식, 진행 중 행동·사건·전투·이동·귀환 기도를 확인한다. 동료가 같은 장소와 던전 방에 있는지 확인하고 이미 다른 동료를 부축하거나 대상이 다른 사람에게 부축되고 있으면 이유와 함께 비활성화한다. 내려놓기는 자신의 저장된 부축 기록이 현재 파티와 자신의 생존 세대에 맞고, 서버의 파티 정보가 자신을 부축자로 보고 있을 때만 활성화한다.

공개 파티 명단에는 다른 인물의 생존 세대나 전체 활동 정보가 없으므로 클라이언트가 이를 추정해 만들지 않는다. 서버의 기존 부축 처리는 실제 대상 세대, 위치·던전 방·생성된 던전 배치, 유효한 빈사 상태와 만료 시각, 활동/전투, 파티와 부축 중복 여부를 최종 확인한다. 오래된 파티 화면에서 버튼을 누르더라도 서버 검사를 우회하지 않는다.

`FantasyPartyExtras.tsx`는 기존 간호·귀환 패널에 `showCarryControls={false}`를 전달한다. 이에 따라 동료 목록 밖에 중복 부축/내려놓기 버튼이 나타나지 않고, 간호와 귀환의 등불, 수락/거절, 현재 부축 상태 표시는 유지한다.

`FantasyCombatPanel.tsx`에서는 부축/내려놓기 행동, 부상자 대상 선택, 내려놓을 칸 선택과 안내를 없앴다. 기존 부축 중 표시, 이동 거리 제한, 이동 기술 제한은 유지한다. `fantasyCombatOrderError`는 소유권·생존·동료 명령 권한 확인 이후 공개 `carry`/`putDown` 요청에 `blocked`를 반환하며 중첩된 동료 명령도 같은 경로로 거부한다.

기존 전투 상태의 `carrying`/`externalCarrying`, 부축 관계 유효성 검사, 이전에 저장된 명령·관계의 정리와 전투 종료 시 처리는 삭제하지 않았다. 이번 수정은 새 전투 중 부축 명령을 차단한다. 사용자는 전투가 끝난 후 파티 행에서 부축/내려놓기를 선택한다. 동시에 진행 중인 길드 토벌의 최대6명·6마리 지원 변경도 유지한다.

사용자 요청에 따라 테스트·타입 검사·빌드·브라우저 QA는 실행하지 않았다. 배포 전 다음 확인이 필요하다.

- 같은 장소의 빈사 동료 행에서 부축하고 지도/던전 이동 후 같은 행에서 내려놓기.
- 자신, 의식 있는 대상, 다른 장소/방, 다른 세대, 사망 또는 빈사 만료 대상의 거부.
- 이미 한 명을 부축 중이거나 대상이 다른 동료에게 부축되고 있을 때의 비활성 이유와 서버 거부.
- 전투·행동·사건·이동·귀환 기도·연결 종료·요청 중 버튼 상태와 응답 후 대기 해제.
- 공개 직접 명령 및 중첩 동료 명령의 `carry`/`putDown` 거부, 이전 전투 저장의 정리와 재접속.
- 부축/내려놓기 선택 UI가 전투 행동/대상/칸 안내에서 사라지고 기존 부축 상태·이동 제약은 남는지 확인.
- 부축을 파티 목록으로 옮긴 뒤에도 길드 예약 토벌의 참가·집결·출발 버튼,6명 대6마리 전장과 일반 전투 행동이 표시되는지 확인.
- 간호·귀환의 등불 및 수락/거절, 한국어·영어·일본어 문구와 좁은 화면에서 파티 행 줄바꿈 확인.
