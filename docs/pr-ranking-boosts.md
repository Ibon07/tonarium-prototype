# ADランキングに記録ごとのBoost数を表示

ランキング送信時の `game.dimensionalBoosts` を、手動・自動共通の送信経路で保存する。代表行と展開した各行には、その記録自身の値を表示する。順位・代表選択・本人表示・認証の処理は維持する。

指定されたBoost数は非負の安全な整数のみ受け付け、不正値は保存前に400で拒否する。旧データと旧形式の送信は省略のまま扱い、公開応答は明示した項目だけを返す。

## 利用者向けの変更

- ADランキングで、反物質量と各記録の送信時点のBoost数を比較できる。
- Boost数のない旧記録は未取得と表示し、実測の0と区別できる。日本語・英語・韓国語に対応する。
- 狭い画面では横スクロールで追加列にアクセスできる。
