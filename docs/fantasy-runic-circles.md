# 마법진·연금술·생산과 발견

2026-10-29 구현 기준이다. 아래 수치와 조건은 개발 검증용 설명이며, 미발견 전직 조건이나 미습득 기술을 게임 메뉴에 공개하지 않는다. [기술별 실제 효과](fantasy-combat-capabilities.md), [탐사 진행](fantasy-dungeons-magic.md), [가구와 부동산](fantasy-property-plan.md)을 함께 참고한다.

## 핵심 하나와 원형 룬 슬롯

마법진 중앙에 핵심 속성을 놓고 주위에 배운 룬을 배치한다. 현재 직업 숙련 XP가0/30/100일 때 추가 노드는2/4/6개, 저장할 주문은1/2/3개다. 빈 노드를 모두 채울 필요는 없고 같은 룬을 여러 칸에 넣을 수 있다. 중복한 룬도 각자 칸을 차지하며 위력 점감과 상한을 유지한다. 합성에는 세계 시간1시간이 들며 MP는 실제 발동 때 소비한다. 저장 전 표시하는 위력·MP·사거리·반경은 서버와 같은 컴파일러의 결과다.

마법사는 전직 시 화염·물결·질풍·대지와 집중·분산·절감을 익힌다. 충격 핵심은 별도로 발견하며 물리 피해를 준다. 회복 핵심과 예전 물·빛 회복 조합은 **사제 전용**이다. 마법사는 회복 합성 주문을 만들거나 발동하지 못하고, 구버전에 저장해 둔 주문도 생활·전투에서 사용할 수 없다. 저장 자료와 숙련 기록 자체는 지우지 않는다. MP 회복 기술은 이 제한과 별개다.

| 룬 | 실제 변화 |
| --- | --- |
| 집중 | 단독 위력×1.35, 사거리−2, 반경−1 |
| 분산 | 위력×0.75, 반경+1 |
| 절감 | 위력×0.8, MP×0.65 |
| 연장 | 사거리+2, MP+2 |
| 공명 | 단독 위력×1.2, MP×1.3 |
| 수호 | 호환되는 회복·정화·축복에 방호4, MP+3 |
| 서리·잔불 | 공격에 둔화1 또는 화상3, 각각 MP+3 |
| 청정 | 호환되는 사제 주문에 정화, MP+3 |
| 생환 | 성인의 기적으로 전투 중 빈사 아군을 일으킴 |

위력 증가를 선형으로 계속 더하지 않는다. 집중·공명·별 문양은 남은 증폭 여지를 나누어 쓰므로 함께 써도 증가폭이 줄며 증폭 계수는1.65에 수렴한다. 분산·절감의 위력 손실은 별도로 적용한다. 최종 위력은1~100, MP는2~60, 사거리 상한10, 반경 상한2다. 일반 합성은 상한을 적용하기 전 사거리·반경 중 하나라도0 이하이면 제작할 수 없다. **자기 축복과 자기 회복만0을 허용**하고 음수는 허용하지 않는다.0을 사용하는 회복은 자신만 대상으로 삼으며, 다른 사람에게 쓰는 축복·회복은 양의 사거리와 실제 타일 거리를 검사한다. 실제 전투 피해에는 지능·방어·저항·명중·엄폐 등도 적용되므로 표시 위력을 확정 피해로 취급하지 않는다.

화염·얼음·대지·바람·별 문양은 현재 선택한 전문 분야가 허용해야 쓴다. 과거에 다른 경로로 배운 기록만으로 사용할 수 없다. 별마법사는 별내림섬의 실제 야간 관측과 마법사 수련이 필요하며 일반 도서 목록만 읽어서는 열리지 않는다. 마법사·사제의 기초 직업 기술은 각각4개로 줄였고, 대체된12개 고급 기술 ID는 저장 호환과 숙련 보존을 위해 남겨 두되 메뉴와 사용 목록에서는 제외한다.

## 사제와 빈사

사제는 신성 공격·치유·정화·결계를 합성한다. 기존 네 분기에 이단심문관·성기사·성인/성녀 경로를 더했다. 축복은 이단심문관·성기사 자신에게만 적용한다. 성인/성녀는 더 깊은 봉사·순례·기도·서약과 실제 발견을 요구하고 생환 룬을 포함한 기적을 사용할 수 있다. 상세 전직 수치는 게임 메뉴에 노출하지 않는다.

전투 중 HP0이면 즉시 영구 사망시키지 않고 빈사 상태로 둔다. 아군을 대상으로 하는 일반 회복과 회복약은 전투 중 빈사를 깨우지 못한다. 기적은 살아 있는 시전자가 쓰러진 다른 아군에게 사용하며 영구 사망한 인물은 되살리지 못한다. 빈사 동료는 기적의 대상이 되도록 전장에 남는다.

전투 뒤에는 신전에서 치료하거나 회복약으로 응급처치할 수 있다. 신전 치료는 최대HP에 따른 비용을 내고 즉시 회복한다. 약 처치는 세계 시간2시간 뒤 의식을 돌려주며 반복 투여로 대기 시간을 줄이지 못한다. 미처치 상태는6시간의 구조 기한을 갖고 기존 마을 인접 구조·오지 영구 사망 규칙을 적용한다. 전투가 계속되는 동안에는 기적의 기회를 먼저 보장한다. 같은 위치·같은 월드의 파티 동료도 자신의 비용과 약으로 도울 수 있고, 두 사람 변경은 같은 저장으로 확정한다.

## 발견과 전투 정보

룬 관련 도서8권, 직업별 발견 유산151종, 별내림섬을 연결했다. 실제 최초 조사 보상과 독서 완료 기록으로 지식을 배운다. 취소한 독서나 가짜 방 보상으로 지식을 받지 못한다. 유산은 당시 직업과 실제 방에 맞춰 정해지고 재접속·직업 변경으로 같은 방을 반복 추첨하지 못한다. 도서는 세계 안의 문헌으로 읽히며 시스템 명령문을 본문에 넣지 않는다.

전투 행동·기술·대상은 접이식 메뉴에서 고른다. 기술은 실제 효과와 MP·범위·자기 자신 대상 가능 여부를 표시한다. 명중률은 판정에 사용하는 공통 함수로 계산하고 거리·조준·상태·직업 상황 보정을 반영한다. 원거리·마력 공격은3칸을 넘으면 칸마다 명중 보정이1씩 감소하고 최대10까지 줄어든다. 자연1·20과 정수 D20 목표 때문에 최종 표시 확률은5% 단위다. 장애물과 시야 때문에 공격할 수 없으면 확률 대신 사유를 표시한다.

몬스터에는 물리·마법 피해 배율을 따로 두고 실제 피해와 설명에 반영한다. 화염술사 대 얼음 장애물, 용창사 대 용, 사제 대 언데드 등 현재 직업·전문 분야와 맞는 상황에서만 보정한다. 생활 판정도 직업에 맞는 지형과 활동에서만 작은 보정을 받는다.

신속·재생·명료·반격 가시·생명 흡수·불굴과 약화·틈새 노출·시야 교란·출혈·속박·침묵의12가지 효과를 직업·종족에 배분했다. 전투는 실제 이동·명중·피해·지속 회복·기술 제한에 적용한다. 생활에서 쓸 수 있는 효과는 신속·재생·명료·불굴이며3시간 유지한다. 재생은 시간이 흐를 때 실제 잃은 HP만 회복한다. 준비만 반복하거나 효과 없이 사용하는 것으로 숙련을 얻지 못한다.

마나 명상·회복의 기도·회복의 후렴은 HP 회복 또는 중복 준비 효과 대신 MP를 회복한다. 전투에서는 자신이나 살아 있는 아군에게 쓸 수 있고 전투당1회, 세계 시간6시간 재사용 간격을 함께 검사한다. 실제 회복된 경우만 유효 사용으로 기록한다.

## 연금술과 소환

연금술사는 현지 공방에서 약초와 몬스터 부산물을 함께 골라 투척병·안개 분무·접촉유를 만든다. 재료 슬롯은 숙련0/30/100에서2/3/4개다. 모든 재료를 실제로 소비하고 제작에2시간이 든다. 재료 성향으로10계열 중 결과가 정해지고3등급·3전달 방식으로 총90개 결과물이 있다. 추가 재료의 품질 증폭도 점점 줄어든다.

화염·산성·서리·연막·속박·섬광 병은 적 공격·약화에, 수호·명료·기력·회복 약액은 아군 지원에 쓴다. 전투 소모품 목록과 실제 대상 제한·범위·소비에 연결했고 빗나간 투척도 한 개를 소비한다. 전투에서만 쓰는 약액을 일반 소지품의 무조건 회복 버튼으로 사용하지 않는다.

소환사 네 전문 분야에 각각 두 소환체를 추가했다. 원소는 화염령·서리령, 야수는 큰늑대·매, 인형은 철갑 수호인형·바늘 인형, 수호는 새벽 치유령·서약 수호령이다. 각자 공격·약화·회복·방호와 유한 MP를 갖고 소유자가 별도로 명령한다. 다른 전문 분야로 바꾸면 계약 기록은 보존하지만 부를 수 없고 전투에도 나오지 않는다. 아군 플레이어의 조작 권한을 가져오지 않는다.

## 생산·가구·가방

기록사는 유적의 빛바랜 고문서를 종이·먹물과 함께 복원하고, 실제 익힌 원전의 룬 기록을 필사하고, 직접 방문한 지역의 소지품 지도를 만든다. 완성 문헌을 자신이 소비해 배우거나 개인 거래·시장 재판매로 양도할 수 있다. 원전이나 방문 조건을 충족하지 않으면 제작할 수 없다. 신규 기본 매대에서 발견 문헌을 무조건 판매하지 않는다.

추가 제작은 기록·요리·제빵·어부 가공품·직물·가죽·약초·도공·보석세공과 목수 가구를 포함한다. 신규 생산품27종·생산법29개와 가구7종·제작법7개를 더했고, 전체 아이템455종·일반 제작법122개다. 연금술의 동적 배합90개는 일반 제작법 수에 중복 계산하지 않는다. 음식은 신선도·재료·실제 회복·기간 제한 효과를 따르며 같은 식사 강화는 무제한 중첩하지 않는다.

목수 침대를 소유 주택에 배치하면 완료한8시간 휴식의 피로 회복이10/20/25 더 늘어난다. 집마다 침대1개, 작업대·궤·식탁 각각1개, 장식 걸상4개로 제한한다. 임차인은 자신이 놓은 가구만 회수한다. 휴식 도중 설치·회수와 중복 수령을 막고 거래·사망 후에도 가구는 그 집에 남는다. 작업대와 궤는 현재 별도 제작 시설이나 창고 기능을 주장하지 않는다.

가방은 **아이템 종류별 슬롯과 총 무게**를 함께 계산한다. 같은 아이템 수량은 한 슬롯이지만 무게는 전부 합산한다. 음식 묶음과 장비 개체의 메타데이터를 추가 소지품으로 이중 계산하지 않는다. 기본20kg/24칸, 시장 배낭25/35/50kg·32/40/48칸, 마탑 매직백50/80/120kg·56/72/96칸이다. 가진 가방 중 하나를 선택하며 가방 자체도 무게와 슬롯을 차지한다. 기존 초과 소지품은 삭제하지 않고 초과량을 늘리는 신규 거래를 막는다. 예약한 일·제작 완료와 전투 전리품에서 새로 생긴 초과 보상은 해당 지역의 보관품으로 남긴다. 그 지역의 소지품 메뉴에서 들어가는 만큼만 수령하며 나머지는 계속 보관한다. 장비 품질과 음식 제조 시각을 유지하고 수령으로 신선도를 초기화하지 않는다.

## 밤의 암시장

마을 주민과 대화해 현지 신뢰를 얻은 인물만 뒷골목 경매의 단서를 받을 수 있다. 단서를 모르는 동안에는 메뉴·매물·개최 확률을 알려주지 않는다. 개최는 세계 날짜·마을·월드에 따라 정해지며 밤20시~다음 날5시, 날짜당 약25%다. 자정이 지나도 같은 경매를 계속한다.

한 번에3~5개 물품을 경매하며 룬 필사본·직업 단서·무기·잡화와 약3%의 희귀 유산 후보를 포함한다. 가격에 맞는 유한 구매 한도를 가진 NPC 수집가와 다른 플레이어가 실제로 경쟁한다. 플레이어 입찰금은 먼저 예치하고 다른 입찰에 밀리면 같은 생존 인물에게 한 번만 환불한다. 낙찰품은 즉시 가방에 밀어 넣지 않고 수령 전까지 경매에 보관한다. 같은 마을에서 마감 후 수령하며 가방이 꽉 차면 보관을 유지한다. 사망 후 새 인물에게 예치금과 낙찰품을 자동 상속하지 않는다. 모든 입찰·환불·수령은 인물과 공유 원장을 같은 파일에 저장한다.

## 보존과 검증

변경은 판타지 월드에 한정한다. 운영 계정·캐릭터 원본은 테스트에 쓰지 않으며 모든 서버 회귀 검사는 임시 저장 폴더를 사용한다. 저장 실패·재시도·재접속·직업 변경·다른 세대·위조 효과/전직/대상·가방 초과를 별도로 검사한다. 세 언어 화면과 실제 명중 함수 일치, 완료 전 타입·번역 데이터·빌드 검사를 실행한다. 운영 서버 배포와 장기 다중 접속 플레이는 이번 로컬 검증과 별개다.
