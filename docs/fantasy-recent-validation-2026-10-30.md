# 최근 기능 검증·요리·전투 밸런스 — 2026-10-30

상태: 최근 기능의 전체 회귀·완료 검사 통과. 일반1–6등급의 기준 표본 승률은 통과했으나, 7등급과 직업별 세부 균형 조정은 미완료. 운영 저장 파일·계정은 수정하지 않았고 커밋/푸시/배포하지 않았다.

## 반영한 수정

- 조리 장소를 배열 등으로 변조하면 영업시간 확인을 우회하던 입력 검사를 수정. 장소는 정확한 문자열 두 종류만 허용하며, 밤의 닫힌 주방에서는 정상/변조 요청 모두 저장 파일과 재료를 바꾸지 않는 회귀를 추가했다.
- 요리를 재료/수량 배합으로 통일. 일치하는 조합이 없으면 상태·재료·시간 불변. 유효한 조리만 숙련도, 소비되는 재료의 신선도, 요리 난이도와 배치 크기로 판정한다. 실패에는 재료/시간/연료가 들고 소량의 요리 숙련을 준다. 기존 레시피 명령도 같은 판정을 거친다.
- 보존 가방에 일부만 들어간 식품은 일반 가방의 종류 슬롯을 비우지 않도록 수정. 실제 소비되는 모든 식품 부분의 부패를 확인하고, 안전한 던전 방의 요리를 허용했다.
- 계약의 없는 선택 필드를 명시적 undefined로 저장하지 않아 최초 상태와 저장/재시작 후 상태가 일치하도록 수정.
- 실제 시장 지형, 두 시간 게시판, 시작 전 공동토벌 처치 미인정 등 최신 규칙과 오래된 검증 자료를 대조했다. 검증을 위해 상품 확률이나 수주 권한을 느슨하게 바꾸지 않았다.
- 일반 직업의 HP/공격/방어/주문 계수를 역할에 맞게 조정. 마법사의 HP0.72배 유지, 과도한 추가 방어 감산 제거, 높은 주문 화력과 긴 사거리의 대가를 HP와 마나로 유지. 기사/방패수는 방어, 격투가는 공격과 HP의 교환, 사제는 실제 치유량을 보강했다.
- 현재 주문 화력과 사거리를 길드 심사/일반 조우 전투력 계산에 포함. 단순 물리 공격 수치만 보던 예전 계산과 달라진다. 등록 길드 등급은 여전히 실적과 심사가 필요하며 자동 승급하지 않는다.
- HP 계산 버전을 기록하고 합리적인 구형 저장만 한 번 이행. HP0/빈사/사망을 회복시키지 않고, 최신 버전의 위조 초과 HP는 거절한다. 활성 전투의 구형 빈사 캐릭터도 생존자로 변환하지 않고 복구한다.
- 공격의 추가 상태이상이 다음 턴 저장 검사에서 잘못 거절되던 문제, 중복 몬스터 식별자, 방어형 적의 예고/실행 주기 불일치를 수정했다.

- 실제 저장/재시작을 포함한 전투력 계산·HP 이행 회귀11건 통과(`rating-integration.log`).

## 승률 해석

승률은 실제 전투 엔진과 고정 몬스터 능력치로 측정한다. 플레이어 등급에 따라 적을 몰래 강화하거나, 결과를 목표 확률로 강제하지 않는다. 기준 캐릭터는 해당 전투력 구간에서 실제 가능한 레벨/장비/숙련을 갖춘 통제된 표본이다. 실적이 부족한 등록 길드 등급과 전투력상의 구간은 다를 수 있다. 각 직업의 상성·수동 전술·숙련·종족·장비 획득 과정 전체를 같은 승률로 보장하지 않는다.

최종 고등급 비교는 고급 제작 무기/갑옷/보조 장비/장신구를 모두 장비한 세팅이다. 이전 무기 단독/전신 장비 최적화 실험을 최상급 전신 장비의 최종 증거로 사용하지 않는다. 희귀 종족과 세부 전직은 일반 밸런스 조정 대상에서 제외한다. 생산·조직·소환 직업의 가치는 단독 정면전 승률만으로 판단하지 않는다.

## 남은 균형 조정과 해석의 한계

v2 고등급 기준 표본은 새200시드에서 총29,000전, 오류/누락/측정 중 소스 변경0이었다. 6→7은4.64%, 7→7은33.51%, 8→7은67.14%, 7→8은1.93%, 8→8은45.83%. **7→7은35–45% 목표보다 낮고, 8→7은55–65%보다 높다. 따라서 고등급 전체 목표는 불합격이며, 모두 균형이 맞았다고 표시하지 않는다.** 후속 실험은 선택용 자료일 뿐 운영 수치에 반영하지 않았고, 운영 코드는 전체 회귀가 통과한v2다.

1–6등급 목표17구간 통과는 인간5개 기준 직업을 합친 평균이다. 개별 직업까지 모두 목표 구간이라는 뜻이 아니다. 예를 들어 같은6등급은 전사58.2%, 기사56.5%, 궁수57.8%, 마법사65.8%, 사제91.1%였고, 초반 무기 없는 궁수 표본과 회복을 활용하는 사제 표본의 차이도 크다. 사제의 회복/파티 기여, 탱커의 방어, 원거리의 사전 공격, 생산·조직·소환 직업의 비전투 가치까지 포함한 다음 조정이 필요하다. 합산 승률만 맞추기 위해 책·장비·종족 능력을 임의로 주거나 삭제하지 않는다.

종족 추가 표본에서 다크엘프의 낮은 승률은 검사 전술이 침묵을 잘못 평가한 문제였다. 실제 주문 피해와 침묵 후 물리 공격을 비교하도록 **측정 도구**를 수정했으며 게임의 다크엘프 능력치를 바꾸지 않았다. 사람의 실제 전술과 자동 정책의 차이를 종족 불균형으로 오인하지 않는다. 상세 범위/누락/수정 후 표본은 승률 보고서를 따른다.

다음 작업은 위 두 고등급 구간과 개별 직업의 큰 편차를 중심으로 한다. 고정 능력치 탐색만 반복하지 말고 회복/방어/사거리의 실제 가치와 전투력 평가, 초반 무기 조건, 파티 기여를 함께 검토한다. 새로운 최종 수치 검증에는 이전에 선택에 사용한 시드를 최종 검증 표본으로 재사용하지 않는다.


### 종족·직업 추가 표본의 최종 범위

인간22개 직업은 일반 전투104,940회와 상위 전투19,140회, 일반12종족은 일반 전투60,600회와 상위 전투52,200개 유효 비교를 기록했다(각30시드). 일반 종족 검사는 등급별 두 몬스터 표본이고, 실제로 만들 수 없는1급 프로필5개를 억지로 생성하지 않았다. 이 추가 검사는 폭과 예외를 찾는 자료이며, 전체 몬스터/모든 직업/종족의 목표 통과 증명이 아니다. 수정된 침묵 평가를 사용한 다크엘프 비교와 인간 주검증 비영향 근거를 승률 보고서에 남겼다.

마지막 `check:completion`도 통과했다(`final-root-completion.log`): 변경 이력 무수정, 콘텐츠39문서, 전체 타입,1150모듈 빌드12.49초. 측정용 스크립트 수정 이후의 검사다. 임시 UI 미리보기 서버는 종료했다. 커밋·PR·배포는 실행하지 않았다.
