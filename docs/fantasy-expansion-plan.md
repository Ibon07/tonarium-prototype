# 판타지 RPG 확장 목록

이 문서는 **이번에 채택해 구현한 내용**과 **후속 설계**를 구분한다. 현재 플레이 규칙은 [RPG 설명](fantasy.md), 실제 등록 수와 이름·스킬·의뢰 ID는 [설정집](world-bible.md)을 기준으로 한다. 미채택 후보와 조사 출처는 [후보 목록](fantasy-expansion-candidates.md)에 남긴다.

2026-10-27 기준의 개편 현황이다. 세부 전직·도서 발견·전용 기술·기본 부동산·전술·파티 이후 거래·주민 생활/법 집행·부동산 계약/운영·호위 수레·대화 스트리밍을 연결했고, RPG 전용 계정·복구와 월드 묶음 백업·오프라인 복원도 추가했다. 후속 기능 단계의1,143개 검사와 타입 검사·빌드·저장 호환 검증을 마쳤고, 이후 NPC 대화 버전5도1,189개 회귀 검사와 타입 검사·빌드를 통과했다. 각 수치는 해당 단계의 완료 기록이며 이번 계정·백업 결과로 합산하지 않는다. 실제 여러 PC의 장시간 멀티플레이·공유 AI 처리량과 RAM/VRAM·실제 모델 답변·장기 밸런스 검수는 별도다.

## 월드 계정·저장 운영의 구현 범위

[월드 전용 계정](fantasy-accounts.md)은 판타지 월드 안에서만 가입·로그인·복구 코드·비밀번호 변경·코드 재발급·로그아웃을 제공한다. 같은 예약 소유자 ID로 다른 기기의 개인 진행을 이어 하며, 개인 RPG 화면과 AI 지원은 서버의 계정 연결이 확정된 뒤 연다. Tonarium의 공통 표시 이름·브라우저 ID와 다른 월드의 접속 절차는 바꾸지 않는다.

예전 브라우저 저장은 자동 연결하지 않는다. 운영자는 서버를 종료한 뒤 기본 읽기 전용 이전 계획을 확인하고, 명시적 적용으로 RPG 소유 참조를 새 예약 소유자에게 옮기고24시간 유효한1회 연결 코드를 발급한다. 확인한 당사자가 아직 캐릭터가 없는 새 계정에서 이 코드를 사용한다. 소유된 캐릭터를 넘겨주거나 두 인물을 자동 병합하지 않는다.

[월드 저장 백업과 복구](fantasy-backups.md)는 세계·시계·공동 사업·의뢰 원장·계정을 함께 보관하고 최근24개·날짜별14일의 스냅샷을 유지한다. 정상 시작/종료·변경 시점 보존, 파일 지문과 형식 확인, 서버 운영 잠금, 오프라인 복구 계획/적용과 중단 복원 처리까지 구현 범위다. 복원한 계정·소유자·비밀번호 및 복구 코드 해시는 보존하고 로그인 세션과 이전 캐릭터 등록 코드 목록만 비운다. 복구 뒤에는 새 로그인과 필요한 등록 코드의 운영자 재발급을 거친다. 원격 저장소 복제나 실제 다중 PC의 장시간 성능 실측은 이 로컬 운영 기능과 구분한다.

이 단계의 자동 검사1,227개와 타입 검사·빌드는 통과했다. 실제 플레이 저장과 기존 캐릭터 소유자는 변경하지 않고 실행용 빌드를 반영했으며 서버는 종료 상태다. 외부 Kokosync 서비스 검사는 건너뛰었고 실제 여러 PC·생성 모델·장기 플레이 검증은 남겨 두었다. [현재 결과](../work/qa/world-accounts-complete.json)는 앞선 단계별 검사 수와 별개다.

## 세부 전직·도서 발견·직업 화면

[세부 전직149갈래](fantasy-job-advancement-candidates.md)는 실제 선택·시간 예약·저장·기술 사용에 연결했다. 사제 외145갈래는 분야별 판정·생산·공격·회복·방호·조준 지원 등에 맞는290기술을, 사제4갈래는8기술을 가진다. 이전 분야의 사용 숙련은 보존하되 현재 선택한 분야의 기술만 활성화한다.

기존34권에 숨긴 세 언어 단서는 인물의 일화·무예·생활·서약·여행 이야기로 표현하며 새 전직 교본 목록을 만들지 않는다. 실제 완독 후에 알게 된 갈래만 전문 분야 선택창에 나타나고 독서 예약이나 책 제목 열람만으로 발견하지 않는다. 발견과 실제 전직·기술 습득은 별개다. 이미 선택해 저장된 분야는 새 단서 책 없이도 표시와 기술 사용을 유지한다.

직업이 있으면 현재 직업과 발견한 전문 분야를 먼저 보여 주고, 다른 기본 직업은 맨 아래 ‘직업 변경’을 직접 열어야 표시한다. 사제는 신앙·숙련, 다른 직업은 숙련·실제 기술 보유를 검사하지만 정확한 수치·필수 기술·해금 방법은 화면·툴팁·GM·NPC에서 공개하거나 추측하지 않는다. 신앙 기록의 전직 팁은 제거하고 미충족 사유는 일반 문장으로 안내한다. 본인 기록과 실제 실행 비용·소요시간은 확인할 수 있다.

## 메인 전투와 후속 확장

본편은18장에서 완결한다. 현재1·3·6·7·10·14·16·17장에8개의 실제 통로 전투를 넣었다. 초반 슬라임부터 후반 흑요석 수호상까지 전조·장비·회복·퇴각 판단을 사용하며, 최상급 도전 몬스터는 본편에서 제외한다. 기존 완료와 조사 증거를 보존한다. 새 전투는10×8칸의 이동·벽·엄폐·사거리·시야를 사용한다. 길드 호위에는 [독립 수레 지휘](fantasy-escort-tactics.md)를 더해 수레 생존·습격자 격파·출구 도착을 함께 확인한다.

시설은 모든 곳에 같게 넣지 않는다. 신규 도시에는 지역 길드와 도서관을 두고, 작은 마을은 식당·약제 공방·대장간 중 생활에 맞는 전문 시설을 갖춘다. 도서관10곳의 서가는 서로 다르다. 새 시설 담당33명과 생활 주민9명, 햇살목초지의 페이까지43명이 더해져 공개 인물은137명이다. 신규43명의 개별 그림도 제작·검수했고, 얼굴·몸·의복과 기후 표현을 확인했다.

## 구현된 신체 판정 목록

같은 상황의 특성 보정은 합산한 뒤 **-5~+5**로 제한한다. 능력치·숙련·기술·허기·피로의 보정은 별도로 적용한다. 일반적인 모든 행동에 보너스를 붙이는 방식이 아니라, 탐사의 추가 상황 판정과 맥락이 지정된 사건 선택·지형 행동에 적용한다.

| 상황 | 탐사의 예 | 해당 특성의 보정 예 |
| --- | --- | --- |
| 좁은 틈 | 동굴 점검구, 낮은 통로 | 작은 체구 +3, 아주 작은 체구 +4, 유연함 +2, 무거운 몸 -3, 큰 체구 -3 |
| 함정 | 유적의 압력판, 경보 줄 | 유연함 +2, 가벼운 몸 +2, 예민한 감각 +1, 무거운 몸 -1 |
| 깊은 물 | 해변·섬·늪의 물길 | 수생 체질 +4, 희미한 형체 +2, 날개 -2, 무거운 몸 -3 |
| 높은 발판 | 산악 비탈, 탑의 발판 | 날개 +3, 작은 체구 +1, 가벼운 몸 +1, 무거운 몸 -2 |
| 고열 | 화산·사막의 열기 | 열에 강한 몸 +4, 수생 체질 -2, 추위에 강한 몸 -2 |
| 추위 | 설원과 찬바람 | 추위에 강한 몸 +4, 단단한 체격 +1, 열에 강한 몸 -2 |

| 미세한 흔적 | 숲의 냄새·소리·발자국 | 예민한 감각 +3 |

예를 들어 바위 골렘의 무거운 몸과 단단한 체격은 무거운 물체 판정에 합계 +5지만, 좁은 틈에는 -3이다. 작은 요정은 틈에 유리해도 무거운 짐과 깊은 물에서는 불리하다. 날개는 높은 발판 판정에 쓰며 장거리 비행을 해금하지 않는다. 수생 체질도 대륙 사이 이동 수단을 대신하지 않고, 희미한 형체는 벽을 통과하는 능력이 아니다.

## 조사·일반 행동 의뢰·호위와 여행 준비

메인은 별도 대분류 안에서 장별로 접고 펼친다. 각 장의 세부 조사·재검증·대조는 정해진 순서로 진행하며, 아직 열리지 않은 단계는 구체적인 단서 대신 일반 목표만 보여 준다. 현재18장 안에48개의 세부 조사 목표가 있다. 일반 의뢰는 다른 대분류로 표시하고 호위 배정도 별도로 확인한다.

일반 행동 의뢰24개(채집·제작·낚시·탐사 각6개)를 추가해 전체 의뢰는167개다. 이24개는 길드의 기존 기한·선점 게시를 사용한다. 수락 뒤 지정 장소에서 실제로 성공한 행동 횟수를 기록하며, 구매품·수락 전 활동·실패·중복 동기화는 실적이 아니다. 제작 회차와 결과물 수량을 구분하고, 획득물은 보관한 채 의뢰인에게 보고한다. 게시 가능한 모든 길드에서 도보·활동·귀환을 포함해 수락 마감 직후의 남은24게임시간 안에 완수 가능한지 검사했다.
