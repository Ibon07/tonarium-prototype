# 판타지 요리 확장 목록

> [2026-10-30 검증 기록](fantasy-cooking-validation-2026-10-30.md): 고정48종과 자유후보66종을 실제 생성하고 삼국어 이름을 검사했다.

고정 요리는 실제 요리명과 세계관의 향토 이름을 섞고, 자유 요리는 즉흥 조리의 장난스러운 별명을 붙였다. 이름은 효과나 추가 버프를 약속하지 않는다.

이번에 새로 추가한 요리만 정리한다. 기존 레시피와 기존 즉석 요리는 아래 집계에 포함하지 않는다.

- 고정 요리 48종: 수프·밥·고기·생선·빵·후식·채소·판타지 향토 요리 각 6종.
- 자유 요리 20계열 × 계열당 3종 = 일반 결과 60종.
- 위험한 자유 요리 2계열 × 계열당 3종 = 불량 결과 6종.
- 신규 조리 결과 총 114종, 신규 식재료 19종. 식재료를 포함한 신규 아이템은 133종.
- 모든 신규 아이템의 이름과 설명은 한국어·영어·일본어로 제공한다.

## 재료 수와 결과

고정 요리는 서로 다른 식재료 5종을 각각 1개씩 사용해 음식 1개를 만든다. 같은 다섯 재료의 순서를 바꿔도 같은 고정 요리다. 아래 표의 재료는 모두 1개다.

자유 요리는 주재료 3칸을 반드시 채우고 첨가재료는 0~2칸만 사용한다. 각 칸에서 재료 1개를 소비하므로 총 소비량은 3~5개다. 같은 종류의 재료를 여러 주재료 칸에 놓을 수 있으며, 놓은 칸 수만큼 실제 수량이 필요하다. 주재료 세 칸의 분류 조합으로 계열을 정하고, 각 계열의 세 결과 가운데 하나를 가중 무작위로 선택한다. 첨가재료 분류와 어느 주재료에 붙였는지가 후보의 가중치를 바꾼다.

후보의 기본 가중치는 1이다. 후보가 선호하는 첨가재료 분류에 맞으면 해당 첨가재료마다 +2, 주재료 분류와 첨가재료 분류의 연결까지 맞으면 해당 연결마다 +3을 더한다. 첨가재료가 없어도 세 후보 모두 선택될 수 있다. 아래 계열 표는 등록된 명시적 계열 목록이며, 그 밖의 조합은 자유 요리 공통 처리에 따른다.

## 자유 요리 20계열과 일반 결과 60종

`고기→향신료`는 고기 주재료 칸에 향신료 첨가재료를 붙이는 경우다. 분류 선호와 연결 선호가 모두 맞으면 두 보정이 함께 적용된다. 이는 확률 보정이며 결과를 확정하지 않는다.

## 불량 결과 6종

불량 계열의 `기타 + 기타 + 기타` 표기는 위험 결과용 식별자다. 일반 주재료 분류 조합으로 선택하는 계열이 아니다. 식재료의 독성 또는 먹을 수 없는 이물질 여부로 위험 계열을 선택한다.

| 위험 계열 | 가능한 결과 3종 | 먹었을 때 | 영양 / 보존 |
|---|---|---|---|
| 거친 이물질 요리 | 숟가락이 꺾인 스튜 / 씹을수록 후회하는 한 접시 / 먹는 돌인가 싶은 구이 | 피로 +10, 쇠약 | 1 / 12시간 |
| 독성 혼합 요리 | 왜 보라색이지 수프 / 숟가락도 도망간 죽 / 뚜껑을 다시 닫은 요리 | 피로 +15, 중독 | 1 / 12시간 |

모든 신규 조리 결과는 제작 전용이다. 불량 음식도 일반 음식처럼 보존 시간이 흐르며, 영양은 1에 불과하다.

## 구현 데이터와 확인 상태

구현 카탈로그는 `shared/fantasy-cuisine-catalog.ts`다. 외부 실행 로직을 가져오지 않고 식재료·완성 음식·레시피·자유 요리 계열의 순수 데이터만 제공한다. 고정 레시피는 `FANTASY_FIVE_INGREDIENT_RECIPES`, 완성 음식은 `FANTASY_CUISINE_ITEMS`, 식재료는 `FANTASY_CUISINE_PANTRY_ITEMS`, 분류표는 `FANTASY_CUISINE_PANTRY_GROUPS`, 자유 요리 계열은 `FANTASY_CUISINE_FAMILIES`에서 제공한다.

사용자 요청에 따라 테스트, 타입 검사, 빌드, 브라우저 확인 및 리뷰는 실행하지 않았다. 확인은 사용자가 별도로 요청할 때 진행한다.
