추가 반영: [마법진·빈사·전문 소환·연금술·생산·가구·가방·암시장](fantasy-runic-circles.md). 회복 합성은 사제 전용이며 마법사의 기존 저장 회복 주문도 발동을 차단한다. 중앙 속성+2/4/6개 룬, 비선형 위력·실제 명중률·직업 상황 보정, 기록사 문헌과 지역 지도, 무게·품목 슬롯 제한, 지역 평판 단서와 실제 경매 예치/환불을 포함한다.
