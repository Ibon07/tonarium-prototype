# 테스트용 인생 초기화

테스트용 인생 초기화 버튼과 확인창은 플레이 화면에서 제거했다. `FANTASY_TEST_TOOLS=1`로 개발 서버를 실행해도 화면에는 초기화 기능을 표시하지 않는다.

자동 회귀 테스트를 위한 서버 요청은 유지한다. 개발 서버를 `FANTASY_TEST_TOOLS=1`로 실행하고 로컬 주소로 연결한 경우에만 허용되며 기본값은 꺼짐이다. 서버는 WebSocket의 실제 접속 주소를 검사하며, 전달된 헤더나 클라이언트 설정으로 허용하지 않는다.

테스트 요청이 승인되면 현재 인물의 소지품·장비·직업·기술과 진행 중인 활동을 끝내고 캐릭터 생성으로 돌아간다. 새 인생은 종족 추첨 기회 5회를 받는다. 이전 인생의 발자취와 이미 세계에 반영한 변화는 남고, 다른 플레이어의 인물은 그대로 유지된다.

서버는 월드 참가 여부, 명시적인 확인, 최신 기록 번호를 모두 확인한다. 저장에 성공한 뒤에만 초기화를 확정하며, 이전 인생의 공유 의뢰 선점·대화 승인·흥정·AI 응답 대기를 해제한다. 중복 요청은 다시 초기화하지 않는다. 새 인생에서는 이전 인생의 대화와 늦게 도착한 응답을 이어받지 않는다.
