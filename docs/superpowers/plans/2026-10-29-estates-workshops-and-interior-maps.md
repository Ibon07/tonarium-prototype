# 사업·주택·고용과 내부 지도 확장

사용자 요구: 지도 계열 기록사의 유적/던전 내부 지도 제작과 판매, 접이식 없는 전투 선택 UI, 다양한 신체 특성과 종족 배정, 생산/연금 재료·생산품 확장, 저택, 상업건물의 NPC 고용·자동 수입·제작·창고, 주거의 작은 수납과 가구 확장.

설계: 기존 세계 시간·부동산 원장·제작·가방·개인 진행 저장을 확장한다. 지도는 제작 시 실제 탐사한 시드/방 정보만 담고 판매·교환으로 소유권을 옮긴다. 주거와 상업 창고를 분리하고, 상업 운영은 실제 인력·재료·자본·임금/유지비·기간을 검사한다. 길드 고용과 야간 암시장 거래의 고용/예속 인력을 구분하며 전투 인력은 기존 부대·동료 전투로 연결한다. NPC는 개별 기술·학습력·성장 기록을 가지며 충분한 카리스마 또는 지도자에게만 상세 능력을 보여 준다.

독립 파일 소유:

1. 내부 지도: 새 지도 모듈, 기존 생산/던전 UI와 공유 행동 연결. 부동산 원장과 서버 저장 본문은 직접 수정하지 않고 필요한 훅을 전달.
2. 재료·생산·신체: 새 재료/제작 카탈로그, 연금 카탈로그, 신체 표와 생산 연결. `fantasy-data.ts`의 병합은 이 담당자가 조정.
3. 부동산·NPC: 부동산 원장/확장, 고용·영업/창고 모듈, 부동산 UI와 필요한 서버 저장. 프로토콜 변경은 통합 담당에게 전달.
4. 통합 담당: 전투 UI, 프로토콜과 각 경계 연결, 문서·인수인계·검사 대기 목록.

운영 저장·AI 설정·변경 이력은 수정하지 않는다. 이전에 합의한 영구 사망 부동산 유산·파티 자금 동의와 원자적 저장을 보존한다. 한국어·영어·일본어를 제공한다. 테스트·타입 검사·빌드·화면 확인·코드 리뷰는 사용자 요청 전 실행하지 않는다. 회귀 사례는 작성하고 대기 목록에 등록한다.

구현 기록: 내부 지도와 사본 거래, 비접이식 전투 선택 UI, 재료/제품/연금/신체 카탈로그, 저택과 가구 수납, 메타데이터 창고와 직접 제작,30명 고용/매입·개별 성장 보존·부대 편입을 연결했다. 추가 요청인 상품별 계절/지역의 실제 판매량과 야간 판매0도 적용했다. 공유 프로토콜은10. 새 회귀6개 파일을 기존 판타지 명령에 등록했고 실행하지 않았다. 상세 수치와 후속 항목은 [통합 기록](../../fantasy-estates-workshops-and-maps.md)과 [검사 대기 목록](../../fantasy-validation-backlog.md)에 있다.
