# 지형·계절에 따른 여정 UI

사용자의 요청에 따라 현재 위치의 지형에 맞는 하나의 Coolors 팔레트를 사용한다. 계절은 다른 팔레트로 교체하지 않고 동일 팔레트의 비중과 밝기, 나무·눈·물결 등의 장식으로 표현한다. 지도에서 목적지를 미리 선택해도 색은 바뀌지 않는다.

## 작업

1. 순수 테마 계산과 테스트: 실제 이동 구간·시간·중단 위치를 반영하고 출발지와 도착지 색을 보간한다. 바다 이동의 중간 구간은 바다 팔레트로 표현한다.
2. 가장자리 장식: 숲의 낙엽과 겨울의 앙상한 가지, 설원의 눈·서리와 여름의 약한 냉기, 바다의 물결 등을 조용하게 표현한다. 포인터와 글자를 가리지 않으며 동작 줄이기를 존중한다.
3. 게임 패널과 별도 NPC 대화창에 색 토큰을 적용한다. 일반 본문·보조 설명·버튼의 글자를 실제 배경과 최소 4.5:1 대비로 유지한다. HP·MP·오류 등 의미를 가진 상태색은 유지한다.
4. 한국어 팔레트 미리보기와 기능 설명 문서를 제공한다. 계절·이동·모바일·동작 줄이기를 실제 화면으로 확인하고 완료 검사를 실행한다.

## 검증 기준

- 각 지형의 팔레트 출처 및 색 목록이 일치한다.
- 경유지·부분 이동·도착·정지 위치에서 색이 불연속적으로 바뀌지 않는다.
- 조작하지 않는 시간에도 글로벌 시간에 따라 계절과 날씨가 반영된다.
- 모든 계절과 이동 색의 보간 중에도 글자 대비가 유지된다.
- 눈·잎·파도는 클릭을 가로채지 않고 중앙의 지도·대화 내용을 덮지 않는다.
- 게임 밖 Tonarium 화면에는 색상이나 장식이 적용되지 않는다.
- 원래 저장 데이터와 기존 작업을 보존한다.

## 후속 요청 반영

- 밝은 파스텔 팔레트로 전 지형을 변경하고 원본의 진한색을 사용 색상에서 제외했다. 글자용 중성색만 어둡게 유지한다. 캐릭터 패널·선택 버튼·대화창도 밝은 배경이다.
- 메뉴 본문 15.5px, 탭 14px, 버튼 14.5px로 키우고, 펼친 메뉴의 비율을 나머지 공간의 40%에서 44%로 늘렸다.
- 탐사한 주변 지역 사이를 단일 안개 마스크로 연결하고 미지의 지역과 대륙·섬 사이의 바다는 보호한다.
- 노크티스의 10개 지역·해안선·지형 표시를 오른쪽 80만큼 함께 옮겼다. 정해진 노선 시간·운임과 다른 대륙·섬의 위치는 유지한다.
- 지형이 바뀌는 순간 다음 지형의 장식이 먼저 진하게 나타나는 현상을 수정했다. 같은 기후의 장식은 한 레이어로 합친다.
- 마을 메뉴에서 파티 정보가 없을 때 발생하던 반복 렌더링도 수정했다.
