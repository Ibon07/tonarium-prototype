# 직업·종족 공격의 사거리와 모양

요구: 무기·신체 특성에 따른 제한적인 사거리/범위 차이, 창의 직선 찌르기·검의 부채꼴 베기·브레스 등 기술별 공격 모양, 구현 후 효과 표.

기존 TypeScript 전투에 선택 필드 `shape`와 광역 보조 피해율을 더한다. 단일/직선/원뿔/부채꼴/원형을 같은 서버·클라이언트 공유 함수로 계산한다. 저장에 필드가 없는 기존 기술은 기존 단일/반경 동작을 유지한다. 합성마법과 지원 대상의 거리 규칙은 유지한다.

구현 선택: 목표를 향한 방향을 사용하며 직선은 좁은 통로, 원뿔은 전방90도, 부채꼴은 전방180도, 원형은 대상 중심 맨해튼 반경을 사용한다. 벽과 시야를 통과하지 않는다. 추가 대상 피해는 형상별로 줄이고 MP·숙련·사용 기록은 한 번만 처리한다. 종족 기술은 무기 사거리를 빌려 쓰지 않고 자체 사거리를 사용한다.

순서:

1. 공유 형상·타일 함수와 기술별/무기별 사거리 파생 규칙.
2. 서버 기술 변환·전투 판정·저장 검증·주변 대상 피해 처리.
3. 기술 요약·대상 선택 시 전장 미리보기·세 언어 설명.
4. 회귀 사례 작성과 상세 표·검사 대기 목록 갱신.

사용자 지시에 따라 테스트·빌드·화면 검사는 실행하지 않는다. 필요한 회귀는 작성하고 검사 대기 목록에 기록한다. 운영 데이터·AI·변경 이력은 수정하지 않는다.

구현 기록: 공유 모양 함수, 서버 기술 변환과 저장 형식, 새 무기 기술7개, 실제 피격/추가 피해 처리, 한·영·일 기술 요약과 전장 범위 강조를 연결했다. 무기 사거리가 발차기에 섞이지 않도록 구분했다. 회귀2개 파일을 작성해 기존 검사 명령에 등록했으며 실행하지 않았다. 효과 표는 [공격 형상 문서](../../fantasy-attack-shapes.md)에 기록했다.
