# 길드 성장·대화 거래·전투 균형 작업계획

사용자 요청을 기존 서버 권한 처리와 NPC 대화 확인 절차에 연결한다. 기존의 테스트 보류 지시를 유지하며 구현과 실측 검증을 구분한다.

## 작업

- 등급 명칭 뒤에 (숫자) 표기. 모든 의뢰는 목적지 위험·과업 종류·적의 총합으로 등급화.
- 최초 코퍼 등록, 현재 등급 의뢰 5개 완료 후 다음 한 단계 심사. 서버 전투력 조건을 함께 확인. 기존 완료 의뢰의 소급 중복 인정 금지.
- 실버 이상 모험가에게 글로벌 하루 한 번 주간 길드 지명의뢰 제시. NPC가 먼저 알리고 대화로만 수락; 실제 의뢰의 수주 규칙 유지.
- NPC의 물품 조회→수량/가격 확인→구매, 여관 잔여 객실→견적→숙박, 적합 의뢰 추천→수주를 실제 서버 거래에 연결. AI 자유문은 지급 권한 없음.
- 스킬 목록에 짧은 용도 설명, 상세 화면에는 수치 설명 유지. 마지막 새벽 명령 확정 전 승리 시 영구 사망 경고와 별도 확인창. 취소 시 명령 전송 없음, 오래된 확인은 폐기.
- 몬스터는 고정 등급·종별 전투 수치로 조정. 동일 등급 단독 전투 60–80%, 한 단계 아래 80–100%, 위 10–40%를 1–6등급의 목표로 기록. 7·8등급은 요청한 별도 승률표. 승패 강제 추첨 없음.

## 경계/파일

- 등급 담당: fantasy-adventurer / quest-grades / guild-progression, 길드/의뢰 UI.
- 대화 담당: npc-transactions 및 지명의뢰 저장 모듈.
- 균형 담당: monster-balance, combat-catalog의 고정 적 능력치.
- 통합: fantasy-store / index / protocol / character types, CombatPanel과 스킬 설명 UI.

## 검증 대기

사용자의 일괄 검사 요청 전에는 테스트·빌드·타입 검사·브라우저 QA를 실행하지 않는다. 다음 검사 때 승률 시뮬레이션, 저장/복구, 수량/재고 경쟁, 객실 정원, 대화 확인 만료, 승급 중복과 취소, 마지막 새벽 확인의 취소·상태변경·접근성을 검사한다.


## 반영 기록

위 기능을 코드에 연결했다. 통합 파일/저장/프로토콜/구현 범위와 미검증 부분은 [인수인계](../../fantasy-guild-dialogue-handoff-2026-10-30.md) 참조. 승률 보고 도구도 작성했으나 실행하지 않았다. 테스트·타입 검사·빌드·브라우저 확인·커밋·배포를 수행하지 않았다.
