# 성직 난도·선택 기술서·시설별 혜택

- 성직 칭호 단계1..5는 모험가1,2,4,6,8에 대응. 각 모험가 승급의5건×봉사/서약9신앙으로0/45/135/225/315. 기존 스킬 보정용 신앙 단계와 전문전직 조건은 분리해서 유지.
- 등록 모험가6 이상과 사제4 이상에게 각 생애당 출처별1회의 선택 교본. 길드/신전에서 현재직업 미습득 일반 기술을 고른다. 소지품 실제 교본1권을 읽어 습득하며 직업 변경 시 기술 사용 제한 유지. 별도 조건의 기적/최종기술/전직 기술은 제외.
- 등급 혜택은 길드/신전 시설에 각각 모으고 NPC에게 현재 등급·이용 가능 혜택·수령 이력과 선택 기술서를 문의할 수 있다. 대화는 서버의 동일 자격 검사를 거쳐 제안/확인/수령한다.
- 생활 지원·기관 우대만 추가하고 전투력·모험가 시험 점수 자체는 높이지 않는다. 대여 보증금, 하루 수량 제한, 숙소 실제 시간·정원, 할인과 호위 보너스를 같은 서버 규칙으로 처리.
- 단계별 구현은 개별 인수인계 문서에 기록. 테스트·타입검사·빌드·브라우저 확인은 사용자 요청 전 실행하지 않고 검증대기에 쌓는다. 커밋·배포 없음.
