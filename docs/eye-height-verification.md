# アバターの目の高さへの追従（PR 説明案・検証記録）

固定 1.6m だった一人称の高さを、アバターの頭の寸法と首・脚のパラメータから求める。Web は既定値から開始し、パラメータ・テクスチャの読み込み後に時定数 200ms の指数補間で追従する。モデル側にも同じ床補正を適用する。体のメッシュだけを変える bodySize は頭の位置を変えない。

既定パラメータの計算値は **1.085556018447876m**。Web の単体テストでこの期待値を検証する。極端値の期待値は headSize=100、neckLength=80、legsDistanceFromBody=70、legsSize=3 で **3.926202306447876m**。反転した寸法のケースもテストする。

頭の上下・前方の目印は headSize の 1/4・1/3。高さには上下成分を使う。通常の待機アニメーションやエモートでカメラが揺れ続けないよう、実行時 Head ワールド座標による上書きは採用せず、静止寸法の計算値を使う。Web のテストは頭の寸法定数と実 GLB の一致、および標準・極端・反転体型の頭の目印と計算値の差も検査する。

## EYE 参照箇所の変更一覧

`git grep -n -w EYE HEAD -- client/src/view3d` で変更前の全 6 箇所を確認。

| 変更前の箇所 | 変更内容 |
| --- | --- |
| interact.ts:17 定義 | DEFAULT_EYE_HEIGHT を標準アバターの既定値として公開 |
| Player.tsx:15 import | EYE を除き useEyeHeight を使用 |
| Player.tsx:96 初期カメラ | 現在の高さに足元の y を加算 |
| Player.tsx:327 毎フレームのカメラ | 補間済みの高さに足元・被弾オフセットを加算 |
| View3D.tsx:13 import | EYE を除き高さの Context を使用 |
| View3D.tsx:287 Canvas 初期位置 | Context の既定値を使用 |

変更後の EYE は interact.ts の標準値の定義のみ。上面視点は `現在の高さ + (16 - 標準の高さ)` とし、標準体型では 16m を維持する。手元のハンマーとカメラはカメラ座標系の相対位置を使う。他者の手持ち表示、照準用コライダー、名札・吹き出しも頭の高さに追従する。他者の手持ちは標準体型のハンマー 0.6m・カメラ 0.9m を維持し、標準の目の高さとの差分を加算する。照準用コライダーは最低 0.7m を確保し、中心を実際の高さの半分に置く。
