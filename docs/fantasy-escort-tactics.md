# 길드 호위의 전술 전장

새 호위 계약은 출발 전에 길드에서 호위대를 지키는 전투를 마친다. 여행자는 자기 행동을 고르고, 계약 주인 또는 처음 지정한 파티장은 호송 수레와 마부에게 별도의 이동·정지 방어 명령을 내린다. 다른 플레이어의 행동을 대신 정하지 않는다.

호위 이동 중에는 실제10초(게임5분)마다9% 확률로 길에서 습격을 판정한다. 발생하면 그 자리에서 이동이 멈추고 전용 조우 '호송 수레를 노리는 습격자'가 열린다. 조우에서 싸우기를 고르면 출발 전 전술 구간과 같은 수레 전장이 `source: escort:<계약ID>`로 시작되고, 수레 HP가0이 되면 계약은 실패한다. 도망이나 대화로 조우를 끝내면 전투 없이 계약만 유지되며 다시 출발할 수 있다.

수레는10×8칸 전장에서 독립 HP와 위치를 가진 비전투 대상이다. 공격·마법을 쓰지 않고 플레이어 수나 소환 동료 수, 독립 보상 인원으로 세지 않는다. 한 라운드에 한 번 두 칸까지 이동하거나 제자리를 지키며 방어한다. 본인의 행동을 확정해도 수레 명령은 따로 고를 수 있다. 지휘자의 수레 명령까지 모이면 라운드가 진행하고, 실제1분의 마감에 입력이 없으면 수레는 제자리에서 방어한다.

지도에서 수레를 선택해 이동 칸을 고르거나 ‘출구 방향으로 전진’을 누른다. 벽·다른 인물·한 번에 이동할 수 있는 거리와 현재 경로를 검사한다. 영웅이나 적이 먼저 움직여 경로가 막히면 수레는 뛰어넘지 않고 멈춘다. 엄폐와 정지 방어는 실제 피해를 줄이며 플레이어의 방호술·회복술로 호송 대상을 지킬 수 있다.

습격자는 수레를 공격할 수 있고 가까이 다가온 적은 짝수 라운드에 수레를 우선 노린다. 수레 HP가0이 되면 영웅이 살아 있어도 계약은 실패한다. 수레의 실패가 살아 있는 플레이어의 사망을 만들지는 않는다. 권한 있는 지휘자가 모두 쓰러지거나 떠난 경우에도 계약을 더 진행하지 않는다.

모든 습격자를 물리치고 수레가 지도 오른쪽의 출구 칸에 도착해야 전술 구간을 통과한다. 적만 처치하거나 수레만 먼저 보내는 것으로 끝나지 않는다. 통과했다고 즉시 호위 보수를 주지 않고, 기존 계약의 동행 이동으로 실제 목적지에 도착해야 한 번 지급한다. 실패·중단·재전송으로 보상을 받지 않는다.

호위 메타데이터는 전투의 `escort`에 저장한다. 계약ID·주인과 그 인생·목적지·출구·수레 능력치·명령 권한과 위치를 엄격하게 확인한다. 수레 상한과 방어는 생성 당시 주인의 능력 스냅샷으로 고정한다. 전투 중 마나 수련으로 영웅의 최대 HP나 방어가 변해도 수레를 다시 강화하거나 저장을 깨뜨리지 않는다. 파티원이 중도 합류하면 수레 HP를 회복하지 않고 기존 라운드의 모든 명령을 지운 뒤 새 입력 시간을 연다. 옛 일반 전투와 최상급 도전에는 이 목표나 추가 명령을 붙이지 않는다.

구현은 `shared/fantasy-escort-battle.ts`와 공통 전투·전술·화면을 따른다. 서버는 `source: escort:<계약ID>`와 실제 수락 계약을 확인한 뒤 `createFantasyCombat`의 `escort` 옵션으로 시작한다. 최종 계약 결과는 `fantasyEscortBattleWon`으로 확인하고 개인 저장과 함께 확정한다. 자동 검사는 소유권·독립 명령·이동 충돌·마감 방어·피해/방호·출구·생존·중도 합류·위조 저장과 기존 전투 회귀를 포함한다.
