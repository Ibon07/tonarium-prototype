# 전투와 도전 규칙

전투는1~6명이 각자 행동을 선택하는 턴 방식이다. 일반 사냥, 도주·은밀 행동 실패의 적대 조우, 메인 이야기의 일부 통로 전투, 사람과의 명시적 충돌, 최상급 도전이 같은 전투 엔진을 사용한다. 몬스터58종과 사람 적대자5종, 총63개 전투 대상에 기본 능력치와 행동 성향이 있다. [전체 대상과 기준 능력치](fantasy-combat-monsters.md)를 참고한다.

## 행동과 진형

각 라운드에 본인의 공격·방어·기술·소모품·이동·퇴각 중 하나를 확정한다. 다른 플레이어나 다른 사람의 동료에게 대신 명령할 수 없다. 살아 있고 퇴각하지 않은 참가자와 출전 동료의 행동이 모두 모이면 라운드를 진행한다. 입력 기한은 세계 시간0.5시간, 실제1분이며 미입력은 자동 방어가 된다. 접속을 끊어도 시작한 전투는 계속되어 쓰러질 수 있다. 자동 방어만 한 사람은 보상 기여자로 인정하지 않는다.

새 전투는10×8칸의 평면 전장을 사용한다. 본인 또는 동료를 고르고 이동할 칸을 클릭해 명령을 확정한다. 이동은 한 행동이며 상하좌우의 실제 경로를 계산한다. 민첩에 따라2~4칸을 이동하고 냉기는 이동거리를1칸 줄인다. 벽과 살아 있는 다른 인물이 차지한 칸을 통과하지 못한다. 같은 빈칸으로 이동하려던 인물이 겹치면 먼저 도착한 인물이 자리를 차지하고 뒤의 이동은 무효가 된다.

근접 공격은 인접1칸, 활·석궁·투창은7칸, 마법은8칸까지 닿는다. 벽은 시야를 차단한다. 엄폐 칸은 물리 공격의 명중을10, 마력 공격의 명중을4 낮추고, 맞았을 때 피해를 각각25%·10% 줄인다. 적도 닿는 상대가 없으면 빈 경로를 따라 접근한다. 기존 저장의 두 줄 진형 전투는 이전 규칙으로 끝내며 새 전장으로 강제 재배치하지 않는다.

기본 공격은 현재 무기와 직업에 맞는 능력을 사용한다. 활 계열은 민첩이 명중과 공격에 관여하고, 마법은 지능과 마력 방호를 사용한다. 장비의 실제 품질·소재·보석, 배운 패시브, 피로·허기·어둠·날씨도 참가자 능력에 반영한다. 등록한 마법사의 합성마법도 실제 전투 기술로 가져온다. 생산용 감별이나 흥정 기술을 이름만 바꾸어 공격 기술로 만들지 않는다.

선택한 세부 갈래의 전투 패시브는 공격·명중·방어·마력 방호 중 실제 능력에 한 번만 적용한다. 공통 패시브 계산에 다시 넣지 않으며 기술 숙련에 따른 보정은 최대3이다. 해당 갈래의 액티브만 배운 기술에 들어오고, 다른 갈래·옛 직업의 기술이나 생활 직업의 제작·상업 준비 기술을 공격으로 바꾸지 않는다. 갈래별 기술 설명과 전투창은 실제 MP·위력·대상을 구분한다.

화염·빙결·독 공격의 추가 상태는 명중해 HP 피해를 준 경우에만 등록 확률로 발동한다. 방어 중이거나 방호가 피해를 전부 흡수하면 추가 상태를 주지 않는다. 같은 상태는 별도 개수로 쌓이지 않고 기간과 강도를 갱신하며, 공격이 빗나가면 공격 기술의 MP도 소비하지 않는다. 사제의 명료함은 공격 대신 아군의 다음 명중을 최대15%p 보조한다. 최대2라운드 안의 첫 실제 공격에만 적용하며 중첩되지 않는다. 준비 때 MP를 소비하고 만료·자동 방어는 숙련을 만들지 않는다. 실제 공격에 사용하면 빗나가도 보정은1회 소비되며 저장·재시도로 기술과 마나 숙련을 중복 지급하지 않는다.

배운 전투 기술만 목록에 나온다. 치유와 방호는 본인이나 동료를 대상으로 쓸 수 있다. HP·MP 포션과 해독제는 본인 소지품에서 실제 효과가 발생할 때 소비하며, 다른 사람의 인벤토리는 공유하지 않는다. 독 전용 해독제가 화상이나 냉기까지 지우지 않는다. 이미 쓰러진 대상이나 회복할 것이 없는 대상에 물품을 낭비하지 않는다.

음식은 전투 안의 즉시 소모품 목록에서 제외한다. 전투 전에 기존 식사 시간과 신선도 규칙으로 먹어 준비하며, 부패한 음식을 전투 소모품으로 써서 상태와 시간을 우회하지 않는다. 마력 공격을 쓰는 적도 MP를 소비하고 부족하면 특수 효과 없는 직접 공격으로 전환한다.

적은 공격·방어·독·냉기·흡수·재생·마력 공격·브레스 등의 성향을 가진다. 강한 행동의 전조를 미리 표시하고 방어로 대응할 수 있다. 적의 방어 전조는 플레이어보다 느리게 움직인다는 이유로 무효가 되지 않는다. D20 결과와 전투 기록을 화면에서 확인한다.

## 사람과의 충돌

노상강도·밀렵자·철가면 선단 사병뿐 아니라 경비대와 기사도 전투 대상이 될 수 있다. 종족이나 직업이 범죄 계열이라는 사실만으로 주변 사람이 자동 적대하지 않는다. 범행 발각 같은 실제 사건이나 위험을 확인한 명시적 공격이 충돌의 원인이다.

경비대나 기사를 먼저 공격하는 선택은 범죄로 처리하여 악명과 지역 관계에 영향을 준다. 이들은 정상적인 토벌 보상 대상처럼 금화·재료를 주지 않는다. 전투에서 사람을 쓰러뜨리는 판정이 거주 NPC137명을 영구 삭제하는 기능은 아니다. 플레이어 사이의 자유 전투·장비 강탈은 현재 범위 밖이다. 공개 세션에서 양쪽이 위험에 동의한 소액 금화 약탈은 [주민과 관청의 별도 규칙](fantasy-civics.md)으로 구현되어 있다.

## 파티 전투와 기록

같은 판타지 세션·장소에서 파티원 각자가 전투 메뉴의 같은 대상에 준비한다. 전원이 동의한 뒤 파티장이 시작할 수 있다. 최상급 도전과 사람 선제공격의 확인도 각자가 해야 한다. 파티장 혼자 다른 사람을 위험한 전투로 끌어들이지 않는다.

참가자1~6명으로 전투 시작 때 적 능력을 정한다. 일반·정예·보스는 서로 다른 HP·피해 보정을 사용한다. 파티 정원이나 구경하는 사람, 부대원·소환체를 별도 플레이어로 세지 않는다. 도중에 퇴각하거나 쓰러져도 남은 적을 약하게 다시 계산하지 않는다. 같은 파티의 새 지원자가 자신의 의사로 합류하면 적의 최대HP·공격은 인원수에 맞춰 상향만 하고, 이미 입힌 피해량을 보존한다. 모두의 기존 선택을 취소하고 새 입력 기한을 주므로 과거 라운드 요청은 다시 실행되지 않는다.

각자 실제로 참여한 행동을 기준으로 개인 경험치와 이야기 승리를 인정한다. 회복·방호도 유효 기여가 될 수 있다. 골드와 재료는 전투 전체 예산에서 분배하며 인원수만큼 같은 물건을 복제하지 않는다. 이미 받은 전투의 결과를 재접속·동기화·중복 입력으로 다시 받지 않는다. 전생한 새 인물에게 옛 전장의 보상을 넘기지 않는다.

전투 상태와 참가자 HP·MP·소모품·생존·보상은 같은 저장 파일에서 원자적으로 확정한다. 저장에 실패하면 일부에게만 결과를 주지 않으며 같은 난수 기록으로 재시도한다. 기존 개인 저장 형식도 읽고, 첫 전투부터는 개인 기록과 전장을 함께 담는 형식으로 저장한다.

## 부대·조직·소환체의 직접 지휘

지도자·범죄조직 두목·소환사는 자신의 현재 편성에서 건강한 동료 최대2명을 출전시킨다. 부대 관리에 표시된 전투 동료를 사용하며, 부상·이탈·편성 해제 상태의 동료나 다른 직업의 옛 동료는 나오지 않는다. 명령 대상에서 본인과 각 동료를 전환해 공격·방어·이동·보유 기술을 따로 확정한다. 방패 호위는 아군을 엄호하고 등불정령은 제한된 마력으로 아군을 치유한다. 동료가 소유자의 소모품을 임의로 사용하지 않는다.

동료의 능력은 주인의 성장과 원래 역할을 기준으로 제한하며 플레이어와 같은 강도의 인물을 추가 복제하지 않는다. 전투 기여는 주인의 지휘에 연결하고 동료 이름으로 경험치·금화·희귀 소재를 따로 복제하지 않는다. 주인이 쓰러지거나 퇴각하면 동료도 더 싸우지 않는다. 전투HP는 원래 동료HP에 비례해 저장하며, 쓰러진 부대원·조직원은 부상, 소환체는 이탈로 남는다. 기존 치료·재계약으로 돌아올 수 있고 영구 삭제하지 않는다.

## 메인 이야기의 전투

전투는1·3·6·7·10·14·16·17장에 간헐적으로 있다. 나머지 조사·사연·대조 장면과 번갈아 진행한다. 초반 슬라임부터 후반의 강한 수호상까지 난도를 올리며 최상급 도전 몬스터는 넣지 않는다. 전투 승리는 길을 확보한 기록이고, 인장·서명·항법의 답을 대신 얻는 것은 아니다. 해당 전투 후에도 실제 조사를 수행해야 한다.

같은 장면에 직접 참여한 파티원은 본인의 통로 확보 기록을 얻는다. 빠른 동료가 먼저 끝내 실제 타격 차례를 받지 못했어도 승리 라운드에 직접 정상 행동을 확정한 생존자는 통로를 함께 확보한 것으로 본다. 자동 방어·방치·도주·새 인물에는 이 예외를 주지 않고, 경험치와 물품은 실제 기여 기준을 별도로 따른다. 가입만으로 다른 사람의 승리를 복사하지 않으며 특정 희귀 종족을 강제로 요구하지 않는다.

기존 완료 장과 조사 증거는 유지한다. 새 전투 규칙을 켠 게임 서버는 남은 단계부터 통로 전투를 적용한다. 업데이트 전에 예약해 둔 정상 조사 하나는 기존 결과로 마무리할 수 있게 보존하고, 이전 방식의 최상급 사냥 예약은 보상·손실 없이 안전하게 해제한다.

## 최상급 몬스터

최상급4종은 고룡·고대 서리용·고대 폭풍용·공허빛 키메라다. 일반 탐색·사냥·메인 전투의 무작위 상대가 되지 않는다. 각 장소의 장치를 먼저 조사하면 위험과 도전 행동을 알 수 있다. 경고 확인은 실제2분간 유효하며, 그 뒤 위험을 알고 도발하는 행동을 명시적으로 선택해야 싸움이 시작된다.

| 장소 | 도전 행동 | 상대 |
| --- | --- | --- |
| 잿불화산 | 제단의 비늘종을 친다 | 고룡 |
| 흰안개고개 | 빙문의 봉인못을 뽑는다 | 고대 서리용 |
| 천둥종섬 | 절벽의 결투 사슬을 당긴다 | 고대 폭풍용 |
| 월식지하궁 | 경계 화로에 불을 붙인다 | 공허빛 키메라 |

장치를 건드리지 않으면 원래 지역의 여행과 메인을 계속한다. 천둥종섬의 일반 중계종 조사는 고룡을 부르는 결투 사슬과 다른 행동이다.

최상급은 기존 성철·아다만트·오리할콘 계열 등의 최고 품질 장비와 충분한 회복을 준비한 도전을 기준으로 삼는다. 첫 처치에 필요한 장비를 첫 처치 보상으로만 만들게 잠그지 않는다.18라운드부터 장기전 경고가 나오고20라운드 뒤3라운드마다 피해가10%씩 늘어나 최대2배가 된다. 준비 없이 무한 회복만 반복하는 방법을 어렵게 하되 일반 메인 상대에는 이 격노를 붙이지 않는다.

성공한 기여자는 명예 칭호를 얻고, 전투 전체에서 희귀 소재를 분배한다. 고룡비늘·빙정핵·폭풍용 힘줄·경계결정으로 검·장궁·지팡이·갑옷·예복·대방패의6제작법을 사용할 수 있다. 소재와 완성 장비는 NPC 상점에서 바로 사지 못한다. 명예 칭호는 중복되지 않으며 같은 강적은 승리 후 게임24시간이 지나야 다시 도전할 수 있다. 각 전투의 보상은 한 번만 확정한다.

## 검증 범위

순수 엔진·원자 저장·실제 임시 통신·세 언어 화면을 검사한다. 과거의 전술225전과 갈래 확장1,174전은 진행 정체·직업 연결·유한 회복을 살피는 예비 검사였다. 당시 고룡3회 성적은 작은 표본이므로 현재 난도의 근거로 쓰지 않는다. 현재 고룡은 아래의 정상 제작 준비와 고정 자동 전략100회씩으로 조정했다.
