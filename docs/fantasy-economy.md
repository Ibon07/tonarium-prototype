# 직접 교환과 공유 상점

같은 판타지 세션의 같은 정착지에 있는 살아 있는 두 인물이 직접 교환할 수 있다. 한 번에 한 거래만 열며 상대가 바쁘거나 전투·사건 중이면 열지 않는다. 각자의 제안은 금화와 최대12종의 소지품이다. 개별 장비는 실제 개체를 지정하고 착용 중인 물건은 먼저 벗는다. 양쪽이 같은 제안 판본을 직접 승인해야 금화와 물품이 함께 이동한다.

제안 하나라도 바꾸면 양쪽 승인이 풀린다. 제안만으로 소지품을 맡기거나 금화를 차감하지 않는다. 따라서 취소·실제2분 만료·접속 종료·장소나 인생 변경·서버 재시작으로 거래가 끝나도 되돌려 받을 재산을 잃지 않는다. 승인 직전에는 양쪽의 생존·세션·장소·활동·인생·소지금을 다시 확인하며 물품도 제안 당시의 정확한 개체와 음식 묶음이어야 한다. 제안 후 먹거나 착용하거나 상태가 달라진 음식은 새로 제안한다.

각 시설의 원래 판매 목록은 유지하되 현재 수량을 공통 장부에서 센다. 음식20개, 보통 재료14개, 보통 장비5개, 고급품3개가 기본 재고다. 같은 마을의 같은 시설에서 누가 사면 다른 여행자에게도 그만큼 줄어들며, 다른 마을이나 다른 시설의 재고와 섞이지 않는다. 세계6시간마다 원래 재고가 상한까지 다시 들어온다. 접속하지 않은 기간의 입고를 무한히 쌓지는 않는다.

공급이 부족하면 구매 단가가 올라가고 과잉 공급이면 낮아진다. 기존 대화 흥정 할인도 구매 견적에 적용한다. 판매 단가는 현재 공급을 반영하되 기존 기본 매입가를 넘지 않는다. 같은 장소에서 즉시 사고파는 것으로 금화를 늘릴 수 없다. 구매·판매는 견적의 시설 판본과 실제 수량을 확인하며 먼저 처리한 거래로 내용이 바뀌면 다시 확인해야 한다.

플레이어가 판 물품은 별도의 유한 중고 묶음이 된다. 음식은 원래 생성 시각을, 제작 장비는 품질·재료·보석·추가 능력치를 보존한다. 다시 산다고 음식이 신선해지거나 장비 품질이 다시 추첨되지 않는다. 낡아 상한 중고 음식은 다음 입고 때 치우며 상한 음식은 구매·판매 대상에서 제외한다. 판매 화면에서는 기존처럼 음식 상태와 장비 개체별 가격을 나누어 확인한다. 최상급 전리품과 원래 상점에 없는 물품을 입고 규칙으로 생성하지 않는다.

개인 인벤토리는 상대에게 공개하지 않는다. 상대가 직접 올린 제안만 볼 수 있고 같은 세션 밖의 거래는 조회하거나 승인하지 못한다. 거래 장부와 양쪽 개인 기록은 서버에서 같은 저장 단위로 확정해야 한다. 저장 실패 때 일부만 교환하지 않으며 오래된 요청과 완료된 거래의 재전송도 보상을 만들지 않는다.

구현은 `shared/fantasy-economy.ts`, 화면은 `FantasyEconomyPanel.tsx`다. `applyFantasyEconomyCommand`는 복사된 장부·개인 기록과 변경 여부를 반환하고 호출자가 권한 있는 세션 명단·세계 시간·요청 식별자를 제공한다. `closeFantasyEconomyTrades`는 재시작 때 미완료 제안만 닫는다. 실제 서버의 기존 구매·판매와 대화 승인 경로도 이 공통 거래 장부를 거쳐야 한다.

자동 검사는 양쪽 승인·제안 수정·동시 구매·중복 제출·기한·재시작·장소·인생·착용 변경·음식 변질·품질 보존·세션 밖 정보 보호·재고 입고·공급 가격과 실패 시 불변을 확인한다. 실제 다인 경제에서 수요와 입고 속도의 장기 균형은 계속 조정한다.
