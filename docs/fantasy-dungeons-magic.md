## 발견해서 배우는 합성마법

새 인물은 합성 요소를 모르는 상태로 시작한다. 원소는 불·물·바람·땅·빛, 형태는 집중·장막·회복이다. 읽기를 완료하거나 탐사 현장의 기록·유물을 직접 조사해야 지식을 얻는다. 독서를 예약했거나 취소한 것만으로는 배우지 않는다.

| 도서 ID | 배우는 요소 |
| --- | --- |
| `mana-primer` | 바람·집중 |
| `advanced-mana-forms` | 빛·장막 |
| `stone-and-flame` | 땅·불 |
| `remedies-and-rites` | 물·회복 |

각 도서관은 기존의 서로 다른 소장 목록을 유지한다. 유적·동굴에서는 방마다 정해진 구성 요소를 찾으며, 수호자가 있는 방은 실제 전투에서 이겨야 기록·물품을 조사할 수 있다. 방의 물품과 발견 영수증은 한 번만 확정된다.

마법사는 등록된 9개 조합을, 사제는 물결 장막·물결 회복·빛의 회복을 사용할 수 있다. 원소와 형태를 모두 배워야 준비할 수 있고, 현재 직업 숙련 0/30/100에 따라 저장 칸이 1/2/3개다. 준비에는 게임 1시간이 걸리며 발동 시 MP를 소비한다. 정확한 생활·전투 효과는 [전투 기능 상세표](fantasy-combat-capabilities.md#합성-마법-9종)에 정리했다. 구현되지 않은 추가 원소 상태이상을 설명에 붙이지 않는다.

직업을 바꿔도 직업·기술 숙련, 배운 합성 요소, 저장 주문은 남는다. 현재 직업에 맞지 않는 직업 기술·전문 기술·주문은 숨기고 서버에서도 사용을 거절한다. 해당 직업으로 돌아오면 자격에 맞는 기술을 다시 쓸 수 있다. 공통 스승 기술과 종족 기술은 별도 자격을 따른다.

### 사제의 기도 발견

실제로 완료된 하루 한 번의 기도에만 적용한다. 처음 1%, 새 요소를 얻지 못한 유효 기도마다 0.25%p 증가, 최대 5%다. 기도로 미지의 물·빛·장막·회복 요소 중 하나를 얻으면 실패 누적을 0으로 되돌린다. 모두 배웠으면 추가 발견 추첨을 하지 않는다. 책·던전 발견은 기도 실패 누적을 초기화하지 않는다. 중복·취소·저장 실패로 발견을 재추첨하거나 지식을 미리 확정하지 않는다. 이 확률은 플레이 메뉴에 노출하지 않는다.

## 탐사 현장

| 종류 | 현장 | 구조·주요 내용 |
| --- | --- | --- |
| 유적 | 옛 망루 지하 | 병영·기록실·무기고·수호자 묘실, 장막·빛 발견 |
| 유적 | 고사리 고대 성소 | 안뜰·샘·뿌리 회랑·제단, 회복·빛 발견 |
| 유적 | 월식 지하궁 | 거울방·봉인·천구·왕좌, 집중·땅 발견 |
| 동굴 | 청수정 동굴 | 웅덩이·암반·수정 회랑, 물·땅 발견 |
| 동굴 | 뿌리 메아리 동굴 | 포자·뿌리 다리·바람 틈·둥지, 장막·바람·회복 발견 |
| 동굴 | 청수정 심층굴 | 하강로·굴뚝·잔불·용암 흔적·수호굴, 불·집중 발견 |

각 현장에 조사와 수호자 토벌 의뢰가 하나씩, 총 12개 추가됐다. 조사 의뢰는 서로 다른 방에서 성공한 조사 기록 3개, 토벌 의뢰는 해당 수호자 격파를 요구한다. 의뢰는 길드의 기존 유동 의뢰 공급 규칙을 사용하므로 항상 모두 게시되지 않는다.

입장하면 세계 지도 대신 해당 현장의 방 지도가 표시된다. 방문한 방과 연결만 그리며 미방문 통로·미발견 함정은 정체를 숨긴다. 인접 통로 버튼 또는 이미 드러난 지도 방을 클릭·키보드로 선택해 이동한다. 출구는 시작 방에만 있다. 청수정 심층굴은 윗동굴 수호자 격파 또는 해당 탐사도를 필요로 한다. 발견 전에는 상세 입구를 나열하지 않는다.

탐사 행동은 즉시 처리하며 세계 시계가 계속 흐른다. 주변 조사는 방마다 세계 공통 날짜 기준 하루 한 번 시도한다. 조사 성공 시 흔적과 함정을 찾는다. 해체는 별도 판정이며 실패하면 개인에게 피해·상태이상이 적용될 수 있다. 방의 위험을 무시한 이동·물품 조사도 함정을 작동시킬 수 있다. 기존 방호·유리 주사위·눈 변경·피로·허기 보정을 동일한 판정 엔진으로 적용한다.

도적은 조사 +2·해체 +3, 레인저는 조사 +3·해체 +1의 상황 보정을 받는다. 엘프 계열과 지정된 감각형 수인(여우·늑대·고양이·토끼·조류)은 추가 +1이다. 자동 성공은 아니며 D20 극단 결과와 개인 상태가 반영된다.

새 직업 레인저에는 추적·위험 감지·활·여행에 맞는 기술과 4개 전문 갈래가 추가됐다. 새 적은 유적 석상 수호자·수정 동굴 거미·기록고 수호자다. 기존 슬라임·해골·골렘·거미 등도 현장에 배치된다. 방의 전투는 기존 전술 전장을 사용하며 단순 버튼 성공으로 생략하지 않는다.

### 파티

최대 6명과 개인 진행을 유지한다. 입장·방 이동·공동 조사는 파티장이 제안하고 동료가 동의한 뒤 시작한다. 같은 방의 공동 조사에서 한 명이 성공하면 정보와 조사 진행을 공유한다. 함정 회피·해체·피해·상태이상·물품 청구 기록은 개인별이다. 전투 수락·거절·불참을 유지하며, 같은 방에서 자격이 확인된 불참자는 동료의 승리 후 길 통과·의뢰 진행을 인정받을 수 있지만 전리품·전투 숙련은 받지 않는다.

## 탐사도와 떠돌이 상인

현장마다 별도의 작은 탐사도가 있다. 사용하면 소모되지만 장소를 배운 기록은 저장된다. 낮의 육로 도보·마차 이동 중 떠돌이 지도상 나루를 만날 수 있다. 실제 10초마다 2%의 별도 만남 추첨을 하며 호위·배·비공정·전이문 구간에는 등장하지 않는다. 습격보다 먼저 발생한 만남에서 실제 위치에 멈추고, 파티 이동이면 동료들도 같은 지점에 멈춘다. 헤어진 뒤 목적지를 다시 선택해 이동한다.

상인은 도로와 세계 날짜별로 1~2종 탐사도를 각 1장 보유한다. 반대 방향 여행자도 같은 도로 재고를 공유한다. 대화는 실제 만남과 낮 시간에만 가능하며 지도명·가격·남은 수량은 서버의 현재 매물로 답한다. 다른 플레이어의 구매로 재고가 바뀌면 이전 AI 응답·견적을 그대로 확정하지 않는다. 일반적인 자유 대화는 기존 KokoaAI를 사용한다.

시장은 현장별 탐사도를 세계 날짜·시장·지도별 3% 확률로 한 장씩 입고할 수 있다. 화면 갱신·접속자마다 다시 추첨하지 않으며 품절·미입고 탐사도는 구매 목록에 노출하지 않는다.

## 세계 공통 재고와 영업시간

시설 재고는 `floor(worldHour/24)`가 바뀔 때 세계 공통 하루 한 번 갱신한다. 모든 플레이어가 남은 수량을 공유한다. 이전 6시간 재입고 저장 형식은 현재 날짜의 이미 판매된 재고를 유지하면서 하루 형식으로 이행한다. 구매 시 재고 개정·가격·금액을 다시 검증하고 재고와 소지품을 함께 저장한다.

여관과 길드는 하루 종일 운영한다. 그 외 시설은 06:00 이상 18:00 미만에 운영한다. 문 닫힌 시설의 일반 대화·거래·도서·수업·기도·제작·시설 계약은 서버에서도 거절한다. 문 닫기 전에 시작한 독서 등은 정상 완료할 수 있다. 여관의 식사·객실과 길드 서비스는 밤에도 사용할 수 있다.

신전에서는 밤에도 실제 부상·중독·화상·동상·쇠약 환자가 사제를 깨워 유료 치료를 받을 수 있다. 비용은 `max(5,ceil(잃은 HP/4)+5)G`, 소요 시간은 게임 0.25시간이다. HP를 회복하고 해당 상태이상을 치료한다. 건강한 사람·사망자·치료비 부족은 이용할 수 없으며, 이 경로로 기도·전직·다른 신전 서비스를 열지 않는다.

## 검증 범위

구성 요소의 저장·재시작·실패 저장·취소·하루 중복, 실제 파티 WebSocket 탐사 및 공동 전투, 함정 방호와 주사위 보정, 공동 재고 소진·다음 날짜 갱신, 야간 문과 환자 전용 치료를 회귀 검사한다. 화면은 별도 임시 인물로 한국어·영어·일본어의 지도·함정·합성·상인 재고·야간 치료를 확인했다. 화면용 임시 파일과 서버는 확인 후 제거했다. 원본 월드 저장은 변경하지 않는다. 실제 운영 서버에서 여러 기기의 장기 플레이·KokoaAI 품질 검사는 별도 범위다.
