# キャンバスとマウス入力の修正確認

2026-10-21、Windows 配布版とローカルサーバーで確認。

- `roundtrip.json`: 実際の KokoSync 接続で送信者・受信者の点列が一致。逆方向、全消去、両者の再参加後のスナップショットを確認。Unityへ渡る更新イベントは各差分につき1回。
- `render.json` / `canvas-live.png`: Unityの通常受信処理へ開始・追加・消去を渡し、同じ板・同じテクスチャのピクセルが更新されることを確認。
- `native-input.json`: 2Dの実コントロールへのポインター入力、バッチ送信、全点受信、点描画、最後の点の送信を確認。
- `pointer.json`: 実Win32ウィンドウで、ロック中のHUD表示と入力透過、クライアント領域へのカーソル制限、解除後のUI操作、最小化時の制限解除を確認。

別途、配布版を実際に操作し、右側HUDを横切っても視点操作を継続できること、Escで解除してアイテムメニューを開けること、Unityキャンバスへ描いた点が手元にも反映されることを確認。操作中のUnityへのキーボードフォーカスと、OSのカーソル制限がUnityクライアント領域と一致することも読み取り確認した。
